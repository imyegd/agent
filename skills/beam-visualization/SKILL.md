# 束流数据可视化技能

## 概述
提供束流数据的时序图绘制功能，生成专业的折线图供用户分析趋势和异常情况。使用 matplotlib 实现，支持多曲线叠加、异常区域高亮等特性。

## 适用场景
- 用户要求查看某段时间的束流变化曲线
- 需要直观展示 target 与相关特征的关系
- 诊断报告中的图表生成

## 工具列表

### plot_beam_data
**功能**: 绘制指定时间段内的束流时序图（折线图）

**参数**:
- `start_time` (必填): 开始时间，格式 "YYYY-MM-DD HH:MM:SS"
- `end_time` (必填): 结束时间，格式同上
- `features` (可选): 在 target 下方额外绘制的特征列名列表，最多 5 个，如 ['feature1', 'feature3']
- `title` (可选): 图表标题，不传则自动生成

**返回结构**:
```json
{
  "success": true,
  "plot_path": "output/beam_20260415_113823_123456.png",
  "message": "已生成时序图，包含 60 条记录",
  "stats": {
    "count": 60,
    "mean": 125.34,
    "max": 156.78,
    "min": 98.23
  }
}
```

**返回说明**:
- `plot_path`: 生成的图片文件路径（相对路径），可在本地查看或提供给前端加载
- `stats`: target 的基础统计信息

**绘图特性**:
- 主图始终显示 target（束流强度），作为核心指标
- 可选叠加若干特征曲线，每行一个副图
- 若传入 anomaly_mask，会在图上用浅红色底色高亮异常区域
- 使用莫兰迪色系，风格统一专业
- 自动处理中文字体显示

**使用示例**:
- "绘制 2025-08-30 18:00:00 到 19:00:00 的束流时序图"
- "帮我画一下 2025-08-30 20:00:00 到 21:00:00 的束流曲线，叠加 feature1 和 feature3"

## 调用时机建议
- **仅在用户明确要求查看图表/可视化时调用**
- 不要自动附加到每次数据查询后
- 如果用户只是问数据情况，优先用 query_beam_data 返回数值结果
