# 异常检测技能

## 概述
基于回归预测偏差 + 3σ工程判据，判断指定时间段内束流数据是否存在异常。使用已训练的随机森林回归模型进行预测，通过比较预测值与正常工况统计分布来识别异常。

## 适用场景
- 用户询问某段时间是否有异常
- 在深入诊断前快速判断异常状态
- 周期性巡检中的异常筛查

## 工具列表

### detect_anomaly
**功能**: 基于回归预测偏差和 3σ工程判据判断指定时间段是否存在异常

**参数**:
- `start_time` (必填): 开始时间，格式 "YYYY-MM-DD HH:MM:SS"
- `end_time` (必填): 结束时间，格式同上

**返回结构**:
```json
{
  "success": true,
  "is_anomaly": true/false,
  "anomaly_ratio": 0.15,
  "prediction_mean": 125.6,
  "normal_mean": 120.0,
  "normal_std": 2.5
}
```

**字段说明**:
- `is_anomaly`: 是否存在异常（任何样本超出μ±3σ即判定为异常）
- `anomaly_ratio`: 异常样本占比
- `prediction_mean`: 预测值的均值
- `normal_mean`: 正常工况的参考均值μ
- `normal_std`: 正常工况的标准差σ

**使用示例**:
- "2025-08-30 18:00:00 到 19:00:00 这段时间有异常吗？"
- "用 3σ判据判断 2025-08-31 00:00:00 到 01:00:00 有没有异常"

**调用时机建议**:
- 用户直接询问某段时间是否有异常时
- 在进行详细诊断前作为初步筛查
- 不要自动附加到每次数据查询后，仅在明确需要时调用

## 原理说明
1. 使用训练好的随机森林回归模型对输入特征进行预测
2. 获取正常工况下的统计参数μ（均值）和σ（标准差）
3. 计算预测值与正常均值的偏差，判断是否超过 3σ
4. 只要有任一样本点超出阈值，即判定为该时段存在异常

## 注意事项
- 该方法依赖于已训练的回归模型，假设模型能够准确预测正常工况下的 target 值
- 3σ判据适用于近似正态分布的误差，对于极端异常可能过于敏感或迟钝
- 如果检测到异常，建议后续调用异常诊断工具定位具体原因
