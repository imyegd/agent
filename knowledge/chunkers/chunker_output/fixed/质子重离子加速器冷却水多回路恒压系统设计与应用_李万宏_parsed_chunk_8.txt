1) 自动切换包含两个程序段，即 “程序段 1: RF CWS的切换条件判断程序 “和 “程序段 2: ECPD 到 RF CWS 的

切换程序” 。 程序段 1 用于判断 RF CWS 的工作状态是否满足切换条件，程序段 2 用于驱动阀门等部件完成自动切换 。

2) 在程序段1 中，第1 步判断切换模式( switch_mode) ，当自动切换模式开启，即 switch_mode 为 1 执行下一步; 第 2步判断泄漏防灾信号( disaster) ，当 disaster 为 0 时执行下一步; 第 3 步判断当前 ECPD 的工作位置( work_p) ，当work_p 为0，即处于空闲状态时，执行下一步; 第 4 步，通过两个 $\mathrm { C M P } < > 1$ 比较器，判断是否收到 OCPD1 的故障信号。 因 OCPD1 内部包含 20 个以上的故障，所以采用两个$\mathrm { C M P } { < } { > } 1$ 比较器，分别存储 16 位二进制数据，如果任意一个不为 0，则系统判定 OCPD1 故障。 此外，采用一个$\mathrm { C M P } = = \mathrm { R }$ 比较器，判断 OCPD1 压强是否为 0。 如果满足上述 3 个条件中的任意一个，则将工作模式( work_mode)置为 1，即 ECPD 向 RF CWS 切换，并执行程序段 2。  
3) 在程序段2 中，第1 步判断切换模式( switch_mode) ，当自动切换模式打开，即 switch_mode 为 1 执行下一步; 第 2步判断工作模式( work_mode) 是否为 1，如果为 1，则开始向 RF CWS 切换; 第 3 步将 OCPD 与 RF CWS 连接的阀门V3 关闭。 为了工作安全，将 V3_close 置 1 的同时，将 V3_open 信号置
