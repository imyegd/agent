的运营成本结构[1]，进行深入的成本效益分析对于优化资源配置、保障设备可持续高效运行具有重要意义。本文从医院管理者视角，对我院医用回旋加速器全生命周期运营的各项固定成本、变动成本及效益进行核算分析，旨在为设备的运行效率提升及资源合理分配提供成本效益测算依据，也为其他医疗机构提供建立医用回旋加速器中心的可行性分析。

# 1资料与方法

# 1.1研究资料

本 文 主 要 研 究 对 象 为 医 用 回 旋 加 速 器（PETTrace 880）。从医院固定资产系统查询医院回旋加速器的原值及维保费用，从设备科、财务部及基建等部门获取各项运行成本，包括设备耗材费用、人员经费、电费、综合管理费等。

# 1.2生产总成本计算

根据目标项目的流程，将项目进行作业的划分，统计资源消耗过程，将其归入各作业环节，最后将各作业的成本进行汇总 [2-3]。回旋加速器日常生产的显像剂主要为 $^ { 1 8 } \mathrm { F } \cdot$ -FDG。生产的固定成本主要为人员经费、设备折旧费、维保费用及第三方检测费用（ $^ { 1 8 } \mathrm { F } .$ -FDG 每月追溯性检验），变动成本主要为卫生材料费用，如富氧水、卡套试剂盒、自动分装仪耗材等，以及电费和管理费用。管理费用 $=$ （固定总成本 $^ +$ 卫生材料费用 $^ +$ 电费成本） $\times 5 . 2 2 \%$ 。汇总各作业环节生产成本，计算生产不同批次 $^ { 1 8 } \mathrm { F } \cdot$ -FDG时的生产总成本。

# 1.3盈亏平衡点计算

根据回旋加速器运营 3 个阶段的生产成本，建

立量本利分析模型 [4-6]，计算单批次生产 $^ { 1 8 } \mathrm { F }$ -FDG 的盈亏平衡点，比较从外购置 $^ { 1 8 } \mathrm { F } \cdot$ -FDG 和运营回旋加速器单批次生产 $^ { 1 8 } \mathrm { F }$ -FDG 的科室成本支出情况。盈亏平衡点 $=$ 单批次生产总成本/单支收费。

# 1.4不同工作量下保本价格及收益率计算

根据《医疗机构药学服务收费项目成本测算指南（试行）》（医保办发〔2022〕12号）第七条，当实际运营成本超过政府指导价时，医疗机构可基于量本利分析模型，通过盈亏平衡点反推放射性药品定价的最低阈值
