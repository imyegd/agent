部热沉积过高引发的样品损伤，还使得单次辐照可覆盖多个样品区域，显著提高了实验通量和效率。该系统特别适用于多种候选核材料的快速服役性能评价和筛选，为先进核能系统关键结构材料的优化设计提供了重要实验支持。

# 4    总　结

作为一台面向多学科研究的强流重离子加速器平台，LEAF 装置在装置构建、束流调试与实验支撑方面均已取得重要进展。试运行结果表明，平台已具备稳定加速质荷比 $2 \sim 7$ 范围内高电荷态离子束的能力，终端典型束流强度最高超过 1 emA，达到国际先进水平；面向复杂辐照需求，平台建成了多离子混合“鸡尾酒束”的协同调控系统，并实现双离子共轨加速与能量调节，为研究多因子耦合作用提供了新型实验手段。此外，结合核天体物理在伽莫夫能区的实验需求，平台建立了低能散、高流强的 $^ { 1 2 } { \mathrm { C } } ^ { 2 + }$ 束流系统，并在稳定运行条件下将能量展宽压缩至 $0 . 2 2 \%$ （FWHM）以下，为精密截面测量奠定了实验基础。

展望未来，LEAF装置仍具进一步拓展空间。一方面，随着引入第二台 DTL 腔体，装置将在维持高传输效率的同时拓展束流能量调控范围，满足更高能区实验需求；另一方面，三离子混合束的稳定加速与多物理量耦合能力的提升，将为核材料辐照研究提供更加接近实际服役环境的实验条件。依托上述发展，LEAF有望在核天体物理、核能材料、原子分子物理等交叉研究方向持续发挥平台价值，成为我国低能重离子加速技术持续演进的重要支撑节点。
