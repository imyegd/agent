# 1.5    结论

本节的束流动力学研究首次揭示了 $\sigma _ { 0 }$ 超越 $9 0 ^ { \circ }$ 对束流品质的复杂影响机制及其对聚售结构的依赖性。当空间电荷主导参数 $\eta { \leqslant } 0 . 7$ 时， $\sigma _ { 0 }$ 局部突破 $9 0 ^ { \circ }$ 会激发四阶共振并引发包络不稳定性，导致束流发射度显著恶化。值得注意的是，不同聚焦结构对此表现出明显差异：在双组合四极透镜系统中， $\sigma _ { 0 }$ 超越临界值会引发呼吸模式与四极模式的强耦合效应，阻带作用时间更长，效果更强，最终造成束流质量急剧下降；而螺线管聚焦通道由于阻带作用时间较短，即使出现局部相移超越现象，束流品质仍能保持相对稳定。当系统进入发射度主导状态 $\hphantom { - } \eta { > } 0 . 7 )$ 时，$\sigma _ { 0 }$ 变化和空间电荷效应对束流特性的影响显著减弱。进一步研究发现，基于低能质子束流与 KV分布假设，在包含射频加速腔的三维束流传输系统中，观测到的束流动力学行为与二维横向模拟结果呈现高度一致性，这为复杂加速器系统的仿真建模提供了重要验证依据。
