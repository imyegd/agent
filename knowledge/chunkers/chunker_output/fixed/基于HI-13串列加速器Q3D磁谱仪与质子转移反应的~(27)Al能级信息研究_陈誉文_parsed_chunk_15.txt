# 3 结语

本次工作系首次通过 $^ { 2 6 } \mathrm { M g ( ^ { 7 } L i , ^ { 6 } H e ) ^ { 2 7 } A l }$ 转移反应对 $^ { 2 7 } \mathrm { A l }$ 的激发态进行研究，依托 HI-3 串列加速器和高精度 Q3D 磁谱仪装置对 3 个激发态的角分布完成测量，同时也获取了 $^ { 2 6 } \mathrm { M g ( ^ { 7 } L i , ^ { 7 } L i ) ^ { 2 6 } M g }$ 弹性散射角分布的数据并拟合得到相应的Woods-Saxon 形式的光学势参数。结合 DWBA 程序FRESCO 对实验测得的角分布进行分析，通过转移角动量对 3 个激发态的自旋宇称做出约束，纠正了早期可能存在问题的实验结论，同时计算了3 个激发态相应的质子谱因子。与传统的直接测量及 $( ^ { 3 } \mathrm { H e } , \mathrm { d } )$ 、(d,n) 转移反应间接测量相比较，$( ^ { 7 } \mathrm { L i } , ^ { 6 } \mathrm { H e } )$ 体系具有其独特的优势，能与其他实验研究形成对照或是纠正，对某些尚未确定的能级信息做出约束，未来计划利用该反应对更多的重

要核素如 $^ { 1 8 } \mathrm { O }$ 、 $^ { 2 6 } \mathrm { A l }$ 、 $^ { 2 7 } \mathrm { S i }$ 的能级信息进行研究。
