经过模数转换得到输出向量，即 $I _ { 1 } \sim I _ { 3 }$ 转换为 $O _ { \mathrm { u t 1 } } \sim O _ { \mathrm { u t 3 } }$ 。在这种架构中，一次输入即可完成VMM运算，将计算复杂度从 $O ( n ^ { 2 } )$ 降至 $O ( 1 )$ ，展现出极高的计算效率。
