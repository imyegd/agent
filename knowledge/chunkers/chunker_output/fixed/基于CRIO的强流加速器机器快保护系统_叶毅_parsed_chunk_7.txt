计算电源输出电流的偏差，偏差超过容忍度时，通过继电器模块输出信号送入触发链路进行实验刹车；同时将每个励磁电源实时输出、加载偏差、执行动作通过以太网EPICS PV的形式发布。

# 2.1 程序结构

CRIO程序在CRIO系统的控制器中运行，CRIO控制器包含实时(RT)控制模块和FPGA模块。RT模块运行实时操作系统VXworks，FPGA模块可重配置I/O端口并能实现底层硬件的开发，基于硬件并行处理模式保证系统

的实时性。RT模块和FPGA模块程序采用LabVIEW进行开发[10-11]，各部分程序关系如图3所示。其中RT程序运行于下位机实时控制器中，主要负责与FPGA终端进行数据交互以及EPICS通信；FPGA程序运行于FPGA终端上，主要负责与硬件I/O交互，对监测信号进行逻辑判断，输出报警信号。

# 2.2 RT 程序

如图3所示，RT程序包括如下3个独立线程或服务。

1) FPGA标签数据交互：该线程主要完成RT控制器与FPGA之间的标签类型数据交互通信。程序运行时，标签类型的数据在各个终端上仅需保持最新数据即可。RT程序通过读写FPGA控件的方式将最新数据写入FPGA终端或从FPGA终端读取最新数据。其中包括将Marx自激检测通道使能、电源加载异常判断容忍度限值等写入FPGA 终端以及从 FPGA 终端获取 Marx 自激检测结果、电源加载异常状态等。  
2) 电源加载数据读取：该线程主要完成电源加载过程中电流数据的读取，具体操作为检查FPGA终端至RT控制器的电流数据直接内存访问(Direct Memory Access，DMA)先入先出(First In First Out，FIFO)状态，实时读取FIFO数据，可以无损地将所有电流数据读取至RT控制器，用户可对电流数据进行存储，用于后续数据分析。  
3) EPICS 通信：采用 I/O Server 中的 EPICS Server 进行 PV 发布，程序中各个节点可通过读写绑定 PV 的共享变量进而实现对PV的读写操作。
