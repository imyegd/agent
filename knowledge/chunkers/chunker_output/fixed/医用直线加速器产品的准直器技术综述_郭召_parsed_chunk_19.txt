态），叶 片 厚 $1 0 0 \ \mathrm { m m }$ ，等 中 心 宽 度 $6 . 2 5 \ \mathrm { m m }$ ，见 图15。通过开关时间来调制子野强度，一个旋转周期内有51个投影，在每个投影中又能快速地产生不均匀强度。TomoTherapy的照射野有 $1 . 0 ~ \mathrm { c m } \times 4 0 . 0 ~ \mathrm { c m }$ 、$2 . 5 ~ \mathrm { c m } \times 4 0 . 0 ~ \mathrm { c m }$ 、 $5 . 0 \ \mathrm { c m } \times 4 0 . 0 \ \mathrm { c m } \ 3$ 种规格的固定照射野和 $1 . 0 \sim 2 . 5 ~ \mathrm { c m } \times 4 0 . 0 ~ \mathrm { c m }$ 、 $1 . 0 \sim 5 . 0 \ \mathrm { c m } \times 4 0 . 0 \ \mathrm { c m } \ 2$ 种可调照射野，最大治疗野为 $4 0 ~ \mathrm { c m } \times 1 3 5 ~ \mathrm { c m } ^ { \ [ 3 5 - 3 7 ] }$ ，见表 7。
