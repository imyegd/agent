加速器质谱（AcceleratorMassSpectrometry，简称 AMS）是核物理研究的副产品，也是核物理技术对其它学科发展贡献巨大的技术之一。加速器质谱与其它质谱具有相同的目的，主要是运用电磁技术方法，通过能量和质量筛选降低同量异位素的影响，进而减小背景，提高探测精度。但加速器质谱又有别于其它同位素比值质谱，其将高能粒子加速技术引入质谱技术中，使其探测能力和应用范围得到了极大的拓展。加速器质谱通过离子源产生稀有同位素离子，经加速器的加速 $\longrightarrow$ 剥离 $\longrightarrow$ 再加速后，形成高能粒子（一般加速到 $0 . 2 \sim 4 0 ~ \mathrm { M e V }$ 或更大），进而利用高能磁铁和静电分析器进行质量和能量筛选，最终利用核物理探测技术对单个高能粒子进行计数，来实现稀有同位素的测量，其具有超高的系统背景压制能力和灵敏度。与传统质谱相比，在某

些情况下，加速器质谱的同位素比值测量的灵敏度是传统质谱的 $1 0 ^ { 8 }$ 倍以上［1］ 。一般质谱的同位素的识别能力在 $1 0 ^ { - 8 }$ 水平，二次离子质谱最高也只有${ { 1 0 } ^ { - 1 2 } }$ 水 平， 而 加 速 器 质 谱 探 测 的 灵 敏 度 可$\leqslant { 1 0 } ^ { - 1 5 [ 2 ] }$ 。加速器质谱由于引入了高能粒子加速和探测技术，探测器中的干扰背景极低，这是一般质谱不可比拟的；另外，加速器质谱使小样品超低含量的稀有同位素测量成为可能，其可以对低于$1 ~ \mathrm { m g }$ 自然样品中含量低于 ${ 1 0 } ^ {  { - } 1 5 }$ 的稀有同位素进行精确测量［3～4］ ，极大拓展了其应用领域。目前其应用领域几乎涵盖从地球和行星科学到生物医学与技术科学的各个领域［4］ 。
