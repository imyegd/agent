}$ ，第 i层的计算结果被写入 eDRAM缓冲区后，该输出作为 $i { + } 1$ 层的输入，当 $i { + } 1$ 层单次操作的输入数据准备好后便执行计算。

PipeLayer[15] 支持神经网络的训练与推理，其通过高效流水线设计实现了神经网络层内和层间流水，并支持多种输入与计算核映射方案。其阵列采用可重构设计，可配置为计算阵列或存储阵列。计算阵列可执行VMM操作，存储阵列可存储权重或中间数据。

FORMS[30] 将 CIM阵 列 划 分 成 子 阵 列 ， 利 用ADMM算法[31] 确保子阵内数据具有相同符号，从而避免使用“正负矩阵”表示有符号数，减少阵列资源使用。此外，采用输入零跳过逻辑电路来识别输入数据的最大有效位以跳过零输入，降低功耗和延迟。

除了加速卷积神经网络，近年来的研究提出多种基 于 CIM 的 Transformer 加 速 器 ， 例 如 TranCIM[32]、MuITCIM[33]。TransCIM 采用了流水线设计以及位线转置结构，使输入和权重的数据方向对齐，并允许中间数据从前一个计算核流向下一个计算核，在 INT8计算中 实 现 20.5  TOPS/W 的 能 效 。 与 TransCIM 相 比 ，MuITCIM通 过 长 重 用 消 除 调 度 器 和 运 行 时 词 元（token）剪枝器优化视频和音频的跨模态注意力计算，进一步优化了加速器的性能。

# 科学计算

采用 CIM加速科学计算面临两大主要挑战：更高的精度要求与更复杂的计算类型。CIM架构受限于器件物理特性，难以直接支持高精度运算。对此，研究者提出位切片技术扩展位宽，但需额外增加移位电路和计算周期。因此，部分工作转向混合精度计算：先利用CIM加速器执行低精度近似计算，再由高精度数字逻辑逐步逼近精确结果。已有研究提出了用于方程求解的 CIM 系统[34]，可支持 5000 个方程求解，误差控制在

${ { 1 0 } ^ { - 6 } }$ 以内。丁文隆等[35] 提出科学计算尾数压缩与对齐位优化策略，在保证高精度浮点 VMM计算的同时，能够根据具体应用的求解精度要求选择合适的浮点数尾数压缩位数，减少阵列及外围电路的能耗。其次，科学计算常涉及 VMM之外的复杂操作，例如矩阵求逆，其时间复杂度呈多项式级增长。对于矩阵求逆操作现已有研究提出基于 CIM的矩阵求逆电路[36] 来加速求解。
