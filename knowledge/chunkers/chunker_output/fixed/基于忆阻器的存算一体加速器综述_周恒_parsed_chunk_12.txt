# 安全算法

安全计算场景需要对数据进行加密和解密，这个过程涉及高维整数系数多项式的加法与乘法运算。典型的加密（解密）算法涉及数论变换（number theoretictransform,  NTT） 及 其 逆 变 换 （ inverse  number  theoretictransform, INTT），以上计算结构与离散傅里叶变换相同，但采用模算术[37]，可分解为乘法和加法。已有研究设计了一个支持此类结构的 CIM宏[38]，采用位串行风格实现多比特操作，并优化了映射调度和模算术算法，在相同位宽下，其延迟和能耗分别是 $\mathbf { \boldsymbol { x } } 8 6$ 软件解决方案的 1/10 和 1/2860。

# 现状及挑战

# 存算一体芯片

目前已有许多研究工作设计基于忆阻器的存算一体 芯 片，以 下 分 别 介绍 3种 忆 阻 器 介 质（RRAM、MRAM 和PCM）的存算一体芯片研究进展。

# 基于 RRAM 的存算一体芯片

Yao 等[39] 提出了基于 1T1R 单元 RRAM 的 CIM阵列，每个芯片包含一个裸阵列，大小为 $1 2 8 \times 1 6$ ，多个芯片连接至同一个印刷电路板（printed circuit board,PCB）以共享外围及控制电路。部署五层卷积神经网络在 MNIST数据集上的准确率为 $9 6 \%$ ，系统能效达11.014 TOPS/W。Wan 等[40] 设计了集成 48 个 $2 5 6 { \times } 2 5 6$ 阵列的存算一体芯片并配置共享神经元电路以实现灵活数据流控制，支持多种AI模型。

华中科技大学冯丹教授团队设计了基于 RRAM存算一体芯片并流片，采用 $2 2 \mathrm { n m }$ 工艺，总容量达 $3 2 \mathrm { M b }$ ，能效达 13.25 TOPS/W。该设计中增加了缓存模块，提升连续计算能力。原型系统采用 FPGA作为控制器，

支持多芯片协同计算，并探索了大模型的部署应用方法。
