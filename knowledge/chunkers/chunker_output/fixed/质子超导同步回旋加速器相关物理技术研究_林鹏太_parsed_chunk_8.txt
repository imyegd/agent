结合磁场参数，可以计算半径 $\rho$ 处横向匹配束流的相椭圆参数满足： $\beta _ { \mathrm { r } } { = } r _ { \mathrm { m a x } } / r _ { \mathrm { \ m a x } } ^ { \prime } { = } \rho / \sqrt { 1 - n }$ ， $\beta _ { \mathrm { z } } { = } z _ { \mathrm { m a x } } / z _ { \mathrm { \ m a x } } ^ { \prime } { = } \rho / \sqrt { n }$ 。其中，$\beta _ { \mathrm r }$ 为径向包络函数， $\beta _ { \mathrm { z } }$ 为轴向包络函数， $r _ { \mathrm { m a x } }$ 为束团径向最大半径， $r _ { \mathrm { m a x } } ^ { \prime }$ 为束团径向最大偏角， $z _ { \mathrm { m a x } }$ 为束团轴向最大半径， $z _ { \mathrm { { m a x } } } ^ { \prime }$ 为束团轴向最大偏角。

我们利用自己编写的程序，对粒子运动轨道进行计算。程序采用四阶龙格库塔算法，以时间为自变量，磁场采用式 (2)、(3)、(4)展开方式获得， $B _ { z } ( r , \theta )$ 关于 r、 $\theta$ 的一阶和二阶导数通过差分方式求得，角向和径向步长分别取1°和 $1 \mathrm { { c m } }$ 。
