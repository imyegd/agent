述，加速器质谱并非传统意义上的质谱，而是一个复杂系统，从离子源、低能质谱系统、加速器、高能系统到探测器的设计，其最终的目的只有一个，即抑制同位素和同量异位素的干扰，提高稀有同位素的识别和探测的能力。下面我们将不同构件在加速器质谱稀有同位素测量中的具体作用作一简要总结。

离子源的主要作用是通过与靶样物质相互作用，产生靶样物质的离子。对于加速器质谱的 C溅射离子源而言，功能是通过 Cs撞击靶样物质表面，溅射出样品物质的负离子，并产生足够多的离子数量。在降低同质异位素的影响方面，离子源的主要贡献是通过分析元素与同量异位素在形成负离子的难易程度及稳定性上的差异，并在形成负离子过程中将稀有同位素和干扰元素分离，从而降低或去除同量异位素的影响。如在 $^ { 1 4 } \mathrm { C }$ 测量中，C元素容易形成稳定的负离子，而其同量异位素 N元素的负离子不稳定［11］ 。因此，通过负离子源可以将 $^ { 1 4 } \mathrm { C }$ 与其干扰同量异位素 $\mathrm { ^ { 1 4 } N }$ 有效分离，去除 $\mathrm { ^ { 1 4 } N }$ 的影响。这一发现对于串列加速器质谱的发展及其应用拓展起到了重要的推动作用。近年来的研究发现，一些稀有同位素的分子负离子可以有效去除同位素的影响， $\mathrm { C a H } _ { 3 } ( ^ { 4 1 } \mathrm { C a } )$ ）易形成 $\mathrm { C a H } _ { 3 } ^ { - }$ ，而 $\mathrm { K H } _ { 3 }$ 则不易形成$\mathrm { K H _ { 3 } } ^ { - [ 4 1 ] }$ ，测量 $^ { 1 8 2 } \mathrm { H }$ f时，使用氟化物 $\mathrm { H f F } _ { 5 }$ ）不易产生干扰 $^ { 1 8 2 } \mathrm { W F } _ { 5 }$ ［42］ 。
