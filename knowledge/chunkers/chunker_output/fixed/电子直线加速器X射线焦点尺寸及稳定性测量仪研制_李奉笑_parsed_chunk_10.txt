{2}}\right) \\ \end{array}
$$

最终使用采集到的X射线强度离散序列 $S ( \boldsymbol { x } ^ { \prime } )$ 来拟合X射线强度实际分布 $f ( x ^ { \prime } , \cdot )$ ，利用半高宽法求出 $X$ 方向的焦点尺寸。同理，也可以求出Y方向的焦点尺寸。

# 2.1 狭缝装置

狭 缝 装 置 由 两 块 尺 寸 为 $2 0 0 \ : \mathrm { m m } { \times } 8 0 \ : \mathrm { m m } { \times }$ $4 0 \mathrm { m m }$ 的不锈钢块构成，且中间通过刻槽加工形成一条宽度为 $2 0 { \sim } 1 0 0 ~ { \mu } \mathrm { m }$ 的狭缝，如图6所示。狭缝的具体尺寸及缝宽均通过仿真模拟分析获得。该狭缝装置能够有效地将焦点处产生的X射线强度进行空间离散化，从而提高后续焦点尺寸拟合的精度。通过该装置，后端探测器可以准确探测到进入狭缝

的有效X射线强度，减少由于散射所带来的干扰。
