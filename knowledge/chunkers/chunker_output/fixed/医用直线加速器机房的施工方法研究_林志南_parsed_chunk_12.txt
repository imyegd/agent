# 3.6 对拉螺栓计算

对拉螺栓计算公式为

$$
N <   [ N ] = f A
$$

式中 $N$ 为对拉螺栓所受的拉力； $A$ 为对拉螺栓有效面积（ $\mathrm { m m } ^ { 2 }$ ）； $f$ 为对拉螺栓的抗拉强度设计值，取 $1 7 0 \mathrm { N } / \mathrm { m m } ^ { 2 }$ 。

对拉螺栓的直径取 $1 6 \mathrm { m m }$ ，有效直径为$1 4 \mathrm { m m }$ ，有效面积A为 $1 4 4 . 0 0 0 \mathrm { m m } ^ { 2 }$ ，则对拉螺栓的最大容许拉力值 $[ \ : N ] = 2 4 . 4 8 0 \mathrm { k N }$ ，对拉螺栓所受的最大拉力 $N { = } 1 0 . 5 5 0 \mathrm { k N }$ ，满足强度要求。

# 4 混凝土施工措施

直线加速器机房的墙、顶板混凝土整体施工要求较高，需一次浇筑，不得留施工缝。由于结构截面尺寸很大，一次性浇筑混凝土量较大，必须设法降低水化热，减小内外温差，以防出现温度裂缝。为满足防辐射要求，混凝土还必须具有良好的均匀性。因此，混凝土施工过程中，防止温度裂缝产生和保证密度均匀性是直线加速器机房墙、顶板混凝土施工成败的关键。

# 4.1 入模温度控制

大体积混凝土入模时，温度要求控制在$2 0 \mathrm { ^ { \circ } C } \sim 3 0 \mathrm { ^ { \circ } C }$ ，夏天可采取凉水拌制或加入冰块拌制。在浇筑过程中，入模温度测量每台班不少于2次。
