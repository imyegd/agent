（如 1MeV vs. 1.5MeV），高低能信号易重叠，导致R值计算误差增大，图像信噪比（SNR）减小，图像质量变差。

因此提高加速器射线的高低能差对于物质识别能力至关重要。

# 4 改进方案

基于自主研发的快检式集装箱货物检查系统，搭载自主研发的 6/3MeV 双能驻波电子直线加速器，从加速器设计、能谱净化两方面协同改进提升高低能差，具体实现路径如下：

1）加速器结构采用分段式加速腔设计。采用多段独立控制的加速腔（3 段结构），通过调节各段微波功率和相位，使电子束在不同腔段获得差异化的能量增益。当低能模式仅激活前段加速腔（3MeV），此时电子束加速距离短，获得能量低，打靶后产生的 X 射线满足 3MeV 能量要求；高能模式则激活全部腔段（6MeV），此时电子束加速距离长，获得能量高，打靶后产生的 X 射线满足6MeV 能量要求。从而显著拉大双能出束时能量差，分离度可达3MeV以上。  
2）能谱滤波净化。在X射线出口处添加可调滤波器，在低能模式下启用低 Z 材料滤片，吸收低能杂散光子，吸收软X射线，减少能谱拖尾。在高能模式下切换为高Z材料滤片，过滤中间能量光子，保留高能特征峰，进一步锐化能谱边缘[7]。

低能模式 (3MeV)：铍窗 $( 0 . 5 \mathsf { m m } ) +$ 铝滤片 $( 1 \mathsf { m m } ) \to$ 吸收 $< 3 0 \mathsf { k e V }$ 光子，提高能谱纯度。

高能模式（6MeV）：铜滤片（2 mm） $^ +$ 锡滤片（1mm） 抑制1–3MeV的康普顿连续谱，减小高能峰半高宽。

切换机构采用旋转式滤片塔，搭载 4–6 种滤片，电机旋转切换时间 ${ < } 1 0 0 \mathrm { m } \mathsf { s } _ { \circ }$ 。
