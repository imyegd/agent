{1} + \tau\right) ^ {2} - t _ {1} ^ {2}\right)} \end{array} \right. \tag {7}
$$

通过式（6）与式（7）可以计算斩束器采取 $\varphi _ { \mathrm { m } }$ 斩束电压工况下的束流下降沿时间，例如束流参数 $E { = } 7 5 \ \mathrm { k e V } .$ 、$L { = } 5 0 \ \mathrm { m m }$ 、 $t _ { 1 } { = } 1 2$ ns、 $t _ { 2 } { = } 2 0$ ns、 $\varphi { = } 3 \mathrm { k V }$ 、 ${ \varphi _ { \mathrm { m } } } ^ { = 4 . 5 \mathrm { k V } }$ ，利用公式可求得 $t _ { 0 } { = } 1 3 . 2 \ \mathrm { n s }$ 、 $\tau ^ { \prime } { = } 8 . 3$ ns、 $\tau _ { 1 } { = } 2 0 . 3 ~ \mathrm { n s }$ ，显然通过采取使斩束器工作电压高于 $\varphi$ 的 $\varphi _ { \mathrm { m } }$ ，会降低束流下降沿时间。

# 3    结　论

本文设计一套用于加速器中子源的斩束器，在设计过程中通过理论计算与软件模拟相结合，根据束流参数设计相应的斩束器。采用圆弧极板结构，使斩束器具有更好的电场分布，束流偏转效果更优。在模拟过程中，为了使得模拟结果更为可靠，导出 CST Studio Suite 静电学模拟电场分布文件，通过 Python 程序处理带入 TraceWin 软件中，解决 TraceWin 软件无法设置圆弧极板电场强度问题，发展了 CST Studio Suite 与 TraceWin 联合仿真模拟方法，更真实的模拟束流动力学表现，模拟结果表明相比平行极板结构的斩束器，圆弧极板斩束器具有更优的偏转束流能力。

对于方案可能存在的问题主要有：软件模拟与实际束流环境会存在差异，整段 LEBT 真空环境存在变化，具体束流传输时束流的空间电荷补偿度变化大小未知，这会导致束流所需偏转电压会略高于设计值，因此在实际生产中电压上限要有余量。这些问题在最终设备加工调试中可以调节
