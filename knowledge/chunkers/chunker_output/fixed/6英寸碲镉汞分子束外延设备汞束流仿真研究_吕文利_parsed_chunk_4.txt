硅基碲镉汞材料外延生长中的束流调控难题, 构建完整的 6 英寸分子束外延生长室仿真模型, 采用多物理场有限元仿真技术, 在固定束源偏置角与束流传输距离的条件下, 通过系统性的参数扫描, 定量分析了 $\mathrm { H g }$ 束源炉坩埚的关键几何参数对6 英寸衬底表面 $\mathrm { H g }$ 束流强度、束流分布均匀性以及材料沉积均匀性的影响规律, 最终建立了具有最佳束流特性的坩埚结构模型。

# 1 仿真与实验

束源炉坩埚的几何形状与开口方式对束流在衬底上的分布起到了决定性的作用, 大尺寸分子束外延设备的实际使用过程中对衬底表面的薄膜沉积均匀性提出了很高的要求, 因此需要对束源炉喷射束流在衬底表面的分布情况进行仿真, 以此优化束源炉结构参数, 实现在大尺寸衬底上高均匀性薄膜沉积的理论设计。在本实验中利用COMSOL软件中的分子流模块进行 6英寸衬底上 $\mathrm { H g }$ 束流分布及薄膜沉积均匀性的仿真, 其计算原理基于Knudsen M提出的束源炉小孔蒸发模型[11], 该模型中束源炉蒸发分子通量 $T _ { e } ( \mathbf { s } ^ { - 1 } )$ 可由小孔面积 $A _ { e } ( \mathbf { m } ^ { 2 } )$ 与温度 $T$ 的关系式如式(1)所示。

$$
\Gamma_ {e} = A _ {e} \left(p _ {e q} - p _ {v}\right) \sqrt {\frac {N _ {A}}{2 \pi M k _ {B} T}} \tag {1}
$$

式中, $p _ { e q }$ 为饱和蒸汽压 $\mathrm { ( P a ) }$ , $p _ { \nu }$ 为出口压强 $\mathrm { ( P a ) }$ , $M$ 为分子质量 $\mathrm { ( k g / m o l ) }$ ), $N _ { A }$ 为阿伏伽德罗常数 $( \mathrm { m o l ^ { - 1 } } )$ ,$k _ { B }$ 为玻尔兹曼常数(J/K)。而由于在大尺寸衬底情况下, 分子束流从束源炉口到达衬底表面各点处距离不同, 其任一点处K分子通量大小 $\cdot N _ { K } ( \mathbf { m } ^ { 2 * } \mathbf { s } )$
