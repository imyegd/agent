$1 0 \ \mathrm { m m }$ ，上下两层叶片交错排列，使其在等中心处的有效投影宽度达到 $5 \ \mathrm { m m }$ ，等中心处最大照射野 $2 8 ~ \mathrm { c m } \times 2 8 ~ \mathrm { c m }$ ，叶片的运行速度 $5 0 \ \mathrm { m m / s }$ ，加速度达到 $2 0 0 \ \mathrm { m m } / \mathrm { s } ^ { 2 }$ ，这种设计的主要优势是叶片的透射和漏辐射更低，叶片的调制速度更快。单聚焦双层多叶光栅从架构上对直线加速器传统准直系统进行了简化，大幅减少了零件种类及数量，使整体结构更简洁，成本更低，更易维护，有利于整机可靠性的提升，这也为多叶光栅准直器的发展及临床应用提供了新的思路。国产的直线加速器如新华XHARX6和东软NeuRT Aurora均采用了类似架构，等中心处最大照射野 $3 0 \ \mathrm { c m } \times 3 0 \ \mathrm { c m }$ 。

# 1.3.2 双聚焦双层多叶光栅

ViewRay公司的 MRIdian放射治疗系统是一款0.35T 核磁成像引导的直线加速器系统，配置了双聚焦双层多叶光栅［19-21］，单层叶片在等中心处投影宽度 $8 . 3 \mathrm { \ m m }$ ，双层多叶光栅交错叠加的分辨率为 $4 . 1 5 \ \mathrm { m m }$ ，叶片在等中心处的投影平均速度为$2 0 \ \mathrm { m m / s }$ 。图6是ViewRay的双聚焦双层多叶光栅示意图，叶片为圆弧形，叶片做圆弧运动成野，结构相对复杂，成本较高，但可以获得更低的半影，提升照射野精度，目前主要应用在ViewRay产品平台上。单聚焦和双聚焦的双层多叶光栅都采用了上下交错的布置方式，极大地减少了叶片间的漏辐射，降低了单层叶片之间的漏辐射要求。单聚焦的双层多叶光栅结构更简单，可以获得更快的速度和更优的调制能力，在直线加速器产品的应用上，相比双聚焦结构更有优势。
