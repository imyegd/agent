# Halcyon 直线加速器机房内辐射剂量场分布测量与应用

刘亚涛1，易艳玲2，赵文涛2，刘海宽2，鄂翔宇1，于静萍1，曾宏伟1

1. 上海中医药大学附属曙光医院, 上海 201203；2. 复旦大学放射医学研究所, 上海 200032

摘要：目的 测量瓦里安公司 Halcyon 医用电子直线加速器机房内辐射水平分布，为该类型设备机房屏蔽设计和潜在照射分析提供依据。方法 在设备6 MV X射线（FFF）模式下，最大剂量率为 $8 0 0 \mathrm { M U / m i n }$ 时，在最大照射野 $2 8 . 0 0 \mathrm { c m } \times$ $2 8 . 0 0 \mathrm { c m }$ 时，旋转出束 ${ 5 4 0 } \mathrm { M U }$ 。采用热释光剂量计 (TLD) 布点测量机房内辐射场分布，将测量得出的辐射场数据应用于屏蔽防护计算，并将计算结果与采用经验公式计算得出的结果进行比较。 结果 机房辐射水平总体在 $1 2 . 2 \mu \mathrm { G y } /$ $5 4 0 ~ \mathrm { M U } { \sim } 5 . 5 2 0 ~ \mathrm { G y } / 5 4 0 ~ \mathrm { M U }$ 范围内，其中剂量最高在剂量中心处为 $5 . 5 2 0 ~ \mathrm { G y } / 5 4 0 ~ \mathrm { M U }$ ，距离机头约 $6 . 5 \mathrm { m }$ 处剂量为$1 2 . 2 \mu \mathrm { G y } / 5 4 0 \mathrm { M U } .$ 。大部分点数据处于 $1 0 0 { \sim } 1 0 0 0 \mu \mathrm { G y } / 5 4 0 \mathrm { M U }$ 之间。Halcyon 型加速器机房内辐射场在 $0 . 5 \mathrm { m } \mathrm { ~ . ~ } 1 . 1 \mathrm { m }$ 和 $1 . 7 \mathrm { m } 3$ 个高度平面呈现出由射束中心向四周快速衰减的趋势，在平行治疗床方向（Y 方向）的衰减要快于垂直治疗床方向（X 方向）。利用实测辐射场结果进行屏蔽防护计算得出的东墙、南墙、西墙和北墙参数分别为 1219、949、12
