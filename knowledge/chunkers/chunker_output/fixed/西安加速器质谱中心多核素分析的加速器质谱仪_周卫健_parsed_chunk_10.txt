# 2.2 测试精度的步骤和计算方法

验收测量精度时，同一材料的样品分成 $n$ 份，每个样品座的样品循环转动，共测 $T$ 次，故每个样品座的样品在 $T$ 次循环中共测得 $T$ 个值(X1，X2…..$X _ { \mathrm { T } } )$ 。每个测量值 $X _ { \mathrm { i } }$ 中又包含 S 次交替测量， $X _ { \mathrm { i } }$ 是 $S$ 次交替测量的平均结果 $( i { = } 1 \dots { } . . . T )$ 。每次交替测量得到的比值(如 $^ { 1 4 } \mathrm { C } / ^ { 1 3 } \mathrm { C }$ 和 ${ } ^ { 1 4 } \mathrm { C } / { } ^ { 1 2 } \mathrm { C } )$ 存入一个数据块。故每个样品座的样品在T次循环中共有 $T { \times } S$ 次交替测量，并测得 $T { \times } S$ 个数据块。

求得每个样品座的样品在 $T$ 次循环中测得的 $T$ 个 $X _ { \mathrm { i } }$ 值的算术平均值

$$
\bar {X} = \frac {1}{T} \sum_ {1} ^ {T} X _ {i}
$$

和该算术平均值的标准偏差

$$
\delta = \sqrt {\frac {\sum_ {1} ^ {T} (X _ {i} - \overline {{X}}) ^ {2}}{T (T - 1)}}
$$
