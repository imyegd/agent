和寄存器分配等优化手段，提升大规模任务的执行效率。  
4）MNSIM[25]：面向忆阻器的存算一体系统仿真工具，提供面积、功耗和延迟的评估模型，并建立行为级模型来评估非理想因素对计算精度的影响；随后还开发了 MNSIM 2.0[28] 与 MNSIM-Time[29]，支持软硬件协同仿真。  
5）PIMCOMP+PIMSIM-NN[26]：PIMCOMP 是一个

针对 CIM加速器的端到端神经网络编译器，实现了NN模型在 CIM硬件上的高效部署。在资源利用方面，PIMCOMP优化了卷积层的展开以及划分，在系统层面平衡计算、存储访问和通信特性。在数据流调度方面，PIMCOMP设计了 2种神经网络层间流水线调度算法，提高并行度。PIMSIM-NN 将 PIMCOMP 编译得到的指令在给定的CIM架构下评估性能。  
6）FADESIM[27]：支持非理想因素的快速、准确仿真。使用了 IR Drop快速迭代仿真算法，将 SPICE 模型仿真时间复杂度由 $O ( n ^ { 6 } )$ 降至 $O ( n ^ { 3 } )$ ，在 IR Drop 影响较轻的情况下，提出优化迭代算法，将时间复杂度进一步降低至接近 $O ( n ^ { 2 } )$ 。支持多种非理想因素（如变异性、噪声、IR Drop、 $I { - } V$ 非线性、ADC量化误差）联合仿真。

# 应用

VMM是神经网络的核心计算操作，许多工作设计基于 CIM的加速器来降低神经网络计算的功耗和时延。除了神经网络，其他数据密集型应用中涉及的VMM或逻辑计算操作也可利用 CIM 加速，如科学计算和安全算法。本节介绍基于 CIM 的神经网络、科学计算以及安全算法的加速器的最新进展。
