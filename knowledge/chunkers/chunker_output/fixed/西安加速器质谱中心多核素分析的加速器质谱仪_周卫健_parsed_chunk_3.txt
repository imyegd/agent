# 1.1 铯溅射负离子源

该离子源为 HVEE 的 ModelSO-110 产品(图2)，系固体气体二用铯溅射负离子源[6]，现先采用固体样品模式，其样品轮可放置 50 个 $\Phi 1 { - } 2 \ \mathrm { m m }$ 样品。

离子源的外壳和样品轮均处于地电位，处于悬浮高电压的部件(如电离器、Cs 罐及 Cs 管、 $\mathrm { C O } _ { 2 }$ 输送管和冷却水管以及高压引线) 为离子源头部，经绝缘法兰伸入离子源内部。此结构的优点是能方便地从壳体旁边拉出该头部，以进行清洗或维修，重新安装时毋须准直[7]。

# 1.2 低能注入系统

样品表面形成的负离子由电离器中心通道吸出，经 Einzer 透镜聚焦，进入 $5 4 ^ { \circ }$ 的球面形静电分析器，进行能量选择，该分析器绕轴旋转后可连接另一台离子源。
