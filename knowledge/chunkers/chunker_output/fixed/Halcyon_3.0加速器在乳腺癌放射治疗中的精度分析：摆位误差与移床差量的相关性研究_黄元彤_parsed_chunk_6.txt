{2}$ 患者均有手术后放疗的指征； $\textcircled{3}$ 患者自愿接受放射治疗，且在整个治疗过程中未曾暂停或终止治疗。

排除标准： $\textcircled{1}$ 行动不便及治疗过程中依从性较差者；$\textcircled{2}$ CBCT图像质量不佳，无法进行准确的影像匹配者； $\textcircled{3}$ 合并其他部位恶性肿瘤者； $\textcircled{4}$ 临床资料或影像数据不完整者。

# 1.2方法

# 1.2.1仪器与材料

本研究所用设备包括：飞利浦医疗公司的Brilliance CTBig Bore模拟定位机；瓦里安医疗系统公司的Halcyon 3.0型直线加速器；Klarity公司的R612多功能人体固定架。

# 1.2.2放疗模拟定位与CT扫描

患者体位：仰卧，双臂上举外展置于托架，头部垫碳纤维头枕，双脚用脚垫固定，确保身体中轴线（鼻尖/颈部标记、剑突、肚脐、脚垫中心）与矢状面激光线重合。标记：在体表激光十字交汇处标记铅点，确保3个铅点在同一横断层面。

保乳术（A组）CT扫描：范围上界为环状软骨上 $1 { \sim } 2 \mathrm { c m }$ 下界至患侧乳腺下皱襞下 $1 { \sim } 2 \mathrm { c m }$ 。改良根治术（B组）CT扫描：范围上界为下颌骨下缘（包含锁骨上淋巴区），下界至健侧乳腺下皱襞下 $1 { \sim } 2 \mathrm { c m }$ 。CT扫描层厚为 $5 \mathrm { m m }$ 。

# 1.2.3摆位误差数据获取

患者每次治疗前，根据体表标记进行摆位后行CBCT扫描。将CBCT图像与定位CT图像进行自动配准后手动微调，全程由2位固定治疗师执行操作，最后由1位医师审核配准结果。记录腹背（VRT）、头脚（LNG）、左右（LAT）3个方向的摆位误差（单位：mm）。

# 1.2.4移床差量数据获取

在TPS中，基于定位CT图像确定治疗等中心点。测量定位参考点（体表标记中心）与治疗等中心点在VRT、LNG、LAT 3个维度上的距离，即为移床差量ΔVRT、ΔLNG、ΔLAT（单位：cm），此距离也是指导治疗床移动的指令值。
