$$
\boldsymbol {E} (t) = E _ {0} \cos \left(\omega_ {\mathrm {r f}} (t) t + \phi_ {\mathrm {s}}\right) \boldsymbol {e} _ {\theta}, \tag {8}
$$

其中： $E _ { 0 }$ 为加速间隙的电场强度峰值，其数值上等于加速电压峰值与加速间隙宽度的比值； $\omega _ { \mathrm { r f } }$ 为加速电场的角频率； $\varphi _ { \mathrm { s } }$ 为粒子加速电场初始相位，即参考质子平衡相位； $e _ { \theta }$ 为 $\theta$ 方向单位向量。由于整个加速过程中相位滑移系数 $\eta { = } \alpha _ { \mathrm { c } } { - } 1 / \gamma ^ { 2 } ( \alpha _ { \mathrm { c } }$ 为动量紧缩因子，γ为相对论因子)恒大于0，则平衡相位 $\varphi _ { \mathrm { s } }$ 必须大于0。

假定参考质子同步相位为 $3 0 ^ { \circ }$ ，加速电压为 $2 0 \mathrm { k V }$ ，使参考质子经过加速间隙获得恒定的能量增益。以时间t作为独立变量，计算的时间步长在 $1 0 ^ { - 1 3 } { \sim } 1 0 ^ { - 1 0 }$ s之间，步长为非恒定值。通过计算参考质子每次到达加速间隙中心的时间，且参考质子到达加速间隙中心时高频加速电场的相依次为 $\pi / 6$ 、 $\pi / 6 { + \pi }$ 、 $\pi / 6 + 2 \pi . \ldots$ ，如此便可获得电场相位随时间的变化关系。实际计算时先获取质子经过加速间隙中心的前一个时间点和后一个时间点，然后通过线性插值计算参考质子刚好到达加速间隙中心的时间。通过式 (7)可知，电场相位随时间变化的一阶导数就是电场频率随时间的变化关系。图5给出参考质子从半径 $5 \mathrm { { c m } }$ 加速到 $4 9 . 5 \ \mathrm { c m }$ 的过程中，参考质子回旋频率和经过加速间隙时的电场相位随时间的变化，半径
