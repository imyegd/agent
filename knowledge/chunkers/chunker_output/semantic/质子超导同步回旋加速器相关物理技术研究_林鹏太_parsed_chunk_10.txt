周期系统的周期传输矩阵为

$$
\left[ \begin{array}{l l} \cos \mu & \beta \sin \mu \\ - \gamma \sin \mu & \cos \mu \end{array} \right] = \left[ \begin{array}{c c} \cos (2 \pi \sqrt {K}) & \frac {\rho \sin (2 \pi \sqrt {K})}{\sqrt {K}} \\ \frac {- \sqrt {K} \sin (2 \pi \sqrt {K})}{\rho} & \cos (2 \pi \sqrt {K}) \end{array} \right] 。 \tag {7}
$$

为进行多粒子模拟分析，横向匹配束流需通过周期传输矩阵 (7)计算，当矩阵 (7)表示径向传输矩阵时$K { = } 1 { - } n$ ，表示垂直方向传输矩阵时 $K { = } n$ 。矩阵(7)中，等号左侧为Twiss参数，等号右侧为粒子在二极磁铁中运动的传输矩阵。其中， $\beta$ 为包络函数， $\mu$ 为相移，γ为偏角包络函数。不难发现 $\beta = \rho / \sqrt { K } = 1 / \gamma$ 。结合磁场参数，可以计算半径 $\rho$ 处横向匹配束流的相椭圆参数满足： $\beta _ { \mathrm { r } } { = } r _ { \mathrm { m a x } } / r _ { \mathrm { \ m a x } } ^ { \prime } { = } \rho / \sqrt { 1 - n }$ ， $\beta _ { \mathrm { z } } { = } z _ { \mathrm { m a x } } / z _ { \mathrm { \ m a x } } ^ { \prime } { = } \rho / \sqrt { n }$ 。其中，$\beta _ { \mathrm r }$ 为径向包络函数， $\beta _ { \mathrm { z } }$ 为轴向包络函数， $r _ { \mathrm { m a x } }$ 为束团径向最大半径， $r _ { \mathrm { m a x } } ^ { \prime }$ 为束团径向最大偏角， $z _ { \mathrm { m a x } }$ 为束团轴向最大半径， $z _ { \mathrm { { m a x } } } ^ { \prime }$ 为束团轴向最大偏角。

我们利用自己编写的程序，对粒子运动轨道进行计算。程序采用四阶龙格库塔算法，以时间为自变量，磁场采用式 (2)、(3)、(4)展开方式获得， $B _ { z } ( r , \theta )$ 关于 r、 $\theta$ 的一阶和二阶导数通过差分方式求得，角向和径向步长分别取1°和 $1 \mathrm { { c m } }$ 。
