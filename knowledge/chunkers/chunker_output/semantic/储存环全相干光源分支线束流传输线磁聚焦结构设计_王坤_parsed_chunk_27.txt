轨道校正方案采用相同的校正铁位置和BPM位置及磁铁元件误差强度。在设置200个随机误差种子的各项误差后，进行粒子追踪模拟。从结果中可以看出，水平方向轨道畸变RMS为 $1 5 0 { \sim } 2 7 0 0 ~ { \mu \mathrm { m } }$ （均值 $1 0 4 4 . 0 \mu \mathrm { m }$ ，方差 $5 2 9 . 2 \mu \mathrm { m } )$ ），垂直方向轨道畸变 RMS 为 $4 0 0 { \sim } 6 4 0 0 \mu \mathrm { m }$ （均值 $2 ~ 1 0 5 . 2 ~ { \mu \mathrm { m } }$ ，方差$1 0 6 0 . 3 ~ \mu \mathrm { m } )$ ）。由此可见，在当前误差强度设置下，水平方向和垂直方向轨道均有较大扰动。
