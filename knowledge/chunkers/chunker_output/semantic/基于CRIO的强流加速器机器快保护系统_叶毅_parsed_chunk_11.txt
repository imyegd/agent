# 2.2 RT 程序

如图3所示，RT程序包括如下3个独立线程或服务。

1) FPGA标签数据交互：该线程主要完成RT控制器与FPGA之间的标签类型数据交互通信。程序运行时，标签类型的数据在各个终端上仅需保持最新数据即可。RT程序通过读写FPGA控件的方式将最新数据写入FPGA终端或从FPGA终端读取最新数据。其中包括将Marx自激检测通道使能、电源加载异常判断容忍度限值等写入FPGA 终端以及从 FPGA 终端获取 Marx 自激检测结果、电源加载异常状态等。  
2) 电源加载数据读取：该线程主要完成电源加载过程中电流数据的读取，具体操作为检查FPGA终端至RT控制器的电流数据直接内存访问(Direct Memory Access，DMA)先入先出(First In First Out，FIFO)状态，实时读取FIFO数据，可以无损地将所有电流数据读取至RT控制器，用户可对电流数据进行存储，用于后续数据分析。  
3) EPICS 通信：采用 I/O Server 中的 EPICS Server 进行 PV 发布，程序中各个节点可通过读写绑定 PV 的共享变量进而实现对PV的读写操作。

# 2.3 FPGA 程序

如图3所示，FPGA程序包括如下2个独立运行线程。

1) Marx自激硬件I/O交互：该线程主要完成自激信号转换后的数字信号读取，并对读取的信号进行逻辑运算，检测是否有通道发生自激放电。一旦自激放电发生，程序自动锁存自激放电发生信号，并将信号输出至固态继电器。用户可重置该检测线程及相关信号的输出及显示。  
2) 电源加载异常硬件I/O交互：该线程主要完成电压信号的采集，并将其换算为电源电流信号，根据用户设置的容忍度限值判断此时电流信号是否处于设定范围内，并将判断结果信号实时输出至固态继电器。程序在进行信号采集的同时将转换完成的电流数据写入电流数据DMA FIFO，该FIFO将数据传输至RT控制器，RT程序对FIFO中数据进行实时读取。

# 3 CRIO 实现 EPICS 架构的 IOC 功能

强流加速器控制系统采用EPICS架构，快保护系统作为控制系统的一部分需要和加速器主控OPI进行通信，同时接收OPI的远程控制，如图3所示。CRIO系统完成本地数据采集和数据处理的任务外，必须作为EPICS架构中的IOC部件将系统需要的数据信息以标准的EPICS PV的形式发布共享，才能被以太网中OPI客户端订阅，实现EPICS架构中CVS的功能；同时也必须充当EPICS CVC客户端，接收并解析以太网中标准的EPICS PV发布共享的数据信息，执行相应的操作。

CRIO系统为实现EPICS架构中IOC的功能，利用LabVIEW的共享变量技术，在共享变量上封装EPICS通道

访问机制来实现。NI 公司的 DSC 组件中封装了“EPICS Server I/O Server”的接口程序，该接口程序可运行在CRIO 系统的 RT 程序，实现对 EPICS PV 的定义、发布和订阅，使 CRIO 对外充当 EPICS 的 IOC 组件[12-14] 。
