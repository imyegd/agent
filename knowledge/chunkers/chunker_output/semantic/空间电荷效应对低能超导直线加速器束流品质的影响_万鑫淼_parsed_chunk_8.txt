强流超导质子直线加速器在核废物嬗变[1]、大功率散裂中子源[2]、中微子工厂等[3]。为提升其流强与功率性能，世界各国相继开展了相关研究项目。经验表明，束流损失需控制在低于 $1 \ \mathrm { W / m }$ ，以保障设备与人员安全[4]。经过长期研究，人们对强流直线加速器中束流运动的理解不断加深，提出了包括包络不稳定性、粒子-束核共振等影响强流直线加速器中束流运动稳定性的理论，总结、形成了一套强流直线加速器设计所应遵循的设计原则，即：零流强周期相移 $( \sigma _ { 0 } )$ 小于 $9 0 ^ { \circ [ 5 ] }$ ；大束流孔径[6]；调谐因子（ $\quad \eta , \eta = ^ { \mathrm { { . } } }$ 带电流周期相移 $\sigma /$ 零流强周期相移 $\sigma _ { 0 }$ ）大于 $0 . 5 ^ { [ 7 ] }$ ； 其中，第一条是为了避免包络不稳定性；第二条则来自对束晕粒子的研究；第三条是为了避免空间电荷效应过强而导致束流损失。在超导直线加速器设计中，为满足 $\sigma _ { 0 }$ 不超过 $9 0 ^ { \circ }$ 的限制，常采用降低腔体工作电压的方式，导致第一加速段前部周期相移接近 $9 0 ^ { \circ }$ ，牺牲了加速效率。尤其在低能注入器中，粒子能量低、束流相宽大，需更大纵向接收度，此现象更为突出。然而，包络不稳定性理论基于严格周期聚焦通道建立，未充分考虑加速引起的聚焦参数变化影响[8]。尽管该理论已在重离子直线加速器实验中得到验证，但该类装置周期长度随能量递增，相移基本恒定，近似为周期传输系统[9]。对于超导加速器这类准周期系统，共振条件未必持续成立。因此， $\sigma _ { 0 }$ 局部超过 $9 0 ^ { \circ }$ 对束流的影响，以及平台相移设计是否必然带来更稳定的束流动力学，仍需深入探讨。

另一个问题是低能端特有的双周期结构对束晕形成、演化的影响。对于大功率强流直线加速器，一个核心课题就是粒子损失的控制，而束晕是造成粒子损失的主要原因之一[10]。根据现有理论，束晕的一个主要产生机制是粒子与失配束流包络之间的共振，该共振由空间电荷力驱动，并与束流的失配状态直接相关[11]。几乎所有的强流高功率超导直线加速器的低能端都采用了双周期结构设计方案[12]，即恒温器内以聚焦单元为周期的聚焦结构及以低温恒温器为单元的恒温器周期结构，这也是低能超导加速器聚焦结构所具有的共同特点，是尽可能短的周期聚焦单元长度的要求与相对较长的恒温器间低温-常温过渡空间需求这一矛盾造成的。该结构在增加聚焦不连续点的同时，可能引入低频调制，从而在特定条件下激发束晕。现有束晕研究多集中于均匀或周期传输通道，对双周期结构下束晕机理的认识尚不充分，亟待系统探究[13-14]。

本文围绕低能超导直线加速器中空间电荷效应的核心影响，从两方面展开研究：第一节分析加速过程中 $\sigma _ { 0 }$ 局部超过 $9 0 ^ { \circ }$ 对包络稳定性的影响，通过理论建模与多粒子模拟，比较螺线管与双组合四极透镜两种聚焦结构下的束流行为；第二节聚焦于双周期结构对束晕形成的影响机制，重点讨论横向与纵向包络耦合及小周期结构数 $N$ 对共振特性的作用。最后总结研究成果，并展望未来研究方向。
