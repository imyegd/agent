宇宙成因核素年代学方法概括起来可以分为 3类：1）放射性定年；2）暴露年代学方法（暴露年代学）；3）埋藏年代学方法（埋藏年代学）。宇宙成因核素放射性定年方法，目前主要是 $^ { 1 4 } \mathrm { C }$ 定年，也是现有加速器质谱测定的主要核素。尽管全球有 160多台加速器质谱，但在这些质谱的应用中， $^ { 1 4 } \mathrm { C }$ 测量的工作量占 $9 0 \%$ 以上；其次是暴露年代学和埋藏年代学宇宙成因核素的测量（10Be、26Al等）。

# 4.1 ${ } ^ { 1 4 } \mathbf { C }$ 定年

$^ { 1 4 } \mathrm { C }$ 年代学，又称放射性碳（Radiocarbon）年代

学，是目前应用最广泛的年代学方法［45］ 。经过准确校准的 $^ { 1 4 } \mathrm { C }$ 年龄是末次冰期考古、地质以及历史时期形成有机化合物准确时间框架的“黄金标准”（GoldStandard）［46］ 。
