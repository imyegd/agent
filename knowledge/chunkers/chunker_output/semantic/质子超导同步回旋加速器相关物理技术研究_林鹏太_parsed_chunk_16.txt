# 3 再生引出系统设计

超导同步回旋加速器加速电场幅值为 $2 0 \mathrm { k V }$ ，依据本文的设计参数可得质子束运动圈间距在引出半径处仅为 $4 0 \mu \mathrm { m }$ 左右，使用偏转电极作为引出器，大量质子束将会撞击偏转电极造成束流的损失。超导同步回旋加速器一般使用再生器引出束流，引出原理示意图如图8所示。其原理是在磁极边缘垫补局部铁块(图中红色扇形框所示)，产生沿半径非线性增加的磁场，利用 $\nu _ { \mathrm { r } } { = } 1$ 共振使质子经过再生器后轨道中心向一个方向移动，从而导致在一定方位角径向圈间距增加，而垂直方向仍然维持稳定运动。一般认为参考质子径向圈间距大于 $1 . 5 \mathrm { { c m } }$ 、

垂直方向维持稳定运动，质子加速至 $2 3 0 \ \mathrm { M e V }$ 时具有足够的径向和垂直方向稳定区域，是判断再生器设计是否合理的判据。

图 8    (在线彩图)再生引出原理示意图

不加再生器时质子在加速过程中会遭遇 $\nu _ { \mathrm { r } } { = } 2 \nu _ { \mathrm { z } }$ 共振，受到 $\nu _ { \mathrm { r } } { = } 2 \nu _ { \mathrm { z } }$ 共振的影响质子径向运动和垂直方向运动将发生能量交换，很可能发生径向振荡振幅减小而垂直方向的振荡振幅增加，从而造成质子束的损失，因此，再生器的放置思路应是在质子进入此共振之前将质子束引出加速器外。再生器的设计是再生器结构调整与动力学计算之间反复迭代计算的过程。再生器垫补过程中随着再生器垫补厚度的增加，再生器产生的磁感应强度增加，束流的圈间距也随之增加；当再生器的垫补厚度超过一定范围以后，束流的圈间距虽然继续增加，但其垂直方向运动振幅也会迅速增加直至撞击磁极而损失。再生器的设计应当满足质子引出要求的同时，尽可能增加再生器的间隙使尽可能多质子通过。经过不断迭代计算，确定了再生器最终结构，图9为再生器结构中心沿径向的1/4截面图和再生器半径 $4 8 . 5 \ \mathrm { c m }$ 处沿角向截面图，再生器结构主要参数见表3。
