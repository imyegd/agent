计算中关于粒子通过剥离膜后能量损失的考虑如下。粒子通过剥离膜的能量损失主要来源于被剥离电子的能量损失，每个被剥离电子导致粒子能量降低约 $0 . 0 5 \%$ ，对应约 $5 0 \mathrm { k e V }$ 。粒子与剥离膜碰撞引起的电离和激发导致的能量变化可忽略不计。根据文献 [14]， $1 0 0 \ \mathrm { M e V }$ 质子在碳剥离膜中的能量损失率为 $6 . 5 \mathrm { \ : M e V \cdot c m ^ { 2 } \ : g ^ { - 1 } }$ ， $2 0 ~ { \mu \mathrm { g } } { \cdot } { \mathrm { c m } } ^ { - 2 }$ 的剥离膜对应的能量损失约为 $1 3 0 \ \mathrm { e V }$ ，因此在计算中未计入该效应。

粒子穿过剥离靶时由于库仑散射产生的散角分布 $\theta _ { 0 }$ 可通过经验公式估算[15]：

$$
\theta_ {0} = \frac {1 4 . 1}{\beta c p} z \sqrt {\frac {T}{X _ {0}}} \left(1 + \frac {1}{9} \lg \frac {T}{X _ {0}}\right) \tag {9}
$$

其中： $\beta$ 为相对论速度参数； $c$ 为光速； $p$ 为动量；$z$ 为入射粒子电荷态； $T$ 为质量厚度； $X _ { 0 }$ 为辐射长度，碳的取 $4 2 . 7 \mathrm { g } \cdot \mathrm { c m } ^ { - 2 }$ 。

式（9）在 $1 0 ^ { - 3 } < T / X _ { 0 } < 1 0 ^ { 3 }$ 内精确度较高。本方案采用的剥离膜厚度小于公式的适用范围，计算结果存在一定误差。考虑到当 $T / X _ { 0 } { = } 1 0 ^ { 3 }$ ，即剥离膜质量厚度为 $4 2 . 7 \mathrm { m g } { \cdot } \mathrm { c m } ^ { - 2 }$ 时，散射角为 1.56 mrad，和束散角的量级相当。本方案采用的剥离膜质量厚度小于该厚度 3 个量级，因此研究中忽略库仑

散射对束散角的影响。
