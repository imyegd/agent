# 3    发展与应用

在完成初步建设与运行验证基础上，LEAF装置正面向更高性能与更广泛应用开展系统性拓展与能力提升规

划。未来发展将主要聚焦于能量调控范围的拓展以及多离子协同辐照能力的增强，以更好地服务于核天体物理、核能材料、原子分子物理等多学科交叉研究需求。

首先，针对部分终端实验对更高入射能量的需求，平台将进一步扩展束流能量覆盖范围。在现有 $\mathrm { R F Q } + \mathrm { I H } { \cdot } \mathrm { D T L }$ 加速结构基础上，拟增设第二台 IH-DTL 腔，用于实现连续调能扩展至 $1 . 0 \mathrm { M e V / u }$ ，如图 11所示。新系统将保留原有调能段的良好能散控制能力，支持 $0 . 3 { \sim } 1 . 0 \mathrm { M e V / u }$ 能量范围内强流高电荷态离子的传输与加速，满足如 $^ { 1 2 } \mathrm { C } + ^ { 1 2 } \mathrm { C }$ 熔合反应与核能材料辐照研究在更宽能区内的测量需求，也为后续中高能终端的建设预留了物理接口。
