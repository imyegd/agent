子离开加速器后，需要对离子束进行聚焦。因此，离子束离开加速器后，通过高能分析系统中的透镜，再次聚焦。多数加速器质谱离子加速后，离子束流的能量在 $1 0 \ \mathrm { M e V }$ 或更高。聚焦后的离子束流进入高能分析磁铁，根据其能量、质量和电荷的综合关系 $ { \mathrm { ~  ~ \omega ~ } } _ { \mathrm { m E / q } } ^ { 2 }$ ）对高能离子进行筛选和分离；分离出的稳定同位素束流在磁铁焦平面的法拉第杯收集并测量；稀有离子将再次聚焦，然后进入静电分析器进行能量筛选 $( \mathrm { E / q } )$ ），进一步降低具有相同的能量、质量和电荷 $\mathrm { m E } / \mathrm { q } ^ { 2 }$ ）离子和同质分子的干扰影响。

# 3.5 探测器

高能质谱和静电分析器经过质量和能量筛选后的离子进入探测器进行计数测量。目前，有多种探测器用于稀有同位素离子的测量，包括气体电离探测器、半导体探测器、飞行质谱探测器、充气磁场探测器和 X射线探测器。最常用的探测器类型是气体电离探测器和半导体探测器。

# 3.5.1 气体电离探测器

气体电离探测器的工作原理是基于电离辐射的技术方法。经过高能系统筛选后的离子进入气体离子探测器，使气体室内的气体发生电离，产生离子－电子对。如果对探测器气体室施加合适电场，离子和电子会分别向阴极和阳极漂移并收集。电荷信号通过配备电荷敏感前置放大器、脉冲整形放大器和模数转换器（ADC）等适当电子设备，将电荷脉冲整合并数字化处理，得到入射离子的原子序数、能量和能量衰减等信息。

气体电离探测器由一个充气的封闭容器组成。
