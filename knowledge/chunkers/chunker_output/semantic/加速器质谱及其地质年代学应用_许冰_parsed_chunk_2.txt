些情况下，加速器质谱的同位素比值测量的灵敏度是传统质谱的 $1 0 ^ { 8 }$ 倍以上［1］ 。一般质谱的同位素的识别能力在 $1 0 ^ { - 8 }$ 水平，二次离子质谱最高也只有${ { 1 0 } ^ { - 1 2 } }$ 水 平， 而 加 速 器 质 谱 探 测 的 灵 敏 度 可$\leqslant { 1 0 } ^ { - 1 5 [ 2 ] }$ 。加速器质谱由于引入了高能粒子加速和探测技术，探测器中的干扰背景极低，这是一般质谱不可比拟的；另外，加速器质谱使小样品超低含量的稀有同位素测量成为可能，其可以对低于$1 ~ \mathrm { m g }$ 自然样品中含量低于 ${ 1 0 } ^ {  { - } 1 5 }$ 的稀有同位素进行精确测量［3～4］ ，极大拓展了其应用领域。目前其应用领域几乎涵盖从地球和行星科学到生物医学与技术科学的各个领域［4］ 。

加速器质谱的发展历史可以追溯到 20世纪 40年代，其发展历史与地球科学的 $^ { 1 4 } \mathrm { C }$ 测量的需要具有密切联系，可以毫不夸张地说， $^ { 1 4 } \mathrm { C }$ 测量需求推动了加速器质谱技术发展。随着加速器质谱技术的发展和应用拓展，特别是近 20年来，加速器质谱数量快

速增加，可测量的核素种类和应用领域也得到了快速拓展。在地球科学中的应用，从当初的 $^ { 1 4 } \mathrm { C }$ 测定，拓展到了目前 60多个核素，开创了诸多新领域［4］ 。单从地质年代学方面而言，不仅使小样品超低含量样品的 $^ { 1 4 } \mathrm { C }$ 定年成为可能，而且开创了宇宙成因核素暴露和埋藏年代学的新领域［5］ 。

在近 20年来，随着小型和微型加速器质谱的问世，全球加速器质谱数量迅猛增加，目前全球加速器质谱已有 160多台。我国加速器质谱数量在近10年来快速增加，从 21世纪初的 3台，增加到了目前的 30多台，绝大多数集中在地学领域。国内许多学者，特别是从事地球科学研究的学者，对加速器质谱技术及其在地学中的应用并不完全了解，在一定程度上限制了我国加速器质谱技术的效能发挥。本文将对加速器质谱技术及其发展进行综述，对其在地质年代学方面的应用进行着重介绍，以期相关学者对加速器质谱的技术优势及其在地球科学中的应用有一个比较全面的了解。

# 1 加速器质谱发展史

加速器质谱是核物理研究中加速器发展的产物。加速器的发展历史可以追溯到 20世纪 40年代。1930 年， 英 国 物 理 学 家 卢 瑟 福 （ErnesRutherford）在研究原子核的结构时，发现原子核的尺寸极小，表明原子核存在高达百万伏特的高库仑势垒。他在研究核子内部精细结构时，首次提出需要能量足够高的粒子束流，如质子流触发核反应。通过离子源提供离子束流，从而利用加速器将离子束流加速到高能状态。许多核反应研究所需的离子电流，介于稳定同位素的质谱研究所需的电流和用于分离数毫克特定稳定同位素所需的极高离子电流之间；而加速器质谱所需要的束流与核物理研究原子核的束流非常相似，在微安培级别［6～7］ 。
