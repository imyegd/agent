# 2.3 屏蔽计算

文献［16］列举了质子打靶后次级中子角度分布，对于 $2 0 0 \mathrm { M e V }$ 质子打靶，其次级中子在前向最多，而在与束流轴垂直的径向是对称分布的，因此总体上采用圆柱形屏蔽材料，其中主体屏蔽材料前半部分开口，确保靶芯位于主体屏蔽材料的前半部分，如图4所示。根据束流管道尺寸和 $2 0 0 \mathrm { M e V }$ 质子射程，选择开口直径和靶芯直径为 $2 0 \mathrm { c m }$ ，靶芯厚度为$3 0 \mathrm { c m }$ 。

利用 FLUKA 的 USRBIN 和 AUXSCORE 计数卡对束流垃圾桶的周围剂量当量值进行了计算。通过在计算模型中调整屏蔽材料的尺寸，观察剂量分布是否满足限值要求，最终确定束流垃圾桶的尺寸。经过屏蔽计算，确定主体屏蔽铁芯的直径为 $7 0 \mathrm { c m }$ ，厚度为 $9 0 \mathrm { c m }$ ，前后两侧面和径向侧面分别覆盖$3 0 \mathrm { c m }$ 和 $2 5 \mathrm { c m }$ 厚的含硼聚乙烯，所有屏蔽体的总重量约4.5t。图5为剂量分布彩图，图中分界线对应的剂量值为 $5 . 5 \mathrm { m S v \cdot h ^ { - 1 } }$ ，可以看到剂量分布呈现出从中心到周围逐渐衰减的特点。在束流垃圾桶尾部侧面（ $Z { = } 1 1 0 \mathrm { c m }$ 处）及横向侧面（ $\scriptstyle { R = 6 0 \mathrm { c m } }$ 处），由于束流损失带来的瞬时剂量率最大值分别为$4 . 2 \mathrm { m S v { \cdot h } ^ { - 1 } }$ 和 $3 . 2 \mathrm { m S v { \cdot } h ^ { - 1 } }$ ，满足设计指标，但是在束流入射的背向，剂量将明显超过限值，由于开口结构的存在，这是无法避免的。
