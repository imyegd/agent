超导同步回旋加速器的主磁场与经典回旋加速器类似，磁场关于中心旋转对称性，同时关于中心平面 $z { = } 0$ 对称，磁极结构比等时性回旋加速器的磁极结构要简单的多。为了减小加速器尺寸，参考IBA设计的 $2 3 0 \mathrm { M e V }$ 超导同步回旋加速器所采用的最大磁场强度，该同步回旋加速器的最大磁场确定为5.71 T，位于磁铁中心。根据带电粒子在旋转对称磁场中横向运动稳定性的要求[9]，超导同步回旋加速器的磁场从中心到磁极边缘随半径应逐渐减小，其磁场降落指数 $n$ 必须满足 $0 { < } n { < } 1$ 。考虑到磁极的利用效率，在大部分区域 $n { < } { < } 1$ 。由于超导同步回旋加速器的加速电压一般较低，质子在加速器中运动的圈数较多，所以受到共振的影响较大。在主磁场设计中，应充分考虑共振对运动稳定性的影响 [12]，使质子尽可能快地通过不可避免的共振线。本文在设计主磁场时考虑了五阶以内共振对质子运动的影响。当质子接近共振线时调整磁极面使磁场迅速减小，减小质子通过共振线的圈数，以最小化共振对质子运动的影响。经过优化，主磁铁主要参数见表1，主磁铁1/4截面结构如图1所示。
