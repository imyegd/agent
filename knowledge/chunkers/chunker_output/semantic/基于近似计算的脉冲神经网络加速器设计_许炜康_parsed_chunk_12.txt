1. 设定AARE阈值AARE_threshold；  
2. 初始化最优加法器 optimalAdder = null;  
3. 初始化最小代价 $\minCost = \inf$   
4. for adder in candidates:   
5. if adder.AARE $<$ AARE_THRESHOLD:   
6. 将该 adder 添加到满足阈值的候选列表 filteredCandidates 中；  
7. max_AARE = max( adder. AARE for adder in filteredCandidates);   
8. max\_power = max(adder.power for adder in filteredCandidates);   
9. max_area = max(adder.area for adder in filteredCandidates);   
10. for adder in filteredCandidates:   
11. normalized_AARE $\equiv$ adder.AARE/max_AARE;   
12. normalized\_power = adder. power / max\_power;   
13. normalized_area = adder.area / max_area;   
14. 计算 adder 的代价 cost = AAREWeight × normalized_AARE + POWER Weight × normalized_power + AREA Weight × normalized_area;   
15. if cost $<$ minCost:   
16. 更新 $\text{minCost} = \text{cost}$   
17. 更新 optimalAdder = adder;   
18. end if   
19. end for   
20. end if   
21. end for   
22. Return optimalAdder;

本文在选择近似加法器的过程中，首先设定了明确的选择标准。其中，AARE是衡量加法器在实际应用中可能产生的精度损失的关键指标。为了筛选出满足精度要求的候选加法器，特别设定了一个AARE阈值。这一筛选条件有助于在众多加法器中初步挑选出符合精度要求的候选者，为后续的选择过程提供基础。

接下来，需要权衡功耗和面积这2个关键因素。在硬件设计中，功耗和面积是限制系统能效和成本的重要因素。因此，为了全面评估候选加法器的综合性能，引入了一个代价函数，该函数综合考虑了AARE、功耗和面积这3个指标。

在代价函数中，计算每个候选加法器的AARE、功耗和面积，并将它们分别与各自在候选列表中的最大值进行归一化，得到归一化的AARE(normalized_AARE)、归一化的功耗(normalized_power)和归一化的面积(normalized_area)。然后，根据这3个归一化后的值以及它们各自的权重（AARE Weight，POWER Weight 和AREA Weight），计算每个候选加法器的总代价。
