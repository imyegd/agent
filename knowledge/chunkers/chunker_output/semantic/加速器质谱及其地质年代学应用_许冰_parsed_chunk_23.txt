方法，如衰变技术方法与同位素富集方法结合，其$^ { 1 4 } \mathrm { C }$ 定年的年代上限可达距今 75000年［50］ 。另外，对于 $^ { 1 4 } \mathrm { C }$ 定年精度而言，除了受实验室制样过程中的污染和仪器的探测精度影响外，同时受过去大气 $\mathrm { C O } _ { 2 }$ 中 $^ { 1 4 } \mathrm { C }$ 活动重建，即 $^ { 1 4 } \mathrm { C }$ 校正曲线精度的影响。根据最新的国际 IntCal20校正曲线［48］ ，包 括 南、北 半球、海水表层的 $^ { 1 4 } \mathrm { C }$ 校正曲线已经延伸到了距今55000年前（cal．aB．P．）。不同时段的校正曲线的精度也不相同，在某些时段，特别是 $^ { 1 4 } \mathrm { C }$ 校正曲线的平台区，即 $^ { 1 4 } \mathrm { C }$ 变率较小时段，产生的年代不确定性会增加（图 5）。

$^ { 1 4 } \mathrm { C }$ 测量结果在使用校正曲线时需考虑以下两个方面的因素影响：一是在短期内， $^ { 1 4 } \mathrm { C }$ 产率主要受太阳活动和地磁场变化影响；另一个因素是人类活动的影响，其中工业革命以来人类活动成为主要影响因素。人类活动的影响，一是稀释作用，即化石燃料（不含 $^ { 1 4 } \mathrm { C }$ ）的燃烧，产生大量 $\mathrm { C O } _ { 2 }$ 排放，对大气中 $^ { 1 4 } \mathrm { C }$ 活度起到稀释作用；另一个因素是人工核素 $^ { 1 4 } \mathrm { C }$ ，由原子弹和核反应过程产生（也成“核爆14C ”）。核爆产生的 $^ { 1 4 } \mathrm { C }$ 使 1963年大气和陆生植物体中的 $^ { 1 4 } \mathrm { C }$ 活度增加了 1倍［51］ 。随《国际核试验禁令条约》的签订，核爆试验减少，加之化石燃料 $\mathrm { C O } _ { 2 }$ 排放，导致大气中 $^ { 1 4 } \mathrm { C }$ 活度缓慢降低。由于上述因素的综合影响，对于 $^ { 1 4 } \mathrm { C }$ 定年来说，如果 $^ { 1 4 } \mathrm { C }$ 年龄小于 200年，一般可认定为现代碳年龄；但在某些特定情况下，如清楚定年材料的沉积时段受人类活动的影响程度，仍可提供一定的年代学信息。
