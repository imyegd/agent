离子源的主要作用是通过与靶样物质相互作用，产生靶样物质的离子。对于加速器质谱的 C溅射离子源而言，功能是通过 Cs撞击靶样物质表面，溅射出样品物质的负离子，并产生足够多的离子数量。在降低同质异位素的影响方面，离子源的主要贡献是通过分析元素与同量异位素在形成负离子的难易程度及稳定性上的差异，并在形成负离子过程中将稀有同位素和干扰元素分离，从而降低或去除同量异位素的影响。如在 $^ { 1 4 } \mathrm { C }$ 测量中，C元素容易形成稳定的负离子，而其同量异位素 N元素的负离子不稳定［11］ 。因此，通过负离子源可以将 $^ { 1 4 } \mathrm { C }$ 与其干扰同量异位素 $\mathrm { ^ { 1 4 } N }$ 有效分离，去除 $\mathrm { ^ { 1 4 } N }$ 的影响。这一发现对于串列加速器质谱的发展及其应用拓展起到了重要的推动作用。近年来的研究发现，一些稀有同位素的分子负离子可以有效去除同位素的影响， $\mathrm { C a H } _ { 3 } ( ^ { 4 1 } \mathrm { C a } )$ ）易形成 $\mathrm { C a H } _ { 3 } ^ { - }$ ，而 $\mathrm { K H } _ { 3 }$ 则不易形成$\mathrm { K H _ { 3 } } ^ { - [ 4 1 ] }$ ，测量 $^ { 1 8 2 } \mathrm { H }$ f时，使用氟化物 $\mathrm { H f F } _ { 5 }$ ）不易产生干扰 $^ { 1 8 2 } \mathrm { W F } _ { 5 }$ ［42］ 。

离子源中产生的负离子，经过预加速进入低能注入系统，在低能注入系统对负离子进行离子筛选和聚焦，筛选出所需测量离子进入加速器。

在加速器中，负离子通过加速聚焦并穿过剥离气体管道，在此过程中负离子外层电子被剥离，经库伦爆炸效应彻底移除分子本底干扰；而剥离电子数量的增加需要高端电压的加速器，如在 $^ { 1 4 } \mathrm { C }$ 测 量中，要得到最大 $\mathrm { C } ^ { 3 + }$ 产率，以氩气为剥离气体其产率约 $33 \%$ ，大约需要 $2 . 5 \ \mathrm { M e V }$ 的端电压，而对于$\mathrm { C } ^ { 4 + }$ 离子，需要更高的能量（约 $6 . 5 \mathrm { M e V }$ ），其产率也会增加到 $6 5 \%$ 左右［43］ 。

在高能端，离子经聚焦后，经高能磁铁进行质量筛选和分离，其中稳定同位素或高丰度核素经法拉第杯收集后直接测量，筛选出的稀有同位素离子及具相同质荷比的离子或部分散射的离子进入静电分析器。静电分析器的主要功能是对离子能量进一步筛选，去除相同动能干扰核素的影响，最后进入探测系统。

在探测系统中，通过入射离子的总能量（固态探测器）或离子在气态介质中能量丢失特征差异区分离子种类。在探测器中充分利用不同原子序数的粒子具有不同能量丢失的性质，即 dE／dx-x，来识别同量异位素和稀有同位素。对于一些核素，为进一步降低同量异位素的影响（BvsBe，ClvsS），会在离子进入探测器前再次进行能量筛选。目前常采样的方法是增加衰减箔技术，其利用不同原子序数的离子经衰减膜后丢失能力不同，对离子进一步筛选，然后进入最终的粒子探测器。
