# 4 混凝土施工措施

直线加速器机房的墙、顶板混凝土整体施工要求较高，需一次浇筑，不得留施工缝。由于结构截面尺寸很大，一次性浇筑混凝土量较大，必须设法降低水化热，减小内外温差，以防出现温度裂缝。为满足防辐射要求，混凝土还必须具有良好的均匀性。因此，混凝土施工过程中，防止温度裂缝产生和保证密度均匀性是直线加速器机房墙、顶板混凝土施工成败的关键。

# 4.1 入模温度控制

大体积混凝土入模时，温度要求控制在$2 0 \mathrm { ^ { \circ } C } \sim 3 0 \mathrm { ^ { \circ } C }$ ，夏天可采取凉水拌制或加入冰块拌制。在浇筑过程中，入模温度测量每台班不少于2次。

# 4.2 温度监测

（1）大体积混凝土测温在界面上监测不少于3个点，体现出混凝土表层与中间的温度，表层测点距表面宜为 $5 0 \mathrm { m m }$ ，中间测点距离不超过$6 0 0 \mathrm { m m }$ 。当测量面积较大时，可按照对称轴线分为2个测区，通过对1个测区监测同时反映整个浇筑面的温度情况。该工程板内监测点布置如图23所示。

（2）测温时间应从测点混凝土浇筑完12h（终凝）后开始，且在24h内，每2h测温1次，24h后，每4h测温1次，72h后至14d，每6h测温1次（力求在接近混凝土出现最高和最低温度时测量），直至测至温度稳定为止。  
（3）出现如下情况时，需要进行监测预警：混凝土的内部温度与表面温度之差不超过 $2 5 \mathrm { { ^ \circ C } }$ ，表面温度与环境温度之差不超过 $2 0 \mathrm { { ^ \circ C } }$ ；混凝土浇筑体在入模温度基础上的温升值不宜大于 $5 0 \%$ ；混凝土浇筑体的降温速度不宜大于 $2 . 0 \% r \mathrm { d }$ ；混凝土浇筑体表面与大气温差不宜大于 $2 0 \mathrm { { ^ { \circ } C } }$ 。

# 4.3 降温措施

（1）浇筑前，应做好配合比试验，并添加引气剂或增塑剂等，减少水泥用量。  
（2）板混凝土分层浇筑过程中，每层厚度控制在 $5 0 0 \mathrm { m m }$ 左右，并进行斜面分层浇筑，混凝土终凝前及时浇水湿润，并覆盖薄膜及厚度不小于$1 . 5 \mathrm { c m }$ 的保温棉絮。  
（3）在混凝土内埋设水管，当温度超过预警值时，在水管内通入冷水进行降温。

# 4.4 混凝土养护

（1）大体积混凝土应进行保温保湿养护，浇

筑完成后，需表面覆盖棉毡，避免温度降低过快。当表面温度与环境最大温差小于 $2 0 \mathrm { { ^ { \circ } C } }$ 时，可以清理保温材料。

（2）保湿养护的持续时间不得少于14d，应经常检查塑料薄膜或养护剂涂层的完整情况，保持混凝土表面湿润。  
（3）在混凝土浇筑完初凝前，应立即进行喷雾养护工作。  
（4）当监测结果不满足温控要求时，立即调整保温养护措施，对表面增加保温层或内部进行通水降温。  
（5）混凝土养护宜采用喷雾养护，避免冷水直接与混凝土表面接触。
