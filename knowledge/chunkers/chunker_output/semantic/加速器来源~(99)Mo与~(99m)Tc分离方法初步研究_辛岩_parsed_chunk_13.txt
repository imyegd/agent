基于上述实验结果，本研究选择 $8 ~ \mathrm { m o l / L }$ 硝酸作为洗脱液用于TEVA树脂柱的钼、铼分离：首先，该条件下 $\mathrm { R e O _ { 4 } } ^ { - }$ 的洗脱峰尖锐，与钼酸根 $\mathrm { ( M o O _ { 4 } } ^ { 2 - }$ ）的保留行为形成显著差异，可确保两组分达到基线分离；其次，高酸度环境能有效抑制 $\mathrm { M o O _ { 4 } } ^ { 2 - }$ 的聚合现象，避免多钼酸根的形成而干扰分离；最后， $8 ~ \mathrm { m o l / L }$ $\mathrm { H N O _ { 3 } }$ 的强洗脱能力可最大限度缩短分离周期，提高工艺效率。

# 2. 3 氧化铝柱对钼铼的分离效果

虽然TEVA树脂对钼铼具有较好的分离效果，但其成本较高，为最大程度发挥TEVA的高效分离能力，考虑到溶液中过高含量的钼酸盐会干扰到高铼酸根的分离，故对钼酸盐进行预分离研究。
