内容提要：目的：探讨乳腺癌患者摆位误差与Halcyon 3.0加速器移床差量之间的关系，以优化放疗精度。方法：回顾性分析 2023年10月 ${ \sim } 2 0 2 4$ 年3月复旦大学附属肿瘤医院放射治疗中心治疗的200例乳腺癌患者，通过CBCT影像验证记录腹背（VRT）、头脚（LNG）、左右（LAT）三维方向上的摆位误差，并计算其总位移（D）；记录TPS计算的腹背（ΔVRT）、头脚（ΔLNG）、左右（ΔLAT）三维方向上的移床差量，并计算其总位移（ΔD）。应用Spearman相关分析评估摆位误差与移床差量的相关性；通过绘制受试者工作特征（ROC）曲线，以摆位误差是否 ${ > } 3 \mathrm { m m }$ 区分阳性（有偏差风险）、阴性（无偏差风险），评估移床差量对摆位误差的预测效能，并计算曲线下面积（AUC）。结果：摆位误差与移床差量在各方向上均呈正相关，其中VRT与ΔVRT弱相关（ $\mathrm { R } { = } 0 . 1 7 5$ ，$P { = } 0 . 0 1 3$ ）；LNG与ΔLNG中等相关（ $\scriptstyle \mathrm { R = } 0 . 3 9 3$ ， $P { < } 0 . 0 0 1$ ）；LAT与ΔLAT中等相关（ $\scriptstyle \mathrm { R = } 0 . 3 6 1$ ， $P { < } 0 . 0 0 1$ ）；D与ΔD弱相关（ $\scriptstyle { \mathrm { R = } } 0 . 2 4 3$ ， $P { = } 0 . 0 0 1$ ）。移床差量的预测效能有限，腹背、头脚、左右方向的AUC值分别为0.536、0.625、0.606。结论：本研究发现，乳腺癌患者的摆位误差与Halcyon加速器移床差量之间存在具有统计学意义但关联强度有限（ $\mathrm { R } { < } 0 . 5$ ， $P { < } 0 . 0 5$ ）的正相关，且基于此的预测模型性能不佳（ $\mathrm { \ A U C { < } 0 . 7 }$ ）；这些结果共同提示，移床差量对摆位误差的影响有限，并非决定性因素。

关 键 词：乳腺癌 摆位误差 Halcyon3.0 放射治疗 最佳截断值
