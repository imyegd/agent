# 科学计算

采用 CIM加速科学计算面临两大主要挑战：更高的精度要求与更复杂的计算类型。CIM架构受限于器件物理特性，难以直接支持高精度运算。对此，研究者提出位切片技术扩展位宽，但需额外增加移位电路和计算周期。因此，部分工作转向混合精度计算：先利用CIM加速器执行低精度近似计算，再由高精度数字逻辑逐步逼近精确结果。已有研究提出了用于方程求解的 CIM 系统[34]，可支持 5000 个方程求解，误差控制在

${ { 1 0 } ^ { - 6 } }$ 以内。丁文隆等[35] 提出科学计算尾数压缩与对齐位优化策略，在保证高精度浮点 VMM计算的同时，能够根据具体应用的求解精度要求选择合适的浮点数尾数压缩位数，减少阵列及外围电路的能耗。其次，科学计算常涉及 VMM之外的复杂操作，例如矩阵求逆，其时间复杂度呈多项式级增长。对于矩阵求逆操作现已有研究提出基于 CIM的矩阵求逆电路[36] 来加速求解。

# 安全算法

安全计算场景需要对数据进行加密和解密，这个过程涉及高维整数系数多项式的加法与乘法运算。典型的加密（解密）算法涉及数论变换（number theoretictransform,  NTT） 及 其 逆 变 换 （ inverse  number  theoretictransform, INTT），以上计算结构与离散傅里叶变换相同，但采用模算术[37]，可分解为乘法和加法。已有研究设计了一个支持此类结构的 CIM宏[38]，采用位串行风格实现多比特操作，并优化了映射调度和模算术算法，在相同位宽下，其延迟和能耗分别是 $\mathbf { \boldsymbol { x } } 8 6$ 软件解决方案的 1/10 和 1/2860。
