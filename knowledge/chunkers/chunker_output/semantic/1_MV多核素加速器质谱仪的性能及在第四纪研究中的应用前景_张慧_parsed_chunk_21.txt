# 3.1 高精度 ${ } ^ { 1 4 } \mathbf { C }$ 定年：重建古气候／古环境的时序框架

AMS将 $^ { 1 4 } \mathrm { C }$ 测年样品量降至毫克至微克级并显著提升精度，成为构建高分辨率年代框架的核心技术，广泛应用于第四纪科学研究的定年［34～35］ 。在青

藏高原湖泊与泥炭沉积物研究中，密集 $^ { 1 4 } \mathrm { C }$ 定年成功建立了末次冰消期（约 $1 8 \mathrm { \ k a \ B . P . }$ ．）以来的连续高精度年代序列，可精准定位新仙女木事件等千年至百年尺度气候突变及其区域和全球 环 境 影 响［36～37］ ； 洞穴石笋作为古季风研究的理想载体，通过 AMS对小样本有机包裹体或碳酸盐的 $^ { 1 4 } \mathrm { C }$ 定年，结合铀系

（U-Th）年龄交叉验证，构建了可靠年代标尺，精细刻画了亚洲季风强度变迁、轨道力驱动响应及突发气 候 事 件 模 式，深 化 了 人－环 境 相 互 作 用 认知［38～39］ ；此外，针对古土壤与黄土序列中的有机质或富集孢粉浓缩物，AMS－ $^ { 1 4 } \mathrm { C }$ 定年有效规避矿物碳污染，直接测定记录古环境信息的有机组分形成时间，精确约束土壤发育速率、风尘堆积变化及古环境转折期（如干湿转换、植被演替），为生态系统重建提供可靠时序框架［40～43］ 。

# 3.2 宇宙成因核素 ${ } ^ { 1 0 } \mathbf { B } \mathbf { e }$ e和 $^ { 2 6 } \mathbf { A l }$ l）：地表过程与构造活动的定量示踪

宇宙成因核素（原位赋存于矿物晶格）的 AM分析为地表过程与地质事件年代学提供独特视角。通过测定冰川地貌（冰碛垄、冰蚀平台）表层石英中$^ { 1 0 } \mathrm { B e } / ^ { 2 6 } \mathrm { A l }$ l浓度，可计算冰川消退后的暴露年龄，在天山、喜马拉雅等地区成功重建冰期 ／间冰期旋回中冰川进退历史与范围，揭示气候－冰川响应机制［44～45］ 。河流阶地、断层陡坎及古滑坡体的暴露测年或内部沉积物埋藏测年（基于 $^ { 1 0 } \mathrm { B e } / ^ { 2 6 } \mathrm { A l }$ l浓度比），能定量反演构造抬升速率、断层复发间隔及滑坡活动周期，为青藏高原周缘等强构造区的地灾风险评估与地壳动力学研究提供关键参数［46～49］ 。

同时，基于河流沉积物原位 $^ { 1 0 } \mathrm { { B e } }$ e浓度反演流域平均侵蚀速率，在千年－百万年尺度上揭示侵蚀－气候关联性，支撑区域性水土保持策略优化［50～51］ 。
