自 20世纪 70年代末，随着串列式加速器质谱的发展与成熟，加速器质谱技术已成为测量微量和珍稀样品以及超低含量稀有同位素的主要方法，有时是唯一的测试技术。测定的核素由初始的 $^ { 1 4 } \mathrm { C }$ 和$^ { 1 0 } \mathrm { { B e } }$ e等少数几个核素，拓展到如今的 60多个，其应用领域也获得了极大拓展，具体到地球科学，应用涵盖了从板块构造活动到行星科学的各个领域，推动了相关学科的快速发展。 $^ { 1 4 } \mathrm { C }$ 定年和埋藏年龄为理解人类起源、迁徙、演化和文化技术交流等方面提供了重要年代学支撑；宇宙成因核素年代学的出现，也使定量化研究外力地质作用过程，如河流、湖泊和海洋阶地的形成，侵蚀风化速率的厘定以及地质地貌过程的演化成为可能；此外，基于加速器质谱探测技术的宇宙成因核素已成为研究太阳活动与地磁场变化的主要技术方法，如冰芯、树轮和具有较好年代控制的沉积物中的宇宙成因核素是太阳活动和古地磁变化的良好记录［66～68］ ；在行星科学中广泛用于宇宙和太阳射线强度变化、星外物质的暴露年龄厘定、超新星事件的识别等领域［69～71］ ；在环境科学领域，广泛应用于人工核素和核污染的源区识别、运移迁移和沉积机制及生态危害评价等研究［72］ 。目前，在地球科学中，常用的核素主要是$^ { 1 4 } \mathrm { C }$ ，其次是 $^ { 1 0 } \mathrm { { B e } }$ e，紧随其后的是 $^ { 2 6 } \mathrm { A l }$ l、 $^ { 3 6 } \mathrm { C l }$ l、 $^ { 4 1 } \mathrm { C a }$ 和129I［31，73～74］ 。未来，加速器质谱发展的一个永恒的 $^ { 1 2 9 } \mathrm { I } ^ { [ 3 1 , 7 3 \sim 7 4 ] }$ 主题仍然是通过硬件和软件的改进，如离子源和探测器的改进、引入诸如激光剥蚀等新技术手段，进一步降低同量异位素和分子的影响，提高稀有同位素识别的灵敏度和计数效率。在实验技术方法上，除了通过化学方法进一步纯化富集稀有同位素和降低干扰核素浓度外，还需要通过合成核素的化合物和分子状态，提高核素的离子化、剥离和传输效

率，同 时 有 效 分 离 同 位 素 和 降 低 同 量 异 位 素 的干扰。
