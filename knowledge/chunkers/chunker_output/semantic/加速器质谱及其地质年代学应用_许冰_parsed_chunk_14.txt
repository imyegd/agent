“同时式”注入系统是稳定和稀有同位素一起注入加速器，通过一系列磁分析器和四极透镜实现，这些装置使得离开离子源后的不同同位素能够沿着不同的轨迹运动；最后，它们在进入加速器之前会重新聚合在一起。为减少稳定同位素的注入，会在靠近镜面平面的位置，即各同位素路径之间的间距达到了最大值时，在稳定同位素的路径附近安装一个旋带槽轮体，确保只有少量稳定同位素离子通过轮体，如对于 $^ { 1 4 } \mathrm { C }$ 测量，只有大约 $1 \%$ 的 $^ { 1 2 } \mathrm { C }$ 通过轮体，避免在终端处产生电流过载。
