其次，为响应先进核能系统材料服役行为研究中对复杂

辐照环境模拟的实际需求，平台将在现有“鸡尾酒束”基础上，结合 FECR离子源高效的电荷剥离能力，进一步发展三种离子的同步协同加速能力。典型应用场景包括 $\mathrm { H _ { 2 } } ^ { + }$ 、 $\mathrm { ^ { 4 } H e ^ { 2 + } }$ 与 ${ } ^ { 5 6 } \mathrm { F e } ^ { 2 6 + }$ （或 $^ { 5 8 } \mathrm { N i } ^ { 2 8 + }$ ）三束协同辐照实验：其中 $\mathrm { H _ { 2 } } ^ { + }$ 和$\mathrm { ^ { 4 } H e ^ { 2 + } }$ 分别模拟反应堆中通过 $( \mathfrak { n } , \mathfrak { a } )$ 、(n,p) 等嬗变反应产生的气体[14]，Fe或 Ni离子用于模拟中子诱导的离位缺陷损伤。这些离位损伤与嬗变气体相互作用，引发氢氦泡演化、辐照硬化、肿胀等协同损伤效应，最终导致材料力学、化学性能的急剧退化[15]。该三离子混合束的构建不仅要求离子源引出束流比例的精准调控能力和长周期束流稳定性控制，还对能量的精准调控和靶前束流一致性提出更高要求。通过集成多离子调控、相空间传输匹配与能散压缩等手段，LEAF平台有望为研究核能材料的精准协同效应、材料结构演化机理等问题提供关键实验条件。
