$$
\begin{array}{l} N _ {2 6} = \left(N _ {2 6, \text {i n h}}\right) e ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} + N _ {2 6, \mathrm {p b}} \rightarrow N _ {2 6} - N _ {2 6, \mathrm {p b}} \\ = \left(N _ {2 6, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \tag {27} \\ \end{array}
$$

由公式（26）和（27）得到：

$$
\begin{array}{l} \frac {N _ {2 6} - N _ {2 6 , \mathrm {p b}}}{N _ {1 0} - N _ {1 0 , \mathrm {p b}}} = \frac {N _ {2 6 , \mathrm {i n h}}}{N _ {1 0 , \mathrm {i n h}}} \mathrm {e} ^ {- (\lambda_ {2 6} - \lambda_ {1 0}) t _ {\mathrm {b}}} \\ = R _ {\mathrm {i n h}} \mathrm {e} ^ {- (\lambda_ {2 6} - \lambda_ {1 0}) t _ {\mathrm {b}}} \tag {28} \\ \end{array}
$$

与土壤和沉积地层相同，对于地层中具有相同埋藏后产生组分的不同样品， $N _ { 2 6 }$ 和 $N _ { 1 0 }$ 呈线性关系，斜率为 R e－（λ26－λ10）tb ［59］ 。 $R _ { \mathrm { i n } } \mathrm { e } ^ { - ( \lambda _ { 2 6 } - \lambda _ { 1 0 } ) t _ { \mathrm { b } } [ 5 9 ] }$ 因此，通过拟合两核素之间线性关系，获得其斜率，就可计算埋藏年龄。

对于继承组分较小的样品，可以根据每个样品的测量值 $R _ { \mathrm { A B } } ( t _ { \mathrm { b } } ) )$ ）计算埋藏年龄，所得数据 $^ { 1 0 } \mathrm { { B e } }$ 和$^ { 2 6 } \mathrm { A l }$ l应位于通过原点的直线上，而有继承组分时，数据不会通过原点；但在实际应用中，由于继承、埋藏后组分和侵蚀速率的影响，可能造成核素初始比值的变化［58］ 。对于上述因素的影响，可以通过多次线性拟合、继承和埋藏组分及侵蚀速率估算，然后校正测量值，经过多次迭代后最终获得可信的埋藏年龄［58～59］ 。 。

等时线方法的一个重要前提是样品经历相同的地质过程，样品经历暴露埋藏后其核素浓度应位于一条直线［58～59］ 。因此，样品的核素浓度是否位于同一直线是判别其是否符合等时线年代学方法的依据。如果样品核素浓度非常离散，表明样品经历了不同且复杂的暴露和／或埋藏过程，不适合进行等时线年龄拟合。
