空间碎片是指失效的人造航天物体及其分解产生的残骸。根据美国空间监测网的统计数据显示，近地空间存在着大量的空间碎片，这些碎片的数量不仅呈现持续增长趋势，其增长速度还在不断加快。碎片以 $7 . 8 ~ \mathrm { k m / s }$ 的第一宇宙速度高速运行，在与航天器发生碰撞时的相对速度最高可达$1 5 \ \mathrm { k m / s }$ ，对在轨航天器的安全运行和航天员的生命安全构成了严重威胁[1-3]。中性粒子束由于不受空间电荷效应和地磁场干扰，具有更好的束流定向性和远距离传输能力，有望通过使用中性粒子束轰击空间碎片将其推离运行轨道或击碎的方式，实现释放轨道资源的目标[4]。

粒子和物质靶发生电荷转移碰撞的截面大小与其能量相关，能量越高，截面越小。当前中性束技术研究主要集中在核聚变领域的中性束注入加热方面[5-7]，由于束流能量较低，所需的电荷转移靶厚度极小，因此普遍采用气体靶方案，而关于固体靶中性化的研究则相对较少。对于高能量束流的中性化过程，若采用气体靶，中性化室长度需显著增加，导致装置体积庞大、结构复杂，对航天器的搭载能力提出了严峻挑战。相较之下，固体靶具

# 1 CYCIAE-100 中性化技术方案

北京放射性核束设施（Beijing Radioactive Ion-beam Facility, BRIF）是国防科技工业局在“十五”至“十一五”期间部署的重点科研基础设施[8]。该设施以中国原子能科学研究院的串列静电加速器为平台，整合了最高能量达 $1 0 0 \ \mathrm { M e V }$ 的质子回旋加速器 CYCIAE-100 作为驱动加速器。作为BRIF 的重要组成部分，CYCIAE-100 于 2014 年首次出束，可以提供能量 ${ 7 0 } \mathrm { \sim } 1 0 0 \ \mathrm { M e V }$ 、平均流强$2 0 0 { \sim } 5 0 0 \mu \mathrm { A }$ 的质子束[9]。CYCIAE-100 的主要参数列于表 1，采用外部离子源产生负氢离子束注入至加速器中，经过 300 余圈的加速后能量可达$1 0 0 \mathrm { M e V }$ ，通过剥离膜将负氢离子束的电子剥离形成质子束进行引出。
