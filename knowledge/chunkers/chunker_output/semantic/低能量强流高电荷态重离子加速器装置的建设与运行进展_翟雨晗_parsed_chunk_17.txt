基于调能器系统，并结合精确的束线设计与束流动力学优化，LEAF 装置实现了对 $\mathrm { C } ^ { 2 + }$ 束流在 $0 . 3 { \sim } 0 . 7 \mathrm { M e V / u }$ 能量范围内的连续可调，同时将能量展宽有效压缩至 $0 . 3 \%$ （FWHM）以内。系统在保持高传输效率的同时，具备对束流纵向发射度的良好抑制能力，满足核天体物理实验对高能量分辨率的要求。为定量计算能散度，采用由狭缝、质谱二极磁铁与高分辨率双丝探测器组成的能谱测量平台进行实测。在束流能量为 $0 . 5 \mathrm { M e V / u } ,$ 、束流流强约$3 9 0 \mathrm { e } \mu \mathrm { A }$ 的工况下，得到束流的相对能量展宽 $\mathrm { d } E / E { \approx } 0 . 2 1 3 3 \%$ （FWHM），如图10 所示。该结果表明，在强流运行条件下，LEAF装置依然能够稳定输出低能散碳离子束，验证了调能系统在束流能谱控制方面的有效性。
