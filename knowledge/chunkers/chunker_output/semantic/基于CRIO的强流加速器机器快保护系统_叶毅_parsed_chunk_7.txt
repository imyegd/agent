国内外的大型物理实验装置，大多采用EPCIS作为控制系统的架构和开发平台，因此其机器保护系统不但要考虑响应速度，还要考虑与 EPICS 架构的集成。ITER 装置发布的最新的控制、数据访问和通信(Control, DataAccess and Communication，CODAC)设计方法和标准手册中，推荐 CRIO 作为响应时间小于 $1 0 0 ~ \mathrm { { m s } }$ 的子系统的快控制器，同时采用 LabVIEW 的分布式系统工具包(Distributed System Toolkit，DSC)模块实现 EPICS 系统的集成[6] 。加速器驱动次临界系统(Accelerator Driven subcritical System，ADS)注入器Ⅱ中，采用先进的 FPGA 芯片和高速光纤网络技术，实现响应时间在 $1 0 ~ \mu \mathbf { s }$ 内的机器快保护；中国散裂中子源(China Spallation Neutron Source，CSNS)机器保护分为两部分，其一为基于可编程控制器(Programmable Logic Controller，PLC)的慢保护，其二为基于 FPGA的快保护，快保护响应时间在 $1 0 ~ \mu \mathbf { s }$ 内 [7] 。

# 1.3 强流加速器机器快保护系统结构

我国的强流直线感应加速器输出束流能量高达 $2 0 \ \mathrm { M e V }$ ，流强为 $2 . 5 \ \mathrm { k A }$ ，实验要求加速器在精准的时刻输出品质满足要求的束流。强流加速器采用“准备好-触发”的工作模式，上千台套仪器设备需要在“触发”时刻处于正常的工作状态，如果某些设备在“触发”时刻发生异常或故障，加速器会异常动作，导致实验失败。加速器在实验进程中实时监控几千路信号，大多数设备的异常和故障可在实验准备阶段发现，可提前中止实验进程进行故障处理和归零，但有两种故障和异常，其不确定性无法提前预判，一旦发生，大概率会造成实验失败，造成难以挽回的损失。这两种故障和异常为：

1) Marx自激提前放电。在Marx充电结束至触发的几秒时间内，Marx工作在上百千伏高压状况，存在一定自激的可能性，这种异常对加速器正常运行会造成致命的影响，并导致相关实验失败[8-9]；

2) 励磁电源加载状况异常。强流加速器实验过程中，几百台励磁电源在几秒的时间内完成“加载-输出-卸载”3个状态，每台励磁电源需在触发时刻输出设置的电流，否则会影响束流品质，对实验结果产生重要影响。

针对强流加速器功率系统中各种Marx装置自激提前放电的快保护，研制了适合各种Marx装置放电的无源检测探头对Marx放电信号进行检测，一旦检测到任一台Marx放电，随即对触发链路进行自动断路控制，从而实现Marx自激的机器快保护。针对励磁电源加载状况的机器快保护，通过在电源输出回路安装高精确度非接触式的霍尔探头对电源输出电流进行采样，在加速器发出触发指令前，根据检测结果决定是否对触发链路进行断路控制，实现励磁电源加载状况异常的快保护。
