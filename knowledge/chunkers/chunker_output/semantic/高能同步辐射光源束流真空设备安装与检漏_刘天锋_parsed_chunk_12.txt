# 1.2 检漏方案设计与设备选型

本文涉及的检漏工作分为两个主要阶段：

安装过程与烘烤前检漏（真空模式法）：该阶段系统处于高真空（约为 $1 0 ^ { - 4 } \mathrm { { P a } }$ ）尚未经过高温烘烤。主要利用氦质谱检漏仪的“真空模式法”进行检漏。将检漏仪通过金属波纹管连接至已安装完成的待检真空系

统区段，在可疑部位喷吹氦气，若存在漏孔，氦气将通过漏孔进入检漏仪并被精准识别。该方法灵敏度高，可准确定位漏点位置。检漏流程如图 2 所示。

真空系统烘烤后与加速器运行期间检漏：真空系统的性能直接关系到束流的品质和加速器的稳定运行，因此我们在真空盒安装完成后，制定了严格的烘烤除气流程以满足不同部位的加热需求，例如将永磁纵向梯度磁铁中的不锈钢真空盒加热温度设定在$1 2 0 \mathrm { { } ^ { \circ } C }$ ，既能满足除气要求又能保护永磁铁的磁性，系统经高温（ $1 2 0 ^ { \circ } \mathrm { C } { \cdot } 2 0 0 ^ { \circ } \mathrm { C } $ ）烘烤后

进入超高真空（ ${ \bf < } 1 0 ^ { - 8 } \mathrm { P a } )$ ）状态。此时，利用系统上的四极质谱仪开展检漏工作。通过监测质量数为 $4 \ : ( \mathrm { H e ^ { + } } )$ 的峰强在喷氦后的变化来判断漏点。同时，四极质谱仪持续监测全谱或特定质量数的分压，能够准确识别 $\mathrm { H } _ { 2 }$ 、He、 $_ \mathrm { H _ { 2 } O }$ 、 $\Nu _ { 2 }$ 、 $\mathrm { O } _ { 2 }$ 、 $\mathrm { C O } _ { 2 }$ 等关键气体，用于残余气体分析。

# 2.1.1 密封垫圈安装缺陷与密封性能优化

密封垫圈安装缺陷是真空系统法兰连接处最主要的泄漏诱因。HEPS 真空系统安装初期，法兰连接处频发不同程度的泄漏现象，其中多数泄漏可通过进一步均匀紧固法兰螺栓消除，部分泄漏则需更换密封垫圈方可达标。
