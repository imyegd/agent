# 1.2   斩束器电磁学模拟

斩束器电磁学模拟 CST Studio Suite软件，束流动力学模拟采用 TraceWin软件，程序参数根据本套加速器中子源低能束流传输线提供参数，束流参数如表 1所示。其中 $E$ 表示能量、I 为流强、duty 为束流占空比、ε为束流发射度、 $\alpha$ 与 $\beta$ 为束流 TWISS参数。

斩束器设计偏转距离 $H { = } 1 9 . 5 ~ \mathrm { c m }$ ， $L ^ { \prime }$ 取 $4 0 ~ \mathrm { m m }$ ，根据束流模拟结果选定极板间距 $d { = } 6 0 ~ \mathrm { m m }$ ，极板宽度为 $8 0 ~ \mathrm { m m }$ ，

根据式（4）计算可得斩束器所需偏转电压取决于极板长度L，一般设计斩束器时，斩束器工作电压不宜过高，过高工作电压会对束流输运有较大影响[15]，通过相关计算 $L$ 取 $8 5 ~ \mathrm { m m }$ ，偏转电压 $\varphi _ { \mathrm { d } } { = } 8 5 6 4 . 7 \ \mathrm { V }$ ，这个数值相对于一般的斩束器偏转电压是略低的，因此对于斩束器工作效果较好，实际生产也比较容易。

在 CST Studio Suite 软件中建立斩束器模型，进行其静电学仿真计算，图 2 是斩束器电场强度矢量分布图，图 3是斩束器横向电场强度变化曲线。
