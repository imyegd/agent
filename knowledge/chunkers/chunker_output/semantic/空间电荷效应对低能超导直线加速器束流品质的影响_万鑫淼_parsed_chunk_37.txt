# 3    总结与展望

本研究通过理论解析、数值计算与多粒子模拟相结合的方法，系统探究了低能超导直线加速器中空间电荷效应影响束流品质的两个关键问题，主要获得以下结论：（1）关于 $\sigma _ { 0 }$ 动态演化与包络稳定性：首次揭示了 $\sigma _ { 0 }$ 在加速过程中局部突破 $9 0 ^ { \circ }$ 对束流品质的影响强烈依赖于空间电荷强度和聚焦结构、当空间电荷效应较弱时， $\sigma _ { 0 }$ 的局部超越不会导致束流品质的显著恶化；而当 $\eta < 0 . 7$ （空间电荷效应较强）时，该超越会激发四阶共振并引发包络不稳定性，导致发射度显著增长，且该效应在双组合四极透镜系统中远比在螺线管系统中更为严重；（2）关于双周期结构与束晕形成机制：揭示了低能端特有的双周期聚焦结构中新奇的束晕形成机制。研究发现，即便每个单元的 $\sigma _ { 0 } <$ $9 0 ^ { \circ }$ ，双周期结构本身也会诱发包络不稳定性。明确了空间电荷主导束流中 2∶1共振（由粒子振荡频率与束核包络

振荡的三倍频耦合引发）是产生束晕的主要原因；而发射度主导束流中则由 4∶1共振主导。本研究进一步发现，在空间电荷效应的作用下，纵向包络可与横向包络发生能量交换，通过改变束核电荷密度分布实现调制作用，进而参与横向共振过程，对束流的共振行为产生影响；同时，减少一个恒温器内的小周期结构数 (N) 会增强低次谐波能量，从而更容易激发1∶1等低阶共振，增大束晕产生的风险。

超导直线加速器低能端的束流优化设计是一个重要的课题，更为全面、系统的工程设计包含的内容较多，而且需要反复的模拟研究及物理设计迭代，尽管已经考虑了大部分物理及工程需求，但是后续有很多细节问题需要进一步分析：（1）目前关于束晕的讨论基于未考虑加速的情况，因此需要考虑束流能量变化下束晕形成机制是否有新的变化；（2）目前的讨论均假定束流是轴对称束流，没有考虑 $x$ 和 y 平面的耦合对稳定性的影响。因此需要考虑在不同自由度耦合下的束流动力学；（3）深入分析高阶共振（如 6∶1、8∶1）及混沌现象对束流品质的影响，完善理论框架。
