# 1.1   斩束器基本理论

在加速器中子源的 LEBT 段，粒子能量往往在几十 keV量级[13]，因此多采用静电式斩束器，图 1是静电式斩束器结构示意图，上下极板间距为 d，极板之间存在一个静电场，带电粒子通过长度 $L$ 的斩束器。获得一个偏转角 θ，再经过 L′的漂移长度最终打到承接屏上，粒子经斩束器作用偏转距离为 $x { + } L ^ { \prime } { \mathrm { t a n } } \theta .$ ，假设下极板电势为 $_ { 0 \mathrm { ~ V ~ } }$ ，上极板电势为 $\varphi _ { \mathrm { d } } ,$ ，粒子纵向匀速运动，横向在电场作用下加速运动，不考虑边缘效应。

带电粒子的拉格朗日函数为[14]

$$
L = T - U = \frac {1}{2} m v ^ {2} - q \varphi \tag {1}
$$

式中： $T$ 是带电粒子动能； $U$ 是带电粒子电势能。
