# 2 横、纵向动力学分析

质子在电磁场中会受到洛伦兹力，其运动满足牛顿第二定律，即

$$
\frac {\mathrm {d}}{\mathrm {d} t} \boldsymbol {P} = q \boldsymbol {E} + q (\boldsymbol {v} \times \boldsymbol {B}), \tag {1}
$$

其中：矢量 $P = \gamma m _ { 0 } \nu$ 为质子的机械动量； $\nu$ 为质子的速度； $\gamma = 1 / \sqrt { 1 - \left( \nu / c \right) ^ { 2 } }$ 为相对论因子； $c$ 为真空中的光速； $m _ { 0 }$ 为质子静止质量； $E$ 为质子所在位置的电场强度矢量； $\pmb { B }$ 为质子所在位置的磁感应强度矢量； $q$ 表示质子电荷量。
