# 空间电荷效应对低能超导直线加速器束流品质的影响*

万鑫淼，   任志强，   廖文龙，   骆小宝，   常轩恺，   朱彦东，   陶德强，   李智慧

（辐射物理与技术教育部重点实验室，四川大学 原子核科学技术研究所，成都 610065）

摘    要 ：   通过理论建模与数值模拟相结合，系统探究了在低能超导质子直线加速器内，加速过程中聚焦参数动态演化对空间电荷主导型包络不稳定性的影响机制，揭示了低能段双周期聚焦结构与束晕产生的内在关联。基于 Vlasov-Poisson方程二阶偶模展开，构建了理论模型，设计零流强周期相移 $( \sigma _ { 0 } )$ 局部突破 $9 0 ^ { \circ }$ 的多种演化方案，全面探究了不同聚焦方案下，局部突破 $9 0 ^ { \circ }$ 对束流品质的影响，并用多粒子模拟软件对低能、归一化均方根发射度 $0 . 2 { \sim } 0 . 4 \pi \cdot \mathrm { m m } { \cdot } \mathrm { m r a d }$ 的质子束进行了多粒子模拟验证；针对双周期聚焦结构特征，设计了相应的聚焦结构与束流
