# 1. 2 活性炭柱对钼锝（铼）的分离

因高锝酸根具有较高的放射性，采用锝的同族元素铼来作为钼锝分离的模拟物，高铼酸根与高锝酸根具有极其相似的化学性质。称取 $1 . 5 0 \mathrm { \ m g \ K R e O _ { 4 } }$ （精确至 $0 . 0 1 \mathrm { { m g } }$ ）溶于 $1 0 ~ \mathrm { m L }$ 水中，得到 $\mathrm { K R e O _ { 4 } }$ 溶液。称取 $0 . 2 0 3 7 \mathrm { \ g \ N a _ { 2 } M o O _ { 4 } } ,$ （精确至 $\mathrm { 0 . 0 0 0 ~ 1 ~ g ) }$ ）溶于水中，然后取 $1 \textrm { m L }$ 的 $\mathrm { K R e O _ { 4 } }$ 溶液加入钼酸钠溶液中，最后定容至 $1 0 ~ \mathrm { m L }$ 得到钼、铼溶液。
