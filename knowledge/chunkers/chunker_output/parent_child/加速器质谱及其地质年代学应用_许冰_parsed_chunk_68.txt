$^ { 1 4 } \mathrm { C }$ 定年的材料包括动植物残体、土壤和湖泊沉积中的有机体、有机质、无机碳酸盐（包括生物碳酸盐壳体）等。但 $^ { 1 4 } \mathrm { C }$ 定年的比较理想材料是生命周期较短的植物残体，如一年生的植物及其残体。除了样品条件外，一个必须满足的条件就是定年物质的形成与所研究的过程和事件具有密切联系，且关系明确，如沉积物有机质或有机体定年中，有机质和有机体必须与沉积过程同期。如果沉积物中的植物残体，如树叶和一年生的草类植物残体随沉积物一起被搬运并沉积，那其年代就代表沉积时期的年代；而在另一种情况下，如土壤中的有机残体和黑炭，是土壤形成过程中的产物，如果这些含碳物质由于土壤风化侵蚀，随后搬运并沉积，那这些碳来源的 $^ { 1 4 } \mathrm { C }$ 年代显然不能代表沉积时代；此外，在考古断代中的 $^ { 1 4 } \mathrm { C }$ 定年，文化层中的木炭和古墓葬中的棺椁所用的木材，其年代可能远老于文化层形成和古墓的年代。
