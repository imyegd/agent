# 3 侧墙模板设计

# 3.1 混凝土的侧压力

墙体混凝土对侧模压力的计算公式为

$$
F = 0. 2 8 \gamma_ {c} t _ {0} \beta \sqrt {V}
$$

式中 γ 为混凝土的重力密度，取 $2 4 . 0 0 0 \mathrm { k N } / \mathrm { m } ^ { 3 }$ ；t为新浇混凝土的初凝时间，为0时（表示无资料）取200/（ $T + 1 5$ ），取5.714h；T为混凝土的入模温度，取 $2 0 . 0 0 0 ^ { \circ } \mathrm { C }$ ；V为混凝土的浇筑速度，取$2 . 5 0 0 \mathrm { m / h }$ ； $\beta$ 为混凝土坍落度影响修正系数，取0.850。

当浇筑速度大于 $1 0 \mathrm { m / h }$ 或坍落度大于 $1 8 0 \mathrm { m m }$ 时，新浇混凝土侧压力计算公式为

$$
F = \gamma_ {c} H
$$

式中 H为混凝土侧压力计算位置处至新浇混凝土顶面总高度，取 $1 . 2 0 0 \mathrm { m }$ 。
