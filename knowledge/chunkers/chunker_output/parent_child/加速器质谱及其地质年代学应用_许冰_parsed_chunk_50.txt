电离探测器。多电极电离室由一个电极组成，该电极沿离子轨迹的总体方向被分割成若干独立的部分（处于同一电位但彼此绝缘）。这一探测器最初也是为重离子核物理实验而开发的［1，34～35］ ，随后应用于加速器质谱［36～37］ ；另外，电极段的单独信号与沿轨迹的相应能量损失成正比，为同位素识别提供了离子原子序数物理量（Z）的有力特征。该原理被澳大利亚国立大学Fifield等［38］ 发现，认为锯齿形电极能给出位置敏感信号，而位置信息在识别 $^ { 3 6 } \mathrm { C l }$ l离子中起到重要作用。多电极电离室既可以作为独立探测器使用［39］ ，也可用于更复杂的探测系统；其可以和充气磁体组合形成充气磁场探测器［40］ ，该探测器可在充有气体的恩格分极磁谱仪的焦平面中检测重放射性核素（如$^ { 5 3 } \mathrm { M n }$ 和 $^ { 6 0 } \mathrm { F e }$ ）。
