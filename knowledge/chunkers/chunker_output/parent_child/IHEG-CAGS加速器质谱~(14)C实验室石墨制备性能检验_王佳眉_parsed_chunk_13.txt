# 1.2 VAC石墨化流程

该系统主要由进样装置、真空泵组、冷阱、 $\mathrm { C O } _ { 2 }$ 流量 计、石 英 管、阀 门、真 空 计 及 还 原 装 置 构 成（图 3）。根据功能模块，可划分为 3个单元：真空保持单元（A）、 $\mathrm { C O } _ { 2 }$ 纯化单元（B）和 $\mathrm { C O } _ { 2 }$ 还原单元（C）。整个装置以高硼玻璃为主要结构材料，极限真空度 $< { 1 0 } ^ { - 5 }$ mbar，真空计实时监测便于直接观察纯化过程。在样品制备前，首先将装有氧化铜及银丝的石英管置于 $8 5 0 \ \mathrm { { ‰} }$ 的高温炉中 $^ \textrm { \scriptsize 5 h }$ ，以去除潜在的有机污染物；然后将固体有机碳样品导入石英管，并在真空条件下火焰密封。真空燃烧后样品中的碳被氧化成 $\mathrm { C O } _ { 2 }$ ，然后 $\mathrm { C O } _ { 2 }$ 通过石英管破碎装置被引入真空系统。溶解性无机碳样品或碳酸盐置于接入真空系统的酸解管中，
