$ 方向的标准 差 。 一 般 采 用 半 高 宽（Full Width at HalfMaximum，FWHM）定义焦点尺寸［19］，如图 2（b）、（c）， $X$ 方向焦点大小为 $a _ { x } = \mathrm { F W H M } _ { x } = 2 \sqrt { 2 \mathrm { l n } 2 } \sigma _ { x } , Y$ 方向焦点大小为 $a _ { y } = \mathrm { F W H M } _ { y } = 2 \sqrt { 2 \mathrm { l n } 2 } \sigma _ { y } \mathrm { _ { \circ } }$ 。
