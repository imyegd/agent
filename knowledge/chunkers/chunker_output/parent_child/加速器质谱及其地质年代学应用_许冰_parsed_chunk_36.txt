# 3.1 离子源

样品制成后，将样品装入靶盘，放入离子源。根据前文介绍，目前几乎所有串列加速器质谱的离子源都是 Middleton型铯溅射负离子源。这种离子源利用氪（Kr）离子溅射表层度有一层 Cs的固体表面，从而溅射出负离子，其中 Cs的功能是降低固体物质表面的工作能。一般串列加速器质谱的溅射离子源具有多样品靶盘，以便样品间的快速转换，且样品转换过程的交叉污染（记忆效应）较小，常用核素可以忽略不计。常用核素除 $^ { 1 4 } \mathrm { C }$ 有时使用气体源外，负离子源一般是针对固体样品的离子源，如$^ { 1 4 } \mathrm { C }$ 测定的石墨样品，其原理是利用能量在几 keV的Cs＋ 聚焦撞击靶心样品表面，从靶心样品表面溅射出样品的自由原子和负离子。早期的离子源称为Cs枪离子源，Cs通过电炉加热气化，而后进入离子发生器，Cs在离子发生器转化成 ${ \mathrm { C s } } ^ { + }$ 离子。样品靶离子发生器距样品有一段距离，因此， $\mathrm { C s } ^ { + }$ 需从狭缝加速引出，通过透镜系统聚焦于样品表面。而现代离子源的离子发生
