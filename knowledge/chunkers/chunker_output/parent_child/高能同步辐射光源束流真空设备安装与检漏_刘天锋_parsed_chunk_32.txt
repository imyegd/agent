通束流后：最显著的变化是氢气（H₂）的信号强度急剧上升，成为主导成分。这是由于同步辐射光照射到真空盒内壁，发生光致解吸（Photon Stimulated Desorption，PSD），

其主要解吸产物就是 $\mathrm { H } _ { 2 } ^ { \mathrm { ~ [ 6 , 1 0 ] ~ } }$ 。同时，我们观察到 CH₄、CO 等气体成分也呈现出特征性变化，这与电子诱导解吸等过程有关。
