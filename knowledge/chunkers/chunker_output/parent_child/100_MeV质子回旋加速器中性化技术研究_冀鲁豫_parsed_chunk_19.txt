# 2 用于中性束剥离的薄剥离膜方案研究

# 2.1 剥离膜厚度和中性化率

电荷转移碰撞是束流中性化的核心机制，粒子束和靶粒子碰撞后发生电荷转移，改变电荷状态。发生电荷转移碰撞的概率用截面 $\sigma$ 表示，碰撞时粒子可能得到或失去 1 个或多个电子， $\sigma _ { i j }$ 为电荷态 i 的粒子碰撞后成为电荷态 $j$ 的粒子的截面。以负氢离子中性化为例， $\sigma _ { - 1 0 }$ 表示负氢离子碰撞后成为氢原子的截面。

对于分子数密度为 $n$ 的靶，定义靶分子数线密度 t：

$$
t = \int_ {0} ^ {L} n \mathrm {d} x \tag {1}
$$

其中， $L$ 为距离。对于氢的中性化，已知 $\mathrm { H } ^ { + }$ 、 $\mathrm { H } ^ { 0 }$ 和$\mathrm { H } ^ { - } \ 3$ 种电荷态初始束流成分占比分别为 $F _ { 1 } , F _ { 0 }$ $F _ { 0 }$ 和$F _ { - 1 }$ ，以及电荷转移碰撞截面。则可通过微分方程组计算束流成分
