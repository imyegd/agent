# 4.3 埋藏年代学

宇宙成因核素埋藏年代定年原理是，定年矿物在地表暴露一段时间，矿物中累积了一定量的宇宙成因核素，而后发生快速埋藏，屏蔽宇宙射线的作用，矿物中不再形成新的宇宙成因核素，样品中的宇宙成因核素含量依其半衰期随时间衰变减少。埋藏年龄相对于暴露年龄而言，由于风化和侵蚀只对表层物质起作用，因此埋藏物质和表层物质的侵蚀一般影响较小。

一种情况是，样品长期暴露在稳定地球表面，其起始产率 $( P _ { i } ( 0 )$ ）和侵蚀速率 ${ \bf \Xi } ( \bf \Lambda _ { \varepsilon } \delta )$ ）达到平衡状态，则样品中宇宙成因核素埋藏前的浓度 $| N _ { i }$ ）为：

$$
N _ {i} = \frac {P _ {i} (0)}{\lambda_ {i} + \rho \varepsilon / \Lambda_ {i}} \tag {13}
$$
