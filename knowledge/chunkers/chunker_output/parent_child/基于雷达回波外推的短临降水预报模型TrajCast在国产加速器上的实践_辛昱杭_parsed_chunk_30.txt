# 3.1 预报准率性评估指标及基准参照性能

本文以6分钟的时间间隔作2小时内的降水预报，共外推20步，以距离起报时间1小时降水预报结果的TS评分[16-17]为模型准确率评价标准。

TS评分在短临预报领域被广泛采用，其计算方式为：

$$
T S = \frac {T P}{T P + F N + F P} \tag {11}
$$

次t，任一阈值等级c（ $\mathrm { c } { > } 0$ ）上有：

$$

$$
