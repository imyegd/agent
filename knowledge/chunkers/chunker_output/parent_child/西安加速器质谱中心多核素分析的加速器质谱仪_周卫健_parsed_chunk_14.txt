# 1.4 高能分析系统

被加速的离子束流经三单元四极透镜聚焦后进入高能分析系统，该系统由两个二极磁铁和一个静电分析器组成。

1.4.1 限缝稳定(Slit stabilization) 束流先进入 $1 1 5 ^ { \circ }$ 的分析磁铁。在该磁铁出口的象平面上，设置了可移动的法拉第杯，用以测量被交替加速的稳定同位素(如 $^ { 1 3 } \mathrm { C }$ ， $^ { 9 } \mathrm { { B e } ) }$ )离子。该法拉第杯内装有限缝用作“限缝稳定”。如端电压波动而引起信号差，该限缝将自动稳定端电压[14]；若信号差由其它电磁参数变化引起，则可改变端电压以补偿这些参数的改变。在验收试验中我们观察到了这一现象，在 2.5MV端电压下达到满意测量精度时，四个核素测试时的端电压改变范围竟有 4— $\cdot 6 \mathrm { k V } ^ { [ 6 ] }$ 。
