# 2. 3 氧化铝柱对钼铼的分离效果

虽然TEVA树脂对钼铼具有较好的分离效果，但其成本较高，为最大程度发挥TEVA的高效分离能力，考虑到溶液中过高含量的钼酸盐会干扰到高铼酸根的分离，故对钼酸盐进行预分离研究。

钼锝发生器中使用氧化铝柱分离钼锝，是将钼酸盐吸附在氧化铝柱上之后再对钼衰变出的高锝酸根进行洗脱［1］。我们测试了氧化铝柱对钼酸钠在不同 pH 值下的吸附情况，结果如图 3a 所示。在 $\mathrm { p H } \leqslant 7$ 时，氧化铝柱对钼酸根的吸附率相对稳定并保持在$80 \%$ 以上，当 $\mathrm { p H } > 7$ 时，氧化铝对钼酸盐的吸附大幅下滑，在浓碱性条件下降低至 $2 5 \%$ 以下。故氧化铝柱的初始环境应维持在 $\mathrm { p H } \leqslant 7$ 的条件下，这与文献报道一致［21］ 。
