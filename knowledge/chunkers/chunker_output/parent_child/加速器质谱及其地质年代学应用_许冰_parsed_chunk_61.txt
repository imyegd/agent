# 4.1 ${ } ^ { 1 4 } \mathbf { C }$ 定年

$^ { 1 4 } \mathrm { C }$ 年代学，又称放射性碳（Radiocarbon）年代

学，是目前应用最广泛的年代学方法［45］ 。经过准确校准的 $^ { 1 4 } \mathrm { C }$ 年龄是末次冰期考古、地质以及历史时期形成有机化合物准确时间框架的“黄金标准”（GoldStandard）［46］ 。

$^ { 1 4 } \mathrm { C }$ 年代学方法是根据大气成因 $^ { 1 4 } \mathrm { C }$ 放射性衰变来进行放射性同位素定年的方法，与传统放射性同位素定年类似，根据 $^ { 1 4 } \mathrm { C }$ 的衰变规律进行定年。$^ { 1 4 } \mathrm { C }$ 定年的 $^ { 1 4 } \mathrm { C }$ 主要是宇宙射线与大气中 $\mathrm { ^ { 1 4 } N }$ 相互作用产生的，其产生机制是宇宙射线产生的次级粒子，即热中子与大气中的 $\mathrm { ^ { 1 4 } N }$ 相互作用，俘获中子
