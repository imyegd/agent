# 1.2 检漏方案设计与设备选型

本文涉及的检漏工作分为两个主要阶段：

安装过程与烘烤前检漏（真空模式法）：该阶段系统处于高真空（约为 $1 0 ^ { - 4 } \mathrm { { P a } }$ ）尚未经过高温烘烤。主要利用氦质谱检漏仪的“真空模式法”进行检漏。将检漏仪通过金属波纹管连接至已安装完成的待检真空系

统区段，在可疑部位喷吹氦气，若存在漏孔，氦气将通过漏孔进入检漏仪并被精准识别。该方法灵敏度高，可准确定位漏点位置。检漏流程如图 2 所示。
