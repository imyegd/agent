# 5.1 经济性评价

初投资、运行能耗费用和维护检修成本等共同组成余热回收系统总耗费。为分析系统的经济性，计算其所增加的初投资和节省的运行费用，再根据其计算静态投资回收期[24]，具体表达式如式(1)所示：

$$
P _ {B P} = \frac {\triangle I _ {n v}}{\triangle I _ {n c}} \tag {1}
$$

式中： $\mathrm { P _ { B P } }$ 为静态投资回收期，a；

$\Delta \mathrm { I } _ { \mathrm { n v } }$ 为系统增加的初投资，万元；

$\Delta \mathrm { I } _ { \mathrm { n c } }$ 为系统相对于燃气锅炉系统节省的运行费用，万元/a。
