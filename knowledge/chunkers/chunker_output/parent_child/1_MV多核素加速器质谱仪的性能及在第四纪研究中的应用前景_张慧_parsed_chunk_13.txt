# 1.2 低能注入系统

经离子源透镜聚焦后的负离子束，首先导入具有 $5 4 ^ { \circ }$ 可 旋 转 方 位 角 设 计 的 球 面 静 电 分 析 器（ElectrostaticAnalyzer，简称 ESA）进行能量筛选。随后，离子束进入 $1 2 0 ^ { \circ }$ °偏转磁铁进行质量分析。该磁 铁 设 计 为 能 量 快 速 切 换 模 式， 质 能 积 为12AMU·MeV，质量分辨率 $( \mathrm { ~ M ~ } / \Delta \mathrm { M } ) > 8 0 0$ ，可在$3 5 \mathrm { \ k e V }$ 束流能量下分析质量数高达 340AMU（原子质量）的离子。为优化测量效率，系统将循环周期的大部分分析时间分配予稀有同位素 （如 $^ { 1 4 } \mathrm { C } ^ { - }$ ：$9 . 7 5 ~ \mathrm { m s }$ s），而对丰度较高的同位素（如 13C－ 、 $^ { 1 2 } \mathrm { C } ^ { - }$ ：各 $0 . 1 ~ \mathrm { m s }$ ）
