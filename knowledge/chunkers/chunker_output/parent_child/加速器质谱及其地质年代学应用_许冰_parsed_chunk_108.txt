# 5 总结与展望

自 20世纪 70年代末，随着串列式加速器质谱的发展与成熟，加速器质谱技术已成为测量微量和珍稀样品以及超低含量稀有同位素的主要方法，有时是唯一的测试技术。测定的核素由初始的 $^ { 1 4 } \mathrm { C }$ 和$^ { 1 0 } \mathrm { { B e } }$ e等少数几个核素，拓展到如今的 60多个，其应用领域也获得了极大拓展，具体到地球科学，应用涵盖了从板块构造活动到行星科学的各个领域，推动了相关学科的快速发展。 $^ { 1 4 } \mathrm { C }$ 定年和埋藏年龄为理解人类起源、迁徙、演化和文化技术交流等方面提供了重要年代学支撑；宇宙成因核素年代学的出现，也使定量化研究外力地质作用过程，如河流、湖泊和海洋阶地的形成，侵蚀风化速率的厘定以及地质地貌过程的演化成为可能；此外，基于加速器质谱探测技术的宇宙成因核素已成为研究太阳活动与地磁场变化的主要技术方法，如冰芯、树轮和具有较好年代控制的沉积物中的宇宙成因核素是太阳活动和古地磁变化的良好记录［66～68］ ；在行星科学中广泛用于宇宙和太阳射线强度变化、星外物质的暴露年龄厘定、超新星事件的识别等
