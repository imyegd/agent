# 1.3.1 单聚焦双层多叶光栅

图5展示了单聚焦双层多叶光栅的架构，目前市面上主流的单聚焦双层多叶光栅是瓦里安医疗系统公司配置在 Halcyon/Ethos产品上的光栅系统［17-18］，叶片采用平行交错排列设计，上层（近端层）多叶光栅由29对叶片组成，下层（远端层）多叶光栅由28对叶片组成，每个叶片的投影宽度 $1 0 \ \mathrm { m m }$ ，上下两层叶片交错排列，使其在等中心处的有效投影宽度达到 $5 \ \mathrm { m m }$ ，等中心处最大照射野 $2 8 ~ \mathrm { c m } \times 2 8 ~ \mathrm { c m }$ ，叶片的运行速度 $5 0 \ \mathrm { m m / s }$ ，加速度达到 $2 0 0 \ \mathrm { m m } / \mathrm { s } ^ { 2 }$ ，这种设计的主要优势是叶片的透射和漏辐射更低，叶片的调制速度更快。单聚焦双层多叶光栅从架构上对直线加速器传统准直系统进行了简化，大幅减少了零件种类及数量，使整体结构更简洁，成本更低，更易维护，有利于整机可靠性的
