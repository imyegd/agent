# 2 粒子加速器余热的主要特征和重要意义

# 2.1 加速器余热的主要特征

# 2.1.1 余热量可观

近年来，国际上和我国高能粒子加速器实验需要的粒子能量越来越高，新建的高能光源亮度越来越大。这些大科学装置的总体功耗达到上百兆瓦，年耗电量将达到 TWh 量级。中国科学家提议建设的环形正负电子对撞机（Circular Electron Positron Collider, CEPC）周长达 $1 0 0 ~ \mathrm { k m }$ ，是 LHC 的三倍多，将成为世界最大的科学装置[12]。CEPC 超导高频功率源系统含 100 套 $6 5 0 \mathrm { M H z } / 8 0 0 \mathrm { k W }$ 高效率速调管，目标能量转化效率为 $8 0 \% ^ { [ 1 3 ] }$ ，连续波模式下总平均功率为 $8 0 \mathrm { M W }$ ，能够被回收再利用的能量将达到 16 MW。假设这部分能量以余热形式回收，以全年运行 10 个月计算，年回收余热可达 41.5 万 GJ，节能效果极其显著。
