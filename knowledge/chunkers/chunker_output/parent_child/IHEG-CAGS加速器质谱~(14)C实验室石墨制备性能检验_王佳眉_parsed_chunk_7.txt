# 1.1 AGE3石墨化流程

AMS $^ { 1 4 } \mathrm { C }$ 石墨化是将含碳样品转化为高纯度石墨靶的前处理过程。作为 AMS－ $^ { 1 4 } \mathrm { C }$ 测试的关键环节，其原理是通过化学氧化－催化还原的方式，先将样品中的碳氧化为 $\mathrm { C O } _ { 2 }$ ，再还原成为具备良好导电性的固体石墨，以满足 $^ { 1 4 } \mathrm { C }$ 测试过程中 AMS离子源对高稳定束流的要求（图 1）。对于原始样品中的无机碳或有机碳提取，需采用有针对性的前处理方法释放 $\mathrm { C O } _ { 2 }$ ，常见手段包括高温氧化法、热解法、及酸处理提取法等。在获得纯净 $\mathrm { C O } _ { 2 }$ 后，通常通过催化还原途径将其转化为石墨，常见的催化还原途径包括 $\mathrm { H } _ { 2 } / \mathrm { F e }$ 法、 $\mathrm { Z n / F e }$ 法及 $\mathrm { Z n - T i H } _ { 2 }
