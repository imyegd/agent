# 3.2 注入和低能分析系统

离开离子源的低能量、发散的离子束流被加速、聚焦，并由注入系统传输到加速器入口。注入和低能分析系统由一个预加速装置、限定束流发射度的孔径装置、透镜和导向器、测量束流电流的束流挡板（法拉第杯收集器）以及用于获取束流信息的其他诊断设备组成。预加速装置位于离子源后端，加速电压一般在 $3 0 \sim 3 0 0 \mathrm { k V }$ 。一般而言，离子束流的能量越大，其光学性质越适合进入加速器。注入器，可以理解为一个传统的质谱系统，它确保只有正确的离子进入加速器。因此，磁分析器（一个或多个）是注入系统中重要构成元件。为使所有同位素都获得相同的聚焦条件，注入系统的所有透镜和导向器都采用静电技术，以确保其不受质量因素的影响。Cs溅射离子源有一个弱点，即其束流信号具有高能拖尾。因此，当需要高质量和能量分辨率时 $^ { 3 6 } \mathrm { C l } )$ ），可以加入一个静电分析器。对于加

速器质谱的注入系统，目前常用的注入系统有两种类型，分别是“顺序式”和“同时式”，其中“顺序式”注入占多数。
