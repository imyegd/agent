待整机预热 $1 0 ~ \mathrm { m i n }$ 后，使用万用表测量灯泡电压，MLC 电压范围应在 $1 2 . 7 \pm 0 . 5$ VAC，否则需要调整射野灯电压。进入维修模式调入MLC画面，观察图像有无反光点，且亮度是否过亮或过暗，否则需要调节MLC摄像头光圈。然后进行 MLC 运行检测，对于型号为 DesktopR5.0 的加速器，运行 MLC $3 \mathrm { c m } \times 3 \mathrm { c m }$ 和 $4 0 \ \mathrm { c m } \times$ $4 0 ~ \mathrm { c m }$ 射野检查，或通过MLC Test程序检测；对于型号为R7.0以上机器，运行MLC光学优化。最后安装罩壳，灯泡更换完成。重新测试后故障解除，加速器恢复正常。
