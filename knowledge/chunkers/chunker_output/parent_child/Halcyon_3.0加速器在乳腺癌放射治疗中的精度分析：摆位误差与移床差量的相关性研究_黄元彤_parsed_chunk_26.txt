本次研究纳入了保乳术和根治术两类手术方式的患者，统计分析后发现两者摆位误差差异无统计学意义（ $P { > } 0 . 0 5$ ），这一结果与丁伟杰等[16]研究一致，故将两组数据合并分析。通过Spearman相关分析探讨了摆位误差与移床差量之间的关联。结果显示，头脚和左右方向（LNG与ΔLNG，LAT与ΔLAT）的摆位误差与移床差量之间存在中等程度的相关性（R 值分别为0.393和0.361， $P { < } 0 . 0 0 1$ ），这证实了在这两个方向上移床操作与最终摆位结果之间存在内在联系。然而，其余两组变量对之间的相关性系数R均低于0.3，属于弱相关。尽管弱相关但仍具有统计学显著性（ $P { < } 0 . 0 5$ ）。这可能源于本研究的CBCT大样本量（ $n { = } 3 4 4 7$ ），当样本量非常大时，即使非常微弱的、在临床上可以忽略的关联， $P$ 值也很容易在统计学上显示出“显著性”。在统计学中， $P$ 值仅反映关联存在的证据强度，而相
