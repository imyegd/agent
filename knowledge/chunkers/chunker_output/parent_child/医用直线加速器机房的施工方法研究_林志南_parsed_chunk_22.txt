# 3.3 模板面板计算

面板为受弯结构，需要验算其抗弯强度和刚度。模板面板按照连续梁计算。面板的计算高度为$6 . 2 0 \mathrm { m }$ ，荷载计算值为 $q { = } 1 . 3 0 \times 2 9 . 7 0 0 \times 6 . 2 0 0 { + } 1 . 5 0$ $\times 4 . 4 0 0 \times 6 . 2 0 0 { = } 2 8 0 . 3 0 2 \mathrm { k N / m }$ ，其力学计算简图如图11所示。
