# 2.1.4 离子泵组件泄漏类型与处置方案

离子泵作为HEPS真空系统的主要抽气手段，其本身的密封性直接影响系统真空度。共发现两类离子泵相关泄漏：

离子泵高压头泄漏：在多台离子泵上观察到漏率缓慢增长现象，检漏仪显示漏率在$1 { \sim } 2 \ \mathrm { m i n }$ 内从 $1 0 ^ { - 1 2 } \ \mathrm { P a } \cdot \mathrm { m } ^ { 3 } / \mathrm { s }$ 量级增长至 10⁻9$\mathrm { P a } { \cdot } \mathrm { m } ^ { 3 } / \mathrm { s }$ 量级。拔下高压头后，直接向高压头插孔喷氦气，检漏仪显示极大漏率，确认高压头内陶瓷碎裂。

离子泵泵体泄漏：在常规检漏中发现，在 1 台离子泵周边区域喷氦时，检漏仪监测到漏率增长，但漏点难以精确定位。拆除离子泵外保护壳，直接向泵体焊缝和接口喷氦气，最终在泵体侧面焊缝处定位漏点。鉴于离子泵结构复杂，直接维修难度较大，故采用整台离子泵更换的处置方案。
