# 3.讨论

在乳腺放射治疗中，设备精度至关重要。体位偏移不仅会导致靶区剂量不足，影响肿瘤控制，还会增加周围正常组织的放射损伤风险。国际辐射单位与测量委员会（ICRU）24号报告显示，靶区剂量偏离度达到 $3 \% { \sim } 5 \%$ 就有可能引起肿瘤原发灶放疗的有效率下降及周围正常组织放射性并发

本次研究纳入了保乳术和根治术两类手术方式的患者，统计分析后发现两者摆位误差差异无统计学意义（ $P { > } 0 . 0 5$ ），这一结果与丁伟杰等[16]研究一致，故将两组数据合并分析。通过Spearman相关分析探讨了摆位误差与移床差量之间的关联。结果显示，头脚和左右方向（LNG与ΔLNG，LAT与ΔLAT）的摆位误差与移床差量之间存在中等程度的相关性（R 值分别为0.393和0.361， $P { < } 0 . 0 0 1$ ），这证实了在这两个方向上移床操作与最终摆位结果之间存在内在联系。然而，其余两组变量对之间的相关性系数R均低于0.3，属于弱相关。尽管弱相关但仍具有统计学显著性（ $P { < } 0 . 0 5$ ）。这可能源于本研究的CBCT大样本量（ $n { = } 3 4 4 7$ ），当样本量非常大时，即使非常微弱的、在临床上可以忽略的关联， $P$ 值也很容易在统计学上显示出“显著性”。在统计学中， $P$ 值仅反映关联存在的证据强度，而相关系数R才代表关联的实际强度，因此在R值较小的情况下，其临床意义较为有限。

ROC曲线分析进一步验证了这一结论。ΔVRT、ΔLNG、ΔLAT的AUC值分别为0.536、0.625、0.606，根据AUC评价标准（0.9~1.0 为优秀，0.8~0.9 为良好，0.7~0.8 为一般，0.6~0.7为较差， $0 . 5 { \sim } 0 . 6$ 为无判别能力），所以腹背方向AUC值（0.536）在统计学中没有临床预测价值，而头脚和左右方向的AUC值（0.625和0.606）预测价值也仅属较差水平。相应的最佳截断值临床实用性有限，以腹背方向的为例，ΔVRT约登指数仅为0.074，这意味着在最佳截断值处，模型正确分类的能力只比随机猜测好 $7 . 4 \%$ ，缺乏实际应用价值。

ROC曲线AUC值偏低的结果，完美印证了相关性分析R值偏低的原因。相关性分析表明，移床差量与摆位误差之间虽然存在统计上可探测的关联，但这种关联强度太弱，导致其作为单一预测因子来判别是否发生摆位误差发生偏差（ $\geqslant 3 \mathrm { m m }$ ）的能力不足（AUC值均不理想）。这表明，移床差量本身虽然是一个相关的观测指标，但仅凭它不足以准确预测最终的摆位超差风险。摆位误差是一个由多种因素（如患者解剖结构变化、体表标记位移、设备精度及操作者技术等）共同影响的复杂结果[17]。

本研究的重要发现在于：移床差量变化对摆位误差的影响甚微，且未能得出移床差量增大导致摆位误差增大的结
