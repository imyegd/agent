# 1. 3 TEVA树脂对钼锝（铼）的分离

称取 $3 . 1 0 \mathrm { m g }$ 钼酸钠（精确至 $0 . 0 1 \mathrm { m g } ,$ ）与 $2 . 6 0 \mathrm { m g }$ 高铼酸钾（精确至 $0 . 0 1 { \mathrm { ~ m g } } { \cdot }$ ）溶于 $1 0 ~ \mathrm { m L }$ 水中。将$1 0 ~ \mathrm { m L }$ 钼锝（铼）溶液上柱，静置 $^ \textrm { \scriptsize 3 h }$ ，确保TEVA柱能对高铼酸根和钼酸根离子进行充分吸附，然后用$1 5 ~ \mathrm { m L }$ 硝酸溶液 $\mathrm { { 1 \ m o l / L } }$ ）进行洗脱并收集洗脱液。之后再次加入 $1 5 ~ \mathrm { m L }$ 硝酸溶液 $\left( 8 \mathrm { m o l / L } \right)$ ）进行洗脱并收集洗脱液。利用ICP-MS法测量洗脱液中钼、铼的浓度。将测定结果绘制成图。
