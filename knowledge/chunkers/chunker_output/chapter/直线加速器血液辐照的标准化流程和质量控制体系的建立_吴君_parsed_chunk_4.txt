# 1.1.3  蒸馏水和冰块

温度对血液成分的保存和安全性至关重要，全血与红细胞成分血的适宜储存温度为 $2 \sim 6 \ \mathrm { ~ \textdegree C }$ ，单采血小板和单采粒细胞为 $2 0 \sim 2 4 \mathrm { ~ \mathcal { C } ~ } ^ { [ 8 ] }$ ，故针对需要辐照的血液成分，准备不同温度的蒸馏水。本模拟研究中使用 $2 0 \sim 2 4 ~ \mathrm { ^ { \circ } C }$ 的蒸馏水。
