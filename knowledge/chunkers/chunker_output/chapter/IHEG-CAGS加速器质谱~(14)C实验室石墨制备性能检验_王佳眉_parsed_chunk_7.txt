# 2.2 IHEG-CAGSAMS ${ } ^ { 1 4 } \mathbf { C }$ 石墨化本底结果对比

本底校正包含石墨化过程的化学本底及仪器测量机器本底［21］ 。为扣除化学本底背景对样品的影响，实际石墨化过程中，未知样品均与空白样品（本底样品）同步进行石墨化处理。空白样品的测量平均值代表了整个化学流程的背景水平，该值将从相应未知样品的测试结果中予以扣除。沉积物TOC样品的化学本底选用邻苯二甲酸酐（PHA），通过高温氧化 $\longrightarrow$ 石墨化还原流程制备。地下水 DIC样品的化学本底选用 IAEA-C1，通过磷酸酸化 石墨化还原流程制备。为评价实验室石墨化本底控制能力，图 4展示了 IHEG-CAGSAMS $^ { 1 4 } \mathrm { C }$ 实验室运行处理的所有空白样品的 $\mathrm { p M C }$ 结果。经长期监测，IHEG-CAGSAMS $^ { 1 4 } \mathrm { C }$ 实验室的总体 PHA平均本底值为 $0 . ~ 1 7 { \pm } 0 . ~ 0 1 ~ \mathrm { p M C } ( \mathrm { n } = 6 4 )$ $\mathrm { n } = 6 4$ ），其中 VAC长期制备PHA平均本底值为 $0 . \ 1 6 { \pm } 0 . \ 0 1 \ \mathrm { p M C } ( \ \mathrm { n } = 1 5 )$ $\mathrm { n } = 1 5$ ），AGE3长期制备 PHA平均本底值为 $0 . \ 1 8 \pm 0 . \ 0 1 \ \mathrm { p M C } ( \mathrm { ~ n = ~ }$ $\mathbf { n } =$ 49）（图 4a）；总体 C1平均本底值为 $0 . 2 1 \pm 0 . 0 1$ pMC ${ \mathrm { n } } = 1 8$ ），其中 VAC长期制备 C1平均本底值为 $0 . \ 1 9 { \pm } 0 . \ 0 1 \ \mathrm { p M C } ( \mathrm { n } = 6 )$ $\mathbf { n } = 6 \mathbf { \Gamma } ,$ ），AGE3长期制备 C1平均本底值为 $0 . 2 2 { \pm } 0 . 0 1 \ \mathrm { p M C } ( \mathrm { n } = 1 2 )$ $\mathbf { n } = 1 2$ （图 4b）。结果表明，IHEG-CAGSAMS $^ { 1 4 } \mathrm { C }$ 实验室的两套石墨化系统均展现出优异的低本底特性，其中AGE3系统的低化学本底得益于 EA／CHS2简洁的高温氧化／磷酸酸化流程及载气输送；VAC系统则依靠分子泵持续提供的高真空 $\left( < 1 0 ^ { - 5 } ~ \mathrm { m b a r } \right)$ ）线路，在石墨化过程中展现出洁净的本底水平。石墨空白样品进行的常规测试显示，IHEG-CAGSAMS $^ { 1 4 } \mathrm { C }$ 实验室石墨化背景值 稳 定，对 应 的 等 效 年 龄 接 近 51000年，即51kaB．P．，表明其本底水平处于良好控制状态。综上所述，IHEG-CAGSAMS $^ { 1 4 } \mathrm { C }$ 实验室具备高质量
