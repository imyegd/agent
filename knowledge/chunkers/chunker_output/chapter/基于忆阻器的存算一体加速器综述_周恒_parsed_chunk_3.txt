# 忆阻器件

阻 变 随 机 存 取 存 储 器 （ resistive  random  accessmemory,  RRAM） 、 磁 阻 随 机 存 取 存 储 器（magnetoresistive random access memory, MRAM）和相变存储器（phase change memory, PCM）通过电阻状态存储信息，因此被称为忆阻器。它们可以通过设置（set）或重置（reset）电压来编程为高电阻（high resistancestate, HRS）或低电阻（low resistance state, LRS）状态。RRAM 单元由顶电极—中间氧化层—底电极组成，其电阻切换是通过导电细丝（conductive filament, CF）的形成或破坏来实现的，CF的尺寸决定了设备的电阻状态。MRAM 的信息存储在磁性隧道结（magnetic tunneljunction, MTJ）中，其由三层构成，包括 2 个铁磁层和夹在其中的氧化层。其中一个铁磁层是参考层，磁化方向固定；另一个是自由层，其磁化方向可根据电流方向自由旋转。当 2个层的磁化方向平行或反平行时，单元分别表现出低阻态和高阻态。PCM 利用了硫族化合物材料（如 $\mathrm { G e } _ { 2 } \mathrm { S b } _ { 2 } \mathrm { T e } _ { 5 }$ ）的非晶态（高阻）和晶态（低阻）之间的巨大电阻差异来存储数据。通过施加不同强度和脉宽的电脉冲，可实现对材料相态的可逆切换。表 1给出了 3 种忆阻器件的指标对比[1−2]。
