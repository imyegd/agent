# 1 仿真与实验

束源炉坩埚的几何形状与开口方式对束流在衬底上的分布起到了决定性的作用, 大尺寸分子束外延设备的实际使用过程中对衬底表面的薄膜沉积均匀性提出了很高的要求, 因此需要对束源炉喷射束流在衬底表面的分布情况进行仿真, 以此优化束源炉结构参数, 实现在大尺寸衬底上高均匀性薄膜沉积的理论设计。在本实验中利用COMSOL软件中的分子流模块进行 6英寸衬底上 $\mathrm { H g }$ 束流分布及薄膜沉积均匀性的仿真, 其计算原理基于Knudsen M提出的束源炉小孔蒸发模型[11], 该模型中束源炉蒸发分子通量 $T _ { e } ( \mathbf { s } ^ { - 1 } )$ 可由小孔面积 $A _ { e } ( \mathbf { m } ^ { 2 } )$ 与温度 $T$ 的关系式如式(1)所示。

$$
\Gamma_ {e} = A _ {e} \left(p _ {e q} - p _ {v}\right) \sqrt {\frac {N _ {A}}{2 \pi M k _ {B} T}} \tag {1}
$$

式中, $p _ { e q }$ 为饱和蒸汽压 $\mathrm { ( P a ) }$ , $p _ { \nu }$ 为出口压强 $\mathrm { ( P a ) }$ , $M$ 为分子质量 $\mathrm { ( k g / m o l ) }$ ), $N _ { A }$ 为阿伏伽德罗常数 $( \mathrm { m o l ^ { - 1 } } )$ ,$k _ { B }$ 为玻尔兹曼常数(J/K)。而由于在大尺寸衬底情况下, 分子束流从束源炉口到达衬底表面各点处距离不同, 其任一点处K分子通量大小 $\cdot N _ { K } ( \mathbf { m } ^ { 2 * } \mathbf { s } )$ 可由式(2)表示。

$$
N _ {K} = I _ {A} \left(\frac {r}{r _ {K}}\right) ^ {2} \cos \theta \cos (\theta + \varphi) \cos \delta \tag {2}
$$

式中, $r _ { \setminus } r _ { K }$ 分别为蒸发口到衬底中心点和任意一点K的距离, 单位为mm, $I _ { A }$ 为衬底中心点处束流大小,可由余弦出射定律确定, θ、 $\varphi$ 、 $\delta$ 分别为衬底中心点与 K 点、蒸发口与衬底中心点、蒸发口与 K 点的夹角, 单位为(°)。计算确定各点分子通量大小后可以从压强与分子通量的关系式求得衬底表面各点束流压强的大小分布, 压强P(Torr)与分子通量 $N _ { K }$ 的关系由式(3)给出。

$$
N _ {K} = \frac {P}{\sqrt {2 \pi M k _ {B} T _ {s}}} \tag {3}
$$

式中, $T _ { s } ( \mathrm { K } )$ 为衬底温度, $M$ 为分子质量 $\mathrm { ( k g / m o l ) }$ ), $k _ { B }$ 为玻尔兹曼常数(J/K), 在 HgCdTe 材料实际生长过程中, 实际生长温度通常在 $1 8 0 ~ ^ { \circ } \mathrm { C }$ 附近。综合式(1)～(3)可以看出, 束流在衬底表面分布大小与材料分子质量、蒸发口偏角、束流传输距离、束源炉工作温度及衬底温度有关。以适合 6英寸衬底外延生长的分子束外延设备为基础进行仿真研究, 构建的分子束外延生长室模型如图1所示。

分子束外延系统中, 束源炉坩埚的结构设计需根据蒸发材料的物理特性及工艺参数要求进行针对性优化。根据形状通常可分为3类, 即圆柱形坩埚、缩颈形坩埚和锥形坩埚。本研究采用的 $\mathrm { H g }$ 束源炉

为热蒸发式设计(不同于阀控式 Hg束源炉), 其坩埚采取复合结构, 以圆柱形石英坩埚为主体, 耦合倒梯形钽罩来对 Hg 束流分布及大小进行调控。这种复合式设计能够实现束流出射孔径及角度的灵活调控。本文中 Hg 束源炉坩埚模型如图 2所示, 图 2 中的右图为蒸发口钽罩锥形开口处的结构参数。
