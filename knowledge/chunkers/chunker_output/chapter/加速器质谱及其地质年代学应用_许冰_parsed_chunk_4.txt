# 2 加速器质谱的分类及分布

加速器可以分成两大类，分别是串列静电加速器质谱和回旋加速器质谱，其中串列加速器质谱在整个市场上占绝对优势。根据 2005年的统计，当时全球大约 80台串列式 AMS中只有一台回旋加速器质谱；而近 20年来，全球加速器质谱数量快速增加，目前增加到 160多台，全部是串列式加速器质谱［15］ 。 。

加速器质谱按端电压可分为 5类（表 1），分别是微型 $\mathit { \Omega } < 0 . 5 \mathrm { M V }$ ），小型（端电压 $0 . 5 \sim 1 . 0 \mathrm { M V }$ ），中型（3.0MV），大型 $( 5 \sim 1 0 \mathrm { M V }$ ）和超大型（14～$2 5 ~ \mathrm { M V }$ ）。在 2004年以前，生产加速器质谱的厂家只有两家，分别是美国 NEC（NationalElectrostaticCorporation） 和 荷 兰 的 HVEE （High VoltagEngineeringCorporation），这两家公司可以生产从小型到超大型的加速器质谱；2004年，第一台微型加速器质谱（Micadas系统）在苏黎世理工大学问世（端电压为 0.2MV）；2016年第二台开始运行，并从苏黎世理工分离，成立 Ionplus公司，成为第三家生产加速器质谱的商业公司。Ionplus专注于小微型专用加速器质谱的生产，开始时仅生产 $^ { 1 4 } \mathrm { C }$ 测量的专用加速器质谱，目前，其新一代加速器质谱可实现对$^ { 1 0 } \mathrm { { B e } }$ e、 $^ { 2 6 } \mathrm { A l }$ l、 $^ { 4 1 } \mathrm { C a }$ 、 $^ { 1 2 9 } \mathrm { I }$ I和部分锕系核素的测量。
