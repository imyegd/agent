# 3 中性束剥离的模拟研究

# 3.1 引出区的束流分布

使用多粒子跟踪方法对 CYCIAE-100 的引出过程进行模拟。模拟从初始能量为较低能量1 MeV 的粒子开始，逐步跟踪粒子的运动轨迹。在模拟过程中，初始粒子分布的选取至关重要：若初始发射度过小，将导致模拟结果偏离实际情况；而初始发射度过大，则会造成大量粒子在模拟过程中丢失，难以跟踪至引出区，降低模拟效率。初始粒子分布选取参考了 CYCIAE-100 加速器接收度的设计[12]。在相空间内生成服从均匀分布的$1 \times 1 0 ^ { 4 }$ 个粒子进行跟踪，如图 5 所示。其中参考粒

计算中采用回旋加速器单位，定义长度单位 $a _ { 0 }$ ：

$$
a _ {0} = \frac {c}{\omega_ {0}} \tag {8}
$$

式中： $c$ 为光速； $\omega _ { 0 }$ 为轨道角频率。 $a _ { 0 }$ 又称为回旋加速器的无穷大半径。计算中以 $m _ { 0 } c / a _ { 0 }$ 作为动量单位（ $m _ { 0 }$ 为粒子静止质量），因此动量单位量纲与长度相同。

使用粒子跟踪程序 OPAL-cycl[13] 开展多粒子模拟，得到剥离靶上的粒子分布，如图 6 所示。在模拟中，剥离点的半径设定为 $1 8 7 . 5 5 ~ \mathrm { c m }$ ，这一数值对应剥离膜半径的最小值。粒子在这一位置的

径向分布与该半径的最小值一致，并且在此位置粒子的分布最为集中，如图6a、c所示。

由于不同相位的粒子在穿越加速间隙时获得的能量增益不同，导致在束团加速过程中，具有不同初始相位的粒子在加速相同圈数后会产生较大的能散，即径向-纵向耦合效应。这种耦合效应使得中心相位的粒子在达 $1 0 0 \ \mathrm { M e V }$ 时能量增益最快，而相位较差的粒子则需经过更多的加速圈才能达到相同的能量。由于中心相位的粒子获得的能量增益最高，而两侧相位粒子能量增益逐渐递减，因此束团的能量-相位分布呈月牙形结构。加速圈数的差异产生了图 6d 中展示的多组束团分布。此外，束团的轴向初始分布是均匀的，位于相椭圆内。引出的过程中，轴向相椭圆在相空间内不断旋转，经过多圈叠加后，形成了一面积更大、分布更集中在中心位置的椭圆形分布，如图 6b所示。
