# 3 加速器质谱的主要构成

加速器质谱具有较强的抗同位素、同量异位素和多原子离子干扰能力［2］ 。如前文所述，加速器质谱可以对同位素比值低于 $1 0 ^ { - 1 5 }$ 的稀有同位素进行高精度测量（常规质谱测量的同位素比值一般不超过 ${ 1 0 } ^ { - 8 }$ ），这种超高的同位素灵敏度，与加速器质谱的复杂构成具有密切关系。下文将对加速器质谱的结构及其在同位素、同量异位素和同质分子抗干扰和识别能力方面的功能和贡献进行介绍。

加速器质谱总体上由五大单元组成，分别是离子源、注入和低能分析系统、加速器、高能分析系统和探测系统（图 1）。在样品进行加速器质谱测试前，一般需要对稀有同位素进行提纯制成靶样。目前多数实验室是固态离子源，因此，需要将稀有同位素进行富集并制成固态靶样。不同稀有同位素靶样的类型也不相同，如 $^ { 1 4 } \mathrm { C }$ 测量需要将样品制成石墨， $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l要分
