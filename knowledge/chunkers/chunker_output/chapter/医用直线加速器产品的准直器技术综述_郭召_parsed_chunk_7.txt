# 1.3.3 双层正交多叶光栅

双层多叶光栅的另一种布置形式是正交排布，即上下层叶片运动方向垂直。较早实现工程化应用的双层正交多叶光栅是Acculeaf［22-23］，其最大照射

野为 $1 0 0 ~ \mathrm { m m } \times 1 1 0 ~ \mathrm { m m }$ ，作为微型光栅配套在直线加速器中应用。图7是Acculeaf多叶光栅成野示意图，如图所示，两层叶片正交运动，两个方向都可以提高靶区的适形度，双层叠加遮挡了叶片间的漏辐射。国内外专利文献中也有对双层正交多叶光栅的构思保护，但研发出工程样机并投入临床应用的较少。苏州雷泰医疗科技有限公司实现了该技术的工程化应用，开发了具有自主知识产权的双层正交多叶光栅系统［24-25］，图8展示了该双层正交多叶光栅的结构，每层 51对叶片，共 204个叶片，最大照射野 $4 0 ~ \mathrm { c m } \times 4 0 ~ \mathrm { c m }$ ，上层光栅最小投影宽度 $6 \mathrm { m m }$ ，最高速度 $6 0 \ \mathrm { m m / s }$ ，下层光栅最小投影宽度 $4 \ \mathrm { m m }$ ，最高速度 $5 0 \ \mathrm { m m / s }$ 。这种正交布置形式在凹多边形或岛状靶区的适形精度上有一定优势。
