# 1 CYCIAE-100 中性化技术方案

北京放射性核束设施（Beijing Radioactive Ion-beam Facility, BRIF）是国防科技工业局在“十五”至“十一五”期间部署的重点科研基础设施[8]。该设施以中国原子能科学研究院的串列静电加速器为平台，整合了最高能量达 $1 0 0 \ \mathrm { M e V }$ 的质子回旋加速器 CYCIAE-100 作为驱动加速器。作为BRIF 的重要组成部分，CYCIAE-100 于 2014 年首次出束，可以提供能量 ${ 7 0 } \mathrm { \sim } 1 0 0 \ \mathrm { M e V }$ 、平均流强$2 0 0 { \sim } 5 0 0 \mu \mathrm { A }$ 的质子束[9]。CYCIAE-100 的主要参数列于表 1，采用外部离子源产生负氢离子束注入至加速器中，经过 300 余圈的加速后能量可达$1 0 0 \mathrm { M e V }$ ，通过剥离膜将负氢离子束的电子剥离形成质子束进行引出。

厚的剥离膜将氢原子束剥离成质子束。未被剥离的负氢离子将继续在加速器内旋转并被加速。当它们旋转 1 圈后，重新到达剥离膜，再次经历剥离过程，可能会被剥离成质子或氢原子。若这些粒子仍未被剥离，会继续这一过程直至发生剥离。

在本方案中，束流因多次穿越剥离膜将导致发射度增长。剥离膜厚度与中性化率负相关，但过薄的剥离膜会显著增加制造工艺难度、缩短使用寿命，同时需更多圈数才能实现束流完全剥离，进而加剧发射度增长。因此，首先选取合适参数的剥离膜，即在保证较高中性化率的同时满足工程可行性要求，并兼顾束流发射度。其次需针对发射度增长问题，通过优化引出区聚焦能力来有效抑制束流包络的扩张，减少束流损失。最终将给出优化后的束流关键参数，为后续工程设计提供依据。为保障实验测量精度，设计要求剥离后的氢原子束与质子束的横向尺寸控制在 $3 \mathrm { m m }$ 以内，避免束流传输损失或束流尺寸过大未被完全接收测量产生的误差。在此基础上，尽可能获得高中性化率。
