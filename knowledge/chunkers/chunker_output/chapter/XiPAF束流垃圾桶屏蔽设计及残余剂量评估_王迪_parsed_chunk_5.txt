# 2.2 材料选择

靶芯吸收了绝大部分束流能量，其材料遴选需兼顾低次级中子产额与低活化特性。中子产额的定义为平均每个质子入射靶材料产生的中子个数，利用FLUKA计算中子产额，产额值为靶材料外表面出射的中子数量。其中靶的形状为圆柱体，其高度为质子射程，而圆柱半径为质子射程的横向岐离，这样设置的目的是尽量减少次级中子与靶材料的进一步 反 应 。 首 先 使 用 SRIM（Stopping and Range ofIons in Matter）程序［12］ 可以快速得到 $1 0 { \sim } 2 0 0 \mathrm { M e V }$ 质子几种常见屏蔽材料（聚乙烯、石墨、铝、铁、铜、铅）中的射程（表1）及横向岐离（表2），作为FLUKA模拟计算中的几何模型参数。在FLUKA计算中，设置质子垂直入射靶材料的圆柱底面中心，使用USRBDX计数卡得到出射到圆柱体外的中子产额（图2）及中子能谱分布（图3）。

同时将 $3 0 \mathrm { M e V }$ 质子入射几种材料的中子产额计算值与文献［13］的参考数据进行了对比，如表3所示，可以看出模拟计算结果与前人的参考结果取得较好的一致性，当中子最低能量阈值取1 MeV时，最大偏差小于 $20 \%$ ，由于模拟计算与文献［13］的靶尺寸不一致，且文献［13］中实验测量的中子能量大于 $2 { \sim } 3 \ \mathrm { M e V }$ ，对于低于该能量的中子，采用模拟计算值，因此认为FLUKA计算结果与文献［13］中的实验结果是基本相符的。

由图2可以看出，中子产额与质子能量是正相关的。总体来看，质子入射聚乙烯的次级中子产额

最少，其次是石墨，而金属靶材料的产额会更高。图3中，金属材料产生的高能次级中子数量低于石墨和聚乙烯，这部分对高能辐射屏蔽有一定贡献，但是考虑到金属靶芯带来的残余剂量将大于原子序数更低的石墨、聚乙烯等材料，因此靶芯材料应在石墨和聚乙烯中选择。由于 $2 0 0 \mathrm { M e V }$ 质子入射聚乙烯与石墨的次级中子能谱几乎相同，且前者的中子产额更低，因此选择聚乙烯作为靶芯材料。

对于质子与靶芯作用产生的次级高能中子，其能量损失以非弹性散射为主，需要使用重元素材料快速消耗快中子的能量，考虑成本、工艺、生物毒性
