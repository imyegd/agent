# 4 加速器质谱在地质年代学中的应用

加速器质谱在地学中的应用主要是测量宇宙成因核素。加速器质谱自 20世纪 70年代末应用于地球科学研究，其测定核素种类快速增加，应用领域也得到了极大扩展。在核素年代学、日－地活动示踪等方面填补了空间和地球科学技术的许多盲区。目前已涉及到地球和行星科学的各个领域，包括地质年代学、全球变化、生命及人类起源演化、文明起源、板块运动、地球深部动力学、空间物理学、比较行星学、矿产资源探测、地震和水土侵蚀等领域，极大地推动了地球科学的发展，促成了一系列重大科学突破，显著拓展了人类的认知范围。由于本专辑中，其它文章会对相关研究领域具体内容进行详细介绍；另外，在许多综述性文章中，对宇宙成因核素的具体应用方法均做过系统介绍。因此，本文只对加速器质谱在地质年代学领域的应用进行简要介绍，并着重于对其基本原理进行介绍，希望对从事相关研究的学者起到一定的启发作用。

宇宙成因核素是通过原子与宇宙射线相互作用而产生的稀有同位素，这些核素与其稳定同位素的比值一般 $\leqslant 1 0 ^ { - 1 2 }$ ，除惰性气体宇宙成因核素外，加速器质谱是测量宇宙成因核素的主要技术方法。宇宙射线是高动能带电粒子，大多来自我们银河系内的超新星。当宇宙射线进入地球时，与大气中物质碰撞，发生一系列次级反应，产生次级粒子；这些粒子会与大气中的氮原子和氧原子等发生碰撞，从而产生诸如 $^ { 1 4 } \mathrm { C }$ 和 $^ { 1 0 } \mathrm { { B e } }$ e等大气成因宇宙成因核素；随后，一些粒子最终到达地球表面，与地球表层岩石矿物中的原子相互作用，生成就地成因核素，如10Be、 $^ { 1 4 } \mathrm { C }$ 、$^ { 2 6 } \mathrm { A l }$ l和 $^ { 3 6 } \mathrm { C l }$ l等核素。宇宙成因核素的产率受宇宙射线强度、太阳活动强度、地磁场变化、矿物中靶元素浓度、遮蔽和埋藏深度等因素的影响［44］ 。

加速器质谱在地质年代学方法的应用也集中在放射性宇宙成因核素年代学方面。根据放射性同位素定量原理 $\boldsymbol { N } = \boldsymbol { N } _ { 0 } \mathrm { e } ^ { - \lambda t }$ t， $N _ { 0 }$ 是样品封闭前放射性核素的初始活度或浓度， $N$ 是经历时间 $t$ t衰变后的剩余活度或浓度），如果知道宇宙成因核素初始活度或衰变子核的浓度，就可以通过测量其子核浓度，得到样品的年代。常规的放射性同位素定年，如 U系定年，多根据定年矿物中的子核浓度来进行定年，定年的前提是子核和母核元素高度不相容，在矿物形成过程中，子核和母核元素在矿物中高度分异，子核的初始值为零或可以忽略不计。在实际应用中，通过对初始子核的浓度厘定，如在 $^ { 2 3 4 } \mathrm { U } - ^ { 2 3 0 } \mathrm { T h }$ 定年过程中，可通过测量矿物中的232Th活度，对矿物中初始 $^ { 2 3 0 } \mathrm { T h }$ 进行估算［45］ 。而宇宙成因核素年代学方法，尽管一些核素（如 $^ { 1 4 } \mathrm { C }$ 定年）也是根据核素的放射性衰变规律进行年代厘定，但其具体的定年方法与传统放射性同位素定年方法并不完全相同；另外，一些核素的定年方法和原理与传统放射性同位素定年方法完全不同，拓展了放射性定年方法及其应用领域。

宇宙成因核素年代学方法概括起来可以分为 3类：1）放射性定年；2）暴露年代学方法（暴露年代学）；3）埋藏年代学方法（埋藏年代学）。宇宙成因核素放射性定年方法，目前主要是 $^ { 1 4 } \mathrm { C }$ 定年，也是现有加速器质谱测定的主要核素。尽管全球有 160多台加速器质谱，但在这些质谱的应用中， $^ { 1 4 } \mathrm { C }$ 测量的工作量占 $9 0 \%$ 以上；其次是暴露年代学和埋藏年代学宇宙成因核素的测量（10Be、26Al等）。
