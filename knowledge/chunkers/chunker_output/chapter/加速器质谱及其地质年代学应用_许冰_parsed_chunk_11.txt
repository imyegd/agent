# 3.5.1 气体电离探测器

气体电离探测器的工作原理是基于电离辐射的技术方法。经过高能系统筛选后的离子进入气体离子探测器，使气体室内的气体发生电离，产生离子－电子对。如果对探测器气体室施加合适电场，离子和电子会分别向阴极和阳极漂移并收集。电荷信号通过配备电荷敏感前置放大器、脉冲整形放大器和模数转换器（ADC）等适当电子设备，将电荷脉冲整合并数字化处理，得到入射离子的原子序数、能量和能量衰减等信息。

气体电离探测器由一个充气的封闭容器组成。

该容器或是密封的，或设计成能够使填充气体持续流动的状态。该气体体积内，在电极之间施加电场，探测器的离子化室内就会产生均匀电场，其方向与入射离子束流方向垂直。气体容器的外壁通常充当其中一个电极，即阴极；用一根金属棒、一个网格或位于气体体积中间的板充当阳极。尽管气体电离计的设计存在多种不同形状，但圆柱形的系统较为常见。气体电离检测器系统对于特定种类及能量的粒子的适用性取决于：1）待电离的填充气体的类型（成分、压力）；2）应用电场强度；3）探测器体积和电极的尺寸、形状和几何结构；4）围绕探测器气体的封装材料的类型和厚度等。

气体电离探测器主要由探测器气体和电子设备及数据采集系统组成。在低能状态下，有些探测器需加入一个探测器窗口。

离子进入气体室，其入射方向与电场方向垂直。在气体室内，高能离子使气体室内气体发生电离，产生离子－电子对；与束流方向垂直的电场会使电子向阳极移动。

目前，加速器质谱，特别是高能加速器质谱的探测器，多采用多电极气体电离探测器。多电极电离室由一个电极组成，该电极沿离子轨迹的总体方向被分割成若干独立的部分（处于同一电位但彼此绝缘）。这一探测器最初也是为重离子核物理实验而开发的［1，34～35］ ，随后应用于加速器质谱［36～37］ ；另外，电极段的单独信号与沿轨迹的相应能量损失成正比，为同位素识别提供了离子原子序数物理量（Z）的有力特征。该原理被澳大利亚国立大学Fifield等［38］ 发现，认为锯齿形电极能给出位置敏感信号，而位置信息在识别 $^ { 3 6 } \mathrm { C l }$ l离子中起到重要作用。多电极电离室既可以作为独立探测器使用［39］ ，也可用于更复杂的探测系统；其可以和充气磁体组合形成充气磁场探测器［40］ ，该探测器可在充有气体的恩格分极磁谱仪的焦平面中检测重放射性核素（如$^ { 5 3 } \mathrm { M n }$ 和 $^ { 6 0 } \mathrm { F e }$ ）。

最常用的电离气体是丙烷（propane），但异丁烷（isobutane）和由 $9 0 \%$ 的氩气（Ar）和 $1 0 \%$ 的甲烷（ $\mathrm { C H } _ { 4 }$ ）组成的混合气体也被使用。气体的电离效率，即产生一个电子－离子对所需的平均能量取决于气体类型，一般在 20～40电子伏特之间（氩气为$2 6 . 4 \ \mathrm { e V }$ ，异 丁 烷 为 $2 3 . 4 ~ \mathrm { { \ e V } }$ ），电 离 能 分 别 为$1 5 . 8 \mathrm { e V }$ 和 $1 0 . 6 \mathrm { e V }$ 。在阳极处收集的电子电荷信息，经前置放大器、脉冲整形放大器和模数转换器（ADC）等适当电子设备，将电荷脉冲整合并数字化

处理，得到入射离子的原子序数、总能量、能量衰减和漂移距离等指标，用于识别稀有同位素与同量异位素离子。
