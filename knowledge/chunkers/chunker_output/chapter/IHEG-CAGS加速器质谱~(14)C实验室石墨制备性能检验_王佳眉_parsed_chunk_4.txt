# 1.2 VAC石墨化流程

该系统主要由进样装置、真空泵组、冷阱、 $\mathrm { C O } _ { 2 }$ 流量 计、石 英 管、阀 门、真 空 计 及 还 原 装 置 构 成（图 3）。根据功能模块，可划分为 3个单元：真空保持单元（A）、 $\mathrm { C O } _ { 2 }$ 纯化单元（B）和 $\mathrm { C O } _ { 2 }$ 还原单元（C）。整个装置以高硼玻璃为主要结构材料，极限真空度 $< { 1 0 } ^ { - 5 }$ mbar，真空计实时监测便于直接观察纯化过程。在样品制备前，首先将装有氧化铜及银丝的石英管置于 $8 5 0 \ \mathrm { { ‰} }$ 的高温炉中 $^ \textrm { \scriptsize 5 h }$ ，以去除潜在的有机污染物；然后将固体有机碳样品导入石英管，并在真空条件下火焰密封。真空燃烧后样品中的碳被氧化成 $\mathrm { C O } _ { 2 }$ ，然后 $\mathrm { C O } _ { 2 }$ 通过石英管破碎装置被引入真空系统。溶解性无机碳样品或碳酸盐置于接入真空系统的酸解管中，与优级纯磷酸混合反应，溶解性无机碳释放产生的 $\mathrm { C O } _ { 2 }$ 进入纯化流程。$\mathrm { C O } _ { 2 }$ 气体首先流经 $- 9 0 ~ \mathrm { { ^ circ C } }$ 的乙醇液氮冷阱以彻底除去水蒸气，随后进入 $- 1 9 6 ^ { \circ } \mathrm { C }$ 液氮冷阱，多次的冷凝

升华循环可以纯化 $\mathrm { C O } _ { 2 }$ ，在此过程中，不可冷凝气体（如 $\mathrm { N } _ { 2 } \setminus \mathrm { O } _ { 2 }$ ）被真空泵抽除［15］ 。将纯化的 $\mathrm { C O } _ { 2 }$ 转移到定容管中，通过测量 $\mathrm { C O } _ { 2 }$ 压力来确定 C含量。根据样品需求量将 $\mathrm { C O } _ { 2 }$ 转移至还原管或备份储存。使用液氮冷阱将 $\mathrm { C O } _ { 2 }$ 与催化剂 Fe及还原剂 $Z \mathrm { n }$ 混合，并用火焰密封还原管［16］ 。密封的还原管放置在高温炉中加热，在催化剂 Fe及还原剂 Zn的作用下， $\mathrm { C O } _ { 2 }$ 转化成石墨，随后将石墨和铁粉压入靶锥后装进 AMS进行测量。VAC系统可根据固体 TOC、液体 DIC或气体 $\mathrm { C O } _ { 2 }$ 等样品来源选择相应的进样途径；两台真空泵提供的高真空环境有效避免了样品纯化过程中的现代碳污染；离线进行的氧化、纯化与还原步骤分离，便于针对不同样品特性定制纯化与还原方案，从而提升石墨化效率与灵活性。
