# 3.1 BEPC 余热资源量化分析

BEPC 是一台粲物理能区国际领先的对撞机和高性能的兼用光同步辐射装置，于 1988 年建成，并于 2008 年完成升级改造。BEPC 投入运行后迅速达到设计指标，成为世界八大高能加速器中心之一，在世界高能物理领域占有一席之地[18]。BEPC采用“一机两用”的运行模式：兼用模式优先用于高能物理对撞实验，同时也提供同步辐射光；专用模式专用于同步辐射研究。

BEPC 每年运行约 10 个月，每周二上午为例行停机检修或机器研究。对撞模式下加速器在粲物理能区下运行并扫描不同的能量点，以获取积分亮度和实验数据；同步辐射时采取恒流注入模式。BEPC 工艺冷却水余热主要来源于磁铁、功率源及高频等系统。根据加速器设计资料[19]，BEPC 储存环中各种不同类型的磁铁共计 387 台，其中偏转（二极）磁铁、四极磁铁、六极磁铁在额定工况下的理论发热功率约为 $2 0 2 0 \mathrm { k W }$ 。冷却塔进、出口平均温度约为 $3 2 / 2 9 \ ^ { \circ } \mathrm { C }$ ，冷却水循环量约为 $6 0 0 ~ \mathrm { m } ^ { 3 } / \mathrm { h }$ ，属于典型低品位热源。为获取客观设计依据，BEPC 在 2024-2025 供暖季的冷却塔进水温度实测曲线见图 1。超过 40 天的监测数据显示，冷却塔进水温度稳定维持在 $3 2 \mathrm { { ^ \circ C } }$ 左右。该实测结果从两方面为系统提供了关键支撑：其一，证实了 BEPC余热温度的稳定性，保障了热泵系统的高效、可靠运行；其二，为后续热泵选型提供依据。

考虑加速器实际运行负荷与设备的同时使用系数（取 0.85），并综合冷冻站运行监测数据，估算得到 BEPC工艺冷却水系统的可回收余热功率约为 $2 ~ 1 0 0 \mathrm { k W }$ 。
