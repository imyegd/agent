# 2 Xi’an-AMS 的性能水平和验收检测

# 2.1 系统测试

验收测试了四个核素的同位素比值的测量精度和本底极限。在端电压锻炼到 3.3MV，并在 3MV下稳定 4h 后， 按合同规定，在 $2 . 5 { \mathrm { - } } 2 . 6 { \mathrm { M V } }$ 端电压下测试四个核素的测量精度和本底。根据我们的要求，还在 3 MV端电压下测量了 $^ { 2 6 } \mathrm { A l }$ 的精度。测试时， $^ { 9 } \mathrm { B e O } ^ { - }$ 、 $^ { 1 2 } \mathrm { C } ^ { \ast }$ 、 $^ { 2 7 } \mathrm { A l } ^ { - }$ 和 $^ { 1 2 7 } \mathrm { I ^ { - } }$ 的束流强度分别为1.7、38、0.25、 $2 . 5 \mu \mathrm { A }$ 。 $^ { 1 2 } \mathrm { C } ^ { \ast }$ 束可达 ${ \mathrm { > } } 1 0 0 \mu \mathrm { A }$ ，测试时用 $3 8 \mu \mathrm { A }$ ，此时 $^ { 1 4 } \mathrm { C }$ 计数率为 $1 5 0 \mathrm { { s } ^ { - 1 } }$ 。Al-束低于合同规定，但已达文献值的一般水平。现代碳样品置于12 个样品座中，每天测 6 个，连续测两天，以测试加速器关停和重新启动后数据的重复性。其它三个核素的精度要求较低，只在四个样品座中测试。验收测试进行的步骤和计算方法见 $\ S 2 . 2$ 。

全部验收测试结果列于表 2，四个核素的测量精度和最小可测的本底值都达到了合同规定的指标。 $^ { 1 4 } \mathrm { C } / ^ { 1 2 } \mathrm { C }$ 比值达到 $0 . 2 \%$ 测量精度[17-19]，已非常接近计数的统计误差，表明 AMS 本身的波动引起的 $^ { 1 4 } \mathrm { C } / ^ { 1 2 } \mathrm { C }$ 比值的不确定度 $< 1 \text{‰}$ 。连续两天 $^ { 1 4 } \mathrm { C } / ^ { 1 2 } \mathrm { C }$ 比值平均值分别为 $1 . 4 4 3 4 3 \times 1 0 ^ { - 1 2 }$ 和 $1 . 4 3 6 8 9 \times 1 0 ^ { - 1 2 }$ ，两天的重复性为 $0 . 4 5 \%$ 。

全部验收测试工作延续了半年多时间，主要问题是最小可测的 $^ { 1 0 } \mathrm { B e } / ^ { 9 } \mathrm { B e }$ 比值达不到合同规定的$3 \times 1 0 ^ { - 1 5 }$ ，虽然提供的试验样品都声称是 ${ 1 0 } ^ { \cdot 1 5 }$ 量级。因为长期以来，人们大多认为，只有在 5MV 的 AMS上才有可能测到 ${ 1 0 } ^ { \cdot 1 5 }$ 量级的 $^ { 1 0 } \mathrm { B e } / ^ { 9 } \mathrm { B e }$ 比值的本底，所以在3MV的Xi’an-AMS上能否达到 ${ 1 0 } ^ { \cdot 1 5 }$ 量级成为衡量方案选择的正确性的一个关键指标。文献报道表明，很多因素会引起对 $^ { 1 0 } \mathrm { { B e } }$ 的干扰(见§2.3)，而在BeO样品制备中最大可能地减少B含量已成为达到 ${ 1 0 } ^ { \cdot 1 5 }$ 量级的关键技术，成为检验 AMS 设备实际探测 $^ { 1 0 } \mathrm { { B e } }$ 灵敏度的不可捉摸的因素。幸而著名的AMS 专家、法国的 Dr. Grant Raisbeck 主动地把他仅存的低 ${ } ^ { 1 0 } \mathrm { B }$ 含量的 BeO样品寄给了我们。我们极为仔细地把样品压制到样品座中，并彻底清洗了离子源，Xi’an-AMS 终于显示了平均为 $3 . 6 5 \times 1 0 ^ { - 1 5 }$ 的$^ { 1 0 } \mathrm { B e } / ^ { 9 } \mathrm { B e }$ 比值的本底。20 多年来，对于 Raisbeck 组报道[20]在 2.2MV 端电压下测得 ${ < } 3 { \times } { 1 0 } ^ { - 1 5 }$ 的 $^ { 1 0 } \mathrm { B e } / \mathrm { B e }$ 的本底，国际 AMS 界的不少人一直持怀疑态度。为此，我们特意重复测量了五次，每次持续约 1h，测得的数据分别为： $3 . 4 2 \times 1 0 ^ { - 1 5 }$ 、 $4 . 8 4 \times 1 0 ^ { - 1 5 }$ 、$4 . 1 3 \times 1 0 ^ { - 1 5 }$ 、 $3 . 5 6 \times 1 0 ^ { - 1 5 }$ 和 $2 . 2 8 \times 1 0 ^ { - 1 5 }$ 。由于本底计数太少，统计误差范围在 $30 \%$ $30 \% - 4 0 \%$ 。
