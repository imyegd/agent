# 加速器质谱及其地质年代学应用*

许冰1，2 ，徐胜3 ，付云翀1，4 ，陈实1，2

（1．中国科学院地质与地球物理研究所，岩石圈演化与环境演变全国重点实验室，北京 100029；2．中国科学院大学地球与行星科学学院，北京 100049；3．天津大学地球系统科学学院，表层地球系统科学研究院，天津 300072；

4．中国科学院地球环境研究所，黄土科学全国重点实验室，西安 710061）

摘要：加速器质谱（AMS）凭借其超高灵敏度和卓越的同位素分辨能力，已成为超低含量稀有同位素测量的主要技术手段，并在某些情况下成为唯一可行的探测方法。当前，加速器质谱的同位素丰度灵敏度 $\leqslant 1 0 ^ { - 1 5 }$ 量级，能够实现对千原子级别的宇宙成因核素进行精确测量。自 20世纪 70年代串列式加速器质谱问世以来，该技术及其应用领域取得了显著发展；如今，加速器质谱已成为核科学技术中对多学科发展具有重要推动作用的关键技术之一，其应用范围几乎涵盖了包括技术圈在内的所有科学与技术领域。文章系统回顾了加速器质谱的发展历程，阐述了 20世纪 40年代 $^ { 1 4 } \mathrm { C }$ 定年技术的出现及其测量需求对加速器质谱研发的关键推动作用；重点介绍了加速器质谱的核心构成单元及其工作原理，特别是各单元在提升系统抗同位素、同量异位素及同质分子干扰能力中的作用机制；同时，概述了加速器质谱在地球科学领域的应用，并对基于该技术的 $^ { 1 4 } \mathrm { C }$ 年代学、暴露年代学和埋藏年代学方法进行了详细综述。

关键词：加速器质谱；稀有同位素；宇宙成因核素； $^ { 1 4 } \mathrm { C }$ ；暴露年代学；埋藏年代学
