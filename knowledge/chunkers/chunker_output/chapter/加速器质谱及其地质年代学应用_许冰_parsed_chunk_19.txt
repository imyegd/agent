# 4.3.3 等时线方法

等 时 线 年 代 学 方 法 是 Balco和 Rovey［59］提 出的，首先应用于土壤和沉积剖面不同深度样品，通过多样品分析来进行埋藏年代计算，其有两个重要前提［59］ ：1）无侵蚀，暴露时间（t）足够短，暴露过程中核素衰变量可以忽略不计；2）埋藏足够深，埋藏后产率可以忽略不计。在满足上述两个条件下，公式（16）和（17）变为

$$
N _ {1 0} = \left(N _ {1 0, \text {i n h}} + P _ {1 0} t _ {\mathrm {e}} \mathrm {e} ^ {- Z / \Lambda_ {\mathrm {i}}} \right) \mathrm {e} ^ {- \lambda_ {1 0} t _ {\mathrm {b}}} \rightarrow t _ {\mathrm {e}} \mathrm {e} ^ {- Z / \Lambda_ {\mathrm {i}}} =
$$

$$
\left(N _ {1 0} \mathrm {e} ^ {\lambda_ {1 0} t _ {\mathrm {h}}} - N _ {1 0, \text {i n h}}\right) / P _ {1 0} \tag {22}
$$

$$
N _ {2 6} = \left(N _ {2 6, \text {i n h}} + P _ {2 6} t _ {\mathrm {e}} \mathrm {e} ^ {- Z / A _ {\mathrm {i}}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \tag {23}
$$

公式 （22）～（23）中， $N _ { \mathrm { 1 0 , i n h } }$ 和 $N _ { 2 6 , \mathrm { i n h } }$ 为 继 承 组分， $P _ { \mathrm { ~ i ~ } } t _ { \mathrm { ~ e ~ } } \mathrm { e } ^ { - Z / A _ { \mathrm { ~ i ~ } } }$ i为埋藏前最后一次暴露过程中产生的核素量（atoms／g）， $Z$ 是质量深度 $( \mathbf { \Delta g } / \mathbf { c m } ^ { 2 }$ ）。将公式（22）带入公式（23），得到如下：

$$
N _ {2 6} = \left(N _ {2 6, \text {i n h}} + P _ {2 6} \left(N _ {1 0} \mathrm {e} ^ {\lambda_ {1 0} t _ {\mathrm {b}}} - N _ {1 0, \text {i n h}}\right) / P _ {1 0}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \rightarrow
$$

$$
N _ {2 6} = \left(N _ {2 6, \text {i n h}} + R _ {\text {i n t}} \left(N _ {1 0} \mathrm {e} ^ {\lambda_ {1 0} t _ {\mathrm {b}}} - N _ {1 0, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \rightarrow \right.
$$

$$
N _ {2 6} = R _ {\text {i n t}} N _ {1 0} \mathrm {e} ^ {- (\lambda_ {2 6} - \lambda_ {1 0}) t _ {\mathrm {b}}} + \left(N _ {2 6, \text {i n h}} - R _ {\text {i n t}} N _ {1 0, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \tag {24}
$$

公式（24）表明，如果测量具有相同埋藏年龄的

样品，测量获得的 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l浓度具有线性关系，斜率为 $R _ { \mathrm { i n t } } \mathbf { e } ^ { - ( \lambda _ { 2 6 } - \lambda _ { 1 0 } ) t _ { \mathrm { b } } [ 5 9 ] }$ ，且过点 $N _ { 2 6 , \mathrm { i n h } }$ ， $N _ { \scriptscriptstyle { 1 0 , \mathrm { i n h } } } \ )$ ）。因此，通过测量多个样品，进行直线拟合，就能得到其斜率 $R _ { \mathrm { { m } } }$ ，进而获得其埋藏年龄：

$$
t _ {\mathrm {b}} = \ln \left(R _ {\mathrm {m}} / R _ {\mathrm {i n t}}\right) / \left(\lambda_ {2 6} - \lambda_ {1 0}\right) \tag {25}
$$

Grang er［58］将这一方法延伸到考古年代学中。考古遗址中，地层埋藏的石英样品 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l，如果矿物 的 埋 藏 过 程 和 时 间 相 同，则 样 品 埋 藏 后（postbural）的产率相同，即样品中的核素浓度由埋藏时的初始浓度和埋藏后的浓度 $( N _ { \mathrm { i , p b } } )$ ）产生的组分所组成，公式如下：

$$
\begin{array}{l} N _ {1 0} = \left(N _ {1 0, \text {i n h}}\right) e ^ {- \lambda_ {1 0} t _ {\mathrm {b}}} + N _ {1 0, \mathrm {p b}} \longrightarrow N _ {1 0} - N _ {1 0, \mathrm {p b}} \\ = \left(N _ {1 0, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {1 0} t _ {\mathrm {b}}} \tag {26} \\ \end{array}
$$

$$
\begin{array}{l} N _ {2 6} = \left(N _ {2 6, \text {i n h}}\right) e ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} + N _ {2 6, \mathrm {p b}} \rightarrow N _ {2 6} - N _ {2 6, \mathrm {p b}} \\ = \left(N _ {2 6, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \tag {27} \\ \end{array}
$$

由公式（26）和（27）得到：

$$
\begin{array}{l} \frac {N _ {2 6} - N _ {2 6 , \mathrm {p b}}}{N _ {1 0} - N _ {1 0 , \mathrm {p b}}} = \frac {N _ {2 6 , \mathrm {i n h}}}{N _ {1 0 , \mathrm {i n h}}} \mathrm {e} ^ {- (\lambda_ {2 6} - \lambda_ {1 0}) t _ {\mathrm {b}}} \\ = R _ {\mathrm {i n h}} \mathrm {e} ^ {- (\lambda_ {2 6} - \lambda_ {1 0}) t _ {\mathrm {b}}} \tag {28} \\ \end{array}
$$

与土壤和沉积地层相同，对于地层中具有相同埋藏后产生组分的不同样品， $N _ { 2 6 }$ 和 $N _ { 1 0 }$ 呈线性关系，斜率为 R e－（λ26－λ10）tb ［59］ 。 $R _ { \mathrm { i n } } \mathrm { e } ^ { - ( \lambda _ { 2 6 } - \lambda _ { 1 0 } ) t _ { \mathrm { b } } [ 5 9 ] }$ 因此，通过拟合两核素之间线性关系，获得其斜率，就可计算埋藏年龄。

对于继承组分较小的样品，可以根据每个样品的测量值 $R _ { \mathrm { A B } } ( t _ { \mathrm { b } } ) )$ ）计算埋藏年龄，所得数据 $^ { 1 0 } \mathrm { { B e } }$ 和$^ { 2 6 } \mathrm { A l }$ l应位于通过原点的直线上，而有继承组分时，数据不会通过原点；但在实际应用中，由于继承、埋藏后组分和侵蚀速率的影响，可能造成核素初始比值的变化［58］ 。对于上述因素的影响，可以通过多次线性拟合、继承和埋藏组分及侵蚀速率估算，然后校正测量值，经过多次迭代后最终获得可信的埋藏年龄［58～59］ 。 。

等时线方法的一个重要前提是样品经历相同的地质过程，样品经历暴露埋藏后其核素浓度应位于一条直线［58～59］ 。因此，样品的核素浓度是否位于同一直线是判别其是否符合等时线年代学方法的依据。如果样品核素浓度非常离散，表明样品经历了不同且复杂的暴露和／或埋藏过程，不适合进行等时线年龄拟合。

$^ { 2 6 } \mathrm { A l / ^ { 1 0 } B e }$ 的定年范围取决于 $^ { 2 6 } \mathrm { A l }$ l的半衰期和测试精度［53］ 。假设 $R _ { \mathrm { A B } } \big ( t _ { \mathrm { b } } \big )$ ）的测量精度为 $5 , 0 \%$ ，造成的埋藏年龄的误差在 10万年，那么，这种方法的下限年龄为 10万年，上限年龄为 $5 . 0 \mathrm { M a } ^ { [ 5 3 ] }$ 。这主要是由于超过 $5 , 0 \mathrm { M a }$ 时， $^ { 2 6 } \mathrm { A l }$ l丰度低于仪器的探测水

平［53］ 。在实际应用中，由于 $^ { 2 6 } \mathrm { A l }$ l初始浓度的变化，其定年范围可能更小［58］ 。

由于埋藏年龄依赖于 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l的衰变，因此精确知道它们的衰变常数和半衰期尤为重要［53］ 。对于 $^ { 1 0 } \mathrm { { B e } }$ e的半衰期目前存在较大争议，早期认为是$1 . 5 1 { \pm } 0 . 0 6 \mathrm { M a } ^ { [ 6 2 ] }$ ，目前仍被广泛应用；Nishiizum等［63］ 的研究认为是 $1 . 3 6 { \pm } 0 . 0 7 \ \mathrm { M a }$ ；最近一些学者认为 $^ { 1 0 } \mathrm { { B e } }$ e半衰期为 $1 . 3 9 { \pm } 0 . 0 1 \mathrm { M a } ^ { [ 6 4 \sim 6 5 ] }$ 。因此，在报告埋藏年龄时必须对所用的 $^ { 1 0 } \mathrm { { B e } }$ e半衰期进行说明，而且核素浓度和 $^ { 2 6 } \mathrm { A l / ^ { 1 0 } B e }$ 的产率比值必须与所用半衰期一致。
