# 2.1 基于氦质谱法的典型漏点特征分析与处置方案

# 2.1.1 密封垫圈安装缺陷与密封性能优化

密封垫圈安装缺陷是真空系统法兰连接处最主要的泄漏诱因。HEPS 真空系统安装初期，法兰连接处频发不同程度的泄漏现象，其中多数泄漏可通过进一步均匀紧固法兰螺栓消除，部分泄漏则需更换密封垫圈方可达标。

典型案例：储存环弧区 R46 周期真空盒VC11 和 VC12 的法兰连接处，氦质谱检漏仪检漏显示漏率为 $2 . 3 { \times } 1 0 ^ { - 9 } \mathrm { P a } { \cdot } \mathrm { m } ^ { 3 } / \mathrm { s }$ ，初步拧紧法兰螺栓后漏率下降至 $8 . 5 { \times } 1 0 ^ { - 1 1 }$ Pa·m³/s，但仍未达标。继续均匀拧紧法兰的螺栓，漏

率进一步下降至 $< 9 . 9 { \times } 1 0 ^ { - 1 4 } \mathrm { P a } { \cdot } \mathrm { m } ^ { 3 } / \mathrm { s }$ ，满足设计要求。而有的法兰即使将螺栓拧至最大扭矩，仍有漏气情况，更换新的金属密封垫圈后，漏率才达到合格。此案例表明，密封垫圈的安装质量直接影响法兰连接的气密性，严格按照安装规程操作至关重要。
