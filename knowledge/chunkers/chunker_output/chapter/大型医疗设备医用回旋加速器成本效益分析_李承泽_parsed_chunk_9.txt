# 2.2生产单批次18F-FDG 盈亏平衡点计算

根据深圳市医疗服务项目价格标准， $^ { 1 8 } \mathrm { F } .$ -FDG 的单支（10mCi）价格为1 000元。单批次生产 $^ { 1 8 } \mathrm { F } .$ -FDG盈亏平衡点计算见表2。回旋加速器运营 $1 \sim 3$ 年、$4 \sim 8$ 年、9年以后3阶段的单批次生产总成本分别为 867.14 万元、1 035.49 万元和 509.39 万元，对应的盈亏平衡点分别为8 672人次/年、10 355人次/年和5 094人次/年。当患者实际数量 $\geqslant$ 盈亏平衡点时，自主生产 $^ { 1 8 } \mathrm { F } \cdot$ -FDG的成本低于从外购药成本。
