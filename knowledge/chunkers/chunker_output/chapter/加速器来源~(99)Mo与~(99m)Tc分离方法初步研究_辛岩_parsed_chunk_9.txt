# 2. 2 TEVA树脂柱对钼铼的分离效果

图 2 是 $1 \ \mathrm { m o l / L }$ 和 $8 \ \mathrm { m o l / L }$ 硝 酸 对 钼 铼 洗 脱曲线，从图2a可知，以 $1 \ \mathrm { m o l / L }$ 硝酸为洗脱液，铼几乎全部保留在树脂柱上，而大部分的钼酸钠则被洗脱，对该图积分可知，洗脱所得的钼的总量为$1 9 . 1 9 \mathrm { \ m g }$ ；而由图2b可看出， $8 \ \mathrm { m o l / L }$ 硝酸为洗脱液则恰恰相反，图2曲线积分并乘以体积可得，洗脱所得高铼酸根约为 $1 9 . 4 ~ \mathrm { m g }$ ，其在树脂柱上的保留值约为 $0 . 2 6 ~ \mathrm { m g }$ ，这一值与高锝酸根在TEVA数值上的保留值相近［17］，故高铼酸根可模拟高锝酸根的洗脱情况。这一现象可以从离子交换机理角度得到解释。TEVA树脂作为季铵盐型阴离子交换树脂，其对 $\mathrm { R e O _ { 4 } } ^ { - }$ 的吸附强度受硝酸根 $\mathrm { ( N O _ { 3 } } ^ { - }$ ）竞争作用的显著影响。随着 $\mathrm { H N O _ { 3 } }$ 浓度的升高，溶液中 $\mathrm { N O _ { 3 } } ^ { - }$ 与树脂固定相中季铵基团的结合位点产生强烈竞争，从而削弱了树脂对 $\mathrm { R e O _ { 4 } } ^ { - }$ 的亲和力。值得注意的是，在$\mathrm { 8 \ m o l / L \ H N O _ { 3 } }$ 条件下， $\mathrm { R e O _ { 4 } } ^ { - }$ 的洗脱体积（ $5 { \sim } 6 ~ \mathrm { m L }$ ）接近色谱柱的死体积 $\left( 4 . 5 \ \mathrm { m L } \right)$ ），表明此时离子交换平衡已强烈偏向解吸方向。这种高效的洗脱特性为后续钼锝分离工艺的设计提供了重要依据。

基于上述实验结果，本研究选择 $8 ~ \mathrm { m o l / L }$ 硝酸作为洗脱液用于TEVA树脂柱的钼、铼分离：首先，该条件下 $\mathrm { R e O _ { 4 } } ^ { - }$ 的洗脱峰尖锐，与钼酸根 $\mathrm { ( M o O _ { 4 } } ^ { 2 - }$ ）的保留行为形成显著差异，可确保两组分达到基线分离；其次，高酸度环境能有效抑制 $\mathrm { M o O _ { 4 } } ^ { 2 - }$ 的聚合现象，避免多钼酸根的形成而干扰分离；最后， $8 ~ \mathrm { m o l / L }$ $\mathrm { H N O _ { 3 } }$ 的强洗脱能力可最大限度缩短分离周期，提高工艺效率。
