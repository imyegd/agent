# 1 多叶光栅准直器

# 1.1 微型多叶光栅

早期的直线加速器准直器比较简单，只有一对光阑，没有多叶光栅。为了在老一代直线加速器产品上开展精准放疗，市场上推出了外挂式微型多叶光栅，可以作为附件安装在加速器机头上对光阑形成的方野进一步适形以获得更加精确的照射野，图1展示了几种外挂式微型多叶光栅的外观和结构。国外常见的外挂式微型多叶光栅是BrainLam $\mathbf { M } ^ { 3 }$ 微型多叶光栅，最大照射野 $1 0 0 ~ \mathrm { m m } \times 1 0 0 ~ \mathrm { m m }$ ，叶片在等中心处的投影宽度为 $2 \ \mathrm { m m } \ ^ { \left[ 3 - 4 \right] }$ 。国内主要的外挂式多叶光栅是苏州雷泰医疗科技有限公司生产的TiGRT系列，最大照射野 $1 0 0 \ \mathrm { m m } \times 1 0 0 \ \mathrm { m m }$ ，叶片在等中心处的投影宽度为 $2 \ \mathrm { m m } \ ^ { \mathrm { ~ [ ~ } 5 \mathrm { ~ ] ~ } }$ 。微型多叶光栅的分辨率更高，可以进一步提高照射野精度，为追求更高的 SRS治疗精度，部分已配备内置多叶光栅的直线加速器也会选配外挂式微型多叶光栅作为补充。

图1 几种外挂式微型多叶光栅准直器 A为 BrainLam M3微型多叶光栅；B为雷泰医疗的外挂式多叶光栅；C、D为外挂式微型多叶光栅的内部结构

在 立 体 定 向 放 射 治 疗 中，与 常 规 光 栅 相 比，微型多叶光栅在分辨率上更有优势，同时相对锥形孔准直器，效率更高。如图2所示，M6型射波刀（CyberKnife）扩展增加了微型多叶光栅 InCise，包含 41对叶片，最大照射野 $1 1 5 \ \mathrm { m m \times 1 0 0 \ \mathrm { m m } }$ ，叶片在等中心处的投影宽度为 $3 . 8 5 \ \mathrm { m m }$ ［源轴距（source-axis distance, SAD） $= 8 0 0 \ \mathrm { m m } \ \mathrm { ] }$ ，叶 片 高 度 $9 0 \ \mathrm { m m }$ ，叶间最大漏辐射 $< 0 . 5 \%$ ，平均漏辐射 $< 0 . 3 \%$ ［6-8］。

配置微型多叶光栅后，射波刀治疗大体积肿瘤的效率得到提升，因此配置微型多叶光栅也成为专用立体定向放疗设备扩展其功能的一种趋势。随着临床对治疗精度要求的提升，加之电动多叶光栅技术的成熟，新一代的直线加速器都配置了内置的电动多叶光栅系统，可开展精准放疗，适形度、分辨率大幅提升，因此对外挂式微型多叶光栅的需求逐步降低。
