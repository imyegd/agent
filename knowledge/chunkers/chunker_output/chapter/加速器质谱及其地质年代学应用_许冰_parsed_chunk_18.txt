# 4.3.2 最大和最小年龄

对于埋藏深度较浅 $\left( < 3 0 \mathrm { ~ m ~ } \right)$ ）、且埋藏时间较长的样品，需要考虑埋藏后产量的影响［58～59］ ；另外，样品在埋藏前，可能经历复杂的暴露历史，在埋藏前最后一次暴露前，可能含有继承组分，造成埋藏时核素比值与地表散列的初始值差别较大。对于继承组分和埋藏后产率的影响，一般采用最大、最小和等时线方法来处理上述因素的影响。

对于埋藏深度不够的样品，其埋藏后产率组分的影响明显［53］ 。由于埋藏后产生核素的核素比值较大，因此，在不考虑继承组分影响情况下，获得的年龄比其真实年龄年轻，为最小年龄；同理，当对埋藏后核素的产量进行最大估算获得的年龄就是最大年龄。在自然条件下，侵蚀是常见现象，导致样品埋藏深度随时间的变化相应变薄。因此，根据现今埋藏深度来估算的埋藏后产率大于真实产率，是埋藏后的最大产率；利用最大埋藏产率对样品的核素含量进行校正得到的年龄即是最大年龄。
