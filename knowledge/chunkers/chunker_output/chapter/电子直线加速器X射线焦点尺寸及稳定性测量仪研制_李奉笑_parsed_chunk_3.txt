# 1 焦点尺寸测量原理

# 1.1 电子直线加速器X射线焦点尺寸的表征

典型的驻波直线加速管如图1所示，主要由加速腔、耦合腔、电子束流通道和射线靶等部分构成［15‒17］。电子枪发射的电子束经过加速后，轰击射线靶，绝大部分电子能量转化为热能，而少部分则通过轫致辐射机制转化为高能X射线。电子束轰击靶表面产生X射线的区域，称为X射线焦点。

焦点发出的X射线强度遵循高斯分布［18］ ，如图2（a）所示：

$$
f (x, y) = I _ {0} \cdot \exp \left(- \left(\frac {x ^ {2}}{2 \sigma_ {x} ^ {2}} + \frac {y ^ {2}}{2 \sigma_ {y} ^ {2}}\right)\right) \tag {1}
$$

式中： $x \cdot y$ 是焦点中心为坐标原点的坐标； $I _ { 0 }$ 为射线强度的最大值； $\sigma _ { x } , \sigma _ { y }$ 为二维高斯分布 $x \cdot y$ 方向的标准 差 。 一 般 采 用 半 高 宽（Full Width at HalfMaximum，FWHM）定义焦点尺寸［19］，如图 2（b）、（c）， $X$ 方向焦点大小为 $a _ { x } = \mathrm { F W H M } _ { x } = 2 \sqrt { 2 \mathrm { l n } 2 } \sigma _ { x } , Y$ 方向焦点大小为 $a _ { y } = \mathrm { F W H M } _ { y } = 2 \sqrt { 2 \mathrm { l n } 2 } \sigma _ { y } \mathrm { _ { \circ } }$ 。
