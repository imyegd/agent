# 2    运行调试

LEAF装置自运行以来，面向终端实验的累计供束时长已超过 $1 3 \ 0 0 0 \mathrm { h }$ 。试运行期间，装置共支撑完成 60余项物理实验任务，其中所外用户占比约 $40 \%$ ，体现出较高的装置开放度与平台共享水平。图 4展示了 LEAF 装置试运行期间各类实验任务的时间分布情况。核天体物理与核材料辐照相关实验占据主导地位，合计时间占比达到$8 3 \%$ ，表明装置建设初期的科研定位与应用重点已在运行实践中得到体现。除两大核心方向外，平台还支撑了装置机器研究、原子分子物理及探测器开发等多类实验，具备良好的科研多样性与扩展潜力。
