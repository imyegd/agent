# 1 加速器质谱发展史

加速器质谱是核物理研究中加速器发展的产物。加速器的发展历史可以追溯到 20世纪 40年代。1930 年， 英 国 物 理 学 家 卢 瑟 福 （ErnesRutherford）在研究原子核的结构时，发现原子核的尺寸极小，表明原子核存在高达百万伏特的高库仑势垒。他在研究核子内部精细结构时，首次提出需要能量足够高的粒子束流，如质子流触发核反应。通过离子源提供离子束流，从而利用加速器将离子束流加速到高能状态。许多核反应研究所需的离子电流，介于稳定同位素的质谱研究所需的电流和用于分离数毫克特定稳定同位素所需的极高离子电流之间；而加速器质谱所需要的束流与核物理研究原子核的束流非常相似，在微安培级别［6～7］ 。

加速器质谱的产生与 LouisAlvarez在美国加州劳伦斯伯克利实验室的研究，特别是质量数为 3的$^ 3 \mathrm { H e }$ 和 $^ 3 \mathrm { H }$ 的发现密切相关。1939年，如何将 $^ 3 \mathrm { H }$ 和相同质量的分子离子分离的问题引起了 Alvarez的关注；因此 Alvarez和 Cornog［8］提出了利用当时新发展的大回旋加速器作为非常高灵敏度的质谱来探测He气中 $^ 3 \mathrm { H e }$ 的想法，并利用伯克利的回旋加速器进行了相关研究，成功地发现了自然 He气中的含量在百万分之几的 $^ 3 \mathrm { H e }$ ，实现了加速器从核物理研究向加速器质谱学的拓展；1951年，Alvarez再次将串列静电加速器引入加速器质谱中，并将加速器质谱

的基 本 原 理 引 入 质 谱 分 析。 因 此， Alvarez被Litherland等［9］ 称为加速器质谱的创始人。

加速器质谱的应用，与 $^ { 1 4 } \mathrm { C }$ 定年的研究密切相关。在 1977年，Muller［10］ 提出将加速器质谱的原理扩展到使用正离子和回旋加速器进行放射性碳年代测定的研究中，并采用了范围法来分离丰度较高的 $\mathrm { ^ { 1 4 } N }$ 正离子与长寿命放射性同位素 $^ { 1 4 } \mathrm { C }$ （半衰期为 5730年）；在随后的 1977～1979年间，多篇文章报道了利用加速器质谱进行 $^ { 1 4 } \mathrm { C }$ 测量的可行性［11～13］ 。这些早期研究均采用正离子源和回旋加速器质谱，而 $^ { 1 4 } \mathrm { C }$ 在回旋加速器质谱测量过程中，受同量异位素 $^ { 1 4 } \mathrm { N }$ 的影响巨大［14］ ，且难以分离，限制了 $^ { 1 4 } \mathrm { C }$ 的精度测定。因此，回旋加速器质谱这一缺陷，限制了其应用，不能算是成熟的加速器质谱技术。

加速器质谱成熟以串列式加速器质谱的面世为标志，出现在 20世纪 70～80年代［9，15］ 。串列式加速器质谱是负离子源和静电加速器结合的产物。相对于负离子源，静电加速器的发明较早，由 VandGraaff等［16］和 Herb等［17］发 明 和 研 制；1937年，Bennett等［11］ 发明了真空静电加速管，使真空高能加速成为可能；到 20世纪末和本世纪初，小型真空静电加速器被引入加速器质谱中，研制出了微型和小型加速器质谱［18］ 。

串列加速器质谱的出现离不开负离子源的发展［19］ 。串列式加速器的高压电极位于加速管中间，地电位位于两端。串列静电加速器先对负离子进行加速，而后在加速管中间的剥离器中，通过剥离气体或剥离膜对加速后的负离子进行电子剥离，形成正离子。正离子在加速管的后半段再次加速，获得高能粒子束流。因此，串列加速器质谱需要与负离子源结合。

负离子源在早期核物理研究中并不为人所知，直到串列加速器出现后，才被关注，进而开启负离子源的研发历程。适用于串列加速器且能够产生合适的高电流的负离子源是由麦吉尔大学的 Whittier［20］ 、Weinman和 Cameron［21］ 开发出来的；此后，无论是加速器质谱还是核物理学领域，这类资源的开发工作一直在持续进行。早期应用的负离子源主要是气体供给型负离子源；但这类源具有非常高的记忆效应，不适合加速器质谱分析。Jolly［22］ 在介绍离子源的发展历程中，提到直到 1969年，Müler和 Hortig开发出新型号的负离子源———溅射离子源，由此加速器质谱的研发才步入快速发展阶段；其中具有革命性的一步是铯（Cs）离子溅射离子源出现［23］ 。Cs离子源在加

速器质谱的 $^ { 1 4 } \mathrm { C }$ 测量中效果极佳，尤其适用于从石墨中产生碳离子以用于核物理研究，因为石墨表面残留的铯为碳离子及其他（但并非全部）阴离子的大量电流生成提供了适宜条件［11］ 。

串列式加速器质谱的成熟得益于 Purser等［13］对克服 $\mathrm { ^ { 1 4 } N }$ 对 $^ { 1 4 } \mathrm { C }$ 的干扰问题的研究。负离子源串联式加速器质谱对 $^ { 1 4 } \mathrm { C }$ 的测定起始于 1975年。当时用的是早期型号的离子源［24～25］ 。用于 $^ { 1 4 } \mathrm { C }$ 测定的负离子是 $^ { 1 4 } \mathrm { C } ^ { 1 5 } \mathrm { N } ^ { - }$ ，其具有较高的结合能。尽管 $^ { 1 4 } \mathrm { C } ^ { 1 5 } \mathrm { N } ^ { - }$ 可以产生较大的离子束流，但 $\mathrm { ^ { 1 4 } N }$ 的干扰巨大，最终被放弃［26］ 。 $^ { 1 4 } \mathrm { N }$ 对 $^ { 1 4 } \mathrm { C }$ 的干扰问题被 Purser等［13］解决。他们的研究发现，N元素难以形成稳定的负离子，而C的负离子却很稳定，且能产生强大的束流。随后的研 究 显 示，利 用 Middleton铯 离 子 溅 射 源，产 生$\mathrm { C } ^ { - }$ 离子，注入串列式加速器就可以有效去除 $\mathrm { ^ { 1 4 } N }$ 的影响，并达到可接受的测量精度［11～12］ 。

此后，配备 Middleton铯离子溅射源的串列式静电加速器成为主流。在 20世纪 90年代，也有一些学者力图通过配备负离子注入的小回旋加速器质谱进行 $^ { 1 4 } \mathrm { C }$ 测量［27～29］ ，但串列式加速器优势如此巨大，因此现在几乎所有加速器质谱均采用串列加速器，并广泛应用于各个领域［15］ 。

近 20年来，加速器质谱领域最显著的进展之一就是 $^ { 1 0 } \mathrm { { B e } }$ 核素在小型 AMS上的成熟应用与推广［2］ ， 国 内 天 津 大 学 和 崂 山 实 验 室 引 进 的0．5MV-AMS均 已 实 现 了 $^ { 1 0 } \mathrm { { B e } }$ e的 有 效 测 量。 $^ { 1 0 } \mathrm { { B e } }$ 是除 $^ { 1 4 } \mathrm { C }$ 外应用最广泛的宇宙成因核素，在过去，一般认为需要端电压 $> 5 . 0 \mathrm { M V }$ 的大型串列加速器，才可以将离子加速到足够能量实现 $^ { 1 0 } \mathrm { { B e } }$ e与同量异位素干扰核素 ${ } ^ { 1 0 } \mathrm { { B } }$ 的分辨，很大程度上限制了 $^ { 1 0 } \mathrm { { B e } }$ e的广泛应用；2008年，苏黎世联邦理工学院 Müller等［30］成功通过衰减膜技术（degraderfoiltechnique）实现了$^ { 1 0 } \mathrm { { B e } }$ e在 0.6MV加速器质谱上的精确测量。该技术首先在包括西安中国科学院地球环境研究所在内的3.0MV大型加速器质谱上得以实现，随后逐步拓展到更小型的加速器上。该技术的原理为，在高能端磁铁后加设特定衰减膜，一般为几十 nm的氮化硅薄膜，使得 $^ { 1 0 } \mathrm { { B e } }$ e与 ${ } ^ { 1 0 } \mathrm { B }$ 束流穿透该膜时损失不同的能量；此时， $^ { 1 0 } \mathrm { { B e } }$ 具有匹配度更好的动能、动量和发散角，通过随后的静电分析器和磁铁时能更有效地抵达最终探测器，而干扰 ${ } ^ { 1 0 } \mathrm { { B } }$ 则被逐次筛选，剂量被极大抑制，最终在气体探测器中不再对 $^ { 1 0 } \mathrm { { B e } }$ 形成大的干扰，实现有效分辨。该技术在0.5MV-AMS上目前可实现 $^ { 1 0 } \mathrm { { B e } }$ e背景值优于 $5 \times { 1 0 } ^ { - 1 5 }$ 。需要指出的

是，该技术的代价是在高能端会损失相当的束流，造成总体传输效率的降低，因此更适合天然浓度较高的大气成因 $^ { 1 0 } \mathrm { { B e } }$ e领域的应用。
