# 4.2 可靠性及运行策略

# 4.2.1 可靠性分析

BEPC 每周二上午停机检修或机器研究，停机时间 4h 左右。考虑到水的热惰性，加之多学科大楼墙体保温性能较好，4h 之内温差变化较小。但考虑到 BEPC 存在因故障长时间停机，导致热回收机组无法回收足够余热的可能性，本项目采用市政管网进入园区公建板换间供出的二次侧热水作为备用热源，在低区（7 层及以下）由二次侧供水压力直接供给，高区（7 层以上）利用位于多学科大楼的地下板式换热器及水泵供给，费用以热量计价。热泵机组供热水温度为 $5 5 ~ ^ { \circ } \mathrm { C }$ ，与现有园区自采暖燃气锅炉供水温度基本一致（ $5 7 ~ ^ { \circ } \mathrm { C } )$ ）。结合新建墙体传热系数分析，此温度下室内风机盘管系统的散热效果可以得到保障。
