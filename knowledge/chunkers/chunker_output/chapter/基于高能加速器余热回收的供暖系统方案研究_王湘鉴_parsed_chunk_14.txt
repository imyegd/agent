热泵选型是系统核心。热泵是采用逆卡诺循环将能量从低温热源转移到高温热源的设备，由于其仅消耗少量电能就能获得较大的供热量，节能效果十分显著，因此被广泛应用于工业和居民供热系统[20]。热泵包括压缩式热泵和吸收式热泵两种常见类型。压缩式热泵通过电能驱动压缩机转动，实现机械压缩提升低温热源温度，具有较高的能效比。吸收式热泵以热能驱动系统循环，以高温热量驱动、回收低温热量，输出中温热量，温差足够大，才能实现热泵的提温功能。本项目经过对冷冻站近一年的数据分析，结合加速器运行的特殊性，冬天负荷较夏天没有明显减少，冷却塔也没有因冬季而过多减少出水温度；冷水机组也未出现因过渡季或者冬季气温较低，而停止工作的情况（即过渡季只开冷却塔，停用冷水机组，无法满足工艺用冷需求）。冷水系统中冷水分水器在 $7 { \sim } 8 ^ { \circ } \mathrm { C }$ 之间，冷水集水器温度在 10~11 ℃之间。对撞区冷水回水温度一般在 $1 0 ~ ^ { \circ } \mathrm { C }$ 左右。冷却水系统侧的冷却塔出水温度稳定在 $2 8 { \sim } 2 9 ^ { \circ } \mathrm { C }$ 左右，冷却塔进水温度稳定在 $3 2 { \sim } 3 3 ^ { \circ } \mathrm { C }$ 左右。根据中央空调供暖设计标准，系统热回收机组二次侧供回水设计温度为 $5 5 / 4 5 ^ { \circ } \mathrm { C } _ { \circ }$ 。因此，根据吸收式热泵的特点，只有在高温热量与中温输出热量之间的温差足够大时，才有较高性价比。故本项目在温差较小的情况下，不适用于吸收式热泵，而采用能效比较高的压缩式热泵。

在压缩式热泵中，重点对比适用于本工程规模的离心式压缩热泵与螺杆式压缩热泵。离心式热泵机组的制热量在 600RT~2800RT 之间，适用于大型建筑，其COP（能效比）通常在 $5 . 5 { \sim } 6 . 5$ 之间，低负荷时易出现喘振，部分负荷效率高。螺杆式热泵机组多适用于 600RT 以下的中小型场景，调节范围广（ $1 0 \% \sim 1 0 0 \%$ ），对热源温度波动适应性更强，其 COP略低于离心式，通常在 4.5~5.5 之间，但占地面积小且运行维护相对简便。针对本项目特点和总采暖负荷，两种主流中大型压缩式热泵的关键性能对比如表 2所示[21-22]。鉴于本项目中等偏小的容量、热源的波动性、对部分负荷性能的较高要求以及经济性考量，螺杆式压缩热泵在技术匹配度、运行稳定性和全生命周期成本等方面均展现出显著优势，是本方案的最优选择。

本项目在设计阶段成功应用建筑信息模型（BIM）技术，完成了余热回收机组站房的精细化建模。模型整合了压缩式热泵、循环泵、软水系统等全部设备与复杂管线，形成了一个可视化的三维数字孪生体。该 BIM 模型通过三维协同设计，有效避免了各专业管线间的交叉碰撞，提升了设计质量和施工效率[23]。其次，基于模型进行了深入的管线综合，优化了站房布局与空间利用率，为施工扫清了障碍。此外，模型还为工程量统计与全生命周期管理提供了精准的数据基础。
