# 1 材料与方法

# 1.1 AGE3石墨化流程

AMS $^ { 1 4 } \mathrm { C }$ 石墨化是将含碳样品转化为高纯度石墨靶的前处理过程。作为 AMS－ $^ { 1 4 } \mathrm { C }$ 测试的关键环节，其原理是通过化学氧化－催化还原的方式，先将样品中的碳氧化为 $\mathrm { C O } _ { 2 }$ ，再还原成为具备良好导电性的固体石墨，以满足 $^ { 1 4 } \mathrm { C }$ 测试过程中 AMS离子源对高稳定束流的要求（图 1）。对于原始样品中的无机碳或有机碳提取，需采用有针对性的前处理方法释放 $\mathrm { C O } _ { 2 }$ ，常见手段包括高温氧化法、热解法、及酸处理提取法等。在获得纯净 $\mathrm { C O } _ { 2 }$ 后，通常通过催化还原途径将其转化为石墨，常见的催化还原途径包括 $\mathrm { H } _ { 2 } / \mathrm { F e }$ 法、 $\mathrm { Z n / F e }$ 法及 $\mathrm { Z n - T i H } _ { 2 } / \mathrm { F e }$ 法。整个流程的准确性与石墨化效率直接影响到 $^ { 1 4 } \mathrm { C }$ 测年的准确性与精确度。

AGE3通过 气 体 转 接 盒 （GSB）与 元 素 分 析 仪（EA）、碳酸盐 处 理 系 统 （CHS2）和 手 动 进 样 装 置（MCD）相连接（图 2）。在 EA-AGE配置下，系统能

够实现固体样品全自动燃烧和石墨化，通常用于制备土壤、植物残体或湖泊沉积物的总有机碳（TOC）石墨样品［12～13］ 。原始样品在 EA中通过 $1 6 ~ \mathrm { m l / m i n }$ 的 $\mathbf { 0 } _ { 2 }$ 燃 烧 $5 0 \ \mathrm { s }$ s，产 生 的 $\mathrm { C O } _ { 2 }$ 通 过 载 气 氦 气 （He，$1 8 0 ~ \mathrm { m l / m i n }$ ）运输，被吸附到AGE3的沸石分子筛捕集器上，随后通过加热沸石捕集器至 $4 2 0 \ \mathrm { { ^ \circ C } }$ 释放，并通过 He输送到指定的石墨化反应器；CHS2-AGE配置专为石墨化溶解性无机碳（DIC）或碳酸盐设计，CHS2-AGE比 EA-AGE更为复杂和耗时，水或碳酸盐样品在 CHS2中进行“氦气洗瓶 注酸 $\longrightarrow$ 洗针 酸化反应 $\longrightarrow$ 取样”一系列流程，耗时约 1.5～$2 . 0 \mathrm { ~ h ~ }$ ，然后 $\mathrm { C O } _ { 2 }$ 同样经吸附并释放到AGE3的反应器中进行石墨化；MCD-AGE针对气体样品的石墨化而设计，其操作相对简便，只需要陆续将装载$\mathrm { C O } _ { 2 }$ 气体的玻璃管装入波纹破管器，通入载气，破碎玻璃管释放气体，更换玻璃管并开始石墨化反应。一台AGE3配备了 7个独立运行的石墨化反应单元，反应单元可保留至多 $1 ~ \mathrm { m g C }$ 当量的 $\mathrm { C O } _ { 2 }$ 气体，多余的 $\mathrm { C O } _ { 2 }$ 通过分子筛被排出。为确保反应的一致性，标准样品的石墨化过程均以 $1 ~ \mathrm { m g C }$ 为标准，样品回收率 $> 9 2 \%$ 。每个单元由还原管及配套
