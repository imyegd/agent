# 3 结论

本文详细介绍了HEPS储存环真空系统从安装到运行全过程的检漏与气体分析实践。通过本研究，可得出以下结论：

1. 检漏策略的有效性：结合氦质谱检漏仪和四极质谱仪，分阶段实施的检漏策略被证明是高效、可靠的。针对六类典型漏点总结的特征与处置方案，对同类大型真空工程的检漏实践具有重要参考价值。  
2. 疑难漏点定位技术：对于材料漏、焊缝漏、离子泵本体漏等疑难漏点，需要采用“分段隔离”、“喷检与罩检结合”等创新性方法，其成功实施的核心在于对系统结构的深度认知与精准把控。  
3. 残余气体分析的重要性：QMS 在超高真空阶段兼具检漏和残余气体分析的双重功能。RGA 数据清晰地揭示了束流加载后引起的动态气载变化，特别是 $\mathrm { H } _ { 2 }$ 的主导性增长，这与理论预测相符，证实了真空系统面临的主要挑战来自光致解吸效应。

4. 系统性能达标：所采用的检漏与质控方法成功保障了HEPS储存环真空系统达到并维持了设计所要求的极高真空度与洁净度，为 HEPS的成功调试与运行奠定了坚实基础。

未来，我们将继续利用 QMS 长期监测真空系统的气体成分变化，深入研究不同运行模式下的气载规律，为 HEPS的性能优化和可靠运行提供持续的数据支持。
