# 3 结论

Xi’an-AMS有赖于其结构上的一系列的技术特性，测得的四个核素的精度和本底水平均属国际先进，为我国地学、考古、生物医学和其它运用 AMS技术的领域提供了一个良好的实验平台。 所测得的 $0 . 2 \%$ 的 $^ { 1 4 } \mathrm { C } / ^ { 1 2 } \mathrm { C }$ 精度再次表明，基于交替注入模式的 AMS，像基于同时注入模式的 AMS一样，可实现 $^ { 1 4 } \mathrm { C } / ^ { 1 2 } \mathrm { C }$ 的高精度测量。探测到 $3 . 6 5 \times 1 0 ^ { - 1 5 }$ 的$^ { 1 0 } \mathrm { { B e } / ^ { 9 } \mathrm { { B e } } }$ 比值再一次证明3 MV AMS可以实现 $^ { 1 0 } \mathrm { { B e } }$ 的高灵敏度探测，关键是仔细把握制样、压样和AMS分析的每一环节。
