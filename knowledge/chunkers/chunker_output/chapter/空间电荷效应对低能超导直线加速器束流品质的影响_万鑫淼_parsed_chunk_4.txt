# 1.2    物理模型

为研究初始 $\sigma _ { 0 }$ 局部超越 $9 0 ^ { \circ }$ 时的横向束流动力学特性，本研究设计了 5种不同聚焦方案来模拟 $\sigma _ { 0 }$ 的演化规律。各方案中最大 $\sigma _ { 0 }$ 分别设置为 $1 2 0 ^ { \circ }$ 、 $1 1 0 ^ { \circ }$ 、 $1 0 0 ^ { \circ }$ 和 $9 0 ^ { \circ }$ ，旨在模拟存在不同梯度加速场时 $\sigma _ { 0 }$ 的变化趋势。加速梯度越大，对应的 $\sigma _ { 0 }$ 值越高。其中方案 $\textcircled{1}$ 对应最高加速梯度，方案 $\textcircled{4}$ 则对应最低加速梯度。此外，我们设计了一组对照组，也就是方案 $\textcircled{5}$ ，它的 $\sigma _ { 0 }$ 始终小于 $9 0 ^ { \circ }$ ，其他参数均和方案 $\textcircled{1}$ 相同。为避免束流对聚焦参数过度敏感，各方案在束流通过 80 个聚焦周期后， $\sigma _ { 0 }$ 最小值统一设定为 $4 0 ^ { \circ }$ 。为此，我们基于一个相移函数设定聚焦方案，该函数能更精确地描述 $\sigma _ { 0 }$ 的动态变化规律。该相移函数为

$$
\sigma_ {0} = A _ {2} + \frac {A _ {1} - A _ {2}}{1 + (x / x _ {0}) ^ {p}} \tag {5}
$$

式中：变量 $x$ 表征周期数； $A _ { 1 }$ 为上限参数，代表方案中设计的初始最大聚焦强度； $A _ { 2 }$ 是下限修正参数，用于微调$\sigma _ { 0 }$ 演化的基线，确保 80个周期后 $\sigma _ { 0 }$ 能稳定降至预设的相移值； $x _ { 0 }$ 代表拐点周期数，表征 $\sigma _ { 0 }$ 从快速变化转为缓慢趋近稳定值的临界周期位置； $p$ 代表变化速率参数，控制 $\sigma _ { 0 }$ 在拐点附近的下降速率。各聚焦方案的具体参数详见表1。图1 则展示了五种不同方案下 $\sigma _ { 0 }$ 的演变轨迹。
