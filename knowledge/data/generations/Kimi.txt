# 、离子注入机概述

离子注入机是集成电路制造前道工序中的关键设备，用于将掺杂元素（如硼B、磷P、砷As等）以离子形式注入到硅晶圆中，从而改变半导体的载流子浓度和导电类型。与常规热掺杂工艺相比，离子注入可实现对注入剂量、注入角度、注入深度和横向扩散的精确控制。

# 1.1 设备组成

离子注入机主要由以下五大部分组成：离子源系统、质量分析器、加速管、聚焦和扫描系统、工艺腔（靶室）。离子源是设备的核心部位，作用是将需要注入的元素气态粒子电离成离子，决定注入离子的种类和束流强度。

# 1.2 传感器变量分类

本知识库涵盖的36个监测变量按功能可分为以下七大类：

• 离子源系统：灯丝电源、弧电源（C1电源）、引出电源、抑制电源

• 加速系统：加速电源

• 聚焦系统：C2/C3电源、消像散电源（斜向/轴向）、微调焦电流

• 对中系统：X/Y偏移电源、X/Y倾斜电源

• 辅助监测：束流、工件台位置、冷水机状态

# 二、监测值：束流强度

# 2.1 定义与意义

束流强度（Beam Current）是离子注入机最核心的监测指标，表示单位时间内通过束流传输路径的离子电荷量，通常以微安（ $\mathsf { \Pi } _ { \mathsf { \Pi } , \mathsf { \Pi } \mu \mathsf { A } } )$ ）或毫安（mA）为单位。束流强度直接决定了离子注入的剂量率，是控制掺杂浓度的关键参数。

# 2.2 影响因素概述

束流强度受多种因素综合影响，主要包括：离子源放电状态（灯丝电流、弧电压）、引出电场强度（引出电压）、抑制电子回流效果（抑制电压）、加速电场强度（加速电压）、束流传输效率（聚焦系统状态）、真空度（冷水机温度/压力）等。各变量通过复杂的耦合关系共同决定最终束流强度。

# 三、离子源系统变量

离子源是离子注入机的“心脏”，负责产生并维持等离子体，为后续束流提供离子。离子源系统的稳定运行是获得稳定束流的基础。

# 8.3 系统耦合关系

离子注入机的各子系统之间存在复杂的耦合关系：

• 离子源系统决定束流的“产生”，是束流强度的源头

• 加速系统决定束流的“能量”，影响注入深度

• 聚焦系统决定束流的“形状”，影响传输效率和注入均匀性

• 对中系统决定束流的“位置”，影响注入精度

• 冷却系统维持设备“稳定”，是所有系统正常工作的保障

在实际运行中，需要综合考虑各变量的相互影响，通过优化控制算法实现束流强度的稳定和注入质量的提升。
