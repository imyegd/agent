# 基于电子射野影像装置（EPID）的直线加速器质量控制研究

陈思嘉

（厦门大学附属第一医院，福建 厦门 361003）

摘要：本研究基于瓦里安 TrueBeam 直线加速器及其 EPID 系统，探讨了电子射野影像装置（EPID）在放射治疗质量控制中的应用。通过对 MLC 叶片到位精度、旋转中心、射野平坦度与对称性、剂量率与机架 /MLC 速度匹配等关键参数的自动化检测，验证了 EPID 结合Pylinac软件在提升质控效率、减少人为误差方面的优势，为临床提供了一种高效、精准的质控新路径。

关键词：直线加速器；质量控制；电子射野影像装置；EPID；多叶准直器

# 1  概述

# 1.1  放射治疗质量控制的重要性

放射治疗作为恶性肿瘤治疗的三大手段之一，其疗效与安全性在很大程度上依赖于治疗过程的精准性与一致性。严格的质量控制（QC）是保障放射治疗质量、提升治疗效果的基石。传统的直线加速器质量控制方法，如胶片剂量测量、电离室阵列验证等，虽然提供了可靠的数据，但往往耗时、劳动密集且自动化程度低，难以满足日益增长的临床需求。这促使医学物理领域不断探索更高效、实时性更强的质控新方法。

# 1.2  直线加速器概述

直线加速器是现代放疗的核心设备，能够产生高能X 射线和电子束。通过精密的多叶准直器（MLC）、准直器和机架系统，直线加速器能够将精确剂量的射线束投射到肿瘤靶区。直线加速器提供了高精度、高效率的治疗技术，包括调强放疗（IMRT）、容积旋转调强放疗（VMAT）等。随着这些先进治疗技术的广泛应用，直线加速器本

# 1.3  电子射野影像装置（EPID）技术发展与应用

电子射野影像装置（EPID）是一种集成在直线加速器上的先进数字探测器。它最初主要用于患者的摆位验证和射野成像。近年来，随着 EPID 技术的显著进步，其在医学物理质量控制中的应用潜力得到了极大的拓展。EPID 不仅能提供高空间分辨率的图像，还能通过图像的灰度值与剂量之间的线性关系，进行剂量学重建与验证。

# 1.4  研究目的与意义

本研究旨在深入探讨基于 EPID 的直线加速器质控方法。针对直线加速器的关键机械和剂量学性能参数，开发并验证利用 EPID 进行常规质控的流程与技术。

# 2.2  基于 EPID 的质控项目

本研究根据放射治疗日常质控的关键需求，并结合EPID 的功能特性，可以进行直线加速器的机械性能和剂量学的质量控制。

（1）MLC 叶 片 到 位 精 度（Picket and Fence）。MLC 叶片到位精度（Picket Fence），是通过检测相邻MLC形成的多个窄缝剂量来判断 MLC位置的到位准确性，直接测量指标是各个窄缝剂量的中间位置的偏差。MLC位置精确性可以用 Picket Fence，调强计划中要包含4 个机架角度（0°、 $9 0 ^ { \circ }$ 、 $1 8 0 ^ { \circ }$ 、270°），来检测重力对 MLC 位置的影响。在 Myvarian 官网下载 PicketFence 的执行文件。导入到放疗计划系统（TPS）后，在射野中添加MV影像接收程序，将EPID板升到坐标（0，0，0）位置，执行计划。导出 DICOM 图像，判断 MLC 到位精度最大误差是否 <1mm。  
（2）MLC 旋转中心（Spoke Shot）。MLC 旋转中心测试（Spoke Shot），用于检测 MLC 是否与射野等中心和准直器旋转轴对齐，原理是通过合并多个准直器角度下的 MLC 形成的窄缝剂量，检测剂量中轴是否汇聚在一个点。直接检测指标是各剂量中轴线的最小内切圆的直径大小。在 Myvarian 官网下载计划执行文件，导入 TPS后找到命名为 MLC spoke shot 的计划，在射野中添加MV影像接收程序，将EPID板升到坐标（0，0，0）位置，执行对应计划射野（准直器角度 $0 ^ { \circ }$ 、 $5 0 ^ { \circ }$ °、 $1 0 0 ^ { \circ }$ °、$1 5 0 ^ { \circ }$ 、 $2 0 0 ^ { \circ }$ °、 $2 5 0 ^ { \circ }$ °）。导出 DICOM 图像，判断形成的最小内切圆直径是否 $\langle 1 \mathrm { m m }$ 。  
（3）射野的平坦度和对称性。对于射束的平坦度和对称性，传统的测量方法为水箱或者二维的平板探测器，如 Mapcheck 等。在使用 EPID 方法时，将机架和准直器都设为 $0 ^ { \circ }$ ° ,EPID 升到坐标（0，0，0）位置，打开 QA 计划，选择合适射野大小 ( 如 $2 0 \mathrm { c m } \times 2 0 \mathrm { c m } )$ 并出束。导出 DICOM 图像，分析平坦度是否 $\langle 2 \%$ ，对称性是否 $\textless 3 \%$ 。  
（4）剂量率与机架速度 (DRGS) 测试。剂量率与机架速度（DRGS）测试是为了评估在 VMAT 过程中加速器精确控制剂量率和机架速度的能力。通过测量条带的剂量来判断机架速度、剂量率是否和计划预设值相同 , 直接检测指标是形成的 7 个条带的剂量差异。在Myvarian 官网下载计划文件，导入到 TPS 后找到命名为T3_MLCSp_MCS 的计划，在射野中添加 MV 影像接收程序，EPID 升到坐标（0，0，0）位置，执行计划。从 TPS 中导出 DICOM 文件，分析条带的剂量与平均剂量的差异是

否 $\leq 1 . 5 \%$ 。

（5）剂量率与 MLC 叶片速度（DRMLC）测试。剂量率与 MLC 叶片速度（DRMLC）测试是 VMAT 的另一项检测方法，是为了评估在 VMAT 计划执行过程中加速器精确控制剂量率和 MLC 运动速度的能力。直接检测指标是形成的 4 个条带的剂量差异。在 Myvarian 官网下载计划文件，导入 TPS 后找到命名为 T2_DR_GS_MCS 的计划，在射野中添加MV影像接收程序，EPID 升到坐标（0，0，0）位置，执行计划。导出 DICOM 文件，选择 VMAT 模块的 DRMLC 功能进行分析。

以上介绍的检测项目，单纯使用 EPID 即可实现。此外，EPID 还可以结合专用的模体、铅丝，来进行光野射野一致性、等中心一致性、MV 二维影像的质量控制。

# 2.3  使用的分析软件

使 用 的 主 要 数 据 处 理 和 分 析 工 具 为 Pylinac。Pylinac 是一个开源的 Python 库，用于帮助医学物理师分析日常质控过程中常用的图像和数据集，通过编程能够自动化地执行图像处理、特征提取和结果报告生成。这些检测可以覆盖大部分《WS 674-2020 医用电子直线加速器质量控制检测规范》和《NCC/T-RT 001-2017 放射治疗质量控制基本指南》要求的内容。由于Pylinac 不具有数据存储功能，安装第三方数据存储程序 QATrack+ 来保存输入的图像及输出的结果。

# 4  结语

直线加速器是一种高精度的放射治疗设备，确保直线加速器的质量对患者的治疗效果至关重要。本文通过对 MLC 叶片到位精度、射野平坦度和对称性等关键质控项目的测试，验证了 EPID 作为一种高效、自动化质控工具的潜力。

传统的质控方法，如胶片剂量测量、电离室阵列验证等，普遍存在耗时、劳动密集且自动化程度低的问题。EPID 可以直接在加速器上获取实时图像，简化了数据采集流程。例如，Picket Fence 测试，传统方法需要使用胶片，涉及复杂的冲洗、扫描和分析过程，而 EPID 则能即时成像并进行软件分析，且测量结果不受人员因素干扰。结合 Pylinac 等开源分析软件，EPID 质控流程实现了高度自动化。图像处理、特征提取和结果报告生成均可通过编程完成，并提高了数据分析的客观性和重复性。EPID 在检测 VMAT 等复杂治疗技术中，能够精确评估加速器在剂量率、机架速度和MLC运动速度持续变化时的控制能力，这些是传统静态测量方法难以全面覆盖的。
