摘要：加速器质谱（AMS）凭借其超高灵敏度和卓越的同位素分辨能力，已成为超低含量稀有同位素测量的主要技术手段，并在某些情况下成为唯一可行的探测方法。当前，加速器质谱的同位素丰度灵敏度 $\leqslant 1 0 ^ { - 1 5 }$ 量级，能够实现对千原子级别的宇宙成因核素进行精确测量。自 20世纪 70年代串列式加速器质谱问世以来，该技术及其应用领域取得了显著发展；如今，加速器质谱已成为核科学技术中对多学科发展具有重要推动作用的关键技术之一，其应用范围几乎涵盖了包括技术圈在内的所有科学与技术领域。文章系统回顾了加速器质谱的发展历程，阐述了 20世纪 40年代 $^ { 1 4 } \mathrm { C }$ 定年技术的出现及其测量需求对加速器质谱研发的关键推动作用；重点介绍了加速器质谱的核心构成单元及其工作原理，特别是各单元在提升系统抗同位素、同量异位素及同质分子干扰能力中的作用机制；同时，概述了加速器质谱在地球科学领域的应用，并对基于该技术的 $^ { 1 4 } \mathrm { C }$ 年代学、暴露年代学和埋藏年代学方法进行了详细综述。

关键词：加速器质谱；稀有同位素；宇宙成因核素； $^ { 1 4 } \mathrm { C }$ ；暴露年代学；埋藏年代学

# 0 0 引言

加速器质谱（AcceleratorMassSpectrometry，简称 AMS）是核物理研究的副产品，也是核物理技术对其它学科发展贡献巨大的技术之一。加速器质谱与其它质谱具有相同的目的，主要是运用电磁技术方法，通过能量和质量筛选降低同量异位素的影响，进而减小背景，提高探测精度。但加速器质谱又有别于其它同位素比值质谱，其将高能粒子加速技术引入质谱技术中，使其探测能力和应用范围得到了极大的拓展。加速器质谱通过离子源产生稀有同位素离子，经加速器的加速 $\longrightarrow$ 剥离 $\longrightarrow$ 再加速后，形成高能粒子（一般加速到 $0 . 2 \sim 4 0 ~ \mathrm { M e V }$ 或更大），进而利用高能磁铁和静电分析器进行质量和能量筛选，最终利用核物理探测技术对单个高能粒子进行计数，来实现稀有同位素的测量，其具有超高的系统背景压制能力和灵敏度。与传统质谱相比，在某

些情况下，加速器质谱的同位素比值测量的灵敏度是传统质谱的 $1 0 ^ { 8 }$ 倍以上［1］ 。一般质谱的同位素的识别能力在 $1 0 ^ { - 8 }$ 水平，二次离子质谱最高也只有${ { 1 0 } ^ { - 1 2 } }$ 水 平， 而 加 速 器 质 谱 探 测 的 灵 敏 度 可$\leqslant { 1 0 } ^ { - 1 5 [ 2 ] }$ 。加速器质谱由于引入了高能粒子加速和探测技术，探测器中的干扰背景极低，这是一般质谱不可比拟的；另外，加速器质谱使小样品超低含量的稀有同位素测量成为可能，其可以对低于$1 ~ \mathrm { m g }$ 自然样品中含量低于 ${ 1 0 } ^ {  { - } 1 5 }$ 的稀有同位素进行精确测量［3～4］ ，极大拓展了其应用领域。目前其应用领域几乎涵盖从地球和行星科学到生物医学与技术科学的各个领域［4］ 。

加速器质谱的发展历史可以追溯到 20世纪 40年代，其发展历史与地球科学的 $^ { 1 4 } \mathrm { C }$ 测量的需要具有密切联系，可以毫不夸张地说， $^ { 1 4 } \mathrm { C }$ 测量需求推动了加速器质谱技术发展。随着加速器质谱技术的发展和应用拓展，特别是近 20年来，加速器质谱数量快

速增加，可测量的核素种类和应用领域也得到了快速拓展。在地球科学中的应用，从当初的 $^ { 1 4 } \mathrm { C }$ 测定，拓展到了目前 60多个核素，开创了诸多新领域［4］ 。单从地质年代学方面而言，不仅使小样品超低含量样品的 $^ { 1 4 } \mathrm { C }$ 定年成为可能，而且开创了宇宙成因核素暴露和埋藏年代学的新领域［5］ 。

在近 20年来，随着小型和微型加速器质谱的问世，全球加速器质谱数量迅猛增加，目前全球加速器质谱已有 160多台。我国加速器质谱数量在近10年来快速增加，从 21世纪初的 3台，增加到了目前的 30多台，绝大多数集中在地学领域。国内许多学者，特别是从事地球科学研究的学者，对加速器质谱技术及其在地学中的应用并不完全了解，在一定程度上限制了我国加速器质谱技术的效能发挥。本文将对加速器质谱技术及其发展进行综述，对其在地质年代学方面的应用进行着重介绍，以期相关学者对加速器质谱的技术优势及其在地球科学中的应用有一个比较全面的了解。

# 1 加速器质谱发展史

加速器质谱是核物理研究中加速器发展的产物。加速器的发展历史可以追溯到 20世纪 40年代。1930 年， 英 国 物 理 学 家 卢 瑟 福 （ErnesRutherford）在研究原子核的结构时，发现原子核的尺寸极小，表明原子核存在高达百万伏特的高库仑势垒。他在研究核子内部精细结构时，首次提出需要能量足够高的粒子束流，如质子流触发核反应。通过离子源提供离子束流，从而利用加速器将离子束流加速到高能状态。许多核反应研究所需的离子电流，介于稳定同位素的质谱研究所需的电流和用于分离数毫克特定稳定同位素所需的极高离子电流之间；而加速器质谱所需要的束流与核物理研究原子核的束流非常相似，在微安培级别［6～7］ 。

加速器质谱的产生与 LouisAlvarez在美国加州劳伦斯伯克利实验室的研究，特别是质量数为 3的$^ 3 \mathrm { H e }$ 和 $^ 3 \mathrm { H }$ 的发现密切相关。1939年，如何将 $^ 3 \mathrm { H }$ 和相同质量的分子离子分离的问题引起了 Alvarez的关注；因此 Alvarez和 Cornog［8］提出了利用当时新发展的大回旋加速器作为非常高灵敏度的质谱来探测He气中 $^ 3 \mathrm { H e }$ 的想法，并利用伯克利的回旋加速器进行了相关研究，成功地发现了自然 He气中的含量在百万分之几的 $^ 3 \mathrm { H e }$ ，实现了加速器从核物理研究向加速器质谱学的拓展；1951年，Alvarez再次将串列静电加速器引入加速器质谱中，并将加速器质谱

的基 本 原 理 引 入 质 谱 分 析。 因 此， Alvarez被Litherland等［9］ 称为加速器质谱的创始人。

加速器质谱的应用，与 $^ { 1 4 } \mathrm { C }$ 定年的研究密切相关。在 1977年，Muller［10］ 提出将加速器质谱的原理扩展到使用正离子和回旋加速器进行放射性碳年代测定的研究中，并采用了范围法来分离丰度较高的 $\mathrm { ^ { 1 4 } N }$ 正离子与长寿命放射性同位素 $^ { 1 4 } \mathrm { C }$ （半衰期为 5730年）；在随后的 1977～1979年间，多篇文章报道了利用加速器质谱进行 $^ { 1 4 } \mathrm { C }$ 测量的可行性［11～13］ 。这些早期研究均采用正离子源和回旋加速器质谱，而 $^ { 1 4 } \mathrm { C }$ 在回旋加速器质谱测量过程中，受同量异位素 $^ { 1 4 } \mathrm { N }$ 的影响巨大［14］ ，且难以分离，限制了 $^ { 1 4 } \mathrm { C }$ 的精度测定。因此，回旋加速器质谱这一缺陷，限制了其应用，不能算是成熟的加速器质谱技术。

加速器质谱成熟以串列式加速器质谱的面世为标志，出现在 20世纪 70～80年代［9，15］ 。串列式加速器质谱是负离子源和静电加速器结合的产物。相对于负离子源，静电加速器的发明较早，由 VandGraaff等［16］和 Herb等［17］发 明 和 研 制；1937年，Bennett等［11］ 发明了真空静电加速管，使真空高能加速成为可能；到 20世纪末和本世纪初，小型真空静电加速器被引入加速器质谱中，研制出了微型和小型加速器质谱［18］ 。

串列加速器质谱的出现离不开负离子源的发展［19］ 。串列式加速器的高压电极位于加速管中间，地电位位于两端。串列静电加速器先对负离子进行加速，而后在加速管中间的剥离器中，通过剥离气体或剥离膜对加速后的负离子进行电子剥离，形成正离子。正离子在加速管的后半段再次加速，获得高能粒子束流。因此，串列加速器质谱需要与负离子源结合。

负离子源在早期核物理研究中并不为人所知，直到串列加速器出现后，才被关注，进而开启负离子源的研发历程。适用于串列加速器且能够产生合适的高电流的负离子源是由麦吉尔大学的 Whittier［20］ 、Weinman和 Cameron［21］ 开发出来的；此后，无论是加速器质谱还是核物理学领域，这类资源的开发工作一直在持续进行。早期应用的负离子源主要是气体供给型负离子源；但这类源具有非常高的记忆效应，不适合加速器质谱分析。Jolly［22］ 在介绍离子源的发展历程中，提到直到 1969年，Müler和 Hortig开发出新型号的负离子源———溅射离子源，由此加速器质谱的研发才步入快速发展阶段；其中具有革命性的一步是铯（Cs）离子溅射离子源出现［23］ 。Cs离子源在加

速器质谱的 $^ { 1 4 } \mathrm { C }$ 测量中效果极佳，尤其适用于从石墨中产生碳离子以用于核物理研究，因为石墨表面残留的铯为碳离子及其他（但并非全部）阴离子的大量电流生成提供了适宜条件［11］ 。

串列式加速器质谱的成熟得益于 Purser等［13］对克服 $\mathrm { ^ { 1 4 } N }$ 对 $^ { 1 4 } \mathrm { C }$ 的干扰问题的研究。负离子源串联式加速器质谱对 $^ { 1 4 } \mathrm { C }$ 的测定起始于 1975年。当时用的是早期型号的离子源［24～25］ 。用于 $^ { 1 4 } \mathrm { C }$ 测定的负离子是 $^ { 1 4 } \mathrm { C } ^ { 1 5 } \mathrm { N } ^ { - }$ ，其具有较高的结合能。尽管 $^ { 1 4 } \mathrm { C } ^ { 1 5 } \mathrm { N } ^ { - }$ 可以产生较大的离子束流，但 $\mathrm { ^ { 1 4 } N }$ 的干扰巨大，最终被放弃［26］ 。 $^ { 1 4 } \mathrm { N }$ 对 $^ { 1 4 } \mathrm { C }$ 的干扰问题被 Purser等［13］解决。他们的研究发现，N元素难以形成稳定的负离子，而C的负离子却很稳定，且能产生强大的束流。随后的研 究 显 示，利 用 Middleton铯 离 子 溅 射 源，产 生$\mathrm { C } ^ { - }$ 离子，注入串列式加速器就可以有效去除 $\mathrm { ^ { 1 4 } N }$ 的影响，并达到可接受的测量精度［11～12］ 。

此后，配备 Middleton铯离子溅射源的串列式静电加速器成为主流。在 20世纪 90年代，也有一些学者力图通过配备负离子注入的小回旋加速器质谱进行 $^ { 1 4 } \mathrm { C }$ 测量［27～29］ ，但串列式加速器优势如此巨大，因此现在几乎所有加速器质谱均采用串列加速器，并广泛应用于各个领域［15］ 。

近 20年来，加速器质谱领域最显著的进展之一就是 $^ { 1 0 } \mathrm { { B e } }$ 核素在小型 AMS上的成熟应用与推广［2］ ， 国 内 天 津 大 学 和 崂 山 实 验 室 引 进 的0．5MV-AMS均 已 实 现 了 $^ { 1 0 } \mathrm { { B e } }$ e的 有 效 测 量。 $^ { 1 0 } \mathrm { { B e } }$ 是除 $^ { 1 4 } \mathrm { C }$ 外应用最广泛的宇宙成因核素，在过去，一般认为需要端电压 $> 5 . 0 \mathrm { M V }$ 的大型串列加速器，才可以将离子加速到足够能量实现 $^ { 1 0 } \mathrm { { B e } }$ e与同量异位素干扰核素 ${ } ^ { 1 0 } \mathrm { { B } }$ 的分辨，很大程度上限制了 $^ { 1 0 } \mathrm { { B e } }$ e的广泛应用；2008年，苏黎世联邦理工学院 Müller等［30］成功通过衰减膜技术（degraderfoiltechnique）实现了$^ { 1 0 } \mathrm { { B e } }$ e在 0.6MV加速器质谱上的精确测量。该技术首先在包括西安中国科学院地球环境研究所在内的3.0MV大型加速器质谱上得以实现，随后逐步拓展到更小型的加速器上。该技术的原理为，在高能端磁铁后加设特定衰减膜，一般为几十 nm的氮化硅薄膜，使得 $^ { 1 0 } \mathrm { { B e } }$ e与 ${ } ^ { 1 0 } \mathrm { B }$ 束流穿透该膜时损失不同的能量；此时， $^ { 1 0 } \mathrm { { B e } }$ 具有匹配度更好的动能、动量和发散角，通过随后的静电分析器和磁铁时能更有效地抵达最终探测器，而干扰 ${ } ^ { 1 0 } \mathrm { { B } }$ 则被逐次筛选，剂量被极大抑制，最终在气体探测器中不再对 $^ { 1 0 } \mathrm { { B e } }$ 形成大的干扰，实现有效分辨。该技术在0.5MV-AMS上目前可实现 $^ { 1 0 } \mathrm { { B e } }$ e背景值优于 $5 \times { 1 0 } ^ { - 1 5 }$ 。需要指出的

是，该技术的代价是在高能端会损失相当的束流，造成总体传输效率的降低，因此更适合天然浓度较高的大气成因 $^ { 1 0 } \mathrm { { B e } }$ e领域的应用。

随着加速器质谱技术的发展和超低含量稀有核素测试需求增加，AMS测定核素种类迅速增加。1987年以前，AMS能够测量的核素主要是 $^ { 1 4 } \mathrm { C }$ 、$^ { 1 0 } \mathrm { { B e } }$ 、 $^ { 2 6 } \mathrm { A l }$ l、 $^ { 3 6 } \mathrm { C l }$ l和 ${ } ^ { 1 2 9 } \mathrm { I } ^ { [ 3 1 ] }$ ，到 2013年 增 加 到 了 55个［4］ ，2022年达到了 61个［2］ （包括原生放射性核素 $^ { 4 0 } \mathrm { K }$ 、 $^ { 2 3 2 } \mathrm { T h }$ 、 $^ { 2 3 5 } \mathrm { U }$ 和 $^ { 2 3 8 } \mathrm { { U } }$ ）： $^ 3 \mathrm { H }$ 、7Be、 $^ { 1 0 } \mathrm { { B e } }$ e、 $^ { 1 4 } \mathrm { C }$ 、 $^ { 2 6 } \mathrm { A l }$ l、$^ { 3 2 } \mathrm { S i }$ i、 $^ { 3 6 } \mathrm { C l }$ l、 $^ { 3 9 } \mathrm { A r }$ r、 $^ { 4 0 } \mathrm { K }$ 、 $^ { 4 1 } \mathrm { C a }$ 、 $^ { 4 4 } \mathrm { T i }$ i、 $^ { 5 3 } \mathrm { M n }$ n、55 Fe、 $^ { 5 9 } \mathrm { N i }$ i、60 Fe、 $^ { 6 3 } \mathrm { N i }$ i、68 Ge、79Se、81Kr、90Sr、 $^ { 9 2 } \mathrm { N b }$ 、 $^ { 9 3 } \mathrm { Z r }$ r、99 Tc、$^ { 1 2 6 } \mathrm { S n }$ 、129 I、135Cs、137Cs、146Sm、 $^ { 1 5 1 } \mathrm { S m }$ 、 $\mathrm { ^ { 1 6 6 } m H o }$ 、 $^ { 1 8 2 } \mathrm { H f } .$ 、202Pb、205Pb、210Pb、210 mBi、226Ra、228Ra、228 Th、229 Th、$^ { 2 3 0 } \mathrm { T h }$ 、231 Pa、232 Th、232U、233U、234 U、235U、236U、237 Np、$^ { 2 3 8 } \mathrm { U }$ 、 $^ { 2 3 9 } \mathrm { { P u } }$ 、240Pu、241Pu、241Am、242Pu、 $^ { 2 4 3 } \mathrm { A m }$ 、244Pu、$^ { 2 4 4 } \mathrm { C m }$ 、246 Cm、247 Cm、 $^ { 2 4 8 } \mathrm { C m }$ 和 $^ { 2 5 0 } \mathrm { C m }$ 。

# 2 加速器质谱的分类及分布

加速器可以分成两大类，分别是串列静电加速器质谱和回旋加速器质谱，其中串列加速器质谱在整个市场上占绝对优势。根据 2005年的统计，当时全球大约 80台串列式 AMS中只有一台回旋加速器质谱；而近 20年来，全球加速器质谱数量快速增加，目前增加到 160多台，全部是串列式加速器质谱［15］ 。 。

# 3 加速器质谱的主要构成

加速器质谱具有较强的抗同位素、同量异位素和多原子离子干扰能力［2］ 。如前文所述，加速器质谱可以对同位素比值低于 $1 0 ^ { - 1 5 }$ 的稀有同位素进行高精度测量（常规质谱测量的同位素比值一般不超过 ${ 1 0 } ^ { - 8 }$ ），这种超高的同位素灵敏度，与加速器质谱的复杂构成具有密切关系。下文将对加速器质谱的结构及其在同位素、同量异位素和同质分子抗干扰和识别能力方面的功能和贡献进行介绍。

加速器质谱总体上由五大单元组成，分别是离子源、注入和低能分析系统、加速器、高能分析系统和探测系统（图 1）。在样品进行加速器质谱测试前，一般需要对稀有同位素进行提纯制成靶样。目前多数实验室是固态离子源，因此，需要将稀有同位素进行富集并制成固态靶样。不同稀有同位素靶样的类型也不相同，如 $^ { 1 4 } \mathrm { C }$ 测量需要将样品制成石墨， $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l要分

别制成氧化铍（BeO）和氧化铝 $\mathrm { . A l } _ { 2 } \mathrm { O } _ { 3 }$ ）。

# 3.2 注入和低能分析系统

离开离子源的低能量、发散的离子束流被加速、聚焦，并由注入系统传输到加速器入口。注入和低能分析系统由一个预加速装置、限定束流发射度的孔径装置、透镜和导向器、测量束流电流的束流挡板（法拉第杯收集器）以及用于获取束流信息的其他诊断设备组成。预加速装置位于离子源后端，加速电压一般在 $3 0 \sim 3 0 0 \mathrm { k V }$ 。一般而言，离子束流的能量越大，其光学性质越适合进入加速器。注入器，可以理解为一个传统的质谱系统，它确保只有正确的离子进入加速器。因此，磁分析器（一个或多个）是注入系统中重要构成元件。为使所有同位素都获得相同的聚焦条件，注入系统的所有透镜和导向器都采用静电技术，以确保其不受质量因素的影响。Cs溅射离子源有一个弱点，即其束流信号具有高能拖尾。因此，当需要高质量和能量分辨率时 $^ { 3 6 } \mathrm { C l } )$ ），可以加入一个静电分析器。对于加

速器质谱的注入系统，目前常用的注入系统有两种类型，分别是“顺序式”和“同时式”，其中“顺序式”注入占多数。

“顺序式”注入是通过改变分析磁铁电气绝缘真空室的电压来实现稳定同位素和稀有同位素之间的转换。在进入和离开磁室时，离子分别受到加速和减速的作用。这样一来，当两种不同的同位素穿过磁场时（该磁场保持恒定），它们的能量就会有所不同。离子源单位时间内产生的稳定和稀有同位素离子的数量有十几个数量级的差异。因此，稳定和稀有同位素离子在加速管上的电力负荷大不相同，从而导致串列装置的高压无法稳定甚至无法维持。为了尽量减少这种影响，稳定同位素的注入时间应比稀有同位素的注入时间短得多。对于 NEC生产的加速器质谱仪，绝大部分时间都用于注入稀有同位素，稳定同位素的束流以短脉冲形式 $1 0 \ \mathrm { H z } )$ ）注入加速器，以避免束流过载。

“同时式”注入系统是稳定和稀有同位素一起注入加速器，通过一系列磁分析器和四极透镜实现，这些装置使得离开离子源后的不同同位素能够沿着不同的轨迹运动；最后，它们在进入加速器之前会重新聚合在一起。为减少稳定同位素的注入，会在靠近镜面平面的位置，即各同位素路径之间的间距达到了最大值时，在稳定同位素的路径附近安装一个旋带槽轮体，确保只有少量稳定同位素离子通过轮体，如对于 $^ { 1 4 } \mathrm { C }$ 测量，只有大约 $1 \%$ 的 $^ { 1 2 } \mathrm { C }$ 通过轮体，避免在终端处产生电流过载。

# 3.4 高能分析系统

由于离子在加速器中加速、剥离和传输过程中，特别是在剥离过程中会产生一定的离散，当离

子离开加速器后，需要对离子束进行聚焦。因此，离子束离开加速器后，通过高能分析系统中的透镜，再次聚焦。多数加速器质谱离子加速后，离子束流的能量在 $1 0 \ \mathrm { M e V }$ 或更高。聚焦后的离子束流进入高能分析磁铁，根据其能量、质量和电荷的综合关系 $ { \mathrm { ~  ~ \omega ~ } } _ { \mathrm { m E / q } } ^ { 2 }$ ）对高能离子进行筛选和分离；分离出的稳定同位素束流在磁铁焦平面的法拉第杯收集并测量；稀有离子将再次聚焦，然后进入静电分析器进行能量筛选 $( \mathrm { E / q } )$ ），进一步降低具有相同的能量、质量和电荷 $\mathrm { m E } / \mathrm { q } ^ { 2 }$ ）离子和同质分子的干扰影响。

# 3.5 探测器

高能质谱和静电分析器经过质量和能量筛选后的离子进入探测器进行计数测量。目前，有多种探测器用于稀有同位素离子的测量，包括气体电离探测器、半导体探测器、飞行质谱探测器、充气磁场探测器和 X射线探测器。最常用的探测器类型是气体电离探测器和半导体探测器。

# 3.5.1 气体电离探测器

气体电离探测器的工作原理是基于电离辐射的技术方法。经过高能系统筛选后的离子进入气体离子探测器，使气体室内的气体发生电离，产生离子－电子对。如果对探测器气体室施加合适电场，离子和电子会分别向阴极和阳极漂移并收集。电荷信号通过配备电荷敏感前置放大器、脉冲整形放大器和模数转换器（ADC）等适当电子设备，将电荷脉冲整合并数字化处理，得到入射离子的原子序数、能量和能量衰减等信息。

处理，得到入射离子的原子序数、总能量、能量衰减和漂移距离等指标，用于识别稀有同位素与同量异位素离子。

# 3.5.2 半导体探测器

半导体探测器，又称面垒探测器，常用半导体材料为硅（Si）或锗（Ge）。由于在许多情况下，进入探测器的干扰（背景）离子和稀有同位素具有不同的能量，因此，可以通过测量离子的能量来识别和测量稀有同位素离子。半导体探测器就是通过测量进入探测器离子的总能量来进行稀有同位素的测量。相对于气体电离探测器，半导体探测器具有较好的能量分辨率。半导体探测器的主要缺陷是其生命周期有限和易损坏，这归因于半导体材料的辐射敏感性，其能量分辨率会随总辐射剂量的增加而降低。当辐射剂量过大，会对探测器产生损坏，如事故性稳定同位素束流的进入，瞬间就会将探测器损毁。

正如前文所述，加速器质谱并非传统意义上的质谱，而是一个复杂系统，从离子源、低能质谱系统、加速器、高能系统到探测器的设计，其最终的目的只有一个，即抑制同位素和同量异位素的干扰，提高稀有同位素的识别和探测的能力。下面我们将不同构件在加速器质谱稀有同位素测量中的具体作用作一简要总结。

离子源的主要作用是通过与靶样物质相互作用，产生靶样物质的离子。对于加速器质谱的 C溅射离子源而言，功能是通过 Cs撞击靶样物质表面，溅射出样品物质的负离子，并产生足够多的离子数量。在降低同质异位素的影响方面，离子源的主要贡献是通过分析元素与同量异位素在形成负离子的难易程度及稳定性上的差异，并在形成负离子过程中将稀有同位素和干扰元素分离，从而降低或去除同量异位素的影响。如在 $^ { 1 4 } \mathrm { C }$ 测量中，C元素容易形成稳定的负离子，而其同量异位素 N元素的负离子不稳定［11］ 。因此，通过负离子源可以将 $^ { 1 4 } \mathrm { C }$ 与其干扰同量异位素 $\mathrm { ^ { 1 4 } N }$ 有效分离，去除 $\mathrm { ^ { 1 4 } N }$ 的影响。这一发现对于串列加速器质谱的发展及其应用拓展起到了重要的推动作用。近年来的研究发现，一些稀有同位素的分子负离子可以有效去除同位素的影响， $\mathrm { C a H } _ { 3 } ( ^ { 4 1 } \mathrm { C a } )$ ）易形成 $\mathrm { C a H } _ { 3 } ^ { - }$ ，而 $\mathrm { K H } _ { 3 }$ 则不易形成$\mathrm { K H _ { 3 } } ^ { - [ 4 1 ] }$ ，测量 $^ { 1 8 2 } \mathrm { H }$ f时，使用氟化物 $\mathrm { H f F } _ { 5 }$ ）不易产生干扰 $^ { 1 8 2 } \mathrm { W F } _ { 5 }$ ［42］ 。

离子源中产生的负离子，经过预加速进入低能注入系统，在低能注入系统对负离子进行离子筛选和聚焦，筛选出所需测量离子进入加速器。

在加速器中，负离子通过加速聚焦并穿过剥离气体管道，在此过程中负离子外层电子被剥离，经库伦爆炸效应彻底移除分子本底干扰；而剥离电子数量的增加需要高端电压的加速器，如在 $^ { 1 4 } \mathrm { C }$ 测 量中，要得到最大 $\mathrm { C } ^ { 3 + }$ 产率，以氩气为剥离气体其产率约 $33 \%$ ，大约需要 $2 . 5 \ \mathrm { M e V }$ 的端电压，而对于$\mathrm { C } ^ { 4 + }$ 离子，需要更高的能量（约 $6 . 5 \mathrm { M e V }$ ），其产率也会增加到 $6 5 \%$ 左右［43］ 。

在高能端，离子经聚焦后，经高能磁铁进行质量筛选和分离，其中稳定同位素或高丰度核素经法拉第杯收集后直接测量，筛选出的稀有同位素离子及具相同质荷比的离子或部分散射的离子进入静电分析器。静电分析器的主要功能是对离子能量进一步筛选，去除相同动能干扰核素的影响，最后进入探测系统。

在探测系统中，通过入射离子的总能量（固态探测器）或离子在气态介质中能量丢失特征差异区分离子种类。在探测器中充分利用不同原子序数的粒子具有不同能量丢失的性质，即 dE／dx-x，来识别同量异位素和稀有同位素。对于一些核素，为进一步降低同量异位素的影响（BvsBe，ClvsS），会在离子进入探测器前再次进行能量筛选。目前常采样的方法是增加衰减箔技术，其利用不同原子序数的离子经衰减膜后丢失能力不同，对离子进一步筛选，然后进入最终的粒子探测器。

# 4 加速器质谱在地质年代学中的应用

加速器质谱在地学中的应用主要是测量宇宙成因核素。加速器质谱自 20世纪 70年代末应用于地球科学研究，其测定核素种类快速增加，应用领域也得到了极大扩展。在核素年代学、日－地活动示踪等方面填补了空间和地球科学技术的许多盲区。目前已涉及到地球和行星科学的各个领域，包括地质年代学、全球变化、生命及人类起源演化、文明起源、板块运动、地球深部动力学、空间物理学、比较行星学、矿产资源探测、地震和水土侵蚀等领域，极大地推动了地球科学的发展，促成了一系列重大科学突破，显著拓展了人类的认知范围。由于本专辑中，其它文章会对相关研究领域具体内容进行详细介绍；另外，在许多综述性文章中，对宇宙成因核素的具体应用方法均做过系统介绍。因此，本文只对加速器质谱在地质年代学领域的应用进行简要介绍，并着重于对其基本原理进行介绍，希望对从事相关研究的学者起到一定的启发作用。

宇宙成因核素是通过原子与宇宙射线相互作用而产生的稀有同位素，这些核素与其稳定同位素的比值一般 $\leqslant 1 0 ^ { - 1 2 }$ ，除惰性气体宇宙成因核素外，加速器质谱是测量宇宙成因核素的主要技术方法。宇宙射线是高动能带电粒子，大多来自我们银河系内的超新星。当宇宙射线进入地球时，与大气中物质碰撞，发生一系列次级反应，产生次级粒子；这些粒子会与大气中的氮原子和氧原子等发生碰撞，从而产生诸如 $^ { 1 4 } \mathrm { C }$ 和 $^ { 1 0 } \mathrm { { B e } }$ e等大气成因宇宙成因核素；随后，一些粒子最终到达地球表面，与地球表层岩石矿物中的原子相互作用，生成就地成因核素，如10Be、 $^ { 1 4 } \mathrm { C }$ 、$^ { 2 6 } \mathrm { A l }$ l和 $^ { 3 6 } \mathrm { C l }$ l等核素。宇宙成因核素的产率受宇宙射线强度、太阳活动强度、地磁场变化、矿物中靶元素浓度、遮蔽和埋藏深度等因素的影响［44］ 。

加速器质谱在地质年代学方法的应用也集中在放射性宇宙成因核素年代学方面。根据放射性同位素定量原理 $\boldsymbol { N } = \boldsymbol { N } _ { 0 } \mathrm { e } ^ { - \lambda t }$ t， $N _ { 0 }$ 是样品封闭前放射性核素的初始活度或浓度， $N$ 是经历时间 $t$ t衰变后的剩余活度或浓度），如果知道宇宙成因核素初始活度或衰变子核的浓度，就可以通过测量其子核浓度，得到样品的年代。常规的放射性同位素定年，如 U系定年，多根据定年矿物中的子核浓度来进行定年，定年的前提是子核和母核元素高度不相容，在矿物形成过程中，子核和母核元素在矿物中高度分异，子核的初始值为零或可以忽略不计。在实际应用中，通过对初始子核的浓度厘定，如在 $^ { 2 3 4 } \mathrm { U } - ^ { 2 3 0 } \mathrm { T h }$ 定年过程中，可通过测量矿物中的232Th活度，对矿物中初始 $^ { 2 3 0 } \mathrm { T h }$ 进行估算［45］ 。而宇宙成因核素年代学方法，尽管一些核素（如 $^ { 1 4 } \mathrm { C }$ 定年）也是根据核素的放射性衰变规律进行年代厘定，但其具体的定年方法与传统放射性同位素定年方法并不完全相同；另外，一些核素的定年方法和原理与传统放射性同位素定年方法完全不同，拓展了放射性定年方法及其应用领域。

宇宙成因核素年代学方法概括起来可以分为 3类：1）放射性定年；2）暴露年代学方法（暴露年代学）；3）埋藏年代学方法（埋藏年代学）。宇宙成因核素放射性定年方法，目前主要是 $^ { 1 4 } \mathrm { C }$ 定年，也是现有加速器质谱测定的主要核素。尽管全球有 160多台加速器质谱，但在这些质谱的应用中， $^ { 1 4 } \mathrm { C }$ 测量的工作量占 $9 0 \%$ 以上；其次是暴露年代学和埋藏年代学宇宙成因核素的测量（10Be、26Al等）。

# 4.1 ${ } ^ { 1 4 } \mathbf { C }$ 定年

$^ { 1 4 } \mathrm { C }$ 年代学，又称放射性碳（Radiocarbon）年代

学，是目前应用最广泛的年代学方法［45］ 。经过准确校准的 $^ { 1 4 } \mathrm { C }$ 年龄是末次冰期考古、地质以及历史时期形成有机化合物准确时间框架的“黄金标准”（GoldStandard）［46］ 。

$^ { 1 4 } \mathrm { C }$ 定年方法在技术方法上与传统同位素年代学方法有所差别。传统放射性同位素定年中，一般通过测量子核和母核的活度，根据母核－衰变产生的子核的关系来进行年代年测定；而 $^ { 1 4 } \mathrm { C }$ 的子核是$\mathrm { ^ { 1 4 } N }$ ，其在大气中丰度非常大，在定年物质中无法识别和厘定放射性成因的 $\mathrm { ^ { 1 4 } N }$ 。因此，难以通过测量子核 $\mathrm { ^ { 1 4 } N }$ 的进行 $^ { 1 4 } \mathrm { C }$ 定年。 $^ { 1 4 } \mathrm { C }$ 定年是通过测量定年物质中的残留 $^ { 1 4 } \mathrm { C }$ 活度与其初始活度之间关系来进行年代厘定的，其初始浓度即定年物质形成时期的大气$\mathrm { C O } _ { 2 }$ 中的 $^ { 1 4 } \mathrm { C }$ 活度。因此， $^ { 1 4 } \mathrm { C }$ 定年的重要前提是定年物质中的碳必须是直接或间接来自含碳物质形成时期的大气 $\mathrm { C O } _ { 2 }$ 。

因此， $^ { 1 4 } \mathrm { C }$ 定年的流程是通过对样品中 $^ { 1 4 } \mathrm { C }$ 进行测量，然后根据 $^ { 1 4 } \mathrm { C }$ 活度计算样品的 $^ { 1 4 } \mathrm { C }$ 年龄。得到 $^ { 1 4 } \mathrm { C }$ 年代后，还需要通过大气 $\mathrm { C O } _ { 2 }$ 的 $^ { 1 4 } \mathrm { C }$ 活度校正，即将样品的 $^ { 1 4 } \mathrm { C }$ 活度初始值校正到样品形成时期大气 $\mathrm { C O } _ { 2 }$ 的 $^ { 1 4 } \mathrm { C }$ 活度水平，得到日历年代。这就需要对地质历史时期大气 $\mathrm { C O } _ { 2 }$ 中 $^ { 1 4 } \mathrm { C }$ 活度进行重

建，即 $^ { 1 4 } \mathrm { C }$ 校正曲线的建立。大气 $\mathrm { C O } _ { 2 }$ 中 $^ { 1 4 } \mathrm { C }$ 活度的重建主要是基于树轮、冰芯、石笋和海洋沉积等具有较好年代控制的沉积记录来建立的，其中树轮是最可靠的记录［47～48］ 。目前标准曲线的时间长度已经达到了 55000年，但基于树轮的 $^ { 1 4 } \mathrm { C }$ 记录只能到13900年［48］ 。

加速器质谱极大地推进了 $^ { 1 4 } \mathrm { C }$ 测量和应用的拓展，与传统放射性衰变计数相比，显示出巨大的优势。如 $1 . 0 \mathrm { m g }$ 的有机质，其 ${ } ^ { 1 4 } \mathrm { C } / { } ^ { 1 2 } \mathrm { C }$ 比值在 ${ 1 0 } ^ { - 1 2 }$ 水平，含有大约 6千万个 $^ { 1 4 } \mathrm { C }$ 原子。根据其 $5 7 3 0 { \pm } 4 0$ a的半衰期计算， $1 . 0 \mathrm { m g }$ 样品中，1小时 $^ { 1 4 } \mathrm { C }$ 衰变的原子个数小于 1，而加速器质谱可以探测到 6千万个原子的 $2 \%$ （即 120万个 $^ { 1 4 } \mathrm { C }$ 原子），其探测效率是辐射衰变探测技术的 1百万倍。因此，利用放射性衰变计数，一般样品量需要 $3 \sim 5 \mathrm { \ g }$ ，探测时间在 1天以上；而现代加速器质谱能对微克级碳含量样品的 $^ { 1 4 } \mathrm { C }$ 进行精确测量，其样品量减少了 1百万倍。

$^ { 1 4 } \mathrm { C }$ 定年的材料包括动植物残体、土壤和湖泊沉积中的有机体、有机质、无机碳酸盐（包括生物碳酸盐壳体）等。但 $^ { 1 4 } \mathrm { C }$ 定年的比较理想材料是生命周期较短的植物残体，如一年生的植物及其残体。除了样品条件外，一个必须满足的条件就是定年物质的形成与所研究的过程和事件具有密切联系，且关系明确，如沉积物有机质或有机体定年中，有机质和有机体必须与沉积过程同期。如果沉积物中的植物残体，如树叶和一年生的草类植物残体随沉积物一起被搬运并沉积，那其年代就代表沉积时期的年代；而在另一种情况下，如土壤中的有机残体和黑炭，是土壤形成过程中的产物，如果这些含碳物质由于土壤风化侵蚀，随后搬运并沉积，那这些碳来源的 $^ { 1 4 } \mathrm { C }$ 年代显然不能代表沉积时代；此外，在考古断代中的 $^ { 1 4 } \mathrm { C }$ 定年，文化层中的木炭和古墓葬中的棺椁所用的木材，其年代可能远老于文化层形成和古墓的年代。

对于 $^ { 1 4 } \mathrm { C }$ 定年范围，上限年代主要依赖于探测背景值所决定。理论上，其上限年代为放射性元素的 8～10个半衰期。对于 $^ { 1 4 } \mathrm { C }$ 而言，理论定年范围在距今 $5 0 0 0 0 \sim 6 0 0 0 0$ 年左右（今指公元 1950年）。具体到每个实验室，由于制样水平和加速器质谱的探测能力的差别，背景值也存在一定差异，定年上限一般在 $4 0 0 0 0 \sim 6 0 0 0 0$ 年不等，但多数实验室的定年上限在距今 50000年以下。对于加速质谱测量报道的最低的背景值是距今 $6 0 . 5 \mathrm { k a }$ a，定年材料为更新世沉积物中的木头，样品量为 $1 ~ \mathrm { m g } ^ { [ 4 9 ] }$ ；而利用其它

方法，如衰变技术方法与同位素富集方法结合，其$^ { 1 4 } \mathrm { C }$ 定年的年代上限可达距今 75000年［50］ 。另外，对于 $^ { 1 4 } \mathrm { C }$ 定年精度而言，除了受实验室制样过程中的污染和仪器的探测精度影响外，同时受过去大气 $\mathrm { C O } _ { 2 }$ 中 $^ { 1 4 } \mathrm { C }$ 活动重建，即 $^ { 1 4 } \mathrm { C }$ 校正曲线精度的影响。根据最新的国际 IntCal20校正曲线［48］ ，包 括 南、北 半球、海水表层的 $^ { 1 4 } \mathrm { C }$ 校正曲线已经延伸到了距今55000年前（cal．aB．P．）。不同时段的校正曲线的精度也不相同，在某些时段，特别是 $^ { 1 4 } \mathrm { C }$ 校正曲线的平台区，即 $^ { 1 4 } \mathrm { C }$ 变率较小时段，产生的年代不确定性会增加（图 5）。

$^ { 1 4 } \mathrm { C }$ 测量结果在使用校正曲线时需考虑以下两个方面的因素影响：一是在短期内， $^ { 1 4 } \mathrm { C }$ 产率主要受太阳活动和地磁场变化影响；另一个因素是人类活动的影响，其中工业革命以来人类活动成为主要影响因素。人类活动的影响，一是稀释作用，即化石燃料（不含 $^ { 1 4 } \mathrm { C }$ ）的燃烧，产生大量 $\mathrm { C O } _ { 2 }$ 排放，对大气中 $^ { 1 4 } \mathrm { C }$ 活度起到稀释作用；另一个因素是人工核素 $^ { 1 4 } \mathrm { C }$ ，由原子弹和核反应过程产生（也成“核爆14C ”）。核爆产生的 $^ { 1 4 } \mathrm { C }$ 使 1963年大气和陆生植物体中的 $^ { 1 4 } \mathrm { C }$ 活度增加了 1倍［51］ 。随《国际核试验禁令条约》的签订，核爆试验减少，加之化石燃料 $\mathrm { C O } _ { 2 }$ 排放，导致大气中 $^ { 1 4 } \mathrm { C }$ 活度缓慢降低。由于上述因素的综合影响，对于 $^ { 1 4 } \mathrm { C }$ 定年来说，如果 $^ { 1 4 } \mathrm { C }$ 年龄小于 200年，一般可认定为现代碳年龄；但在某些特定情况下，如清楚定年材料的沉积时段受人类活动的影响程度，仍可提供一定的年代学信息。

暴露在宇宙射线下稳定的地质表面中的宇宙成因核素会随时间累积［44］ 。如果无侵蚀，则在任何地表深度 $z$ z的宇宙成因核素的浓度 $\cdot N _ { \mathrm { t o t a l } } ( \textit { t , z } )$ ）随时间（t）的变化为：

$$

由以上所有公式可知，宇成核素的累积量至少是暴露年龄和侵蚀剥蚀速率两个独立参数的函数。因此，如果表面侵蚀速率不能通过独立的方法进行确定和估算时，单一核素只能给出最小暴露年龄。而要获得较可靠的暴露年龄，需对同一样品进行至少两种核素的测定，并且这两种核素的半衰期差距越大越好。如同时 $^ { 1 4 } \mathrm { C } - ^ { 1 0 } \mathrm { B e }$ e要比 $^ { 1 0 } \mathrm { B e } - { } ^ { 2 6 } \mathrm { A l }$ l的效果要好———这是由于 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l半衰期只差一倍，它们的比值不是侵蚀速率和暴露年龄的敏感函数［53］ 。

另外，还可以通过对大于厚度 $1 , 5 \mathrm { ~ m ~ }$ 的剖面进行系统的样品测试来确定暴露年龄和侵蚀速率，即通过单一核素的浓度－深度剖面与模型预测拟合来求得暴露年龄和侵蚀速率。一般情况下剖面深度要大于 $1 , 5 \mathrm { ~ m ~ }$ ，样品个数在 6个以上［54～56］ 。

暴露年龄的研究对象，包括：冰碛物、洪积物和海岸沉积；熔岩流暴露年龄；侵蚀面的暴露年龄，包括冰蚀岩床、洪积切面、浪切面、风蚀岩床、崩岩疤痕、断裂疤痕等。另外，在进行暴露年龄研究时，还要考虑遮挡、覆盖度、抬升、下沉等因素对宇成核素产率的影响。

# 4.3 埋藏年代学

宇宙成因核素埋藏年代定年原理是，定年矿物在地表暴露一段时间，矿物中累积了一定量的宇宙成因核素，而后发生快速埋藏，屏蔽宇宙射线的作用，矿物中不再形成新的宇宙成因核素，样品中的宇宙成因核素含量依其半衰期随时间衰变减少。埋藏年龄相对于暴露年龄而言，由于风化和侵蚀只对表层物质起作用，因此埋藏物质和表层物质的侵蚀一般影响较小。

一种情况是，样品长期暴露在稳定地球表面，其起始产率 $( P _ { i } ( 0 )$ ）和侵蚀速率 ${ \bf \Xi } ( \bf \Lambda _ { \varepsilon } \delta )$ ）达到平衡状态，则样品中宇宙成因核素埋藏前的浓度 $| N _ { i }$ ）为：

$$
N _ {i} = \frac {P _ {i} (0)}{\lambda_ {i} + \rho \varepsilon / \Lambda_ {i}} \tag {13}
$$

具体到 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l：

$$
N _ {2 6} = \frac {P _ {2 6} (0)}{\lambda_ {2 6} + \rho \varepsilon / \Lambda_ {i}} \tag {14}
$$

$$
N _ {1 0} = \frac {P _ {1 0} (0)}{\lambda_ {1 0} + \rho \varepsilon / \Lambda_ {i}} \tag {15}
$$

另外，如果样品埋藏深度不够，埋藏后还会产生新的宇宙成因核素，则埋藏后的核素浓度变化为：

$$
N _ {2 6} = \frac {P _ {2 6} (0)}{\lambda_ {2 6} + \rho \varepsilon / \Lambda_ {i}} \mathrm {e} ^ {- \lambda_ {2 6} t _ {b}} + \frac {P _ {2 6} (z)}{\lambda_ {2 6}} \left(1 - \mathrm {e} ^ {- \lambda_ {2 6} t _ {b}}\right) \tag {16}
$$

$$
N _ {1 0} = \frac {P _ {1 0} (0)}{\lambda_ {1 0} + \rho \varepsilon / \Lambda_ {i}} \mathrm {e} ^ {- \lambda_ {1 0} t _ {\mathrm {b}}} + \frac {P _ {1 0} (z)}{\lambda_ {1 0}} \left(1 - \mathrm {e} ^ {- \lambda_ {1 0} t _ {\mathrm {b}}}\right) \tag {17}
$$

因此，通过测量样品中 $^ { 1 0 } \mathrm { { B e } }$ 和 $^ { 2 6 } \mathrm { A l }$ l浓度，以及得到这两种核素在研究区的产率及其随深度的变化，根据公式（16）和（17）就可以得到埋藏年龄 $\left( \mathbf { \sigma } _ { t _ { \mathrm { b } } } \right)$ ）和侵蚀速率。如果样品埋藏足够深且埋藏时间较短（不是远大于核素的半衰期），其埋藏后产率可以忽略不计；另外，在暴露阶段，如果侵蚀速率足够大，侵蚀过程中核素衰变的核素数可以忽略不计（一般情况下满足），则公式（16）和（17）简化为：

$$
N _ {2 6} = \frac {P _ {2 6} (0)}{\varepsilon / \Lambda_ {i}} \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \tag {18}
$$

$$
N _ {1 0} = \frac {P _ {1 0} (0)}{\varepsilon / \Lambda_ {i}} \mathrm {e} ^ {- \lambda_ {1 0} t _ {\mathrm {b}}} \tag {19}
$$

因此，对于两个或两个以上宇宙成因核素测量，其核素比值随时间变化为：

$$
R _ {\mathrm {A B}} \left(t _ {\mathrm {b}}\right) = \frac {C _ {\mathrm {A}} \left(t _ {\mathrm {b}}\right)}{C _ {\mathrm {B}} \left(t _ {\mathrm {b}}\right)} = R _ {\mathrm {A B}} (0) \mathrm {e} ^ {- t _ {\mathrm {b}} \left(\lambda_ {\mathrm {A}} - \lambda_ {\mathrm {B}}\right)} \tag {20}
$$

则埋藏年龄为：

$$
t _ {\mathrm {b}} = - \ln \left(\frac {R _ {\mathrm {A B}} \left(t _ {\mathrm {b}}\right)}{R _ {\mathrm {A B}} (0)}\right) / \left(\lambda_ {\mathrm {A}} - \lambda_ {\mathrm {B}}\right) \tag {21}
$$

公式（20）～（21）中， $R _ { \mathrm { A B } }$ 是两核素 $C _ { \mathrm { { A } } }$ 和 $C _ { \mathrm { B } }$ 的比值，而 $t _ { \mathrm { b } }$ 是埋藏年龄， $\lambda _ { \mathrm { ~ A ~ } }$ 和 $\lambda _ { \mathrm { ~ B ~ } }$ 是两核素的衰变常数； $R _ { \mathrm { A B } } ( 0 )$ 和 $R _ { \mathrm { A B } } \left( \mathrm { \Delta } t _ { \mathrm { b } } \right)$ ）分别是起始时间和测得时间的核素比值。

目前常用的，用于埋藏年龄的核素对包括$^ { 1 0 } \mathrm { B e } - ^ { 2 6 } \mathrm { A l }$ l， $^ { 1 4 } \mathrm { C } - ^ { 1 0 } \mathrm { B e }$ e， $^ { 2 1 } \mathrm { N e } - ^ { 1 0 } \mathrm { B e }$ ， $^ { 2 1 } \mathrm { N e } - ^ { 3 6 } \mathrm { C l }$ l等，其中应用最广泛也是最合适的用于埋藏年龄的核素对是 $^ { 1 0 } \mathrm { { B e } }$ 和 $^ { 2 6 } \mathrm { A l } ^ { [ 5 3 , 5 7 \sim 5 8 ] }$ 。这是由于［59］ ：1）它们产生于同一矿物（石英）中；2）它们产率比值不受纬度和海拔的影响；3）在 岩 石 中 核 素 比 值 随 深 度 变 化 不 大；$4 ) ^ { 2 6 } \mathrm { A l / ^ { 1 0 } B e }$ 的初始比值对侵蚀速率相对不敏感。特征 2）和 3）表明，它们的初始比值，即埋藏前的比值通常能较好确定，近似于地表散裂作用产生的核素比值，特征 3）在不同应用情况下应给予考虑［51，59］ 。

# 4.3.1 简单埋藏年龄

如果样品快速埋藏并与宇宙射线完全隔离，那么样品的暴露年龄可以利用公式（14）和（15）进行

计算。快速埋藏是指样品埋藏与宇宙射线隔离过程所用的时间，远小于埋藏年龄［58］ 。如一旦突发事件沉积物被带入深的洞穴系统［53，60］ ，其依赖于埋藏前宇成核素的浓度和埋藏时间，一般完全隔离宇宙射线的沉积厚度在 $\geqslant 3 0 \mathbf { m } ^ { [ 5 3 , 6 1 ] }$ 。

# 4.3.2 最大和最小年龄

对于埋藏深度较浅 $\left( < 3 0 \mathrm { ~ m ~ } \right)$ ）、且埋藏时间较长的样品，需要考虑埋藏后产量的影响［58～59］ ；另外，样品在埋藏前，可能经历复杂的暴露历史，在埋藏前最后一次暴露前，可能含有继承组分，造成埋藏时核素比值与地表散列的初始值差别较大。对于继承组分和埋藏后产率的影响，一般采用最大、最小和等时线方法来处理上述因素的影响。

对于埋藏深度不够的样品，其埋藏后产率组分的影响明显［53］ 。由于埋藏后产生核素的核素比值较大，因此，在不考虑继承组分影响情况下，获得的年龄比其真实年龄年轻，为最小年龄；同理，当对埋藏后核素的产量进行最大估算获得的年龄就是最大年龄。在自然条件下，侵蚀是常见现象，导致样品埋藏深度随时间的变化相应变薄。因此，根据现今埋藏深度来估算的埋藏后产率大于真实产率，是埋藏后的最大产率；利用最大埋藏产率对样品的核素含量进行校正得到的年龄即是最大年龄。

# 4.3.3 等时线方法

等 时 线 年 代 学 方 法 是 Balco和 Rovey［59］提 出的，首先应用于土壤和沉积剖面不同深度样品，通过多样品分析来进行埋藏年代计算，其有两个重要前提［59］ ：1）无侵蚀，暴露时间（t）足够短，暴露过程中核素衰变量可以忽略不计；2）埋藏足够深，埋藏后产率可以忽略不计。在满足上述两个条件下，公式（16）和（17）变为

$$
N _ {1 0} = \left(N _ {1 0, \text {i n h}} + P _ {1 0} t _ {\mathrm {e}} \mathrm {e} ^ {- Z / \Lambda_ {\mathrm {i}}} \right) \mathrm {e} ^ {- \lambda_ {1 0} t _ {\mathrm {b}}} \rightarrow t _ {\mathrm {e}} \mathrm {e} ^ {- Z / \Lambda_ {\mathrm {i}}} =
$$

$$
\left(N _ {1 0} \mathrm {e} ^ {\lambda_ {1 0} t _ {\mathrm {h}}} - N _ {1 0, \text {i n h}}\right) / P _ {1 0} \tag {22}
$$

$$
N _ {2 6} = \left(N _ {2 6, \text {i n h}} + P _ {2 6} t _ {\mathrm {e}} \mathrm {e} ^ {- Z / A _ {\mathrm {i}}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \tag {23}
$$

公式 （22）～（23）中， $N _ { \mathrm { 1 0 , i n h } }$ 和 $N _ { 2 6 , \mathrm { i n h } }$ 为 继 承 组分， $P _ { \mathrm { ~ i ~ } } t _ { \mathrm { ~ e ~ } } \mathrm { e } ^ { - Z / A _ { \mathrm { ~ i ~ } } }$ i为埋藏前最后一次暴露过程中产生的核素量（atoms／g）， $Z$ 是质量深度 $( \mathbf { \Delta g } / \mathbf { c m } ^ { 2 }$ ）。将公式（22）带入公式（23），得到如下：

$$
N _ {2 6} = \left(N _ {2 6, \text {i n h}} + P _ {2 6} \left(N _ {1 0} \mathrm {e} ^ {\lambda_ {1 0} t _ {\mathrm {b}}} - N _ {1 0, \text {i n h}}\right) / P _ {1 0}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \rightarrow
$$

$$
N _ {2 6} = \left(N _ {2 6, \text {i n h}} + R _ {\text {i n t}} \left(N _ {1 0} \mathrm {e} ^ {\lambda_ {1 0} t _ {\mathrm {b}}} - N _ {1 0, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \rightarrow \right.
$$

$$
N _ {2 6} = R _ {\text {i n t}} N _ {1 0} \mathrm {e} ^ {- (\lambda_ {2 6} - \lambda_ {1 0}) t _ {\mathrm {b}}} + \left(N _ {2 6, \text {i n h}} - R _ {\text {i n t}} N _ {1 0, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \tag {24}
$$

公式（24）表明，如果测量具有相同埋藏年龄的

样品，测量获得的 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l浓度具有线性关系，斜率为 $R _ { \mathrm { i n t } } \mathbf { e } ^ { - ( \lambda _ { 2 6 } - \lambda _ { 1 0 } ) t _ { \mathrm { b } } [ 5 9 ] }$ ，且过点 $N _ { 2 6 , \mathrm { i n h } }$ ， $N _ { \scriptscriptstyle { 1 0 , \mathrm { i n h } } } \ )$ ）。因此，通过测量多个样品，进行直线拟合，就能得到其斜率 $R _ { \mathrm { { m } } }$ ，进而获得其埋藏年龄：

$$
t _ {\mathrm {b}} = \ln \left(R _ {\mathrm {m}} / R _ {\mathrm {i n t}}\right) / \left(\lambda_ {2 6} - \lambda_ {1 0}\right) \tag {25}
$$

Grang er［58］将这一方法延伸到考古年代学中。考古遗址中，地层埋藏的石英样品 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l，如果矿物 的 埋 藏 过 程 和 时 间 相 同，则 样 品 埋 藏 后（postbural）的产率相同，即样品中的核素浓度由埋藏时的初始浓度和埋藏后的浓度 $( N _ { \mathrm { i , p b } } )$ ）产生的组分所组成，公式如下：

$$
\begin{array}{l} N _ {1 0} = \left(N _ {1 0, \text {i n h}}\right) e ^ {- \lambda_ {1 0} t _ {\mathrm {b}}} + N _ {1 0, \mathrm {p b}} \longrightarrow N _ {1 0} - N _ {1 0, \mathrm {p b}} \\ = \left(N _ {1 0, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {1 0} t _ {\mathrm {b}}} \tag {26} \\ \end{array}
$$

$$
\begin{array}{l} N _ {2 6} = \left(N _ {2 6, \text {i n h}}\right) e ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} + N _ {2 6, \mathrm {p b}} \rightarrow N _ {2 6} - N _ {2 6, \mathrm {p b}} \\ = \left(N _ {2 6, \text {i n h}}\right) \mathrm {e} ^ {- \lambda_ {2 6} t _ {\mathrm {b}}} \tag {27} \\ \end{array}
$$

由公式（26）和（27）得到：

$$
\begin{array}{l} \frac {N _ {2 6} - N _ {2 6 , \mathrm {p b}}}{N _ {1 0} - N _ {1 0 , \mathrm {p b}}} = \frac {N _ {2 6 , \mathrm {i n h}}}{N _ {1 0 , \mathrm {i n h}}} \mathrm {e} ^ {- (\lambda_ {2 6} - \lambda_ {1 0}) t _ {\mathrm {b}}} \\ = R _ {\mathrm {i n h}} \mathrm {e} ^ {- (\lambda_ {2 6} - \lambda_ {1 0}) t _ {\mathrm {b}}} \tag {28} \\ \end{array}
$$

与土壤和沉积地层相同，对于地层中具有相同埋藏后产生组分的不同样品， $N _ { 2 6 }$ 和 $N _ { 1 0 }$ 呈线性关系，斜率为 R e－（λ26－λ10）tb ［59］ 。 $R _ { \mathrm { i n } } \mathrm { e } ^ { - ( \lambda _ { 2 6 } - \lambda _ { 1 0 } ) t _ { \mathrm { b } } [ 5 9 ] }$ 因此，通过拟合两核素之间线性关系，获得其斜率，就可计算埋藏年龄。

对于继承组分较小的样品，可以根据每个样品的测量值 $R _ { \mathrm { A B } } ( t _ { \mathrm { b } } ) )$ ）计算埋藏年龄，所得数据 $^ { 1 0 } \mathrm { { B e } }$ 和$^ { 2 6 } \mathrm { A l }$ l应位于通过原点的直线上，而有继承组分时，数据不会通过原点；但在实际应用中，由于继承、埋藏后组分和侵蚀速率的影响，可能造成核素初始比值的变化［58］ 。对于上述因素的影响，可以通过多次线性拟合、继承和埋藏组分及侵蚀速率估算，然后校正测量值，经过多次迭代后最终获得可信的埋藏年龄［58～59］ 。 。

等时线方法的一个重要前提是样品经历相同的地质过程，样品经历暴露埋藏后其核素浓度应位于一条直线［58～59］ 。因此，样品的核素浓度是否位于同一直线是判别其是否符合等时线年代学方法的依据。如果样品核素浓度非常离散，表明样品经历了不同且复杂的暴露和／或埋藏过程，不适合进行等时线年龄拟合。

$^ { 2 6 } \mathrm { A l / ^ { 1 0 } B e }$ 的定年范围取决于 $^ { 2 6 } \mathrm { A l }$ l的半衰期和测试精度［53］ 。假设 $R _ { \mathrm { A B } } \big ( t _ { \mathrm { b } } \big )$ ）的测量精度为 $5 , 0 \%$ ，造成的埋藏年龄的误差在 10万年，那么，这种方法的下限年龄为 10万年，上限年龄为 $5 . 0 \mathrm { M a } ^ { [ 5 3 ] }$ 。这主要是由于超过 $5 , 0 \mathrm { M a }$ 时， $^ { 2 6 } \mathrm { A l }$ l丰度低于仪器的探测水

平［53］ 。在实际应用中，由于 $^ { 2 6 } \mathrm { A l }$ l初始浓度的变化，其定年范围可能更小［58］ 。

由于埋藏年龄依赖于 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l的衰变，因此精确知道它们的衰变常数和半衰期尤为重要［53］ 。对于 $^ { 1 0 } \mathrm { { B e } }$ e的半衰期目前存在较大争议，早期认为是$1 . 5 1 { \pm } 0 . 0 6 \mathrm { M a } ^ { [ 6 2 ] }$ ，目前仍被广泛应用；Nishiizum等［63］ 的研究认为是 $1 . 3 6 { \pm } 0 . 0 7 \ \mathrm { M a }$ ；最近一些学者认为 $^ { 1 0 } \mathrm { { B e } }$ e半衰期为 $1 . 3 9 { \pm } 0 . 0 1 \mathrm { M a } ^ { [ 6 4 \sim 6 5 ] }$ 。因此，在报告埋藏年龄时必须对所用的 $^ { 1 0 } \mathrm { { B e } }$ e半衰期进行说明，而且核素浓度和 $^ { 2 6 } \mathrm { A l / ^ { 1 0 } B e }$ 的产率比值必须与所用半衰期一致。

# 5 总结与展望

自 20世纪 70年代末，随着串列式加速器质谱的发展与成熟，加速器质谱技术已成为测量微量和珍稀样品以及超低含量稀有同位素的主要方法，有时是唯一的测试技术。测定的核素由初始的 $^ { 1 4 } \mathrm { C }$ 和$^ { 1 0 } \mathrm { { B e } }$ e等少数几个核素，拓展到如今的 60多个，其应用领域也获得了极大拓展，具体到地球科学，应用涵盖了从板块构造活动到行星科学的各个领域，推动了相关学科的快速发展。 $^ { 1 4 } \mathrm { C }$ 定年和埋藏年龄为理解人类起源、迁徙、演化和文化技术交流等方面提供了重要年代学支撑；宇宙成因核素年代学的出现，也使定量化研究外力地质作用过程，如河流、湖泊和海洋阶地的形成，侵蚀风化速率的厘定以及地质地貌过程的演化成为可能；此外，基于加速器质谱探测技术的宇宙成因核素已成为研究太阳活动与地磁场变化的主要技术方法，如冰芯、树轮和具有较好年代控制的沉积物中的宇宙成因核素是太阳活动和古地磁变化的良好记录［66～68］ ；在行星科学中广泛用于宇宙和太阳射线强度变化、星外物质的暴露年龄厘定、超新星事件的识别等领域［69～71］ ；在环境科学领域，广泛应用于人工核素和核污染的源区识别、运移迁移和沉积机制及生态危害评价等研究［72］ 。目前，在地球科学中，常用的核素主要是$^ { 1 4 } \mathrm { C }$ ，其次是 $^ { 1 0 } \mathrm { { B e } }$ e，紧随其后的是 $^ { 2 6 } \mathrm { A l }$ l、 $^ { 3 6 } \mathrm { C l }$ l、 $^ { 4 1 } \mathrm { C a }$ 和129I［31，73～74］ 。未来，加速器质谱发展的一个永恒的 $^ { 1 2 9 } \mathrm { I } ^ { [ 3 1 , 7 3 \sim 7 4 ] }$ 主题仍然是通过硬件和软件的改进，如离子源和探测器的改进、引入诸如激光剥蚀等新技术手段，进一步降低同量异位素和分子的影响，提高稀有同位素识别的灵敏度和计数效率。在实验技术方法上，除了通过化学方法进一步纯化富集稀有同位素和降低干扰核素浓度外，还需要通过合成核素的化合物和分子状态，提高核素的离子化、剥离和传输效

率，同 时 有 效 分 离 同 位 素 和 降 低 同 量 异 位 素 的干扰。
