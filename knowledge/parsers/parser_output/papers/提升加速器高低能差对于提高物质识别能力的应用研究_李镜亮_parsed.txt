# 提升加速器高低能差对于提高物质识别能力的应用研究

■ 文/ 中广核贝谷科技有限公司 李镜亮 张得涛 邹光辉 陈朝龙 黎超

摘　要：双能 X 射线透射成像技术是一种基于两种不同能量 X 射线穿透物体后，通过分析物质对不同能量 X 射线的吸收差异，实现材料识别的成像方法。海关对货物、集装箱等目标的物质识别能力要求达到四分类，但行业内普遍难以达到，特别是较厚物质区分难度很大，在图像上出现混色或涂色错误等问题。本文基于自主研发的高端组合移动式集装箱车辆检查系统，采用6/3MeV双能驻波电子直线加速器，深入研究了物质识别的影响因素，从加速器设计、能谱净化两方面协同改进，提升高低能差，成功地提升了物质识别能力，验证了解决方案的有效性，为行业内安检系统的图像物质识别能力提升提供了切实可行的改进思路。

关键字：双能透射成像 物质识别 高低能差 能谱净化 双能加速器

# 1 引言

在海关货物安检中，利用 X 射线成像进行货物车辆检查已成为各国海关的通行做法，无须开箱人工检查，从而实现了快速通关，减轻了海关人员的工作强度，提高了违禁品检出率。基于 X 射线透射成像原理，通过光电效应探测物质阻挡衰减后的射线，生成灰度图像，从而判断物质的形态厚度判断是否与报关货物相符。如果射线源采用双能电子直线加速器，通过调节加速器能量（如 6MeV 和 3MeV），可生成两种不同能量级别的 X射线。低能X射线对低原子序数物质（有机物）更敏感，而高能 X 射线可穿透高密度物质（如金属、厚钢板）。不同材料对高低能 X 射线的吸收率存在差异。通过分析两种能量下 X 射线的衰减数据，可计算被检物的等效原子序数（Z值）[1]，从而区分有机物（如毒品、爆炸物等）、无机物（如陶瓷、玻璃等）和金属（如武器、走私品等）。

从而显著提升海关对货物、集装箱等目标的检测能力和违禁品识别精度。

各国海关客户对于物质识别的要求越来越高，在 IEC62523-2010《辐射防护仪货物车辆射线照相检查系统》中针对物质识别能力提出了四分类要求，即区分石墨（graphite）、铝（aluminium）、钢（steel）、铅（lead）四种典型物质的不同质量厚度，由薄到厚分别为 T1~T5，这代表了安检成像系统对于有机物、混合物、无机物、重金属的物质分辨能力，如表1所示。

但由于影响安检成像系统物质识别能力的因素复杂多样，行业内普遍难以达到四分类，特别是较厚物质区分难度很大，铁和铅容易发生识别错误，在图像上容易出现混色或涂色错误等问题。Chen Y 等 [2] 通过测定高低能差下的物质识别检出率，发现在高低能差 $\geqslant$ 3MeV（2MeV/5MeV）下，铀（ $\scriptstyle ( Z = 9 2 )$ ）与钨（ $( Z { = } 7 4 )$ ）的 R 值差异增大，检出率可大幅提高。本文基于自主研发的高端组合移动式集装箱车辆检查系统，采用 6/3MeV 双能驻波电子直线加速器，对于所获取的双能图像，深入研究了物质识别的影响因素，从加速器设计、能谱净化三方面协同改进，提升高低能差，成功的提升了物质识别能力，验证了解决方案的有效性。

# 2 物质识别原理

驻波电子直线加速器的工作原理是脉冲调制器将市电转变成高压脉冲。高压脉冲通过脉冲变压器为磁控管（或速调管）供电。磁控管在微波激励源激励下产生射频微波，该微波功率经过波导系统以及波导窗馈入到驻波加速管中，形成驻波。加速管的电子枪产生热电子，并与高压脉冲同步加速至加速腔中。电子与加速腔中的驻波电场相互作用，使电子在驻波场中不断得到加速，在加速终了时打到靶上，由于轫致辐射作用，产生高能 X 射线。双能加速器是通过交替改变磁控管脉冲电流和电子枪高压来实现双能的交替输出的。一般情况下，进入加速管的微波功率越高，被加速电子得到的能量就越高，输出 X 射线的能量就越高；另一方面，电子枪发射电流越大，每个电子获得的能量就越低，输出X射线的能量就越低。在加速器系统中，磁控管脉冲电流的大小决定了微波功率的大小；电子枪高压的高低决定了电子枪发射电流的大小。所以，在加速器系统双能交替输出时，一个高能的脉冲对应的是较高的磁控管脉冲电流和较低的电子枪高压；一个低能的脉冲对应的是较低的磁控管脉冲电流和较高的电子枪高压。

X 射线的衰减，能量损耗情况与其本身的能量有关，也与与之作用的物质所属的类别和其厚度相关联。若一束X 射线在均匀的介质透射，其强度的衰减量与被穿透物质的厚度以及入射射线强度有如下关系：

$$
I = I _ {0} e ^ {- \mu t} \tag {1}
$$

式中：

I —入射X射线强度；

I—透射X射线强度；

t—被穿透物质厚度；

—线衰减系数；

由公式 (1) 可知，X 射线穿透物质时，物体厚度的线性增加会造成射线指数级的衰减。

通过研究X 射线的衰减规律可知，被检物体的厚度是影响透射射线强度的重要原因。双能 X 射线物质识别技术在计算 R 值得过程中，因为使用了比值的形式，恰好消除了厚度因素[3]。对于双能X射线有：

$$
\mu_ {\mathrm {h}} \cdot x = \ln \frac {I _ {o h}}{I _ {h}} \tag {2}
$$

$$
\mu_ {1} \cdot x = \ln \frac {I _ {o l}}{I _ {l}} \tag {3}
$$

式中：

I 、I 分别为高、低能X射线的出射强度；

I 、I 分别为高、低能 X 射线穿透物质后被探测器检测到的强度；

μ 、 $\mu _ { 1 }$ 分别对应高、低能 X 射线在同一物质的衰减系数；

$\pmb { \times }$ 为沿X射线射入路径上被穿透物质的厚度。

由公式 (2)、公式 (3) 两式得：

$$
\frac {\mu_ {l}}{\mu_ {h}} = \frac {\ln \frac {I _ {o l}}{I _ {l}}}{\ln \frac {I _ {o h}}{I _ {h}}} \tag {4}
$$

令

$$
R = \frac {\mu_ {l}}{\mu_ {h}} = \frac {\ln \frac {I _ {o l}}{I _ {l}}}{\ln \frac {I _ {o h}}{I _ {h}}} \tag {5}
$$

R 的值和物质原子序数有关，在 R 的计算过程 x 在比值中被抵消，所以 R 值与被穿透物质的厚度无关。如果检测的是混合物，通过R值得到的是物质的有效原子序数。即便被检测物质是混合物也可以计算 R 值来区分物质种类 [4, 5]。 。

在实际应用中，会针对不同质量厚度的四种标准物质块（如石墨、铝、钢、铅）采集标准图像，计算取得标准R值，作为四种物质的 R 值标准数据库，然后针对实际货物图像计算其不同区域的R 值数据，查询落在标准R值的区间范围，可认定相应区域的实际物体跟哪种标准物质接近，涂上相应颜色显示，帮助给海关客户判断货物的物质种类。

# 3 高低能差对于物质识别能力的影响

双能电子直线加速器在安检成像中的物质识别能力受多种因素影响，这些因素涉及物理原理、设备性能、环境条件以及数据处理算法等。在限定探测器、算法软件、环境条件的前提下，双能电子直线加速器的高低能差对于物质分辨力影响极大，高低能差指电子直线加速器产生的高能 X 射线与低能 X 射线的能量差异（如 3MeV vs.6MeV），其直接影响双能成像的物质分辨能力，高低能X 射线的能量差需足够大，若能量重叠过多，会导致材料区分度下降。

物质对 X 射线的衰减系数随能量变化呈现不同趋势[6] ：低 Z 物质（如有机物）：在低能区（ $< 1 0 0 \ \mathsf { k e V } )$ ）衰

减显著，高能区衰减快速下降；高 Z 物质（如金属）：高低能区衰减差异较小。高低能差越大，高低能衰减比（R值）的差异越显著，Z值分辨力越强。

同时若高低能差过小（如 1MeV vs. 1.5MeV），高低能信号易重叠，导致R值计算误差增大，图像信噪比（SNR）减小，图像质量变差。

因此提高加速器射线的高低能差对于物质识别能力至关重要。

# 4 改进方案

基于自主研发的快检式集装箱货物检查系统，搭载自主研发的 6/3MeV 双能驻波电子直线加速器，从加速器设计、能谱净化两方面协同改进提升高低能差，具体实现路径如下：

1）加速器结构采用分段式加速腔设计。采用多段独立控制的加速腔（3 段结构），通过调节各段微波功率和相位，使电子束在不同腔段获得差异化的能量增益。当低能模式仅激活前段加速腔（3MeV），此时电子束加速距离短，获得能量低，打靶后产生的 X 射线满足 3MeV 能量要求；高能模式则激活全部腔段（6MeV），此时电子束加速距离长，获得能量高，打靶后产生的 X 射线满足6MeV 能量要求。从而显著拉大双能出束时能量差，分离度可达3MeV以上。  
2）能谱滤波净化。在X射线出口处添加可调滤波器，在低能模式下启用低 Z 材料滤片，吸收低能杂散光子，吸收软X射线，减少能谱拖尾。在高能模式下切换为高Z材料滤片，过滤中间能量光子，保留高能特征峰，进一步锐化能谱边缘[7]。

低能模式 (3MeV)：铍窗 $( 0 . 5 \mathsf { m m } ) +$ 铝滤片 $( 1 \mathsf { m m } ) \to$ 吸收 $< 3 0 \mathsf { k e V }$ 光子，提高能谱纯度。

高能模式（6MeV）：铜滤片（2 mm） $^ +$ 锡滤片（1mm） 抑制1–3MeV的康普顿连续谱，减小高能峰半高宽。

切换机构采用旋转式滤片塔，搭载 4–6 种滤片，电机旋转切换时间 ${ < } 1 0 0 \mathrm { m } \mathsf { s } _ { \circ }$ 。

# 4.2 物质识别效果

为评价物质识别效果，引入 α 曲线散点图[8]。

在迪卡尔坐标系中定义横坐标为：

$$
x = a _ {H} = - \ln T \left(E _ {H}, Z, t\right) \cdot s \tag {6}
$$

纵坐标为：

$$
\mathrm {y} = \mathrm {a} _ {\mathrm {L}} - \mathrm {a} _ {\mathrm {H}} = (\ln \mathrm {T} \left(\mathrm {E} _ {\mathrm {H}}, \mathrm {Z}, \mathrm {t}\right) - \ln \mathrm {T} \left(\mathrm {E} _ {\mathrm {L}}, \mathrm {Z}, \mathrm {t}\right)) \cdot \mathrm {s} \tag {7}
$$

式中，s 是比例因子， $\mathrm { T } ( \mathrm { E _ { H } , Z , t } )$ 、 $\mathrm { T } ( \mathrm { E _ { L } , Z , t } )$ 是高低能对应的透视度：

$$
\mathrm {T} (\mathrm {E}, \mathrm {Z}, \mathrm {t}) = \frac {\int_ {0} ^ {\mathrm {E M}} \mathrm {P} (\mathrm {E}) \exp (- \mu (\mathrm {Z} , \mathrm {E}) \mathrm {t}) \mathrm {d E}}{\int_ {0} ^ {\mathrm {E M}} \mathrm {P} (\mathrm {E}) \mathrm {d E}} \tag {8}
$$

式中，P(E) 涉及探测器能量相应函数以及 $\pmb { \times }$ 光源能谱分布函数， $\mu$ (Z,E) 是质量衰减系数，t 是质量厚度， $\mathsf { E } _ { \mathsf { M } }$ 是能谱最高能量。

# 5 结语

本文针对安检成像系统的双能图像特点进行了深入的研究，总结了目前物质识别存在的问题，并对高低能差对于物质识别的影响进行了分析，通过采用分段式加速腔的加速器结构获得差异化的能量增益、可调式滤波器用于净

化能谱等措施，成功将高低能差由2.8MeV提升到3.4MeV，在自主研发的高端组合移动式安检系统上进行了图像验证测试，物质识别效果提升显著，涂色更准确，已经很好地识别开铁和铅。在后续研究中，将进一步针对能谱稳定性开展深入研究，进一步提升物质识别性能。
