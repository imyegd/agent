# 基于雷达回波外推的短临降水预报模型TrajCast在国产加速器上的实践

辛昱杭，王琦祎，孙婧，赵春燕*，刘雨佳，梁雪，陈杰

国家气象信息中心，北京100081

摘 要：【目的】本文旨在构建一种基于深度学习的短时临近降水预报模型，并探索国产加速器在气象领域的应用，以提高气象防灾减灾建设中的预报准确性，为城市建设和交通等提供更可靠的气象保障。【文献范围】本文聚焦于短临降水预报技术的发展，特别是基于深度学习的雷达回波外推方法在气象领域的应用。【应用背景】传统数值预报在前两小时内的降水预报存在不确定性，而基于光流法和交叉相关法等物理模型的雷达回波外推方法在复杂气象条件下预测精度和稳定性受限。【方法】本文采用中国气象局研发的短时强降水AI应用专项数据集，基于TrajGRU深度学习网络架构改进形成短临降水预报模型TrajCast，并在国产加速器上应用数据并行和混合精度训练技术进行模型训练。【结果】试验结果表明，模型在降水预报性能上优于传统光流法，且通过计算优化技术实现了国产加速器单卡模型训练性能4.1倍的加速比。【局限】模型在实际应用中对数据质量和计算资源有一定要求，且在极端天气条件下的表现仍需进一步验证。【结论】本文的研究为短临降水预报提供了新的方法和技术支持，推动了国产加速器在气象领域的应用，模型已在湖南、浙江、湖北等气象部门进行了示范应用，为实现高分辨率、高时率的气象智能预报产品提供了智能算法支撑。

关键词：短临降水预报；深度学习；国产加速器；雷达回波外推；混合精度训练

# Application of Radar Echo Extrapolation Based Model TrajCast on Domestic Accelerators for Short-Term and Imminent Precipitation Forecasting

XIN Yuhang, WANG Qiyi, SUN Jing, ZHAO Chunyan* , LIU Yujia, LIANG Xue, CHEN Jie

National Meteorological Information Centre, Beijing 100081, China

Abstract: [Objective] This paper aims to construct a short- term and imminent precipitation forecasting model based on deep learning and explores the application of domestic accelerators in the field of meteorology, with the goal of improving the accuracy of meteorological disaster prevention and mitigation, and providing more reliable meteorological support for urban development and

transportation. [Literature Scope] This paper focuses on the development of short-term precipitation forecasting technology, especially the application of deep learning-based radar echo extrapolation methods in the field of meteorology. [Context] Traditional numerical weather prediction has uncertainty in precipitation forecasting within the first two hours, and radar echo extrapolation methods based on physical models, such as optical flow and crosscorrelation methods, have limited prediction accuracy and stability under complex meteorological conditions. [Methods] In this study, we employ specialized datasets for short-term intense precipitation of an AI application developed by China Meteorological Administration. Based on TrajGRU, a deep learning network architecture, we establish the short-term and imminent precipitation forecasting model TrajCast. Employing data parallelism and mixed-precision training techniques, the model training is implemented on domestic accelerators. [Results] Experiment results demonstrate that the model outperforms traditional optical flow methods in precipitation forecasting, achieving a 4.1-fold acceleration ratio in model training on a domestic accelerator. [Limitations] The model has certain requirements for data quality and computing resources in practical applications, and its performance under extreme weather conditions still needs further verification. [Conclusions] This study provides new methods and technical support for short-term precipitation forecasting, promotes the application of domestic accelerators in the field of meteorology. The model has been demonstrated and applied in meteorological departments in Hunan, Zhejiang, and Hubei provinces, providing intelligent algorithm support for high- resolution and high- frequency meteorological intelligent forecasting products.

Keywords: short-term and imminent precipitation forecast; deep learning; domestic accelerator; radar echo extrapolation; mixed-precision training

# 引 言

短时临近降水预报旨在对发展迅速的强降水等灾害性天气进行预报，在我国的气象防灾减灾建设中具有重要的作用和意义，为城市的建设、安全生产、交通和生态环境保驾护航。具体而言，短临降水预报是指对一个区域未来短时间段内的降雨进行预测，这一段时间通常是0到6小时，传统降雨预测基于数值预报模式对大气进行物理建模，通过模拟物理模型去进行之后的预测。这种方法的优势是对于更长时间范围的预测比较准确，但是在前一两小时并不能进行预报，不适用于短临场景。

随着雷达技术的不断进步和计算机技术的快速发展，雷达回波外推成为降水预报的关键技术之一，即通过对雷达观测到的回波数据进行处理和分析，预测未来短时间内降水的发展变化。其基本原理是利用雷达回波数据中的时间连续性和空间相关性，通过插值、滤波、平滑等处理方法，提取出回波的运动特征和演变规律，进而预测未来短时间的降水情况。传统的雷达

回波外推方法主要基于光流法、交叉相关法等物理模型[1-2]，这些方法在一定程度上能够捕捉到回波的运动特征，但在复杂的气象条件下，其预测精度和稳定性受到一定限制。近年来，随着深度学习技术[3]的快速发展，越来越多的研究者开始尝试将深度学习模型应用于气象领域[4]，而雷达回波外推是最典型的应用场景之一。基于深度学习的雷达回波外推模型通过将雷达回波数据作为输入，利用深度学习模型自动学习回波数据的特征表示和演变规律，实现对未来情况的预测。这些深度学习模型，如卷积神经网络（CNN）[5-6]、循环神经网络（RNN）[7-8]及其变体（如LSTM、GRU等）[9- 12]，能够自动学习雷达回波数据的特征表示和演变规律，从而提高外推精度和鲁棒性。

TrajGRU[13]模型作为一种改进的GRU模型，能够引入轨迹信息来更好地捕捉雷达回波的运动轨迹和演变规律，从而提高外推精度。Tra-jGRU 模型基于 Encoder-Forecaster 的宏观架构，对时序建模单元 ConvGRU[14]作了改进。Tra-jGRU利用子网络在状态转换之前输出状态到状

态的连接结构，使时序传递过程中卷积核的感受野形状可变，从而允许模型沿着一定的轨迹来聚合状态。这种方式比连接结构固定的Convolu-tional GRU（ConvGRU）更灵活，有利于捕捉非平稳过程中关键信息位置的飘移。

本文面向气象领域临近降水服务应用场景，基于中国气象局研发的短时强降水AI应用专项数据集[15]，采用TrajGRU深度学习网络架构完成了短临降水预报模型TrajCast的构建，模型输入为6分钟前与现在时刻的4通道雷达参量 $( 3 . 0 \mathrm { k m }$ 等高面反射率CAP30、组合反射率CR、混合扫描反射率HBR、垂直累积液态水含量VIL），输出为2小时内逐6分钟的降水场数据产品。模型训练采用国产加速器实现，并在太原计算平台国产C86异构计算平台实现了工程化部署。模型1小时降水预报TS评分[16-17]优于光流法，模型训练应用了数据并行[18]、混合精度[19]计算技术，实现了训练效率优化，性能测试表明，应用优化技术后国产加速器单卡训练加速比达4.1。扩展性测试表明，随着国产加速器数量的增加，计算性能呈现近线性增长趋势。模型于浙江省气象局气象信息网络中心、湖北省气象局信息保障中心、湖南省气象信息中心，实现气象AI示范应用部署，为实现高分辨率、高时率的气象智能预报产品提供智能算法支撑。通过本文的研究，为短临降水预报模型

的研究和应用提供新的思路和方法，探索推动国产加速器在深度学习等领域的应用示范。

本文的主要贡献有：

（1）基于中国气象局研发的短时强降水AI应用专项数据集，构建短临降水预报模型Traj-Cast，以4通道雷达参量（CAP30、CR、HBR、VIL）为输入，输出2小时内逐6分钟的高时空分辨率降水场预报，其TS评分显著优于传统光流法；  
（2）模型采用国产加速器训练，通过混合精度技术，国产加速器单卡实现4.1倍训练加速，并在国产C86异构计算平台上实现了工程化部署，验证国产加速器的近线性扩展能力。

# 1 TrajGRU雷达外推基准算法

TrajGRU[13]由施行健等人在2017年提出，该算法最初解决的问题是单通道雷达回波的外推，在HKO-7雷达外推数据集[13]上进行训练和评估。其运作机制为：

模型输入-1与0时次的单通道雷达数据（如组合反射率CR），经过一个基于RNN编解码器架构的神经网络，产生未来一系列时次该种雷达数据的预测。其核心模块为图1中的TrajGRU单元，此单元的运作方式为，将本时次输入和上一时次的隐状态拼接作卷积，得到L组局部连接

情况下每个格点的坐标偏移量：

$$
U _ {t}, V _ {t} = \gamma \left(X _ {t}, H _ {t - 1}\right), U _ {t}, V _ {t} \in \mathbb {R} ^ {L \times H \times W} \tag {1}
$$

其中，U对应横坐标，V对应纵坐标。之后将所有 ConvGRU 中对 $\mathrm { H } _ { \mathrm { t } - 1 }$ 的卷积操作替换为，分别使用每一种局部连接情况下的坐标偏移对 $\mathrm { H } _ { \mathrm { t } - 1 }$ 作重采样，之后使用 $1 \times 1$ 的卷积核对重采样后的 $\mathrm { H } _ { \mathrm { t } - 1 }$ 作卷积，最后再将这L种情况下的结果加和。写成公式表达，原有ConvGRU单元的操作方式为：

$$
Z _ {t} = \sigma \left(W _ {x z} * X _ {t} + W _ {h z} * H _ {t - 1}\right) \tag {2}
$$

$$
R _ {t} = \sigma \left(W _ {x r} * X _ {t} + W _ {h r} * H _ {t - 1}\right) \tag {3}
$$

$$
H _ {t} ^ {\prime} = f \left(W _ {x h} * X _ {t} + R _ {t} \circ \left(W _ {h h} * H _ {t - 1}\right)\right) \tag {4}
$$

$$
H _ {t} = \left(1 - Z _ {t}\right) \circ H _ {t} ^ {\prime} + Z _ {t} * H _ {t - 1} \tag {5}
$$

在改进为TrajGRU单元后，其操作方式更新如下，其中warp代表重采样操作：

$$
Z _ {t} = \sigma \left(W _ {x z} * X _ {t} + \sum_ {l = 1} ^ {L} W _ {h z} ^ {l} * w a r p \left(H _ {t - 1}, U _ {t, l}, V _ {t, l}\right)\right) \tag {6}
$$

$$
R _ {t} = \sigma \left(W _ {x r} * X _ {t} + \sum_ {l = 1} ^ {L} W _ {h r} ^ {l} * w a r p \left(H _ {t - 1}, U _ {t, l}, V _ {t, l}\right)\right) \tag {7}
$$

$$
H _ {t} ^ {\prime} = f \left(W _ {x h} * X _ {t} + R _ {t} \circ \left(\sum_ {l = 1} ^ {L} W _ {h h} ^ {l} * w a r p \left(H _ {t - 1}, U _ {t, l}, V _ {t, l}\right)\right)\right) \tag {8}
$$

$$
H _ {t} = \left(1 - Z _ {t}\right) \circ H ^ {\prime} _ {t} + Z _ {t} * H _ {t - 1} \tag {9}
$$

# 2 TrajCast短临降水预报方案

# 2.1 数据集介绍

本文的研究工作使用了国家气象信息中心研制的短时强降水AI应用专项数据集[15]，该数据集从更大范围的强对流天气人工智能应用训练基础数据集[20]中整理而来。在短时强降水AI应用专项数据集中收集了2016到2018年间福建、江西、安徽、浙江、湖南、湖北6个省份所有的强降水天气过程共计3,186个，数据帧间隔为逐6分钟，共计有约12万个逐6分钟的时次。而该数据集中每个时次均包括了组合反射率（CR）、混合扫描反射率（HBR）、 $0 . 5 \mathrm { k m }$ 等高面反射率（CAP05）、 $1 ~ \mathrm { k m }$ 等高面反射率（CAP10）、 $1 . 5 \mathrm { k m }$ 等高面反射率（CAP15）、 $2 . 0 \ \mathrm { k m }$ 等高面反射率

（CAP20） $. 3 . 0 \mathrm { k m }$ 等高面反射率（CAP30）、 $. 5 . 5 \mathrm { k m }$ 等高面反射率（CAP55）、回波顶高（ET）、垂直累积 液 态 水 含 量（VIL）、降 水 场 标 签（RA_LA-BEL）、降水落区标签（RB_LABEL）共12种场，其空间大小为 $3 0 1 \times 3 0 1$ ，文件格式为用于存储numpy[21]中 n 维数组的 npy。图 2 展示了 2017 年安徽省某个强降水过程的一个逐6分钟时次所有数据分量的可视化。

# 2.2 预报方案构建

为了使数据集中各种不同的要素、通道得到充分利用，本文没有直接采用原TrajGRU中单通道外推的设定。在单通道外推的情况下，应直接使用-1、0时次的降水场标签来预测后面2小时的逐6分钟降水场，但这样就无法利用到数据集中的各种雷达参量。另外，因实际业务场景下的降水场标签非实时可得，单通道外推方式在后期实时业务应用中无法及时得到输入数据。故在本文的预报方案中以-1和0时次的四通道雷达参量（CAP30、CR、HBR、VIL）为输入数据，以1到20时次的降水场为模型输出目标（每时次间隔6分钟）。整体运行机制如图1所示。

在训练时的损失函数上，本文与原始Tra-jGRU类似，采用反向加权策略，损失函数值：

$$
L = \frac {1}{2} w _ {c} \left[ M S E \left(y _ {\text {p r e d}}, y _ {\text {l a b e l}}\right) + M A E \left(y _ {\text {p r e d}}, y _ {\text {l a b e l}}\right) \right] \tag {10}
$$

其中 $w _ { c }$ 表示不同降水强度区间的权重值。

降水区间的划分则遵循短时强降水AI应用专项数据集中的约定，以 $0 \mathrm { m m }$ （实际取 $0 . 0 1 \mathrm { m m }$ ）、$0 . 1 \ \mathrm { m m } , 1 \ \mathrm { m m } , 2 \ \mathrm { m m } , 3 \ \mathrm { m m }$ 为区间的间隔点位，划分为不同的降水强度。

下文中为便于表述，将以上预报方案中的模型记作 TrajCast。

# 3 评估指标

# 3.1 预报准率性评估指标及基准参照性能

本文以6分钟的时间间隔作2小时内的降水预报，共外推20步，以距离起报时间1小时降水预报结果的TS评分[16-17]为模型准确率评价标准。

TS评分在短临预报领域被广泛采用，其计算方式为：

$$
T S = \frac {T P}{T P + F N + F P} \tag {11}
$$

在强降水AI应用专项数据集的约定中，降水按其强度分为以下几个阈值等级： $0 \mathrm { m m } . 0 . 1 \mathrm { m m }$ 、$1 \ \mathrm { m m } \cdot 2 \ \mathrm { m m } \cdot 3 \ \mathrm { m m }$ 。对于1到20的某一预报时

次t，任一阈值等级c（ $\mathrm { c } { > } 0$ ）上有：

$$
T S (t, c) = \frac {T P (t , c)}{T P (t , c) + F N (t , c) + F P (t , c)} \tag {12}
$$

其中 TP( ) t,c 为同时满足预报降水量 pred> $\textstyle \mathtt { \mu } \mathtt { > } \mathbf { C }$ 且标签值 $\mathrm { g t } > = \mathrm { c }$ 的网格点个数，FN( )t,c 为同时满足 pred<c 且 $\mathrm { g t } > = \mathrm { c }$ 的网格点个数，FP( ) t,c 为同时满足 pred> $\scriptstyle > = { \mathrm { c } }$ 且gt<c的网格点个数；特别地，阈值$\mathrm { c } { = } 0$ 的情形主要用来衡量对无降水这一情形的识别准确率，实际计算方式为， $\mathrm { T P } ( \mathfrak { t } , \mathfrak { c } )$ 为同时满足预报降水量 pred ${ < } 0 . 0 1$ 且标签值 $\mathrm { g t } { < } 0 . 0 1$ 的网格点个数，FN( ) t,c 为同时满足 pred $> = 0 . 0 1$ 且 gt<0.01 的网格点个数，FP( )t,c 为同时满足 pred<0.01 且 $\mathrm { g t } > = 0 . 0 1$ 的网格点个数。对以上5个c取值下的TS评分计算平均值，即得到对某一预报时次 t 的评分值 TS(t)。由于预报的时间间隔为逐6分钟，1小时后对应为第10个时次，因此本文用来评价预报准确率的量化指标即为TS（10）。

对TS（10）的计算均在相应的测试集上进行遍历，统计完全部网格点的累计数目后才计算其比例。本文将光流法ROVER[24]在全量测试集（全部6省在2018年5、7、9三个月上的数据）上的 TS（10）定为基准参照性能，其值为$2 8 . 4 2 ( \% )$ 。

# 3.2 算法运行效率评估指标

在运行效率（速度方面），本文采用单位时间（秒）内处理的样本数量，其值由单次迭代所消耗的时间换算而来。本文在测量运行时间时，只考虑在GPU或类GPU国产加速器上的操作，对于前后处理等CPU上的操作则不在测量范围内。

# 4 实 验

# 4.1 计算资源规格

在类GPU国产加速器上进行测试，硬件环境配置：CPU为32核心x86处理器，具有16G显存，带宽

$2 0 0 \mathrm { G b } / \mathrm { s } _ { \mathrm { o } }$ 。对比实验使用单卡NVIDIA $\mathrm { P l } 0 0 ^ { [ 2 5 ] }$ 和NVIDIA V100[26]。

# 4.2 训练及评估策略

本文首先构建了一个小规模样本数据集，用以进行密集的调优和对比实验。小样本数据集取安徽省2018年7月的数据为测试数据，并在安徽省 2016-2018 年数据中除去 2018 年 5、7、9 三个月的剩余部分中随机选取了1/3的降水过程用作训练数据。完成小规模数据集上的训练、测试、性能评估以及对比实验后，本文又在全量数据集上进行了一次大规模训练，并在全量的测试集上取得了显著超越基准值的预报准确率。

在训练和测试之前，首先需要进行样本构造。根据前述的预报方案，对于任一时间，取该时间和其6分钟后的四通道雷达参量（CAP30、CR、HBR、VIL），是为输出数据；再向后寻找20个时次，取其降水场标签（RA_LABEL），是为输出真值，所有这些数据集合在一起，计为一个样本。按此种构造方式，对整个数据集中的时间戳进行遍历，即得到全部的样本。

如此，在小规模数据集中，训练样本的数量为6,675，测试样本的数量为2,438。在全量数据集中，训练样本的数量为105,415，测试样本的数量为23,072。

对两种规模的数据集均在训练集上进行训练，在测试集上对模型预报结果计算TS（10），并与基准性能值相比较。

# 4.4 完整数据集上的预报性能

最终在完整全量数据集上，本文对文中的模型作了180,000次训练迭代，初始学习率为1e-4，并在第60,000次和第120,000次后相继将学习率

# 5 应用成效

本文模型已在浙江省气象局气象信息网络中心、湖北省气象局信息保障中心和湖南省气象信息中心作为气象AI示范应用成功部署。这些地区的模型运行情况良好，达到了预期的示范效果，为实现高分辨率、高时率的气象智能预报产品提供了有力的算法支持。

# 6 总结和展望

本文针对气象领域短临降水预报的实际需求，基于短时强降水AI应用专项数据集和深度学习雷达回波外推算法，构建了短时强降水预报模型，并在国产加速器上进行了移植优化，评估了算法的运行性能及其实际效果。

研究结果表明，模型在国产加速器上的训练性能得到了显著提升，优化后的模型训练速度提高了4倍，国产加速器单卡与CPU单核心相比加速比为 80.4，与 CPU 32 核心相比加速比为 23.2，与GPU单卡相比加速比为0.7。模型的瞬时利用率达到了 $1 0 0 \%$ ，资源利用效率高。在实际业务应用中，模型的部署显著提升了气象预报的准确性和时效性，为气象防灾减灾提供了有力的技术支持。

本文为短临降水预报模型的研究和应用领域带来了创新视角与策略，同时推动了国产加速器在深度学习领域的实践应用与示范，展示了强大的潜力和价值。后续将继续研究模型在国产加速器上的移植与优化，在提高模型预报准确率和训练效率上探索，为国产加速器在气象领域技术的发展和应用提供更有力的支持。
