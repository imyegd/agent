# 加速器来源 99Mo 与 99mTc 分离方法初步研究

摘　要　锝 $- 9 9 \mathrm { m } ( ^ { 9 9 \mathrm { m } } \mathrm { T c } )$ 是核医学中应用最广泛的放射性核素之一，其独特的物理和化学性质使其成为诊断成像的理想选择。受到部分生产堆退役的影响，未来国际上 ${ } ^ { 9 9 \mathrm { m } } \mathrm { T c }$ 可能面临紧缺问题，而基于加速器生产99mTc的方法受到越来越多关注。本研究旨在建立来源于质子打靶产生的 $^ { 9 9 } \mathrm { M o }$ 与其衰变产物 ${ } ^ { 9 9 \mathrm { m } } \mathrm { T c }$ 分离的方法，为利用加速器生产99mTc打下良好基础。本文以高铼酸钾作为高锝酸根的模拟物，比较活性炭、Tetravalent Actinides and Technetium 树脂（以下称 TEVA 树脂）和氧化铝对钼 -锝（铼）的分离效果，通过电感耦合等离子体质谱（ICP-MS）分析洗脱液中钼和铼的浓度，评估不同方法的分离效率。研究表明，活性炭在中性或碱性条件下无法有效分离钼和铼。相比之下，TEVA树脂在酸性条件下表现出优异的分离性能，使用8 mol/L硝酸可以有效地从TEVA洗脱高铼酸根。此外，研究发现，氧化铝在 $\mathrm { p H } \leqslant 7$ 时对钼酸根具有强吸附作用，而生理盐水可有效洗脱高铼酸根。基于上述结果，本研究设计了一种氧化铝与TEVA树脂组合的分离流程，即先利用氧化铝柱吸附钼酸根，再用生理盐水洗脱高铼酸根，最后通过TEVA树脂进一步纯化。该方法实现了高铼酸根的平均回收率为 $6 9 . 7 \% \sim 8 1 . 4 \%$ ，而钼含量低于 $1 \%$ ，从而为钼-锝分离提供了一种高效、可行的技术路线，为基于加速器生产 ${ } ^ { 9 9 \mathrm { m } } \mathrm { T c }$ 打下良好基础。

关键词　钼锝分离；活性炭；TEVA树脂；氧化铝

# 要点

） 比较了活性炭柱、 树脂柱和氧化铝柱在加速器来源的钼-锝（铼）的分离效果。  
2） TEVA树脂柱在酸性条件下表现出优异的分离性能。  
3） 氧化铝柱与TEVA树脂柱组合可更好地分离钼、锝。

锝 $- 9 9 \mathrm { m } ( ^ { 9 9 \mathrm { m } } \mathrm { T c } )$ 是核医学中应用最广泛的放射性核素之一，其独特的物理和化学性质使其成为诊断成像的理想选择。 $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 的半衰期较短（约6. 0 h），主要释放 $1 4 0 . 5 \mathrm { ~ k e V }$ 的 $\gamma$ 射线，这种射线能量适中，

易于检测且对患者辐射剂量较低［1］。此外， $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 可以通过配体修饰形成多种放射性药物，用于心脑血管、肿瘤、骨骼和感染性疾病的诊断［2］。例如， ${ ^ { 9 9 \mathrm { m } } \mathrm { T c } } \mathrm { - }$ 甲氧基异丁基异腈（ $^ { 9 9 \mathrm { m } } \mathrm { T c }$ -MIBI）用于心肌灌注显像，

${ ^ { 9 9 \mathrm { m } } \mathrm { T c } } \mathrm { - }$ 亚甲基二膦酸盐（ $^ { 9 9 \mathrm { m } } \mathrm { T c }$ -MDP）用于骨扫描［3］。每年进行的数百万次诊断性核医学检查中，约 $80 \%$ 使用了 $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 。

目前， $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 主要通过钼-99（ $^ { 9 9 } \mathrm { M o } )$ ）衰变获得，而$^ { 9 9 } \mathrm { M o }$ 主要来源于铀 $- 2 3 5 ( ^ { 2 3 5 } \mathrm { U } )$ 的裂变反应。然而，全球 $^ { 9 9 } \mathrm { M o }$ 生产依赖少数反应堆，其中一半已经运行了60 a以上。反应堆的老化使得全球 $^ { 9 9 } \mathrm { M o } / ^ { 9 9 \mathrm { m } } \mathrm { T c }$ 供应链日益不稳定［4-5］，促使开发不依赖 $^ { 2 3 5 } \mathrm { U }$ 的$^ { 9 9 } \mathrm { M o } / ^ { 9 9 \mathrm { m } } \mathrm { T c }$ 生产的新方法。

近年来，基于加速器生产 $^ { 9 9 } \mathrm { M o }$ 及 ${ } ^ { 9 9 \mathrm { m T c } }$ 的技术因其安全性和可持续性受到关注。该技术低成本、产生较少放射性废物且不引发核扩散等优点。基于质子束生产 $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 可以通过反应 $^ { 1 0 0 } \mathrm { M o ( p , 2 n ) ^ { 9 9 m } T c }$ 实现，此反应过程需要高流强射线轰击纯 $^ { 1 0 0 } \mathrm { M o }$ 靶。研究表明，能量在 $3 0 \ \mathrm { M e V }$ 的质子束通过 $^ { 1 0 0 } \mathrm { { M o ( p , p n ) ^ { 9 9 } } \mathrm { { M o } } }$ 反应生成 $^ { 9 9 } \mathrm { M o }$ 是性价比较高的方案［6-7］。目前我国已经有中国散裂中子源伴生质子束平台［6-7］、小型回旋质子加速器，以及大型质子加速器和高流强低能质子回旋器等［8］，为我国加速器生产 $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 提供了平台。钼锝发生器主要利用氧化铝对钼酸根的强吸附作用对钼锝进行分离，但加速器法产生的 $^ { 9 9 } \mathrm { M o }$ 比活度较低，传统氧化铝柱分离效率不足［5］。前面研究了基于加速器的质子束流打靶获得 $^ { 9 9 } \mathrm { M o }$ 的方法［7］，本文将进一步研究源于质子加速器的 $^ { 9 9 } \mathrm { M o }$ 及其衰变产物$^ { 9 9 \mathrm { m } } \mathrm { T c }$ 的分离方法研究，从而有助于保障 $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 的稳定供应。

目前用于 ${ } ^ { 9 9 \mathrm { m } } \mathrm { T c }$ 分离的色谱柱填料包括活性炭［9-11］及聚乙二醇树脂［8，12-13］等。活性炭作为一种用途广泛的固相吸附材料，已有报道其可用于分离钼和铼以及用于从水中吸附锝［14-18］，本文也将探索利用活性炭分离加速器来源的钼及其衰变产物锝。

TEVA树脂（Tetravalent Actinides and Technetium树脂）已成功用于分离钼、锝［19-20］，研究表明，随酸浓度的增加，TEVA树脂对锝的吸附率逐渐降低，从而与钼分离，但TEVA树脂易发生饱和吸附，这可能造成分离效率的下降或产物不纯。因此，要使用TEVA树脂得到较为纯净的高锝酸根离子，需要对进入TEVA树脂的溶液进行前处理。因此，可考虑综合利用氧化铝柱和TEVA树脂对低比活度钼及其产物锝进行分离。

活性炭是一种广泛应用于工业领域的吸附剂，对高锝酸盐具有很强的吸附能力［21-25］。在过去几十年里，活性炭对高锝酸盐的选择性在地下水和废水

处理方面得到了广泛研究［26-32］。

本文参考已报道的研究方法［33-35］，将研究活性炭、TEVA树脂柱及氧化铝柱对钼、锝的吸附情况，并研究综合利用氧化铝柱与TEVA柱分离加速器来源的钼及其衰变产物锝（以铼替代）的分离效果，从而为基于质子加速器生产 $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 打下良好基础。

# 1. 2 活性炭柱对钼锝（铼）的分离

因高锝酸根具有较高的放射性，采用锝的同族元素铼来作为钼锝分离的模拟物，高铼酸根与高锝酸根具有极其相似的化学性质。称取 $1 . 5 0 \mathrm { \ m g \ K R e O _ { 4 } }$ （精确至 $0 . 0 1 \mathrm { { m g } }$ ）溶于 $1 0 ~ \mathrm { m L }$ 水中，得到 $\mathrm { K R e O _ { 4 } }$ 溶液。称取 $0 . 2 0 3 7 \mathrm { \ g \ N a _ { 2 } M o O _ { 4 } } ,$ （精确至 $\mathrm { 0 . 0 0 0 ~ 1 ~ g ) }$ ）溶于水中，然后取 $1 \textrm { m L }$ 的 $\mathrm { K R e O _ { 4 } }$ 溶液加入钼酸钠溶液中，最后定容至 $1 0 ~ \mathrm { m L }$ 得到钼、铼溶液。

活性炭柱的制备：称取1. 27 g的活性炭，加入足量的二次水，煮沸三次。过滤并在室温下放置 $1 8 \ \mathrm { h }$ 后在烘箱中 $1 2 0 ~ \mathrm { { ^ { \circ } C } }$ 下烘干8 h后置于离心管中备用。取 $2 0 ~ \mathrm { m L }$ 注射器，底部用双层滤纸贴合，喷入少量的水使其紧贴底部，底部填充少量玻璃棉。将处理后的活性炭样品装于注射器内，顶层放入滤纸，压实，注射器的口部安装一个滤头。

使用活性炭柱进行以下实验：1）将3 mL NaOH溶液（ $3 \ \mathrm { m o l / L } )$ ）多次缓慢通过活性炭柱，测试填装柱是否有堵塞的同时，将填充柱内部的环境变为3 mol/L NaOH的强碱性环境。然后将高铼酸钾与钼酸钠的混合溶液 $1 0 ~ \mathrm { m L }$ 加入活性炭柱中，置于铁架台上静置 $1 2 \ \mathrm { h }$ ，使得活性炭可充分吸附柱上的钼与铼。然后使用 $3 \ \mathrm { m o l / L }$ 的NaOH溶液对活性炭柱进行洗脱，每 $0 . 5 ~ \mathrm { m L }$ 作一个组别，收集流出液，利用电

感耦合等离子体质谱（ICP-MS）法测量溶液中的钼铼浓度。2）使用5 mol/L NaOH溶液重复1），其余条件与1）相同，重复1）的操作。3）先使用二次水进行洗脱，再使用3 mol/L NaOH进行洗脱处理，每 $0 . 5 ~ \mathrm { m L }$ 作一个组别，收集流出液，利用ICP-MS法测量溶液中的钼铼浓度。4）将钼酸钠浓度减半，其余条件与1）相同，重复1）的操作。

# 2 结果与讨论

# 2. 1 活性炭对钼铼分离情况

图1a展示了3 mol/L NaOH溶液洗脱活性炭柱后对钼铼的分离情况。由图1a可见，钼与铼的含量变化具有相同趋势，两者均为在碱洗脱条件下，洗脱液中钼铼含量快速下降，在洗脱液体积为 $1 0 ~ \mathrm { m L }$ 左右快速降为0，说明3 mol/L NaOH溶液的条件下活性炭柱并不能对钼铼进行分离。

图1b展示了5 mol/L NaOH溶液洗脱活性炭柱后对钼铼的分离情况。改变NaOH浓度后，洗脱曲线出现了非常剧烈的波动，但钼与铼含量具有相同的变化趋势。说明5 mol/L NaOH溶液的条件下活性炭柱同样不能对钼铼进行分离。

文献［21］报道 $\mathrm { p H } { = } 7$ 时，活性炭对于钼酸根和高铼酸根的吸附率差异最大，因此尝试先使用二次水对活性炭柱进行洗脱，然后使用3 mol/L NaOH溶液洗脱活性炭柱，结果如图 1c 所示。可以发现，钼与铼在洗脱前期浓度迅速下降，但之后出现浓度变化的平台期，之后钼铼浓度快速降低但钼与铼仍具有相同的变化趋势。由此可见，变更洗脱顺序同样不能分离钼锝，说明在这种条件下活性炭柱无法对钼锝进行分离。

为避免饱和吸附带来的影响，在实验中采取降低钼酸钠浓度，然后以3 mol/L NaOH进行洗脱。结果如图1d所示。可以看到，钼与铼含量仍具有相同的变化趋势。因此，利用本文所用的活性炭无法分离钼铼。

以上结果表明，虽然有文献报道活性炭柱可用于分离钼铼甚至是水中痕量锝［15-19］，但我们的研究表明，在中性或碱性条件下活性炭无法用于钼锝分离。这可能是所使用的活性炭材料不同所致。

# 2. 2 TEVA树脂柱对钼铼的分离效果

图 2 是 $1 \ \mathrm { m o l / L }$ 和 $8 \ \mathrm { m o l / L }$ 硝 酸 对 钼 铼 洗 脱曲线，从图2a可知，以 $1 \ \mathrm { m o l / L }$ 硝酸为洗脱液，铼几乎全部保留在树脂柱上，而大部分的钼酸钠则被洗脱，对该图积分可知，洗脱所得的钼的总量为$1 9 . 1 9 \mathrm { \ m g }$ ；而由图2b可看出， $8 \ \mathrm { m o l / L }$ 硝酸为洗脱液则恰恰相反，图2曲线积分并乘以体积可得，洗脱所得高铼酸根约为 $1 9 . 4 ~ \mathrm { m g }$ ，其在树脂柱上的保留值约为 $0 . 2 6 ~ \mathrm { m g }$ ，这一值与高锝酸根在TEVA数值上的保留值相近［17］，故高铼酸根可模拟高锝酸根的洗脱情况。这一现象可以从离子交换机理角度得到解释。TEVA树脂作为季铵盐型阴离子交换树脂，其对 $\mathrm { R e O _ { 4 } } ^ { - }$ 的吸附强度受硝酸根 $\mathrm { ( N O _ { 3 } } ^ { - }$ ）竞争作用的显著影响。随着 $\mathrm { H N O _ { 3 } }$ 浓度的升高，溶液中 $\mathrm { N O _ { 3 } } ^ { - }$ 与树脂固定相中季铵基团的结合位点产生强烈竞争，从而削弱了树脂对 $\mathrm { R e O _ { 4 } } ^ { - }$ 的亲和力。值得注意的是，在$\mathrm { 8 \ m o l / L \ H N O _ { 3 } }$ 条件下， $\mathrm { R e O _ { 4 } } ^ { - }$ 的洗脱体积（ $5 { \sim } 6 ~ \mathrm { m L }$ ）接近色谱柱的死体积 $\left( 4 . 5 \ \mathrm { m L } \right)$ ），表明此时离子交换平衡已强烈偏向解吸方向。这种高效的洗脱特性为后续钼锝分离工艺的设计提供了重要依据。

# 2. 3 氧化铝柱对钼铼的分离效果

虽然TEVA树脂对钼铼具有较好的分离效果，但其成本较高，为最大程度发挥TEVA的高效分离能力，考虑到溶液中过高含量的钼酸盐会干扰到高铼酸根的分离，故对钼酸盐进行预分离研究。

钼锝发生器中使用氧化铝柱分离钼锝，是将钼酸盐吸附在氧化铝柱上之后再对钼衰变出的高锝酸根进行洗脱［1］。我们测试了氧化铝柱对钼酸钠在不同 pH 值下的吸附情况，结果如图 3a 所示。在 $\mathrm { p H } \leqslant 7$ 时，氧化铝柱对钼酸根的吸附率相对稳定并保持在$80 \%$ 以上，当 $\mathrm { p H } > 7$ 时，氧化铝对钼酸盐的吸附大幅下滑，在浓碱性条件下降低至 $2 5 \%$ 以下。故氧化铝柱的初始环境应维持在 $\mathrm { p H } \leqslant 7$ 的条件下，这与文献报道一致［21］ 。

图3b结果表明，在 $\mathrm { p H } { = } 7$ 的条件下， $3 0 { \sim } 4 0 ~ \mathrm { m L }$ 的生理盐水可洗脱大部分的高铼酸根。因此，氧化铝柱分离钼铼的最佳条件是 $\mathrm { p H } { = } 7$ 利用生理盐水洗脱大部分高铼酸根。

# 3 结论

本文以高铼酸钾作为高锝酸根的模拟物，以钼酸根和高铼酸根为主要研究对象，测定了活性炭柱、TEVA树脂以及氧化铝柱对钼铼的分离效果。从实验结果来看，本文使用的活性炭不具备分离钼锝的

能力，这可能是由于本文所使用的活性炭不具有吸附钼锝的特异基团，而TEVA树脂具有优异的分离钼锝的能力。为充分提高TEVA树脂的分离效率，设计了联合使用氧化铝柱与TEVA柱分离钼铼的工艺，可以得到较为纯净的产物，锝（铼）的回收率为$6 9 . 7 \% \sim 8 1 . 4 \%$ 。与氧化铝法相比，本方法显著提升了分离高锝酸根的效率。该路线可为基于加速器生产 $^ { 9 9 \mathrm { m } } \mathrm { T c }$ 打下良好基础。下一步将验证该流程对实际打靶产生的 $^ { 9 9 } \mathrm { M o }$ 及其衰变产物 ${ } ^ { 9 9 \mathrm { m } } \mathrm { T c }$ 的分离效果，从而进一步完善本文所建立的分离方法。

# Pilot Study on the Separation of $^ { \mathbf { { \boldsymbol { \mathsf { g } } } \mathbf { \boldsymbol { \mathsf { u } } } \mathbf { \boldsymbol { \mathsf { u } } } } } \mathbf { \mathbf { \Sigma } }$ and 99mTc Originated from Proton Accelerator

Abstract Technetium- $. 9 9 \mathrm { m }$ （ $^ { 9 9 \mathrm { m } } \mathrm { T c }$ ），a crucial nuclear medicine，primarily stems from $9 9$ Mo decay in nuclear reactors. However，aging reactors have disrupted the 99Mo and 99mTc supply chain. Proton accelerators present a promising alternative for $^ { 9 9 } \mathrm { M o }$ and 99mTc production，yet they yield low-radioactivity 99Mo and face inefficient separation through alumina column. This study explores activated carbon，TEVA resin，and alumina for molybdate and pertechnetate separation. Potassium perrhenate was used to substitute pertechnetate in adsorption and elution experiments，with ICP-MS analyzing eluent concentrations to assess separation efficiency. Activated carbon proves ineffective for separation under neutral or alkaline conditions. TEVA resin，however，excels under acidic conditions. $1 \mathrm { m o l / L }$ nitric acid elutes most molybdate while perrhenate adsorbs onto the resin. Perrhenate recovery surges with $8 \mathrm { m o l / L }$ nitric acid elution，retaining less than $1 \%$ molybdenum. Alumina strongly adsorbs molybdate at $\mathrm { p H } \leqslant 7$ ，and normal saline effectively eluates perrhenate. A combined separation process leveraging both alumina and TEVA resin is proposed. Molybdate is adsorbed by alumina, which is followed by perrhenate elution with saline and further TEVA resin purification. Then， $1 \mathrm { m o l / L }$ nitric acid is used to recover residual molybdate，while $8 \mathrm { m o l / L }$ nitric acid is used to elute perrhenate，achieving $6 9 . 7 \% - 8 1 . 4 \%$ recovery with merely about $1 \%$ residual molybdenum. In summary，this study offers an efficient and viable technical pathway for molybdate and pertechnetate separation，paving the way for $^ { 9 9 \mathrm { m } } \mathrm { T c }$ production via proton accelerators in nuclear medicine.
