# 0 0 引言

加速器质谱（AcceleratorMassSpectrometry，简称 AMS）是一种基于粒子加速器与高能粒子鉴别技术的超高丰度灵敏度质谱分析方法。其核心原理是将样品负离子化后，利用加速器将负离子加速至兆电子伏特（MeV）量级，通过与介质碰撞转化为摆脱了同质分子干扰的正离子被进一步加速，再通过组合磁分析器、静电分析器及粒子鉴别探测器对特定同位素原子进行直接计数［1～3］ 。AMS直接计数目标原子核本身，不受半衰期限制，对长寿命放射性核素（如 $^ { 1 0 } \mathrm { { B e } }$ e、 $^ { 2 6 } \mathrm { A l }$ l和 ${ } ^ { 1 2 9 } \mathrm { I }$ I）具有突破性分析能力。相较于传统质谱，AMS可有效消除同质异位素和同质分子本底的干扰，使丰度灵敏度可达 $1 0 ^ { ^ { - 1 5 } } \sim 1 0 ^ { ^ { - 1 6 } }$ ，相比传统质谱的约 ${ 1 0 } ^ {  { - 9 } }$ 提高了 6～8个数量级。AM仅需使用毫克至微克级样品，可显著降低对珍贵样本（如考古文物、陨石、单颗粒物）的破坏性；同

时，单样品测量时间缩短至数分钟，相比衰变计数法的数天至数周，分析效率提升百倍以上，支持高通量分析［4～8］ 。

第四纪（约 $2 . 5 8 \ \mathrm { M a }$ 至今）是地球环境剧变和人类文明演进的关键时期，其高精度年代框架与古环境过程重建亟需突破传统技术瓶颈。AMS技术的引入，革新了第四纪研究的时空解析能力，使珍贵微量样本得以用来精准定年与环境示踪。在年代学领域，AMS $^ { 1 4 } \mathrm { C }$ 定年将样本量降至传统衰变计数法的千分之一，解决了小样本的定年难题，数千年尺度误差可控制在 $\pm 2 0$ 年内，显著提升了晚第四纪事件的年代分辨率［9～11］ ；在地表过程示踪中，宇宙成因核素（如 $^ { 1 0 } \mathrm { { B e } }$ 、 $^ { 2 6 } \mathrm { A l }$ l）的 AMS定量分析实现了暴露年代与侵蚀速率的高精度反演，为冰川进退、构造抬升及陨石撞击事件提供直接证据［12～13］ ；在地下水和海洋循环研究中，有明确释放来源的 ${ } ^ { 1 2 9 } \mathrm { I }$ I等核素则成为地下水循环与海洋通风过程的灵敏示踪

剂［14］ 。当前，AMS多核素协同分析（如 $^ { 1 4 } \mathrm { C } - ^ { 1 0 } \mathrm { B e }$ e联合）正推动第四纪科学向多尺度、多指标集成研究范式转变，为理解气候突变机制、生物圈响应及人类适应策略提供了关键支撑［15～16］ 。

近年来，AMS技术呈现向紧凑化、多核素分析及高灵 敏 度 方 向 发 展 的 趋 势。相 较 于 大 型 AMS$( \geqslant 3 { \mathrm { ~ M V } }$ ），紧凑型 AMS（0.2～1.0MV）在成本效益、维 护 便 捷 性 及 占 地 面 积 方 面 具 有 显 著 优势［17～22］ 。2023年 4月，中国地质科学院水文地质环境地质研究所（厦门）（以下称水环所）建成并引进了荷兰高压公司（HVE）生产的 1MV多核素 AM系统，并于同年 6月完成验收。作为自然资源部系统内首台 AMS设备，该仪器主要应用于地下水 $^ { 1 4 } \mathrm { C }$ 定年及第四纪沉积物定年研究，是水环所地下水环境示踪分析、第四纪地层年代测定与古环境重建技术体系的核心支撑设备。为了保证 AMS高效运行，实验 室 配 备 了 瑞 士 Ionplus公 司 自 动 石 墨 化 系 统

（AGE3）和自主研制的真空石墨制靶系统，保障 $^ { 1 4 } \mathrm { C }$ 样品的高通量制备；同时建立了适用于富含石英地质样品 $^ { 1 0 } \mathrm { { B e } }$ e和 $^ { 2 6 } \mathrm { A l }$ l的提取制备流程，服务于 $^ { 1 0 } \mathrm { B e } / ^ { 2 6 } \mathrm { A l }$ 暴露 定 年 及 侵 蚀 速 率 研 究［23］ 。 本 文 重 点 介 绍 该1MVAMS系统的技术特点、性能参数及其在第四纪科学中的应用前景，旨在为地球科学和环境科学相关研究提供技术支撑。

# 1.2 低能注入系统

经离子源透镜聚焦后的负离子束，首先导入具有 $5 4 ^ { \circ }$ 可 旋 转 方 位 角 设 计 的 球 面 静 电 分 析 器（ElectrostaticAnalyzer，简称 ESA）进行能量筛选。随后，离子束进入 $1 2 0 ^ { \circ }$ °偏转磁铁进行质量分析。该磁 铁 设 计 为 能 量 快 速 切 换 模 式， 质 能 积 为12AMU·MeV，质量分辨率 $( \mathrm { ~ M ~ } / \Delta \mathrm { M } ) > 8 0 0$ ，可在$3 5 \mathrm { \ k e V }$ 束流能量下分析质量数高达 340AMU（原子质量）的离子。为优化测量效率，系统将循环周期的大部分分析时间分配予稀有同位素 （如 $^ { 1 4 } \mathrm { C } ^ { - }$ ：$9 . 7 5 ~ \mathrm { m s }$ s），而对丰度较高的同位素（如 13C－ 、 $^ { 1 2 } \mathrm { C } ^ { - }$ ：各 $0 . 1 ~ \mathrm { m s }$ ）采用短时测量。同位素的选择通过在$\pm 3 \mathrm { ~ k V }$ 电压范围内以 $1 0 0 \ \mathrm { H z }$ z频率进行快速切换注入实现，此设计可显著抑制离子源不稳定性对测量结果的影响。在注入磁铁下游，配置有束流精密定时注入电极，能够实现纳秒级精度的束流注入时序控制。低能注入系统还配置了两个移动法拉第杯，用于测量稳定同位素的低能端束流强度以计算传输效率。负离子束进入加速器前还需通过 Q-snout透镜，其作用是将只有 $3 5 \mathrm { \ k e V }$ 较低注入能量的负离子束聚焦到位于加速器高压终端的气体电荷剥离器中心。

# 1.3 串列加速器

本加速器为 1MV串列式静电加速器，采用全固态高频电源设计，运动部件少。加速管密封于充有 $\geqslant 5$ bar $\mathrm { S F } _ { 6 }$ 绝缘气体的 T型钢制压力容器内。在 1MV工作电压下，采用感应伏特计（GVM）稳压技术，电压稳定度可达 $\pm 1 5 0 \mathrm { V }$ ；对于电流密度分布对称的束流，也可采用法拉第杯内置狭缝反馈稳压技术，稳定度可提升至 $\pm 7 5 \mathrm { ~ V ~ }$ 。端电压采用低纹波

设计，电压纹波仅为 $2 5 ~ \mathrm { V } _ { \mathrm { R M S } }$ 。加速器配置双路剥离气系统，可选氩气或氦气作为剥离介质，以优化剥离效率并减少 离 子 散 射。剥 离 管 道 长 $6 3 0 \mathrm { m m }$ ，内径 $6 \mathrm { m m }$ 。管道内气体压力通过临近安装的压力计实时监测，并集成于闭环反馈回路中，确保剥离气压长时间稳定。

# 1.4 高能分析系统

高能分析系统由 $9 0 ^ { \circ }$ °高分辨率磁铁、 $1 2 0 ^ { \circ }$ °球面静电分析器和 $3 0 ^ { \circ }$ °偏转磁铁组成。 $9 0 ^ { \circ }$ °磁铁最大磁刚度为 63AMU·MeV，质量分辨率 $> 5 0 0$ 0，磁铁后配备两个偏置法拉第杯：一个固定杯用于 $^ { 1 2 } \mathrm { C }$ 测量，另一个可移动杯用于 $^ { 1 3 } \mathrm { C }$ 、 $^ { 9 } \mathrm { { B e } }$ 、 $^ { 2 7 } \mathrm { A l }$ l和 $^ { 1 2 7 } \mathrm { I }$ I等稳定同位素的测量，并配备内部狭缝系统，通过反馈信号稳定 加 速 器 终 端 电 压 使 理 想 束 流 的 位 置 偏 差$< 0 . \mathrm { ~ 1 ~ m m }$ 。 $1 2 0 ^ { \circ }$ °半径 $6 5 0 \mathrm { m m }$ 的球面静电分析器用于分离目标放射性核素中的不同能量离子。 $^ { 1 0 } \mathrm { { B e } }$ e测量时采用 $1 5 0 \mathrm { n m }$ 厚 $\mathrm { S i } _ { 3 } \mathrm { N } _ { 4 }$ （Silson公司）吸收膜以区分 $^ { 1 0 } \mathrm { { B e } }$ e与 ${ } ^ { 1 0 } \mathrm { { B } }$ 的能量差异。 $3 0 ^ { \circ }$ °半径 $8 5 0 ~ \mathrm { m m }$ 偏转磁铁置于气体电离探测器前，抑制 ESA电极散射离子以降低本底。

# 1.5 探测器和控制系统

放射性同位素探测器采用异丁烷气体电离室结构，配备双阳极实现 $\Delta \mathrm { E } { \mathrm { - E } } _ { \mathrm { r e s } }$ 二维能谱测量。工作气压 5～20mbar可 调 以 适 应 不 同 核 素 测 量 需 求，$7 5 \mathrm { n m }$ 厚 $\mathrm { S i } _ { 3 } \mathrm { N } _ { 4 }$ 入射窗实现探测器气体与束流线真空隔离。探测器信号经 FAST前置／主放大器处理后传输至 MCA-4双参数系统（双 ADC架构）实现稀有同位素数据采集。稳定同位素通过 HVE研发的门控电荷泵数字化仪采集，所有的采集数据经计数板实时存储，均受硬件定时器控制保障时序精度。所有磁铁通过霍尔探头实现磁场设定与闭环控制，结合参数存储功能确保运行稳定性与配置复现性。此外还配置用于束流调试的束流剖面仪（BPM）、可伸缩光阑、X-Y导向器、狭缝、透镜和偏置法拉第杯等。控制架构采用专用机柜集成滤波模块及本地微控制器，各机柜作为 CAN节点通过光纤硬接线组网，实现控制区域网络通信和计算机与设备电隔离防护。安全机制包括本地联锁程序按工况实施操作禁止，以及硬件看门狗监控微控制器运行状态。

# 1.6 真空系统和辅助设备

该设备的真空系统由 4台莱宝前级真空油泵和

9台抽速为 $4 0 0 \mathrm { L / s }$ 的莱宝 361分子泵组成，分子泵极限真空度为 $< 1 \times { 1 0 } ^ { - 1 0 }$ mbar，常规运行期间真空度维持在 ${ { 1 0 } ^ { - 7 } } \sim { { 1 0 } ^ { - 8 } }$ mbar范围内。为保障 AMS装置安全稳定运行，配备了额定容量为 $1 2 0 \ \mathrm { k V A }$ 的稳压电源，可在市电中断时实现不间断快速切换至蓄电池供电模式，蓄电池可持续供电至少 $3 0 \mathrm { m i n }$ ，确保完成正常的关机流程。AMS运行过程中，离子源、磁铁及电源等关键部件需持续冷却，为此配备了王牌机械 LS325BT型冷水机组，其制冷量为$3 9 . 8 \mathrm { ~ k W }$ ，水温控制精度可达 $\pm 0 . 1 \mathrm { { ^ { q } C } }$ 。机房温湿度由 York中央空调系统进行恒温恒湿控制，温度维持在 $2 2 \pm 0 . 5 \mathrm { ~ \textdegree C }$ ，相对湿度（RelativeHumidity，简称RH）控制在 $5 5 \% \pm 5 \%$ ，确保持续稳定的设备运行环境。此外，系统还配备 Atlas空压机，最大压力为$0 . 7 8 ~ \mathrm { M P a }$ ，用于为气动阀、法拉第杯、进样气缸等元件提供压缩空气动力。

同时，基于河流沉积物原位 $^ { 1 0 } \mathrm { { B e } }$ e浓度反演流域平均侵蚀速率，在千年－百万年尺度上揭示侵蚀－气候关联性，支撑区域性水土保持策略优化［50～51］ 。

# 3.3 多核素协同分析：集成解析复杂地质过程

AMS的多核素协同分析能力支持同一样品／地点的综合研究，突破单一方法局限。典型案例如洞穴系统：AMS $^ { 1 4 } \mathrm { C }$ 测定流石中有机包裹体（花粉、植物碎屑）年龄反映洞外环境变迁，而石英沉积物的$^ { 1 0 } \mathrm { B e } / ^ { 2 6 } \mathrm { A l }$ l浓度则指示洞穴崩塌或埋藏事件年代，二者结合完整重构洞穴地质－环境演化史［47，52］ 。在古土壤序列中，AMS $^ { 1 4 } \mathrm { C }$ 精确测定有机质年龄以标识土壤发育期次，而母质继承或原位生成的 $^ { 1 0 } \mathrm { { B e } }$ e可示踪土壤形成速率、暴露历史及侵蚀／稳定阶段，共同揭示土壤发生的时空动态［53～55］ 。

AMS技术通过提升定年分辨率与多核素协同分析能力，有力推动了第四纪科学在古气候重建、地表过程定量化及构造活动解析等方面的研究进展。该技术在高精度年代框架建立与复杂地质过程多维度反演中发挥着不可替代的作用，为地球系统科学研究提供了关键方法论支持。未来工作中，我

们将进一步提高第四纪常用核素 $^ { 1 4 } \mathrm { C }$ 、 $^ { 1 0 } \mathrm { { B e } }$ e、 $^ { 2 6 } \mathrm { A l }$ l的测试精度与分辨率，增强测年结果的准确性与可靠性，建立更精细的环境变化年代序列，从而更精确地重建古气候变化及关键古环境事件的发生与持续时间。同时，还将致力于发展与优化多核素联合测年方法，综合利用不同核素的互补特性，提升对复杂地质过程的解析能力。

# 4 系统运行与维护

AMS系统的长期稳定运行是获得高质量数据的关键，其稳定性主要取决于离子源性能、端电压波动及真空维持水平。离子源的稳定性可通过监测运行靶电流、引出电流及空白样品本底来评估，通常每 2～3个月需对离子源进行清洗维护，以保证其输出束流的稳定性。采用感应伏特计（GVM）稳压技术可使端电压稳定度优于 $\pm 1 5 0 \mathrm { V }$ ，系统运行期间，可通过监测 $^ { 1 3 } \mathrm { C }$ 法拉第杯的狭缝百分比偏差独立评估加速器稳定性，该值维持在 $\pm 3 \%$ 以内即表明系统处于高度稳定状态。真空系统需定期更换泵油并进行检漏，以维持所需的高真空环境。正式测量前，系统需充分预热 $^ { 2 \mathrm { ~ h ~ } }$ 以上，待离子源铯炉温度稳定后，方可进行束流调试与电磁元件参数优化，以确定最佳测量条件。所有操作需依据标准操作规程（SOP）执行，并进行系统监控与数据记录，以确保长期可靠运行。此外，常用试剂（如铁粉、商业石墨等）和标准样品应妥善保存于手套箱或真空干燥箱中，避免受潮与污染。

# 5 结论和展望

本文展示了水环所 1MV多核素 AMS所具备的基础兼潜在的优异性能，其紧凑化设计兼具高精度$^ { 1 4 } \mathrm { C }$ 的 4个靶均值精度 $1 . 2 6 \text{‰}$ 有待进一步提高）与低本底 $^ { 1 4 } \mathrm { C }$ 本底 $1 . 7 1 \times { { 1 0 } ^ { - 1 6 } }$ ， $0 . 0 1 6 ~ \mathrm { p M C }$ ， $^ { 1 0 } \mathrm { { B e } }$ e和$^ { 2 6 } \mathrm { A l }$ l本底达 $1 0 ^ { ^ { - 1 5 } } \sim 1 0 ^ { ^ { - 1 6 } }$ ）优势，有望提升第四纪研究的时空分辨率与多维解析能力，推动第四纪沉积物定年、地下水循环示踪及地表过程定量重建的相关研究。未来将进一步拓展 $^ { 4 1 } \mathrm { C a }$ 生物示踪与 $^ { 2 3 9 } \mathrm { { P u } }$ 环境行为监测，深化多核素协同分析在复杂地质过程解析中的应用，并重点聚焦全球变化响应研究、地下水循环机制及地质灾害预警等前沿领域，为地球系统科学的持续发展提供坚实技术支撑。
