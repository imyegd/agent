# Installation and Leak Detection of Beam Vacuum Equipment for the High Energy Photon Source

LIU Tianfeng, GUO Dizhou, DONG Haiyi, LIU Baiqi*, TIAN Pilong, SUN Xiaoyang, ZHU Bangle, YANG Qi, ZHANG Lei, LI Qi, WANG Xujian,

HUANG Tao, MA Yongsheng, SUN Fei, DENG Binglin, YANG Yuchen, HE Ping

（Institute of High Energy Physics, Chinese Academy of Sciences, Beijing 100049, China）

Abstract As an internationally advanced fourth-generation light source with ultra-high brightness and ultralow emittance, the High Energy Photon Source (HEPS) imposes stringent requirements on the sealing performance and cleanliness of its vacuum system.Vacuum leak detection and residual gas analysis are key procedures to ensure the vacuum system meets performance standards. This paper systematically elaborates on the strategies and practices of vacuum leak detection for the HEPS storage ring vacuum system during the installation, commissioning, and operation phases. It focuses on expounding the leak detection scheme using the vacuum mode method of helium mass spectrometer leak detectors, detailing the procedures and solutions for locating various leak points (such as weld defects and improper installation of sealing rings), and analyzing the typical response characteristics of the instrument interface during leak detection. Meanwhile, this paper deeply explores the dual roles of Quadrupole Mass Spectrometers (QMS) in the commissioning of vacuum systems: on the one hand, as a high-sensitivity leak detection tool, it assists in locating difficult-to-detect leaks that are challenging for helium mass spectrometer leak detectors; on the other hand, as a key device for residual gas composition analysis, it systematically measures and compares the residual gas spectra in the vacuum chamber of the storage ring before and after beam loading. This study verifies the effectiveness and reliability of the adopted leak detection methods and analysis strategies, providing a solid guarantee for the qualification and stable operation of the HEPS storage ring vacuum system. Its experience holds important reference value for vacuum quality control and analysis of similar large scientific facilities.

Keywords High Energy Photon Source (HEPS), Storage ring vacuum system, Vacuum leak detection, Helium mass spectrometer leak detection, Residual gas analysis

摘要 高能同步辐射光源（HEPS）作为具有极高亮度和极低发射度的国际先进的第四代光源，其对真空系统的密封性和洁净度提出了严苛要求。真空检漏与残余气体分析是保障真空系统性能达标的关键环节。本文系统论述了 HEPS 储存环真空系统在安装、调试与运行阶段的真空检漏策略与实践。重点阐述了

利用氦质谱检漏仪的真空模式法的检漏方案，详述了定位各类漏点（如焊缝缺陷、密封圈安装不当等）的流程与解决方案，并分析了检漏过程中仪器界面的典型响应特征。同时，本文深入探讨了四极质谱仪（QMS）在真空系统调试中的双重作用：一方面作为高灵敏度的检漏工具，辅助定位了氦质谱检漏仪在难以检漏情形下的疑难漏点；另一方面，作为残余气体成分分析的关键设备，系统测量并对比了储存环有束流加载前后真空腔内的残余气体谱图。本研究证实了所采用的检漏方法与分析策略的有效性与可靠性，为 HEPS 储存环真空系统的达标与稳定运行提供了坚实保障，其经验对同类大科学装置的真空质控与分析具有重要的参考价值。

关键词 高能同步辐射光源 储存环真空系统 真空检漏 氦质谱检漏 残余气体分析

高能同步辐射光源（High Energy PhotonSource，HEPS）是我国正在建设的世界顶尖第四代同步辐射光源，其设计亮度高于第三代光源一个量级以上，发射度接近衍射极限[1]。为实现电子束流的长期稳定储存，HEPS储存环真空系统必须保持为超高真空环境（静态真空度优于 $6 . 6 { \times } 1 0 ^ { - 8 } \mathrm { P a }$ 量级）与极低的动态气载[2-3]。因此，对于高能光源总长约$1 8 0 0 \mathrm { m }$ 的复杂真空系统来说，该真空度要求对系统所有部件的制造、整体安装及检漏工艺提出了前所未有的技术挑战。漏率累积效应或材料放气率不达标都可能导致真空度恶化，进而影响束流寿命和光源的性能。

真空检漏是保障真空系统性能达标的最关键环节之一。HEPS 储存环真空系统结构复杂，包含近万个可拆卸法兰连接点并且每根真空盒有数条焊缝，漏点可能存在于焊缝、波纹管、密封连接口等任何位置[4]。传统的氦质谱检漏技术是真空工程中最灵敏、最常用的方法，但在 HEPS这类庞大复杂的系统中，如何高效精准定位各类漏点并制定科学的处置标准，是工程实践中的核心技术难点[5]。此外，在系统完成初步检漏和烘烤除气后，进入超高真空状态，此时传统的外接检漏仪喷氦法已不再适用，需要依靠四极质谱仪（Quadrupole Mass Spectrometers，QMS）进行在线监测和疑难漏点排查。同时，QMS 提供的残余气体分析（Residual GasAnalyzer，RGA）数据是评估真空洁净度、研究束流与真空盒内壁作用机制（如光致解

吸、电子诱导解吸）的重要依据[6-7]。

本文系统总结了HEPS储存环真空系统在安装、调试和运行阶段的真空检漏策略与实践。重点分析了基于氦质谱检漏仪的真空模式法在复杂工况下的应用，分类阐述了典型漏点的特征、定位方法与处置方案。进一步，研究了 QMS 在超高真空阶段的检漏辅助功能，并对比分析了有无束流加载条件下真空管道内残余气体成分的演变规律，为HEPS 真空系统的长期稳定运行与优化提供了重要的数据支撑和工程经验。

# 1HEPS储存环真空系统与检漏技术概述

# 1.1 真空系统简介

HEPS 储存环周长约 $1 3 6 0 \mathrm { ~ m ~ }$ ，由 48 个弧区（Arc Section）和连接它们的直线节（Straight Section）组成。其真空系统主要由铬锆铜（ $\mathrm { C r Z r C u }$ ）真空盒、不锈钢真空盒、波纹管、各类真空泵（离子泵、NEG泵等）和冷规等设备组成[2,4]。所有部件在安装前均经过严格的预处理和初检。

# 1.2 检漏方案设计与设备选型

本文涉及的检漏工作分为两个主要阶段：

安装过程与烘烤前检漏（真空模式法）：该阶段系统处于高真空（约为 $1 0 ^ { - 4 } \mathrm { { P a } }$ ）尚未经过高温烘烤。主要利用氦质谱检漏仪的“真空模式法”进行检漏。将检漏仪通过金属波纹管连接至已安装完成的待检真空系

统区段，在可疑部位喷吹氦气，若存在漏孔，氦气将通过漏孔进入检漏仪并被精准识别。该方法灵敏度高，可准确定位漏点位置。检漏流程如图 2 所示。

真空系统烘烤后与加速器运行期间检漏：真空系统的性能直接关系到束流的品质和加速器的稳定运行，因此我们在真空盒安装完成后，制定了严格的烘烤除气流程以满足不同部位的加热需求，例如将永磁纵向梯度磁铁中的不锈钢真空盒加热温度设定在$1 2 0 \mathrm { { } ^ { \circ } C }$ ，既能满足除气要求又能保护永磁铁的磁性，系统经高温（ $1 2 0 ^ { \circ } \mathrm { C } { \cdot } 2 0 0 ^ { \circ } \mathrm { C } $ ）烘烤后

进入超高真空（ ${ \bf < } 1 0 ^ { - 8 } \mathrm { P a } )$ ）状态。此时，利用系统上的四极质谱仪开展检漏工作。通过监测质量数为 $4 \ : ( \mathrm { H e ^ { + } } )$ 的峰强在喷氦后的变化来判断漏点。同时，四极质谱仪持续监测全谱或特定质量数的分压，能够准确识别 $\mathrm { H } _ { 2 }$ 、He、 $_ \mathrm { H _ { 2 } O }$ 、 $\Nu _ { 2 }$ 、 $\mathrm { O } _ { 2 }$ 、 $\mathrm { C O } _ { 2 }$ 等关键气体，用于残余气体分析。

# 2 安装阶段真空检漏工艺及典型漏点处置研究

在 HEPS储存环安装调试过程中，我们遇到了多种类型的漏点，以下结合典型案例分析各类泄漏的特征与解决方案，并将其特征、定位方法和处置方案总结于表 1。

# 2.1 基于氦质谱法的典型漏点特征分析与处置方案

# 2.1.1 密封垫圈安装缺陷与密封性能优化

密封垫圈安装缺陷是真空系统法兰连接处最主要的泄漏诱因。HEPS 真空系统安装初期，法兰连接处频发不同程度的泄漏现象，其中多数泄漏可通过进一步均匀紧固法兰螺栓消除，部分泄漏则需更换密封垫圈方可达标。

典型案例：储存环弧区 R46 周期真空盒VC11 和 VC12 的法兰连接处，氦质谱检漏仪检漏显示漏率为 $2 . 3 { \times } 1 0 ^ { - 9 } \mathrm { P a } { \cdot } \mathrm { m } ^ { 3 } / \mathrm { s }$ ，初步拧紧法兰螺栓后漏率下降至 $8 . 5 { \times } 1 0 ^ { - 1 1 }$ Pa·m³/s，但仍未达标。继续均匀拧紧法兰的螺栓，漏

率进一步下降至 $< 9 . 9 { \times } 1 0 ^ { - 1 4 } \mathrm { P a } { \cdot } \mathrm { m } ^ { 3 } / \mathrm { s }$ ，满足设计要求。而有的法兰即使将螺栓拧至最大扭矩，仍有漏气情况，更换新的金属密封垫圈后，漏率才达到合格。此案例表明，密封垫圈的安装质量直接影响法兰连接的气密性，严格按照安装规程操作至关重要。

# 2.1.2 材料表面渗气特性与定位处置技术

材料表面微孔渗气是真空系统中较为隐蔽的泄漏类型。在 HEPS 项目中，检出 1处不锈钢转接头存在表面渗气特性，检漏仪监测到漏率随时间缓慢上升，一般在 $2 { \sim } 5 \mathrm { m i n }$ 内达到峰值漏率。解决方案：采用酒精涂覆方法定位渗气区域，当酒精涂覆至特定区域时，检漏仪读数瞬时下降，吹除酒精后读数恢复至原有水平，据此可准确定位渗气区域。对于不影响超高真空性能的微量渗气，采用临时刷涂真空密封胶的方式封堵；对于渗气较大的部位，则需在系统维护期间更换真空部件。

# 2.1.3 冷却水管焊缝缺陷泄漏的定位与处置

真空盒上焊接的冷却水管焊缝泄漏是

HEPS 项目中遇到的最隐蔽的泄漏类型之一。在一例典型案例中，检漏仪监测到系统存在持续泄漏信号，且漏率随时间缓慢增长。初期排查阶段，对所有法兰连接口进行氦气喷检，均未定位漏点，最终针对冷却水管进行重点检测时发现泄漏源。

解决方案：将氦气喷枪直接对准冷却水管接口，检漏仪显示漏率急剧上升，确认焊

缝存在缺陷。此案例表明，对于复杂真空系统，需要全面考虑所有可能泄漏路径，特别是那些容易被忽视的连接部位。

# 2.1.4 离子泵组件泄漏类型与处置方案

离子泵作为HEPS真空系统的主要抽气手段，其本身的密封性直接影响系统真空度。共发现两类离子泵相关泄漏：

离子泵高压头泄漏：在多台离子泵上观察到漏率缓慢增长现象，检漏仪显示漏率在$1 { \sim } 2 \ \mathrm { m i n }$ 内从 $1 0 ^ { - 1 2 } \ \mathrm { P a } \cdot \mathrm { m } ^ { 3 } / \mathrm { s }$ 量级增长至 10⁻9$\mathrm { P a } { \cdot } \mathrm { m } ^ { 3 } / \mathrm { s }$ 量级。拔下高压头后，直接向高压头插孔喷氦气，检漏仪显示极大漏率，确认高压头内陶瓷碎裂。

离子泵泵体泄漏：在常规检漏中发现，在 1 台离子泵周边区域喷氦时，检漏仪监测到漏率增长，但漏点难以精确定位。拆除离子泵外保护壳，直接向泵体焊缝和接口喷氦气，最终在泵体侧面焊缝处定位漏点。鉴于离子泵结构复杂，直接维修难度较大，故采用整台离子泵更换的处置方案。

2.1.5 真空盒焊缝缺陷泄漏的应急处置与长效保障

真空盒焊缝泄漏是HEPS项目中最严重的泄漏类型之一，需根据漏率等级与泄漏位置制定差异化处置策略。若安装阶段检出焊缝泄漏，直接更换真空盒。但在设备运行期间，对于漏率较小且不影响设备运行的泄漏采用真空胶临时封堵，待加速器停机后进行更换。所有焊缝补焊操作均在洁净环境中开展，并严格遵循焊后处理流程，包括化学清洗、纯水冲洗和快速烘干。

从工程实践来看，“冷却水管内焊缝漏”和“离子泵高压头漏”是定位最为困难的漏点类型。因为它们的漏点没有直接暴露在外面，氦气难以直接到达。这要求检漏人员必须深刻理解系统结构，并具有一定的检漏经验。例如，冷却水管内焊缝漏的解决表明，将复杂的系统分解为若干子系统进行排查是高效定位疑难漏点的关键[8]。图 4显示了在真空盒焊缝处发现的疑似漏点位置。

# 3 结论

本文详细介绍了HEPS储存环真空系统从安装到运行全过程的检漏与气体分析实践。通过本研究，可得出以下结论：

1. 检漏策略的有效性：结合氦质谱检漏仪和四极质谱仪，分阶段实施的检漏策略被证明是高效、可靠的。针对六类典型漏点总结的特征与处置方案，对同类大型真空工程的检漏实践具有重要参考价值。  
2. 疑难漏点定位技术：对于材料漏、焊缝漏、离子泵本体漏等疑难漏点，需要采用“分段隔离”、“喷检与罩检结合”等创新性方法，其成功实施的核心在于对系统结构的深度认知与精准把控。  
3. 残余气体分析的重要性：QMS 在超高真空阶段兼具检漏和残余气体分析的双重功能。RGA 数据清晰地揭示了束流加载后引起的动态气载变化，特别是 $\mathrm { H } _ { 2 }$ 的主导性增长，这与理论预测相符，证实了真空系统面临的主要挑战来自光致解吸效应。

4. 系统性能达标：所采用的检漏与质控方法成功保障了HEPS储存环真空系统达到并维持了设计所要求的极高真空度与洁净度，为 HEPS的成功调试与运行奠定了坚实基础。

未来，我们将继续利用 QMS 长期监测真空系统的气体成分变化，深入研究不同运行模式下的气载规律，为 HEPS的性能优化和可靠运行提供持续的数据支持。
