郭 召 1,2

【摘要】 高精度准直器是医用直线加速器实施精准放射治疗的核心部件，其性能直接影响治疗精准度。随着治疗精准度要求的不断提升，高性能直线加速器产品的准直器设计也在不断迭代创新，新型准直器的开发成为放疗设备创新的关键环节。本文对市面上广泛应用的几类医用直线加速器的准直器进行介绍，对比分析了不同准直器的性能及结构特点，总结了准直器设计制造的关键技术点，对医用直线加速器产品的准直器发展进行了展望，旨在为国产医用直线加速器的研发提供一定参考。

# Overview of collimator technology for medical linear accelerator products

Guo Zhao1,2

(1.Research and Development Center, OUR United Corporation, Xi’an 710018, China;

2. School of Mechanical Engineering, Xi’an Jiaotong University, Xi’an 710049, China)

【Abstract】 The high-precision collimator is the core component of a medical linear accelerator (linac) for delivering precise radiotherapy, and its performance directly impacts treatment precision. As the requirements for treatment precision continue to increase, the collimator design in high-performance linac products has been continuously iterated and innovated. The development of novel collimators has become a key link in radiotherapy product innovation. This article introduces several types of collimators widely used in medical linacs on the market, analyzes and compares the performance and structural characteristics of different collimators, summarizes the key technical points in collimator design and manufacturing, and provides an outlook on the development of collimators for medical linac products. This holds significant reference value for the research and development of domestically produced medical linear accelerators.

【Key words】 Multi-leaf collimator (MLC); Cone beam collimator; Beam shaping; Radiotherapy

医用直线加速器是治疗癌症的主要装备之一，准直器作为医用直线加速器核心部件，通常包含初级准直器与次级准直器，其中次级准直器直接参与照射野形状精准调控，对治疗精度产生关键影响，是实现精准放疗的核心执行单元。早期的医用直线加速器只配置光阑，仅能形成方野，因此只能开展普放治疗。为了提升适形精度，医务工作者采用低

熔点铅依据患者照射野形状制成适形挡块作为辅助准直器。随后为了提升工作效率，市场上推出了手动多叶光栅，可以根据患者照射野形状快速手动调整叶片位置形成所需照射野形状。到 20世纪 90年代，数控技术及精密制造技术的快速发展推动了多叶光栅的电动化。电动多叶光栅（dynamic multi-leaf collimator, D-MLC）的出现推动了精准放射治疗

时代的到来，并逐渐演变出多种不同规格形式的多叶光栅，在临床中发挥着重要作用，尤其是调强放射治疗（intensity modulated radiation therapy, IMRT）和容积旋转调强放射治疗（volumetric modulated arctherapy, VMAT）［1］。与此同时，为满足立体定向放射 外 科（stereotactic radiosurgery, SRS）、立 体 定 向放 射 治 疗（stereotactic radiotherapy, SRT）、体 部 立体 定 向 放 射 治 疗（stereotactic body radiation therapy,SBRT）、立 体 定 向 消 融 体 部 放 射 治 疗（stereotacticablative body radiation therapy, SABR）等治疗技术对小半影和高精度的需求，锥形孔准直器技术也获得了快速发展，成为准直器技术的另一个重要分支。锥形孔准直器通过锥孔全聚焦设计，实现小野剂量精确投照，有效降低半影，在立体定向放射治疗中发挥着重要作用，配置多叶光栅的医用直线加速器也选择配置锥形孔准直器作为附件用于开展立体定向放射治疗［2］。同时，多叶准直器技术也在向着更高照射野精度、更小投影宽度（分辨率）、更小半影、更优适形度、更高可靠性及更强剂量调制能力的方向发展。总之，准直器的技术进步推动着放射治疗精准度的不断提升。现有的研究多针对某一款准直器的性能进行测试研究，缺少对医用直线加速

器准直器的系统论述，本文对医用直线加速器的准直器技术进行介绍，分析不同准直器的性能及结构特点，总结准直器设计制造的关键技术点，以期为相关研究人员提供参考。

# 1 多叶光栅准直器

# 1.1 微型多叶光栅

早期的直线加速器准直器比较简单，只有一对光阑，没有多叶光栅。为了在老一代直线加速器产品上开展精准放疗，市场上推出了外挂式微型多叶光栅，可以作为附件安装在加速器机头上对光阑形成的方野进一步适形以获得更加精确的照射野，图1展示了几种外挂式微型多叶光栅的外观和结构。国外常见的外挂式微型多叶光栅是BrainLam $\mathbf { M } ^ { 3 }$ 微型多叶光栅，最大照射野 $1 0 0 ~ \mathrm { m m } \times 1 0 0 ~ \mathrm { m m }$ ，叶片在等中心处的投影宽度为 $2 \ \mathrm { m m } \ ^ { \left[ 3 - 4 \right] }$ 。国内主要的外挂式多叶光栅是苏州雷泰医疗科技有限公司生产的TiGRT系列，最大照射野 $1 0 0 \ \mathrm { m m } \times 1 0 0 \ \mathrm { m m }$ ，叶片在等中心处的投影宽度为 $2 \ \mathrm { m m } \ ^ { \mathrm { ~ [ ~ } 5 \mathrm { ~ ] ~ } }$ 。微型多叶光栅的分辨率更高，可以进一步提高照射野精度，为追求更高的 SRS治疗精度，部分已配备内置多叶光栅的直线加速器也会选配外挂式微型多叶光栅作为补充。

在 立 体 定 向 放 射 治 疗 中，与 常 规 光 栅 相 比，微型多叶光栅在分辨率上更有优势，同时相对锥形孔准直器，效率更高。如图2所示，M6型射波刀（CyberKnife）扩展增加了微型多叶光栅 InCise，包含 41对叶片，最大照射野 $1 1 5 \ \mathrm { m m \times 1 0 0 \ \mathrm { m m } }$ ，叶片在等中心处的投影宽度为 $3 . 8 5 \ \mathrm { m m }$ ［源轴距（source-axis distance, SAD） $= 8 0 0 \ \mathrm { m m } \ \mathrm { ] }$ ，叶 片 高 度 $9 0 \ \mathrm { m m }$ ，叶间最大漏辐射 $< 0 . 5 \%$ ，平均漏辐射 $< 0 . 3 \%$ ［6-8］。

配置微型多叶光栅后，射波刀治疗大体积肿瘤的效率得到提升，因此配置微型多叶光栅也成为专用立体定向放疗设备扩展其功能的一种趋势。随着临床对治疗精度要求的提升，加之电动多叶光栅技术的成熟，新一代的直线加速器都配置了内置的电动多叶光栅系统，可开展精准放疗，适形度、分辨率大幅提升，因此对外挂式微型多叶光栅的需求逐步降低。

# 1.2 单层多叶光栅

随着临床应用中对治疗精度要求的提升，各厂商将多叶光栅内置化，将光阑和电动多叶光栅整合形成新的准直系统，使直线加速器的性能及精度得到大幅提升。新的准直系统包含了光阑和多叶光栅。光阑通常分为两组，一组和叶片运动方向相同，用于遮挡叶片间的漏辐射；一组和叶片运动方向垂直，用于遮挡叶片端部闭合缝隙处的漏辐射，光阑和多叶光栅配合，形成复杂照射野，降低了照射野外漏辐射。目前市面上直线加速器产品普遍采用光阑和单层多叶光栅组合的准直器形式，典型的单层多叶光栅有医科达（Elekta）的 MLCi2［9-10］和 Agility160［11-12］，瓦 里 安（Varian）的 Millennium120 ［13-14］和 HD120［15-16］。MLCi2由 40对叶片组成，每片投影宽度 $1 0 \ \mathrm { m m }$ ；Agility160由 80对叶片组成，每片投影宽度 $5 \ \mathrm { m m }$ ，其 结 构 如 图 3所 示。Millennium120由 60对叶片组成，中间40对每片投影宽度 $5 \mathrm { \ m m }$ ，两侧各10对，每片投影宽度 $1 0 \ \mathrm { m m }$ 。HD120由 60对叶片组成，中间40对每片投影宽度 $2 . 5 \ \mathrm { m m }$ ，两侧各10对，每片投影宽度 $5 \ \mathrm { m m }$ ，其结构如图4所示。国内厂家

近几年推出的新型直线加速器产品均采用了与上述接近的架构设计，例如，西安大医和上海联影的电动多叶光栅均采用了60对叶片的光栅结构，中间40对每片投影宽度 $5 \mathrm { { m m } }$ ，两侧各10对，每片投影宽度$1 0 \ \mathrm { m m }$ 。综上，单层多叶光栅发展较早，叶片投影宽度不断精细化，目前多数集中在 $5 \ \mathrm { m m }$ ，架构基本定型。

# 1.3 双层多叶光栅

# 1.3.1 单聚焦双层多叶光栅

图5展示了单聚焦双层多叶光栅的架构，目前市面上主流的单聚焦双层多叶光栅是瓦里安医疗系统公司配置在 Halcyon/Ethos产品上的光栅系统［17-18］，叶片采用平行交错排列设计，上层（近端层）多叶光栅由29对叶片组成，下层（远端层）多叶光栅由28对叶片组成，每个叶片的投影宽度 $1 0 \ \mathrm { m m }$ ，上下两层叶片交错排列，使其在等中心处的有效投影宽度达到 $5 \ \mathrm { m m }$ ，等中心处最大照射野 $2 8 ~ \mathrm { c m } \times 2 8 ~ \mathrm { c m }$ ，叶片的运行速度 $5 0 \ \mathrm { m m / s }$ ，加速度达到 $2 0 0 \ \mathrm { m m } / \mathrm { s } ^ { 2 }$ ，这种设计的主要优势是叶片的透射和漏辐射更低，叶片的调制速度更快。单聚焦双层多叶光栅从架构上对直线加速器传统准直系统进行了简化，大幅减少了零件种类及数量，使整体结构更简洁，成本更低，更易维护，有利于整机可靠性的提升，这也为多叶光栅准直器的发展及临床应用提供了新的思路。国产的直线加速器如新华XHARX6和东软NeuRT Aurora均采用了类似架构，等中心处最大照射野 $3 0 \ \mathrm { c m } \times 3 0 \ \mathrm { c m }$ 。

# 1.3.2 双聚焦双层多叶光栅

ViewRay公司的 MRIdian放射治疗系统是一款0.35T 核磁成像引导的直线加速器系统，配置了双聚焦双层多叶光栅［19-21］，单层叶片在等中心处投影宽度 $8 . 3 \mathrm { \ m m }$ ，双层多叶光栅交错叠加的分辨率为 $4 . 1 5 \ \mathrm { m m }$ ，叶片在等中心处的投影平均速度为$2 0 \ \mathrm { m m / s }$ 。图6是ViewRay的双聚焦双层多叶光栅示意图，叶片为圆弧形，叶片做圆弧运动成野，结构相对复杂，成本较高，但可以获得更低的半影，提升照射野精度，目前主要应用在ViewRay产品平台上。单聚焦和双聚焦的双层多叶光栅都采用了上下交错的布置方式，极大地减少了叶片间的漏辐射，降低了单层叶片之间的漏辐射要求。单聚焦的双层多叶光栅结构更简单，可以获得更快的速度和更优的调制能力，在直线加速器产品的应用上，相比双聚焦结构更有优势。

# 1.3.3 双层正交多叶光栅

双层多叶光栅的另一种布置形式是正交排布，即上下层叶片运动方向垂直。较早实现工程化应用的双层正交多叶光栅是Acculeaf［22-23］，其最大照射

野为 $1 0 0 ~ \mathrm { m m } \times 1 1 0 ~ \mathrm { m m }$ ，作为微型光栅配套在直线加速器中应用。图7是Acculeaf多叶光栅成野示意图，如图所示，两层叶片正交运动，两个方向都可以提高靶区的适形度，双层叠加遮挡了叶片间的漏辐射。国内外专利文献中也有对双层正交多叶光栅的构思保护，但研发出工程样机并投入临床应用的较少。苏州雷泰医疗科技有限公司实现了该技术的工程化应用，开发了具有自主知识产权的双层正交多叶光栅系统［24-25］，图8展示了该双层正交多叶光栅的结构，每层 51对叶片，共 204个叶片，最大照射野 $4 0 ~ \mathrm { c m } \times 4 0 ~ \mathrm { c m }$ ，上层光栅最小投影宽度 $6 \mathrm { m m }$ ，最高速度 $6 0 \ \mathrm { m m / s }$ ，下层光栅最小投影宽度 $4 \ \mathrm { m m }$ ，最高速度 $5 0 \ \mathrm { m m / s }$ 。这种正交布置形式在凹多边形或岛状靶区的适形精度上有一定优势。

# 2 锥形孔准直器

在加速器上开展立体定向放射治疗时，通过采用锥形孔准直器可降低半影，提高照射野精度。配置锥形孔准直器的直线加速器产品主要有X-刀、射波刀（CyberKnife）、RayerKnife及 ZAP-X。

# 4 准直器设计制造的关键技术

# 4.1 物理设计

物理设计主要关注照射野精度、半影大小及漏辐射，这些性能指标主要受光路设计、准直器整体布局、准直器结构的影响。将需要在等中心获得的物理指标转化为准直器的结构设计指标，通过理论计算及仿真模拟进一步转化为具体的结构尺寸，例如光栅叶片的端面形状、截面形状、叶片高度，锥形孔形状等。其中叶片端部的形状设计是重点，其形状对半影的影响较大，不同的曲率设计、分段优化设计目的都是最大化地减少半影。

# 4.2 可靠性设计

准直器是放疗设备中运动最为频繁的部件，失效率相对较高，其可靠性设计是保证产品整机可靠性的基础。在准直器的概念构思阶段就要考虑可靠性设计，在满足功能性能的基础上，选择简化的概念结构，采用已成熟的技术及零部件。现有光栅结构中，丝杆丝母的损耗是最大的，通过材质的改良、加工工艺的优化可以降低其磨损量，提高使用寿命及可靠性。

# 4.3 可维护性设计

在直线加速器的应用过程中，准直器的维护保养是最为频繁的，开展可维护性设计才能提高维修效率，降低维修成本。可维护性设计要充分考虑可测试性，能快速地隔离故障，准确定位故障源，提高维修效率。新一代的准直器也开展预测性维修，在使用过程中对器件的电压、电流等参数进行采集，对故障进行预警，在失效前发出维修提示，保

证设备的开机率。

# 5 小结与展望

高精度准直器是医用直线加速器实施精准放射治疗的核心部件，其性能影响治疗精准度。随着治疗精准度要求的不断提升，高性能直线加速器产品的准直器设计也不断迭代创新，高性能新型准直器的开发成为放疗设备创新的关键环节。叶片速度提升，可以提高剂量调制能力，获得更优的靶区剂量分布，叶片运行的高速化成为光栅准直器的重要方向。双层多叶光栅用叶片替代了光阑，简化了准直器的整体结构，成野速度更快，叶间漏辐射大幅降低，将成为新一代加速器产品的标准配置。随着基于X射线的立体定向照射技术及装备的发展，锥形孔准直器也将伴随更多新型立体定向放射治疗设备的应用而得到更广泛的使用，特别是在追求极致小野剂量学和超低半影的 SRS、SRT、SBRT和 SABR应用中，通过多叶光栅准直器和锥形孔准直器的集成，构成复合型准直器，在兼顾高效的同时保证精准也是发展方向之一。多叶光栅是医用直线加速器中运动最为频繁的部件，国产部件在可靠性方面和进口品牌相比仍存在差距，需要在实际应用中总结经验，形成完善的故障处理经验。产品化迭代、数字化监测技术的应用、开展故障预警及预测性维护也是提升可靠性的新思路。随着对放射治疗精准度要求的持续提升，各种新型的准直器不断追求更好的照射野精度、适形度、低漏射率、靶区保护能力及剂量调整能力，以满足临床应用需求。
