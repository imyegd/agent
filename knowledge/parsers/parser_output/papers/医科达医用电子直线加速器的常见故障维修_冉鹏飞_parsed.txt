# 医科达医用电子直线加速器的常见故障维修

冉鹏飞，喻皇飞（通信作者）

遵义市第一人民医院　（贵州遵义　563000）

〔关键词〕医科达；直线加速器；故障维修

〔中图分类号〕TH774 〔文献标识码〕B 〔文章编号〕1002-2376（2025）22-0112-04

〔DOI〕10.3969/j.issn.1002-2376.2025.22.032

医科达医用电子直线加速器是临床治疗恶性肿瘤的“利器”，属于大型医疗设备，其结构复杂、功能多样，操作精细 [1]。在临床使用医疗设备过程中，由于受到所处环境、使用年限以及治疗频次和强度的影响，时常出现不同场景的故障，快速排查并解除故障是维护设备良好状态、保障临床治疗质量的前提和基础。本院医科达医用电子直线加速器于 2017 年投入使用，本研究总结了使用过程中几种常见的故障类型，供同行借鉴参考。

# 1  结构组成及工作原理

医科达医用电子直线加速器主要由控制供电系统、电子枪、磁控管、真空泵系统、加速管、偏转磁铁、电离室、治疗床等组成（见图1）。治疗床承载患者，靠内置电机多方向运动，确保患者体位与照射中心对准。机架是核心支撑，容纳加速管等部件，支持辐射头旋转以满足不同角度照射需求[2]。辐射头集成多叶光栅等组件，形成照射野并控制射线剂量分布，精准照射肿瘤靶区 [3]。各部分通过机械传动和电气控制协同工作，保障设备在放疗中高效稳定运行。

![](images/8ff9d1aa22d36c96c5cb078ef9a1bbfdcf91dcf990582e51ad081161fdf285bf.jpg)  
图1　医科达医用电子直线加速器结构组成示意图

医科达医用电子直线加速器工作原理：基于微波电场加速电子产生高能射线对癌细胞进行杀伤。磁控管产生微波能量传至加速管形成高频电磁场，电子枪发射电子束注入加速管，在微波电场作用下

加速至近光速。高能电子撞击钨靶产生X射线束，经钨门和多叶光栅（multi-leaf collimator，MLC）调控后照射肿瘤靶区 [4]。整个过程中，能量产生、传输及照射受精密控制系统监测调整，确保射线剂量准确均匀分布于靶区，保护周围正常组织。

# 2  故障一

# 2.1  故障现象

操作人员开启设备时，发现治疗床无法移动，设备报“i159 Height Control”联锁错误警示。

# 2.2  故障分析与处理方法

治疗床通过前后、上下、左右的平移及围绕中心的旋转和自旋转等复杂动作来精准地校对患者中心点。由于操作频繁，因此分析此故障可能是由其内置的电机和电位器在长时间使用后出现磨损或性能下降导致。

经检查发现，治疗床升降相关的电位器（包括 Fine、Coarse、Check 电位器和上下限位开关及制动闸）均处于正常工作状态。然而，在手动升降治疗床时会出现联锁故障，因此推测电机可能存在潜在问题。随后，使用万用表对电机供电情况进行检测，发现治疗床上下运动时电压在某些位置出现跳变。拆下电机后手动旋转电机，使用万用表测量电机内阻，发现某些位置电机内阻值为10 Ω，正常范围应为 $2 4 \pm 2 \Omega$ ，表明可能存在碳刷磨损或接触不良。更换碳刷后，重新测量电机电阻值，发现已恢复正常且稳定不跳变 [5]。安装所有配件后重新启动设备，治疗床功能恢复正常，故障解除。

# 3  故障二

# 3.1  故障现象

开机后顺利进入治疗模式，当旋转大机架时，小机头钨门出现异常开大现象，设备在钨门 Y1 限位或X2 电位器报联锁错误，见图2。

# 3.2  故障分析与处理方法

退出治疗模式进入维修模式，并进入机房手动尝试旋转机架。通过检查发现，当光栅 X1、$\mathrm { X } 2 \geqslant 1 0$ 时，钨门会出现 2 次开大现象，而 Y 侧钨

门也跟随开大。凭借经验判断，可能为公共元件短 路导致电压变化，从而引发联锁反应。

首先，翻阅使用说明书查看电路图，使用三用表测量X位置电位器电压，结果显示数值为10 V，

电压在正常范围内；其次，检查多叶光栅（MLC）电路板，先拆卸小机头外壳，更换多叶光栅控制线路板后故障依旧存在；再次，更换扁平电缆，并仔细检查了各线路接插件，但故障仍未排除，继续更换了 5 区的 6 个通用马达驱动（见图 3）电机驱动线路板仍未能有效解决问题。最后，通过仔细观察发现，旋转过程中 X2 数值存在微小抖动变化，偶尔伴有 Fine 电位器报错。经过综合分析，判断可能是双抽头电位器 RV6运动故障所致，更换RV6电位器后，重新测试，机器恢复正常运转 [5]。

# 4  故障三

# 4.1  故障现象

开机晨检，医科达医用电子直线加速器预热时，禁止项显示靶端离子泵压强值为 $1 0 ^ { - 4 }$ Torr，异常。

# 4.2  故障分析与处理方法

医科达医用电子直线加速器要求压强必须小于 $1 0 ^ { - 4 }$ Torr，以确保设备正常稳定运行 [6]。经过深入分析，该故障可能由以下 2 个原因引起：（1）端离子泵出现泄漏，导致其工作负荷过高而陷入瘫痪状态；（2）离子泵使用年限过长，达到报废阶段。

首先，交换 2 个离子泵电源接线进行测试，发现靶端离子泵无响应，而电子端离子泵工作正常且显示压强值为 $1 0 ^ { - 6 }$ Torr，并有明显的发热现象，由此确定为靶端离子泵损坏 [7]。根据离子泵工作原理，高压电场电离残气为正离子与电子，正离子加速撞击钛阴极溅射出钛原子，形成高活性钛膜，

![](images/68cff025c4fa49e8e5b8454ee0525e7c908fff0c5d430b19200b18e813f41659.jpg)  
图2　医科达医用电子直线加速器电路图

通过物理和化学吸附残余气体；部分正离子嵌入钛阴极晶格被永久埋存，同时吸气剂持续吸附气体，实现真空长期维持。而过度使用加速器进行旋转出束操作可能导致极板上的化合钛堆层杂质脱落，进而引发放电使离子泵出现故障。为解决此问题，采用敲击离子泵体的方法：在泵体下垫 1 块厚木板并用木方将其顶起，避免因击打导致衔接处断裂，接着有节奏地击打多次后，重启系统，发现靶端离子泵压强值恢复正常，重新测量直线加速器的平坦度、对称性及剂量率，故障解除。

# 5  故障四

# 5.1  故障现象

治疗过程中 MLC 检测异常，图像丢失，射野灯不亮，设备报错：Lost Reflector Rate，即未检测出反光点。

# 5.2  故障分析与处理方法

MLC 射野灯不亮，根据电路图（图 4）初步判断为灯泡故障。检查灯泡供电，测量射野灯底座电压，交流 12.5 V，正常；取下灯泡测灯泡电阻无穷大，判断为灯泡损坏[8]。

MLC 射野灯泡为卤素灯泡，一般寿命为 3 个月左右，维修记录显示上次更换灯泡为 4 月前，因此需更换 MLC 灯泡。具体操作如下：将机架和小

机头调整至 $1 8 0 ^ { \circ }$ ，拆除机头及 MLC 射野灯外壳（Precise 型直线加速器仅需打开前窗；Synergy 及以上机型直线加速器需先拆除罩壳4个固定螺钉，然后拆除两面罩壳）；关闭机器等待 $1 0 \mathrm { m i n }$ 后，用纱布握住灯泡防止烫伤，断开灯泡固定座，同时使用一字改锥拆掉固定灯泡的2个V字形卡簧，更换新的灯泡；固定新灯泡（注意备件名称：Projectorhalogen bulb 13.8 V，规格：50 W），灯泡紧靠上端 2 颗定位螺钉，同时扶紧 2 个 V 字形卡簧，拧紧卡簧一字螺钉。启动机器，等待整机预热 $1 0 ~ \mathrm { m i n }$ 后，使用万用表测量灯泡电压，MLC 电压范围应在 $1 2 . 7 \pm 0 . 5$ VAC，否则需要调整射野灯电压。进入维修模式调入MLC画面，观察图像有无反光点，且亮度是否过亮或过暗，否则需要调节MLC摄像头光圈。然后进行 MLC 运行检测，对于型号为 DesktopR5.0 的加速器，运行 MLC $3 \mathrm { c m } \times 3 \mathrm { c m }$ 和 $4 0 \ \mathrm { c m } \times$ $4 0 ~ \mathrm { c m }$ 射野检查，或通过MLC Test程序检测；对于型号为R7.0以上机器，运行MLC光学优化。最后安装罩壳，灯泡更换完成。重新测试后故障解除，加速器恢复正常。
