# XiPAF束流垃圾桶屏蔽设计及残余剂量评估

王 迪 陈 伟 吕 伟 闫逸花 于俊英 王敏文 王忠明

（强脉冲辐射环境模拟与效应全国重点实验室（西北核技术研究所） 西安 710024）

摘要 为了确保西安 $2 0 0 \mathrm { M e V }$ 质子应用装置（Xi'an 200 MeV Proton Application Facility，XiPAF）升级之后的辐射安全，对束流垃圾桶进行了屏蔽设计与残余剂量评估。首先分析了不同材料的中子产额特征，选择聚乙烯作为低中子产额的靶芯材料。基于FLUKA蒙特卡罗模拟设计了复合结构束流垃圾桶，主体屏蔽材料为铁，外围屏蔽材料为含硼聚乙烯。计算结果表明，束流垃圾桶尾部侧面和横向侧面的最大剂量当量率分别为 $4 . 2 \mathrm { m S v { \cdot h } ^ { - 1 } }$ 和 $3 . 2 ~ \mathrm { m S v { \cdot h } ^ { - 1 } }$ ，满足 $5 . 5 \mathrm { m S v ^ { \cdot } h ^ { - 1 } }$ 的设计限值。与传统石墨靶芯相比，聚乙烯靶芯在上游方向的剂量降低约 $7 5 \%$ 。对连续出束1 h、1 d、1 w三种工况的残余剂量分析显示，桶入口处剂量衰减至 $2 . 5 \mu \mathrm { S v } { \cdot } \mathrm { h } ^ { - 1 }$ 所需时间均为 $2 { \sim } 3 \mathrm { ~ h ~ }$ 。研究结果为中能质子加速器束流垃圾桶设计提供了重要参考，有助于确保XiPAF工作人员的辐射安全。

关键词 束流垃圾桶，辐射屏蔽，残余剂量，蒙特卡罗模拟

# Radiation shielding design and residual radioactivity assessment for the beam dump at XiPAF

WANG Di CHEN Wei LYU Wei YAN Yihua YU Junying WANG Minwen WANG Zhongming

(National Key Laboratory of Intense Pulsed Radiation Simulation and Effect, Northwest Institute of Nuclear Technology, Xi'an 710024, China)

Abstract [Background] The Xi'an $2 0 0 \ \mathrm { M e V }$ proton application facility (XiPAF) is planned for upgrade and transformation into a versatile experimental facility for both proton and heavy-ion applications, requiring comprehensive radiation protection design for operational safety. [Purpose] This study aims to develop a radiationsafe beam dump design ensuring compliance with operational dose limits during operation and minimizing postirradiation residual doses. [Methods] Firstly, the neutron yield characteristics of different target materials were analyzed using FLUKA Monte Carlo simulations to determine the optimal core material with low neutron production. Then, a composite structure beam dump was designed with polyethylene as the target core material, iron as the main shielding material, and borated polyethylene as the outer shielding layer. Finally, shielding performance was quantified via ambient dose equivalent rate mapping at critical locations, and residual dose decay kinetics were modeled for three operational scenarios: 1-h, 1-d, and 1-w continuous irradiation at maximum beam intensity of $1 . 3 \times$ $1 0 ^ { 1 0 }$ protons per second. [Results] The computational results show that the maximum ambient dose equivalent rates at the rear and transverse sides of the beam dump are $4 . 2 \mathrm { m S v { \cdot h } ^ { - 1 } }$ and $3 . 2 ~ \mathrm { m S v { \cdot h } ^ { - 1 } }$ respectively, both below the design limit of $5 . 5 \mathrm { m S v ^ { \cdot } h ^ { - 1 } }$ . Compared to traditional graphite core, polyethylene demonstrates approximately $7 5 \%$ lower upstream dose while maintaining equivalent downstream shielding performance. Analysis of residual dose under the

three operational scenarios shows consistent decay patterns, with all cases reaching the dose constraint of $2 . 5 ~ \mu \mathrm { S v } { \cdot } \mathrm { h } ^ { - 1 }$ after 2~3 h cooling time. [Conclusions] The polyethylene-core composite beam dump design provides effective radiation protection for the XiPAF facility upgrade, with significantly reduced neutron backscattering compared to conventional graphite targets. The residual radioactivity analysis indicates that facility access can be safely permitted within 2~3 h after beam shutdown for all typical operational scenarios. These results provide practical reference for radiation protection design of beam dumps at similar intermediate-energy proton accelerator facilities.

Key words Beam dump, Radiation shielding, Radioactivity, Monte-Carlo simulation

西安 $2 0 0 \mathrm { M e V }$ 质 子应 用装 置(Xi'an 200 MeVProton Application Facility，XiPAF）是为宇航器件的空间单粒子效应研究而建设的一台加速器装置，在“十四五”期间，XiPAF计划升级改造为一台质子/重离子通用实验装置［1‒2］。为了确保人员、设备和环境安全，该类加速器装置的辐射防护问题不可忽视，其中束流垃圾桶在辐射防护中扮演着至关重要的角色。束流垃圾桶可以吸收废弃的束流，在原有建筑

屏蔽墙的基础上形成叠加屏蔽结构，从而提升总体屏蔽效能，同时避免了束流直接照射到屏蔽墙体后对墙体及周围设备材料造成的活化。如图1所示，束流垃圾桶位于XiPAF装置高能输运线及辐照终端的末尾，在加速器停机之后，此处将是实验人员出入最频繁的区域，因此研究设计XiPAF束流垃圾桶并评估其残余放射性水平，对于该装置的辐射安全具有重要意义。

本文将对常用的屏蔽材料的屏蔽性能进行对比分析，提出束流垃圾桶的材料及结构，通过蒙特卡罗模拟进行屏蔽计算和验证，并评估不同运行时间停机后，靶芯中产生的放射性核素种类及活度。研究结果可以为中能质子加速器束流垃圾桶的设计及人员辐射防护提供参考。

# 1 设计需求

根据XiPAF重离子升级工程的设计指标［2］ ，装置既能引出最高能量为 $2 0 0 \mathrm { M e V }$ 的质子，也能引出最高能量约 $1 0 \mathrm { M e V } { \cdot } \mathrm { u } ^ { - 1 }$ 的重离子，考虑到质子具有更强的穿透能力，且质子流强比重离子流强高3个量级，从辐射防护角度分析，质子的辐射屏蔽需求占主导地位。质子打靶束流强度最大为 $1 . 3 \times 1 0 ^ { 1 0 }$ PPS

（Protons Per Second），对应的束流功率小于 1 W，远小于采用自然冷却的最大功率上限，因此不必考虑热量沉积问题。另外，目前国内对于束流垃圾桶自身的屏蔽效果，还没有相关规范，中国散裂中子源的束流垃圾桶在设计时，参考日本原子能研究所（Japan Atomic Energy Research Institute，JAERI）$3 \mathrm { G e V }$ 储存环质子束流垃圾桶的设计指标，其要求屏蔽体外 $1 \mathrm { m }$ 深度里的土壤剂量率在 $5 . 5 \mathrm { m S v ^ { \cdot } h ^ { - 1 } }$ 以下［3］。考虑到XiPAF的束流能量和强度均低于上述装置，束流垃圾桶的尺寸及建设成本相对可控，根据辐射防护的最优化原则，本文在设计束流垃圾桶时采用更保守的剂量限值，即在束流垃圾桶外侧边沿的剂量率限值为 $5 . 5 \mathrm { m S v ^ { \cdot } h ^ { - 1 } }$ 。

# 2 屏蔽设计及计算

# 2.1 设计思路

质子作为带电粒子，其在材料中的射程是较为固定的。质子轰击靶材料会产生多种次级粒子，尤其是与靶材料原子核反应产生的次级中子和次级γ光子，这些中性粒子穿透能力强，是瞬发辐射场屏蔽的主要对象［4‒5］。对于能量高于约 $1 0 \mathrm { M e V }$ 的质子加速器，次级中子在瞬发辐射场中做主要贡献［6］。根据公开文献可以看出，国内外加速器装置中束流垃圾桶的屏蔽设计主要基于经验，没有固定的范式［3，7‒10］。本文根据XiPAF束流的参数及辐射场特点，在设计中遵循以下4个要素：

1）束流垃圾桶采用复合结构，由靶芯材料、主体屏蔽材料及外围屏蔽材料组成，且几何形状在束流径向是对称的；  
2）靶芯材料直接吸收质子束流，应选择次级中子产额低的材料；  
3）主体屏蔽材料为密度较大的金属材料，用于在有限体积内慢化高能次级中子，同时对次级γ光子有较好的屏蔽效果；  
4）外围屏蔽材料应对慢化后的中子有较好的屏蔽性能。

前人虽然提出一些关于屏蔽计算的经验公

式［6］ ，但是对于复杂几何结构以及多种材料组合的情况，利用公式计算则不太准确，此时蒙特卡罗模拟的方法则更具优势。蒙特卡罗模拟软件FLUKA（FLUktuierende KAskade）基于粒子与物质相互作用的模拟计算，被广泛应用于高能物理、空间辐射、放射治疗、辐射屏蔽计算、感生放射性分析等多个领域［11］。本文中的蒙特卡罗模拟工作主要基于FLUKA开展。

# 2.2 材料选择

靶芯吸收了绝大部分束流能量，其材料遴选需兼顾低次级中子产额与低活化特性。中子产额的定义为平均每个质子入射靶材料产生的中子个数，利用FLUKA计算中子产额，产额值为靶材料外表面出射的中子数量。其中靶的形状为圆柱体，其高度为质子射程，而圆柱半径为质子射程的横向岐离，这样设置的目的是尽量减少次级中子与靶材料的进一步 反 应 。 首 先 使 用 SRIM（Stopping and Range ofIons in Matter）程序［12］ 可以快速得到 $1 0 { \sim } 2 0 0 \mathrm { M e V }$ 质子几种常见屏蔽材料（聚乙烯、石墨、铝、铁、铜、铅）中的射程（表1）及横向岐离（表2），作为FLUKA模拟计算中的几何模型参数。在FLUKA计算中，设置质子垂直入射靶材料的圆柱底面中心，使用USRBDX计数卡得到出射到圆柱体外的中子产额（图2）及中子能谱分布（图3）。

# 2.3 屏蔽计算

文献［16］列举了质子打靶后次级中子角度分布，对于 $2 0 0 \mathrm { M e V }$ 质子打靶，其次级中子在前向最多，而在与束流轴垂直的径向是对称分布的，因此总体上采用圆柱形屏蔽材料，其中主体屏蔽材料前半部分开口，确保靶芯位于主体屏蔽材料的前半部分，如图4所示。根据束流管道尺寸和 $2 0 0 \mathrm { M e V }$ 质子射程，选择开口直径和靶芯直径为 $2 0 \mathrm { c m }$ ，靶芯厚度为$3 0 \mathrm { c m }$ 。

# 3 残余剂量评估

中能质子加速器在运行期间由于束流损失而产生瞬时辐射，这些束流粒子与各个部件材料相互作用会使材料活化，导致在加速器停机之后仍存在残余辐射，这是加速器停机之后的检修、换样等工作人员需防护的重要对象［8］。而束流垃圾桶是束流损失最集中的元件，同时位于XiPAF辐照终端的下游，因此需评估其残余辐射水平，特别是束流垃圾桶入口位置处。

使 用 FLUKA 的 IRRPROFI、DCYTIMES、DCYSCORE等输入卡组合，可以方便地设置束流损失率、辐照时间、冷却时间等关键参数。设置质子束流能量为 $2 0 0 \mathrm { M e V }$ ，束流损失率为 $1 . 3 \times 1 0 ^ { 1 0 }$ （每秒粒子数），图8给出了连续照射1 d并冷却不同时间之后，束流垃圾桶周围的残余剂量率分布，图中分界线对应的剂量值为 $2 . 5 \mu \mathrm { S v } { \cdot } \mathrm { h } ^ { - 1 }$ 。可以看出，随着冷却时间的增加，残余剂量变低，并且残余辐射主要存在束流垃圾桶的入口处。

根据核反应中放射性核素的生成规律［18］，易得：

$$
A = N _ {s} \sigma I \left(1 - 2 ^ {- \frac {t _ {0}}{T _ {1 / 2}}}\right) \cdot 2 ^ {- \frac {t _ {c}}{T _ {1 / 2}}} \tag {1}
$$

式中： $A$ 为放射性活度； $N _ { \mathrm { s } }$ 为单位面积靶上的靶核数； $\sigma$ 为质子与靶原子核反应产生某种放射性核素的平均截面；I为束流强度； $T _ { 1 / 2 }$ 为放射性核素的半衰期； $t _ { 0 } \cdot t _ { \mathrm { c } }$ 分别为辐照时间和冷却时间。当束流种类、能量、靶材料不变时，式（1）中的因子均为常量，式（1）中括号项即为辐照 $t _ { 0 }$ 时间后的该放射性核素的饱和程度，当辐照5个半衰期后，饱和程度约达到$9 7 \%$ 。使用FLUKA的RESNUCLE计数卡得到三种

# 4 结语

本文根据XiPAF束流参数（最高能量 $2 0 0 \mathrm { M e V } .$ 、最大引出束流强度 $1 . 3 \times 1 0 ^ { 1 0 }$ （每秒粒子数）），对束流垃圾桶的屏蔽设计及残余放射性进行了深入研究。采用一种便于加工制造的复合结构，其中选择聚乙

烯作为靶芯材料，与传统使用的石墨相比，聚乙烯具有中子产额低、活化水平低的优势。通过FLUKA模拟计算，得到束流垃圾桶周围的瞬时剂量率小于$5 . 5 \mathrm { m S v ^ { \cdot } h ^ { - 1 } }$ ，满足设计指标。对两种靶芯材料进行对比计算，其主要差异为，在束流垃圾桶前向，使用聚乙烯靶芯所产生的中子剂量比石墨靶芯降低了约$7 5 \%$ ，在单粒子效应辐照终端具有独特的优势。

最后评估了束流垃圾桶产生的残余剂量，计算了三种不同辐照时间产生的残余剂量衰减及主要放射性核素产生情况，计算结果与公式规律吻合较好。这三种工况覆盖了XiPAF装置绝大部分应用场景，可以为停机之后人员进入终端区域的辐射安全提供数据参考。
