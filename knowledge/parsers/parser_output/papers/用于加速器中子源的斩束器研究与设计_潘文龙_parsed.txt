# 用于加速器中子源的斩束器研究与设计

潘文龙1,2，   李海鹏1,2，   王　盛1,2,3，   苏浩泉1,2，   朱　颉1,2

（1.西安交通大学 核科学与技术学院，西安 710049；   2. 西安交通大学 湖州中子科学实验室，

浙江 湖州 313000；   3. 华硼中子科技（杭州）有限公司，杭州 310000）

摘    要 ：   针对应用于硼中子俘获治疗的加速器中子源的束流偏转问题，为其低能束流传输线部分设计了一套斩束器，通过理论计算与软件模拟，验证方案的可行性。为了解决斩波器电场强度不均匀问题，引入圆弧电极设计结构，微波工作室（CST Studio Suite）模拟仿真表明其具有更好的电场分布均匀性。发展了基于 Python程序的 CST 与 TraceWin 联合束流动力学模拟，结果表明设计的斩波器能够高效率地实现束流偏转功能，设计方案具有良好的实际应用价值和意义。

# Research and design of chopper for accelerator neutron source

Pan Wenlong1,2，   Li Haipeng1,2，   Wang Sheng1,2,3，   Su Haoquan1,2，   Zhu Jie1,2

（1. School of Nuclear Science and Technology, Xi’an Jiaotong University, Xi’an 710049, China;

2. Huzhou Neutron Science Laboratory, Xi’an Jiaotong University, Huzhou 313000, China;

3. Hua Boron Neutron Technology (Hangzhou) Co, Ltd, Hangzhou 310000, China）

Abstract：    [Background] Cancer is a major global health issue. With the development of accelerator physics, boron  neutron  capture  therapy  based  on  accelerator  neutron  sources  has  received  widespread  attention.  In  the accelerator system, the low energy beam transport is responsible for connecting the ion source and accelerator, as well as processing the beam. For the problem of beam deflection, the chopper is required, so a high-performance chopper is crucial  for  the  entire  system. [Purpose] This  study  aims  to  improve  the  electric  field  uniformity  of  the  chopper  by using  circular  arc  plates  instead  of  parallel  plates,  and  to  simulate  the  chopper  design  through  Python  program coupling using CST Studio Suite and TraceWin software. [Methods] The beam deflection formula of the chopper was theoretically  derived,  and  the  electrostatic  and  beam  dynamics  design  was  completed  using  CST  Studio  Suite  and TraceWin software. The advantages and feasibility of the circular arc plate were verified through coupling simulation of  the  two  software. [Results] Theoretical  calculations  and  simulations  show  that  the  electric  field  distribution  of circular  arc  plates  is  more  uniform,  and  the  beam  deflection  function  is  efficiently  completed,  confirming  the feasibility of the design scheme. [Conclusions] By coupling CST Studio Suite with TraceWin software for simulation, a more realistic simulation of beam dynamics can be achieved, which addresses the issue that TraceWin software is incapable  of  setting  the  electric  field  strength  of  circular  arc  plates.  The  coupled  simulation  method  of  CST  Studio Suite and TraceWin has been developed, which has certain value for research on chopper design.

Key  words：    accelerator-based  neutron  source, boron  neutron  capture  therapy, chopper, beam  dynamic, electrostatic field calculation

加速器中子源是利用加速器将粒子加速到一定能量通过打靶产生中子，以建造周期短、中子产额高、安全等优势受到广泛关注。加速器中子源可以用于中子探测、中子成像等方面[1-2]，尤其在核医学领域有着广阔前景。

癌症是全球范围重大公共卫生问题，是全球第二大死因[3]。以中美为例，2022年，中国癌症新发病例数约为

482.47 万例，新增癌症死亡例数约为 257.42 万例，2024 年，美国新发病例与死亡病例为 200.11 万例和 61.17 万例[4]。硼中子俘获治疗（Boron Neutron Capture Therapy, 简称 BNCT）作为核医学领域新方法成为当下研究热点[5]，研究用于BNCT 的加速器中子源具有重要意义。

加速器中子源中位于离子源与加速器之间的部分称为低能束流传输线[6]（Low Energy Beam Transport, 简称 LEBT），负责调节束流时间结构参数，通常射频加速器采用脉冲束流的模式，而离子源产生的质子束流长度通常在毫秒或者亚毫秒量级[7]，由离子源产生的束流，其脉冲时间结构和后端粒子加速器运行模式往往不匹配，所以在进入加速器之前需要把多余的束流斩切掉，这样就需要引入束流偏转系统，具有这样功能的装置称为斩束器（chopper）。

斩束器根据结构分类有三种：静电类[8-9]、静电结合静磁类[10]，以及磁合金感应类[11]。一般对于速度接近光速需要采用相对论动力学处理的粒子，称为高能粒子，反之则为低能粒子。对于低能粒子常采用电偏转方式，而高能粒子采用磁偏转方式[12]，在 LEBT 段的粒子速度通常在 $1 0 ^ { 6 } \mathrm { m / s }$ 量级，所以采用静电类型斩束器。本文基于应用于硼中子俘获治疗的加速器中子源，为其研究设计了斩束器装置，优化了电场分布均匀性以改善束流品质，并通过Python 程序实现 CST Studio Suite 与 TraceWin 软件对斩束器的耦合模拟以验证设计方案的性能。

# 1    斩束器结构设计与模拟

# 1.1   斩束器基本理论

在加速器中子源的 LEBT 段，粒子能量往往在几十 keV量级[13]，因此多采用静电式斩束器，图 1是静电式斩束器结构示意图，上下极板间距为 d，极板之间存在一个静电场，带电粒子通过长度 $L$ 的斩束器。获得一个偏转角 θ，再经过 L′的漂移长度最终打到承接屏上，粒子经斩束器作用偏转距离为 $x { + } L ^ { \prime } { \mathrm { t a n } } \theta .$ ，假设下极板电势为 $_ { 0 \mathrm { ~ V ~ } }$ ，上极板电势为 $\varphi _ { \mathrm { d } } ,$ ，粒子纵向匀速运动，横向在电场作用下加速运动，不考虑边缘效应。

带电粒子的拉格朗日函数为[14]

$$
L = T - U = \frac {1}{2} m v ^ {2} - q \varphi \tag {1}
$$

式中： $T$ 是带电粒子动能； $U$ 是带电粒子电势能。

并对电势 $\varphi$ 进行线性近似，即

图 1    静电式斩束器结构示意

$$
\varphi = \varphi_ {0} + \varphi^ {\prime} d \tag {2}
$$

在束流光学中，将粒子传输方向定义为 z 方向，与 $z$ 方向正交的平面定义为横向截面，横向截面的正交轴 x、$y$ 轴与 $z$ 轴满足右手法则。假定时间 $\scriptstyle { t = 0 }$ 时，粒子坐标 $y { = } 0$ ， $z { = } 0$ ，对于束流偏转角采用泰勒展开并取一阶近似$\tan \theta { \approx } \theta .$ ，带入到拉格朗日方程中，最终可以求得斩束器作用下束流偏转距离公式为

$$
H = K \varphi = \frac {1}{2} \left(\frac {L}{2} + L ^ {\prime}\right) \frac {L}{d} \frac {\varphi_ {\mathrm {d}}}{W} \tag {3}
$$

式中：W为带电粒子引出电压， $K$ 为斩束器偏转灵敏度，表示极板间电势差为 1 V 时粒子偏转距离， $\varphi _ { \mathrm { d } }$ 为偏转电压。

从式（3）不难看出斩束器中束流的偏转距离与束流粒子种类无关。若考虑粒子相对论效应，则需要对式（3）进行修正，此时束流偏转距离表达式为

$$
H = \frac {q l (l + 2 L) \varphi_ {\mathrm {d}}}{2 m _ {0} \gamma \beta^ {2} c ^ {2} d} \tag {4}
$$

式中： $q$ 为粒子所带电荷量， $m _ { 0 }$ 是粒子静质量， $c$ 为光速， $\beta$ 为相对速度，γ为相对论因子。

# 1.3    CST Studio Suite 软件与 TraceWin 软件耦合模拟

就一般束流动力学模拟来说，可以只利用 TraceWin软件独立完成，通过仿真模拟，图 7 为斩束器作用下束流包络图，可以看到在斩束器工作段束流被完全偏转掉了，图 8是斩束器作用下束流偏转相图，大部分粒子偏转距离为 $1 9 . 5 ~ \mathrm { c m }$ ，均打到斩束器后边承接元件上。

通过理论推导结合软件模拟，在 1.2 节设计了斩束器的几何结构、参数，通过束流动力学软件模拟，验证了斩束器作用下对束流的偏转效果，但是对于 TraceWin 软件来说，模拟中采用的斩束器电场参数为理想平行极板结构下的参数。然而实际运行中，如图 3所示，由于边缘效应会导致平行极板斩束器电场强度高度不均匀化，所以会影响模拟效果。其次对于特殊结构的元件 TraceWin软件是无法完成建模仿真的，因此这时更需要与其他软件配合完成工作。例如在本设计方案采用了圆弧极板，圆弧极板的电场分布参数并不能直接体现在模拟中，因此为了解决这问题，从而使得仿真更为可靠，本文基于 Python 软件程序处理 CST Studio Suite 静电学模拟得到的电场强度文件，将 CST Studio Suite 模拟得到的电场强度文件放到 TraceWin软件中，实现了两种软件的耦合模拟。图 9是在实际圆弧极板的斩束器作用下束流的包络图。

# 2    斩束电压脉冲前后沿与束流脉冲前后沿关系

对于斩束器而言，另一个重要关系是斩束电压脉冲前后沿和束流脉冲前后沿关系。实际上，静电斩束束流的上升（下降）沿由电压上升（下降）沿和带电粒子在斩束器内飞行时间决定[15]，假设束流偏转电压为 $\varphi$ ，图 12 是斩束器电压波形图，带电粒子在斩束器内飞行时间为 $t _ { 0 } { = } L / \nu$ ，$L$ 是极板长， $\nu$ 是粒子速度，在 $t _ { 0 } { \sim } 0$ 这段时间束流不被偏转， $\scriptstyle { t = 0 }$ 时刻斩束器开始工作，那么 $t _ { 0 } { + } t _ { 1 }$ 这段时间束流得不到有效的偏转，这就是束流下降沿时间，对于束流上升沿，与其反过来，是束流通过斩束器时间加上斩束器电压下降时间。

![](images/34ddab9b5083529e0f726854f9fc3f920a1d43af4660f2e8fe382d340bf4a4d2.jpg)  
Fig. 12    Voltage waveform diagram of the beam chopper   
图 12    斩束器电压波形图

束流的上升沿与下降沿越短越好，束流传输的波动会影响后续加速器的工作，而这主要取决于斩束器电压的上升沿于下降沿[16]，因此对于斩束器的驱动电压要求在尽量短时间完成工作，便于分析计算假设 $L ^ { \prime } { = } 1 5 \ \mathrm { m m }$ ，斩束器驱动电压有 $1 \%$ 波动会带来束流轴心位置偏离 $0 . 3 \mathrm { m m }$ ，这样带来的束流发散角为 $\pm 3 \mathrm { \ m r a d }$ ，若束斑为理想圆形束斑，假设半径为 $5 \mathrm { { m m } }$ ，则束流的归一化发射度为 $0 . 1 3 \pi$ ·mm·mrad，加速器入口要求束流归一化发射度 $< 0 . 3 \pi$ ·mm·mrad，由此可见斩束器电压的上升沿与下降沿时间对于束流发射度的影响还是较大的。

为了让束流上升沿与下降沿时间降低，一般情况斩束器工作电压会采用高于 $\varphi$ 的 $\varphi _ { \mathrm { m } } ^ { \ [ 1 5 ] }$ ，这时束流的上升沿与下降沿计算式就要有所变化。根据文献 [8]，假设极板长 $L$ ，极板间距 $d ,$ ，电压实际输出幅值 $\varphi _ { \mathrm { m } } .$ ，踢束所需电压 $\varphi$ ，粒子飞行时间 $\tau ,$ ，电压由 0升至 $\varphi$ 所需时间 $t _ { 1 }$ ，升至 $\varphi _ { \mathrm { m } }$ 所需时间 $t _ { 2 \circ }$ 利用微积分知识易求得以下关系式

$$
\left\{ \begin{array}{l} \tau_ {1} = \tau^ {\prime} + t _ {1} \\ \tau^ {\prime} = \tau \frac {\varphi \tau}{\int_ {t _ {1}} ^ {t _ {1} + \tau} \varphi \mathrm {d} t} \end{array} \right. \tag {5}
$$

式中： $\tau ^ { \prime }$ 定义为归一化飞行时间。

（1）当 $t _ { 2 } - t _ { 1 } < \tau$

$$
\left\{ \begin{array}{l} \int_ {t _ {1}} ^ {t _ {1} + \tau} \varphi \mathrm {d} t = \int_ {t _ {1}} ^ {t _ {2}} \varphi \mathrm {d} t + \int_ {t _ {2}} ^ {t _ {1} + \tau} \varphi \mathrm {d} t = \frac {\varphi_ {\mathrm {m}}}{t _ {2}} \frac {1}{2} \left(t _ {2} ^ {2} - t _ {1} ^ {2}\right) + \varphi_ {\mathrm {m}} (\tau + t _ {1} - t _ {2}) \\ \tau_ {1} = t _ {1} + \tau \frac {\varphi \tau}{\frac {\varphi_ {\mathrm {m}}}{t _ {2}} \frac {1}{2} \left(t _ {2} ^ {2} - t _ {1} ^ {2}\right) + \varphi_ {\mathrm {m}} (\tau + t _ {1} - t _ {2})} \end{array} \right. \tag {6}
$$

（2）当 $t _ { 2 } - t _ { 1 } > \tau$

$$
\left\{ \begin{array}{l} \int_ {t _ {1}} ^ {t _ {1} + \tau} \varphi \mathrm {d} t = \frac {\varphi_ {\mathrm {m}}}{t _ {2}} \frac {1}{2} \left(\left(t _ {1} + \tau\right) ^ {2} - t _ {2} ^ {2}\right) \\ \tau_ {1} = t _ {1} + \tau \frac {\varphi \tau}{\frac {\varphi_ {\mathrm {m}}}{t _ {2}} \frac {1}{2} \left(\left(t _ {1} + \tau\right) ^ {2} - t _ {1} ^ {2}\right)} \end{array} \right. \tag {7}
$$

通过式（6）与式（7）可以计算斩束器采取 $\varphi _ { \mathrm { m } }$ 斩束电压工况下的束流下降沿时间，例如束流参数 $E { = } 7 5 \ \mathrm { k e V } .$ 、$L { = } 5 0 \ \mathrm { m m }$ 、 $t _ { 1 } { = } 1 2$ ns、 $t _ { 2 } { = } 2 0$ ns、 $\varphi { = } 3 \mathrm { k V }$ 、 ${ \varphi _ { \mathrm { m } } } ^ { = 4 . 5 \mathrm { k V } }$ ，利用公式可求得 $t _ { 0 } { = } 1 3 . 2 \ \mathrm { n s }$ 、 $\tau ^ { \prime } { = } 8 . 3$ ns、 $\tau _ { 1 } { = } 2 0 . 3 ~ \mathrm { n s }$ ，显然通过采取使斩束器工作电压高于 $\varphi$ 的 $\varphi _ { \mathrm { m } }$ ，会降低束流下降沿时间。

# 3    结　论

本文设计一套用于加速器中子源的斩束器，在设计过程中通过理论计算与软件模拟相结合，根据束流参数设计相应的斩束器。采用圆弧极板结构，使斩束器具有更好的电场分布，束流偏转效果更优。在模拟过程中，为了使得模拟结果更为可靠，导出 CST Studio Suite 静电学模拟电场分布文件，通过 Python 程序处理带入 TraceWin 软件中，解决 TraceWin 软件无法设置圆弧极板电场强度问题，发展了 CST Studio Suite 与 TraceWin 联合仿真模拟方法，更真实的模拟束流动力学表现，模拟结果表明相比平行极板结构的斩束器，圆弧极板斩束器具有更优的偏转束流能力。

对于方案可能存在的问题主要有：软件模拟与实际束流环境会存在差异，整段 LEBT 真空环境存在变化，具体束流传输时束流的空间电荷补偿度变化大小未知，这会导致束流所需偏转电压会略高于设计值，因此在实际生产中电压上限要有余量。这些问题在最终设备加工调试中可以调节偏转电压参数及空间电荷补偿度进行调整。
