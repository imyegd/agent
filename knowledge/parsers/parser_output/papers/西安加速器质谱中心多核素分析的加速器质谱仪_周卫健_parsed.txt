# 1.1 铯溅射负离子源

该离子源为 HVEE 的 ModelSO-110 产品(图2)，系固体气体二用铯溅射负离子源[6]，现先采用固体样品模式，其样品轮可放置 50 个 $\Phi 1 { - } 2 \ \mathrm { m m }$ 样品。

离子源的外壳和样品轮均处于地电位，处于悬浮高电压的部件(如电离器、Cs 罐及 Cs 管、 $\mathrm { C O } _ { 2 }$ 输送管和冷却水管以及高压引线) 为离子源头部，经绝缘法兰伸入离子源内部。此结构的优点是能方便地从壳体旁边拉出该头部，以进行清洗或维修，重新安装时毋须准直[7]。

# 1.2 低能注入系统

样品表面形成的负离子由电离器中心通道吸出，经 Einzer 透镜聚焦，进入 $5 4 ^ { \circ }$ 的球面形静电分析器，进行能量选择，该分析器绕轴旋转后可连接另一台离子源。

1.2.1 快交替注入 注入系统的 $9 0 ^ { \circ }$ 分析磁铁用作

预分析。为提高半衰期长于 $^ { 1 4 } \mathrm { C }$ 的放射性核素(如$^ { 1 0 } \mathrm { B e } )$ 的探测灵敏度，采用能量跳跃磁铁实现交替注入[8,9]，采用 $1 0 0 \mathrm { H z }$ 快交替[10] $^ { - 1 4 } \mathrm { C } { \cdot } 9 \mathrm { m s }$ ， $^ { 1 3 } \mathrm { C } { \cdot } 0 . 1 \mathrm { m s }$ ，$^ { 1 2 } \mathrm { C } { - } 0 . 1 \mathrm { m s } )$ 以减少离子源不稳或束流不稳对测量结果的影响。

1.2.2 束流精确限时注入电极(Beam blanking unit)

不同于一般的二极磁铁，能量跳跃磁铁的特点是其磁隙中的真空盒与上下磁极和前后束流管道绝缘。所加 2—3kV 高压脉冲的上升时间约 $5 0 \mu \mathrm { s }$ ，为精确限定不同质量离子的注入时间或测量时间，能量跳跃磁铁后配有束流精确限时注入电极[10]。它相当于一付特殊的导向器，在其上加 300V 左右的脉冲低压，脉冲上升时间仅 50 ns。在该脉冲的间隙期内(即精确限定的时间)，被测离子通过该电极板注入加速器[6](图 3)。

# 1.3 3 MV Tandetron

Tandetron[13]由高频电源并联馈电的 CockroftWalton 型供电系统获得高电压，工作频率 $3 5 \mathrm { k H z }$ 。T形钢筒内充 $7 0 0 \mathrm { { k P a } }$ 的 $\mathrm { S F } _ { 6 }$ 绝缘气体，端电压0.2—$3 . 0 \ \mathrm { M V }$ 。电压纹波仅 $3 0 \mathrm { V _ { p p } }$ ，用传统的静电伏特计稳压，电压可稳定在<300Vpp。 ${ < } 3 0 0 \mathrm { V _ { p p } }$

1.3.1 次级电子抑制措施 工作中的加速管总有次级电子的轫致辐射，会降低 $\mathrm { S F } _ { 6 }$ 的绝缘性[8]，甚至危及人员安全。为此，采取了永磁和静电斜场等措施抑制加速管次级电子，这些措施足以屏蔽加速管轫致辐射[8]。  
1.3.2 加速管辐射防护 加速器两端各设置辐射抑制电极，剥离器与高能加速管连接处套有铅屏蔽管。加速器工作时，离钢筒壁 1m处的 X射线剂量远小于 $2 \mu \mathrm { S v / h }$ 。  
1.3.3 体剥离器 Tandetron 采用气体剥离器而无固体剥离箔。剥离管道设计得较长 $( 1 . 2 5 \mathrm { m } )$ ，且把剥离器设计成循环系统，使 $9 7 \%$ 的剥离气体返回到剥离器的中央[9]。

# 1.4 高能分析系统

被加速的离子束流经三单元四极透镜聚焦后进入高能分析系统，该系统由两个二极磁铁和一个静电分析器组成。

1.4.1 限缝稳定(Slit stabilization) 束流先进入 $1 1 5 ^ { \circ }$ 的分析磁铁。在该磁铁出口的象平面上，设置了可移动的法拉第杯，用以测量被交替加速的稳定同位素(如 $^ { 1 3 } \mathrm { C }$ ， $^ { 9 } \mathrm { { B e } ) }$ )离子。该法拉第杯内装有限缝用作“限缝稳定”。如端电压波动而引起信号差，该限缝将自动稳定端电压[14]；若信号差由其它电磁参数变化引起，则可改变端电压以补偿这些参数的改变。在验收试验中我们观察到了这一现象，在 2.5MV端电压下达到满意测量精度时，四个核素测试时的端电压改变范围竟有 4— $\cdot 6 \mathrm { k V } ^ { [ 6 ] }$ 。  
1.4.2 消除本底离子干扰 （1）氮化硅膜。测量 $^ { 1 0 } \mathrm { { B e } }$ 时采用 Raisbeck 等的方法[15]，他们采用碳箔，Xi’an-AMS采用氮化硅膜，其致密性高，能更有效地抑制 ${ } ^ { 1 0 } \mathrm { B }$ 离子[16]。（2）高色散的 $6 5 ^ { \circ }$ 静电分析器。被测放射性核素(如 $^ { 1 0 } \mathrm { B e } )$ 进人 $6 5 ^ { \circ }$ 圆柱面形的静电偏转板，其有较高的色散能力，使 $^ { 1 0 } \mathrm { { B e } }$ 与 ${ } ^ { 1 0 } \mathrm { B }$ 离子在探测器的入口平面处分开 $3 . 6 \mathrm { c m } ^ { [ 1 7 ] }$ ，这大大抑制了同量异位素离子 ${ } ^ { 1 0 } \mathrm { B }$ 进入到探测器。（3） $3 0 ^ { \circ }$ 偏转磁铁。Xi’an-AMS 中增加了一台 $3 0 ^ { \circ }$ 的偏转磁铁，使从静电偏转板漏网的干扰粒子不进入探测器，以进一步提高探测灵敏度。这对于分析重离子更为重

要，因为质量相近的重离子间的静电偏转曲率半径相差较小，易从静电偏转板逃逸出来。

# 2.2 测试精度的步骤和计算方法

验收测量精度时，同一材料的样品分成 $n$ 份，每个样品座的样品循环转动，共测 $T$ 次，故每个样品座的样品在 $T$ 次循环中共测得 $T$ 个值(X1，X2…..$X _ { \mathrm { T } } )$ 。每个测量值 $X _ { \mathrm { i } }$ 中又包含 S 次交替测量， $X _ { \mathrm { i } }$ 是 $S$ 次交替测量的平均结果 $( i { = } 1 \dots { } . . . T )$ 。每次交替测量得到的比值(如 $^ { 1 4 } \mathrm { C } / ^ { 1 3 } \mathrm { C }$ 和 ${ } ^ { 1 4 } \mathrm { C } / { } ^ { 1 2 } \mathrm { C } )$ 存入一个数据块。故每个样品座的样品在T次循环中共有 $T { \times } S$ 次交替测量，并测得 $T { \times } S$ 个数据块。

求得每个样品座的样品在 $T$ 次循环中测得的 $T$ 个 $X _ { \mathrm { i } }$ 值的算术平均值

$$
\bar {X} = \frac {1}{T} \sum_ {1} ^ {T} X _ {i}
$$

和该算术平均值的标准偏差

$$
\delta = \sqrt {\frac {\sum_ {1} ^ {T} (X _ {i} - \overline {{X}}) ^ {2}}{T (T - 1)}}
$$

所以， $N$ 个样品座的样品共有 $N$ 个测量值和相应的标准偏差 $\delta _ { \mathrm { j } } ( j = 1 , 2 , . . . . N )$

若各个样品座样品的 $\delta _ { \mathrm { j } }$ 相差较大，则要求加权平均值。由于 AMS 设备性能较好，各个样品座样

品的 $\delta _ { \mathrm { j } }$ 相差不会太大， 所以我们不考虑权重

令求得 $N$ 个样品座样品测量值的算术平均值为

$$
\bar {Y} = \frac {1}{N} \sum_ {1} ^ {N} \overline {{X _ {j}}} \quad (j = 1, 2, \dots \dots N)
$$

各个 holder 样品测量值相对于该算术平均值的标准偏差 $\sigma$ 为

$$
\sigma = \sqrt {\frac {\sum_ {1} ^ {N} \left(\bar {X _ {j}} - \bar {Y}\right) ^ {2}}{(N - 1)}} \quad (j = 1, 2, \dots \dots N)
$$

它们的相对标准偏差为

$$
\sigma_ {r e l a t i v e} = \frac {1}{\bar {Y}} \sqrt {\frac {\sum_ {1} ^ {N} \left(\bar {X _ {j}} - \bar {Y}\right) ^ {2}}{(N - 1)}} \quad (j = 1, 2, \dots \dots N)
$$

这就是要达到的精度验收指标，它表示 AMS测量相同样品的不确定性。文献表明，HVEE[3-5,17-19]和 NEC[21]公司的产品都采用了这一验收精度的方法。显然，所达到的验收精度是与 holder 数目有关的。

# 2.3 影响 ${ } ^ { 1 0 } \mathrm { \mathbf { B } } \mathbf { e }$ 测量中的本底的因素

任何产生具有足够能量的 $^ 7 \mathrm { B e }$ 、 $^ { 9 } \mathrm { { B e } }$ 、 $^ { 1 0 } \mathrm { { B e } }$ 的化学过程或物理(核反应)过程都将叠加到 $^ { 1 0 } \mathrm { { B e } }$ 的谱上形成本底干扰。根据文献[22]—[24]报道综述影响$^ { 1 0 } \mathrm { { B e } }$ 测量中的本底的因素如下：

2.3.1 本底 ${ } ^ { 1 0 } \mathrm { B }$ 同量异位素 ${ } ^ { 1 0 } \mathrm { B }$ 能形成负离子与$^ { 1 0 } \mathrm { { B e } }$ 离子一起加速并进入探测器，须在制样和 AMS分析过程中予以清除。一般剥离后选用三价 $\mathrm { B e } ^ { 3 + }$ 离子， $\mathrm { B } ^ { 3 + }$ 离子干扰使探测到的最小 $^ { 1 0 } \mathrm { B e } / ^ { 9 } \mathrm { B e }$ 比值为${ 1 0 } ^ {  { - } 1 4 }$ 量级。如果剥离后选用二价 $\mathrm { B e } ^ { 2 + }$ 离子，本底计数会更大，而 Raisbeck组采取二次剥离后测量三价$\mathrm { B e } ^ { 3 + }$ 离子的方法，把 $\mathrm { B } ^ { 3 + }$ 离子干扰抑制了约500倍[20]。2.3.2 本底 $\mathrm { ^ 7 B e } ~ 5 \mathrm { M V }$ AMS 分析 $^ { 1 0 } \mathrm { { B e } }$ 时，高能 $^ { 1 0 } \mathrm { { B } } ^ { 3 + }$ 离子与探测量器前 mylar 箔窗中的氢原子会发生强的核反应 $\mathrm { H ( ^ { 1 0 } B , ^ { 7 } B e ) ^ { 4 } H e }$ 形成 $^ 7 \mathrm { B e }$ ，但在端电压 ${ < } 3 \mathrm { M V }$ 下，三价硼离子的能量低于 $\mathrm { H ( ^ { 1 0 } B , ^ { 7 } B e ) ^ { 4 } H e }$ 的反应阈。2.3.3 本底 $^ { 9 } \mathrm { { B e } }$ 可能来自与探测器前或吸收器前的薄箔的核反应。若 $^ { 9 } \mathrm { B e O H } ^ { \mathrm { - } }$ 离子随质量为 26 的$^ { 1 0 } \mathrm { B e } ^ { 1 6 } \mathrm { O } ^ { - }$ 离子一起注入加速器，在高能加速管内发生电荷交换，形成连续谱，其中的 $^ { 9 } \mathrm { { B e } }$ 进入探测器后发生散射而有可能落在 $^ { 1 0 } \mathrm { { B e } }$ 谱上。

在选用三价 $\mathrm { B e } ^ { 3 + }$ 离子时，与 $^ { 1 0 } \mathrm { B e } ^ { 3 + }$ 离子磁刚度相等的 $^ { 9 } \mathrm { { B e } }$ 离子在高能加速管内相继发生电荷交换$^ { 9 } \mathrm { B e O ^ { - } } \mathrm {  } ^ { 9 } \mathrm { B e } ^ { 4 + } \mathrm {  } ^ { 9 } \mathrm { B e } ^ { 3 + }$ 。

为防止这一本底机制，高能 AMS 中选用四价离子。于是散射到加速器内的 BeH离子，在剥离器处形成 $^ { 9 } \mathrm { { B e } ^ { 4 + } }$ 离子，它们与 $^ { 1 0 } \mathrm { B e } ^ { 4 + }$ 离子同时注入，并在高能分析器中发生小角度散射。

2.3.4 本底 $^ { 1 0 } \mathrm { { B e } }$ 过去制样中用 $^ 7 \mathrm { B e }$ 作示踪剂，用来制造 $^ 7 \mathrm { B e }$ 的 $^ 7 \mathrm { L i }$ 中的污染与质子或中子核反应会形成 $^ { 1 0 } \mathrm { { B e } }$ ， 也可从矿石或土壤污染、或 $^ { 9 } \mathrm { { B e } }$ 的就地分裂反应或俘获中子反应、或上述机制中某些组合所形成。在商购的 Al 中也发现 有 $( 4 - 1 0 ) { \times } 1 0 ^ { 7 }$ atoms/g 的 $^ { 1 0 } \mathrm { { B e } }$ 。  
2.3.5 本底 H- , Li-和 $^ { 1 2 } { \mathrm { C } } ^ { 4 + }$ H- , Li-来自 $^ { 1 0 } \mathrm { { B e } }$ 与薄箔中的污染 C和 O的核反应。质量为 25 的 $^ { 1 2 } \mathrm { C } ^ { 1 3 } \mathrm { C } ^ { \cdot }$ 离子与稳定同位素离子 $^ { 9 } \mathrm { { B e } ^ { 1 6 } \mathrm { { O } } }$ 一起注入加速器后，分解为 $^ { 1 2 } { \mathrm { C } } ^ { 4 + }$ 而干扰 $^ { 9 } \mathrm { { B e } } ^ { 3 + }$ 离子，约有比值 $^ { 1 2 } { \mathrm { C } } ^ { 4 + } /$ $^ { 9 } \mathrm { B e } ^ { 3 + } { = } 0 . 0 1$ 。  
2.3.6 其它 BeO-的流强为 1— ${ \it 2 } \mu \mathrm { A }$ ，限制了最小可测的比值 $^ { 1 0 } \mathrm { { B e } / ^ { 9 } \mathrm { { B e } } }$ 为 ${ 1 0 } ^ { \cdot 1 5 }$ 量级。

离子源交叉污染不是一个问题。

# 3 结论

Xi’an-AMS有赖于其结构上的一系列的技术特性，测得的四个核素的精度和本底水平均属国际先进，为我国地学、考古、生物医学和其它运用 AMS技术的领域提供了一个良好的实验平台。 所测得的 $0 . 2 \%$ 的 $^ { 1 4 } \mathrm { C } / ^ { 1 2 } \mathrm { C }$ 精度再次表明，基于交替注入模式的 AMS，像基于同时注入模式的 AMS一样，可实现 $^ { 1 4 } \mathrm { C } / ^ { 1 2 } \mathrm { C }$ 的高精度测量。探测到 $3 . 6 5 \times 1 0 ^ { - 1 5 }$ 的$^ { 1 0 } \mathrm { { B e } / ^ { 9 } \mathrm { { B e } } }$ 比值再一次证明3 MV AMS可以实现 $^ { 1 0 } \mathrm { { B e } }$ 的高灵敏度探测，关键是仔细把握制样、压样和AMS分析的每一环节。

Abstract The Institute of Earth Environment of the Chinese Academy of Sciences and Xi'an Jiaotong University have jointly created an AMS center, under the support of Ministry of Science and Technology, Chinese Academy of Sciences and Ministry of Education. The Xi’an 3MV multi-element AMS system will be a national experimental platform for earth environmental studies, archeology, biomedical research and other fields related to the AMS technique. This paper describes the AMS’s major components with their unique features，including body grounded ion source accepting both $\mathrm { C O } _ { 2 }$ and solid samples； low energy injector with precisely timing and fast switching；low radiation accelerator containing the accelerator tubes with combined magnetic permanent and declined electrostatic field suppression of secondary electrons； high energy analyzing system with high dispersion and slit stabilization.
