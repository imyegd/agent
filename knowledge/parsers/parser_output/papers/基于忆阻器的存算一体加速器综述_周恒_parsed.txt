# 引言

人 工 智 能 （ artificial intelligence, AI） 算 法 迅 速 发展，已广泛应用于虚拟现实/增强现实（virtual reality/augmented reality）、自然语言处理、无线通信和科学计算等多个领域。随着 AI模型在规模和复杂性上的不断增长，支撑这些模型的硬件平台的能耗问题已成为一个主要关注点。因此，大规模部署 AI不仅需要能够训练数十亿参数大模型的高能效硬件平台，还需要快速的推理加速器，用于在低功耗边缘设备中执行推理任务。然而，传统数字计算平台在速度和能效方面受到两大制约：其一是“冯·诺依曼瓶颈”，即存算分离导致的数据频繁传输；其二是“存储墙”，即存储器速度与处理器速度之间日益扩大的差距。存算一体（computing-in-memory, CIM）有望摆脱这些制约，其通过在数据存储单元直接执行计算操作，从而大幅提升计算速度和能效。

忆阻器（memristor）具备非易失性、高速、低功耗和良好的可扩展性等优势，非常适合构建用于 AI加速的CIM 系统。当这些器件以交叉阵列（crossbar array）形式组织时，可利用其电导值表示矩阵数值。根据物理定律（如欧姆定律和基尔霍夫电流定律），阵列能够实现并 行 的 向 量 −矩 阵 乘 法 （ vector-matrix  multiplication,VMM）运算，和传统冯·诺依曼架构相比延迟更低、能效更高。

# 忆阻器件、阵列及非理想因素

# 忆阻器件

阻 变 随 机 存 取 存 储 器 （ resistive  random  accessmemory,  RRAM） 、 磁 阻 随 机 存 取 存 储 器（magnetoresistive random access memory, MRAM）和相变存储器（phase change memory, PCM）通过电阻状态存储信息，因此被称为忆阻器。它们可以通过设置（set）或重置（reset）电压来编程为高电阻（high resistancestate, HRS）或低电阻（low resistance state, LRS）状态。RRAM 单元由顶电极—中间氧化层—底电极组成，其电阻切换是通过导电细丝（conductive filament, CF）的形成或破坏来实现的，CF的尺寸决定了设备的电阻状态。MRAM 的信息存储在磁性隧道结（magnetic tunneljunction, MTJ）中，其由三层构成，包括 2 个铁磁层和夹在其中的氧化层。其中一个铁磁层是参考层，磁化方向固定；另一个是自由层，其磁化方向可根据电流方向自由旋转。当 2个层的磁化方向平行或反平行时，单元分别表现出低阻态和高阻态。PCM 利用了硫族化合物材料（如 $\mathrm { G e } _ { 2 } \mathrm { S b } _ { 2 } \mathrm { T e } _ { 5 }$ ）的非晶态（高阻）和晶态（低阻）之间的巨大电阻差异来存储数据。通过施加不同强度和脉宽的电脉冲，可实现对材料相态的可逆切换。表 1给出了 3 种忆阻器件的指标对比[1−2]。

# 非理想因素

尽管忆阻器具有许多非常突出的优点，但忆阻器本身也存在许多非理想因素，包括忆阻器单元层次的非理想因素，以及忆阻器阵列层次的非理想因素。这些非理想因素一定程度影响了基于忆阻器的 CIM 系统的可靠性，表现为读写和计算准确度降低。

1）单元非线性：单元非线性是忆阻器单元的固有特性，一种典型的单元非线性表现为指数形式的电流−电压（I-V）关系。当执行读取或计算操作时，单元两端电压处于读取电压区间，其 $I { - } V$ 关系为 $I = \beta \cdot \sinh ( \alpha \cdot V )$ 。现有研究表明单元非线性 $I { - } V$ 可能导致读写和计算准确度显著下降。  
2）器件变化性：忆阻器在写入过程中的变化性主要包括 2 个维度：器件间（device-to-evice, D2D）变化性

和周期间（cycle-to-cycle, C2C）变化性，二者对计算结果具有累积性影响。D2D变化性由制造工艺决定，表现为阵列中不同单元在写入相同数据时，其阻值存在一定差异，通常服从正态分布。C2C变化性是忆阻器固有特性，即同一单元被多次编程为相同数据时，其每次写入后的电阻值之间会有微小差异，这种差异服从对数正态分布，且阻值越高，C2C变化性越显著。  
3）焦耳热串扰：交叉阵列中的单元间焦耳热串扰（thermal crosstalk）是一种写入扰动。当忆阻器交叉阵列中选中单元被重置时，其相邻的半选定和未选中单元会因重置带来的焦耳热效应而遭受不可忽视的电阻值变化。这是因为单元重置过程中会出现较大电流，从而产生大量焦耳热。更重要的是，热串扰现象会导致受干扰的忆阻器单元的存储状态从 LRS转变为

HRS，造成数据丢失。此外，随着特征尺寸的不断缩小，电阻状态退化将会更加严重[7]。

4）电压降：阵列中连接单元的字线与位线存在不可忽略的互连线电阻。由于阵列互连线尺寸处于纳米尺度，输入电压在传输过程中会因互连线电阻产生分压效应，导致实际施加在忆阻器单元两端的电压低于预设值，从而导致计算结果出现偏差，该现象被称为电压降（IR drop）问题。随着工艺节点的缩小，互连线电阻进一步增大，会加剧电压降问题，不仅影响计算精度，还会造成功耗的上升。为了缓解电压降影响，Liu等[8] 提出了一种以比阵列规模小的计算单元（operation unit, OU）为粒度的低开销电压降补偿方法ICON，对 OU受到的电压降模型以及补偿电路进行合理简化，在保证补偿准确的同时，降低补偿电路开销。  
5）潜行电流：当读/写阵列中某个单元时，对目标单元字线施加读/写电压，位线则接地。理想情况下，电流只流经目标单元，但在实际情况下，部分非目标单元两端也会存在非零电压差，导致电流从这些处于半选通单元流过，被称为潜行电流。潜行电流会造成显著的能耗开销，甚至导致单元读/写错误。  
6）耐久性：耐久性指器件在失效前能够承受的擦写循环次数。如表 1所示，不同忆阻器的耐久性存在显著差异。为了延长系统寿命，Zhou等[9] 提出了基于

忆阻器的存算一体系统磨损均衡策略 TIWL，并针对运行时磨损均衡调度导致的通信性能劣化提出了数据布局感知的选择性重映射策略 LASR[10]，在保证磨损均衡性能的同时最小化通信性能的影响，相比不使用磨损均衡将系统寿命提升了 $1 0 0 . 3 \sim 2 0 5 . 9 $ 倍。单元硬错误（stuck at fault, SAF）是指单元由于到达耐久性极限等原因，导致单元永久丧失切换状态的能力，严重影响读/写和计算的准确性。

# 存算一体计算范式与架构

让计算更靠近数据是存算一体的核心理念，计算所处位置决定了计算结果产生的位置，如图 2（a）所示。计算发生在内存内部的可称为 CIM，根据计算结果产生位置可细分为存内逻辑计算（logic-in-memory,LIM），如图 2（a）中 $\textcircled{1}$ 所示和存内模拟计算（analog-in-memory, AIM），如图 2（a）中 $\textcircled{2}$ 所示，其中 LIM的计算结果在内存阵列中产生，而 AIM 的计算结果在外围电路中产生。除此之外，将额外计算单元（如 ASIC电路、处理器等）放在内存附近但不在内存中的可称为近数据处理（near data processing, NDP），如图 2（a）中 $\textcircled{3}$ 架构[11] 所示。

文献 [12] 的 FloatPIM、文献 [13] 的 RACER 等采用 LIM计算范式，其核心计算单元为忆阻器组成的逻辑门，阵列中大量的逻辑门相互协同使得其可以执行逻辑计算。常见的使用忆阻器组成的逻辑门包括或非

（nor）、与（and）、非（not）等。图 2（b）展示了或非逻辑门的结构，其中输入数据以电导形式存储在 $\mathrm { i n } _ { 1 }$ 、 $\mathrm { i n } _ { 2 }$ 忆out阻器单元中，逻辑计算的结果以 忆阻器单元的电导形式呈现。通过在 $\mathrm { i n } _ { 1 }$ 、 $\mathrm { i n } _ { 2 }$ 这 2个忆阻器单元上施加计

算电压（ $\left. V _ { 0 } \right.$ out  ），同时将 忆阻器单元接地，即可令 $\mathrm { i n } _ { 1 }$ 、$\mathrm { i n } _ { 2 }$ 两个单元中存储的数据执行或非逻辑计算，并将结out果输出到 单元。

文献 [14] 的 ISAAC、文献 [15] 的 PipeLayer 等采用 AIM架构，其核心计算原理如图 2（c）所示，当执行VMM运算时，在初始化阶段，参与计算的矩阵数据被写入阵列单元中；在计算阶段，输入向量经过数模转换变 成 相 应 的 电 压 加 载 在 阵 列 的 各 个 行 线 上，即$D _ { 1 } \sim D _ { 4 }$ 转换为 $V _ { 1 } \sim V _ { 4 }$ ，根据欧姆定律以及基尔霍夫定律，流经各单元的电流会在相应的列线上汇总，例如第一列的输出电流为 $I _ { 1 } = V _ { 1 } \times W _ { 1 1 } + V _ { 2 } \times W _ { 2 1 } + V _ { 3 } \times W _ { 3 1 } +$ $V _ { 4 } \times W _ { 4 1 }$ ，最后经过模数转换得到输出向量，即 $I _ { 1 } \sim I _ { 3 }$ 转换为 $O _ { \mathrm { u t 1 } } \sim O _ { \mathrm { u t 3 } }$ 。在这种架构中，一次输入即可完成VMM运算，将计算复杂度从 $O ( n ^ { 2 } )$ 降至 $O ( 1 )$ ，展现出极高的计算效率。

# 存算一体编译器

本节以面向神经网络（ neural network, NN）的存算一体编译器（以下简称编译器）为例，阐述编译过程并简要概括现有编译器存在的问题。编译器的目标是抽象并自动化神经网络模型的部署过程，使用户无需感知底层细节，将神经网络计算任务通过多层中间表达（intermediate representation, IR）进行翻译和优化，最终生成目标硬件的可执行机器码。图 3给出了面向神经网络的存算一体编译器的概览及编译流程。

编译器主要包括 2个部分：编译器前端和编译器后端。如图 3所示，IR贯穿前端和后端编译流程，其是程序的一种抽象形式，用于程序优化。编译器会将神经网络模型转换为多层次 IR：高层次 IR（high-level IR）位于前端，低层次 IR（low-level IR）位于后端。前端负责与硬件无关的转换与优化；后端负责硬件相关的优化、代码生成与编译。

2）GENIEx[24]：通过 HSPICE（一款模拟电路仿真软件，是集成电路设计的行业标准工具之一）的仿真数据训练三层多层感知机（multilayer perceptron, MLP）来模拟忆阻器交叉阵列的非理想因素，以快速分析阵列非理想因素对神经网络性能的影响，但其准确性需要用户根据自身场景仔细确认。  
3）PUMA[16]：提出一种可编程且高效的忆阻器存算一体加速器，并提供了配套编译器和仿真工具，支持将高 层 代 码 编 译 为 PUMA 指 令 集 架 构 （ instruction  setarchitecture, ISA）并部署到仿真工具中运行。其微架构基于专用 ISA设计，在保证可编程性的同时保留了高能效优势。PUMA编译器通过图划分、指令调度和寄存器分配等优化手段，提升大规模任务的执行效率。  
4）MNSIM[25]：面向忆阻器的存算一体系统仿真工具，提供面积、功耗和延迟的评估模型，并建立行为级模型来评估非理想因素对计算精度的影响；随后还开发了 MNSIM 2.0[28] 与 MNSIM-Time[29]，支持软硬件协同仿真。  
5）PIMCOMP+PIMSIM-NN[26]：PIMCOMP 是一个

针对 CIM加速器的端到端神经网络编译器，实现了NN模型在 CIM硬件上的高效部署。在资源利用方面，PIMCOMP优化了卷积层的展开以及划分，在系统层面平衡计算、存储访问和通信特性。在数据流调度方面，PIMCOMP设计了 2种神经网络层间流水线调度算法，提高并行度。PIMSIM-NN 将 PIMCOMP 编译得到的指令在给定的CIM架构下评估性能。  
6）FADESIM[27]：支持非理想因素的快速、准确仿真。使用了 IR Drop快速迭代仿真算法，将 SPICE 模型仿真时间复杂度由 $O ( n ^ { 6 } )$ 降至 $O ( n ^ { 3 } )$ ，在 IR Drop 影响较轻的情况下，提出优化迭代算法，将时间复杂度进一步降低至接近 $O ( n ^ { 2 } )$ 。支持多种非理想因素（如变异性、噪声、IR Drop、 $I { - } V$ 非线性、ADC量化误差）联合仿真。

# 应用

VMM是神经网络的核心计算操作，许多工作设计基于 CIM的加速器来降低神经网络计算的功耗和时延。除了神经网络，其他数据密集型应用中涉及的VMM或逻辑计算操作也可利用 CIM 加速，如科学计算和安全算法。本节介绍基于 CIM 的神经网络、科学计算以及安全算法的加速器的最新进展。

# 神经网络

ISAAC提出了一种基于 RRAM的卷积神经网络（convolutional neural network, CNN）推理加速器[14]。其由多个瓦片（tile）组成，tile之间通过集中式网格结构（C-Mesh）互联。每个 tile包括计算核心、移位累加单元 、 Sigmoid 单 元 、 最 大 池 化 （ Max  Pooling） 单 元 、eDRAM缓存和输出寄存器。ISAAC采用了流水线设计，对于两个相邻的卷积层 i和 $i { + 1 }$ ，第 i层的计算结果被写入 eDRAM缓冲区后，该输出作为 $i { + } 1$ 层的输入，当 $i { + } 1$ 层单次操作的输入数据准备好后便执行计算。

PipeLayer[15] 支持神经网络的训练与推理，其通过高效流水线设计实现了神经网络层内和层间流水，并支持多种输入与计算核映射方案。其阵列采用可重构设计，可配置为计算阵列或存储阵列。计算阵列可执行VMM操作，存储阵列可存储权重或中间数据。

FORMS[30] 将 CIM阵 列 划 分 成 子 阵 列 ， 利 用ADMM算法[31] 确保子阵内数据具有相同符号，从而避免使用“正负矩阵”表示有符号数，减少阵列资源使用。此外，采用输入零跳过逻辑电路来识别输入数据的最大有效位以跳过零输入，降低功耗和延迟。

除了加速卷积神经网络，近年来的研究提出多种基 于 CIM 的 Transformer 加 速 器 ， 例 如 TranCIM[32]、MuITCIM[33]。TransCIM 采用了流水线设计以及位线转置结构，使输入和权重的数据方向对齐，并允许中间数据从前一个计算核流向下一个计算核，在 INT8计算中 实 现 20.5  TOPS/W 的 能 效 。 与 TransCIM 相 比 ，MuITCIM通 过 长 重 用 消 除 调 度 器 和 运 行 时 词 元（token）剪枝器优化视频和音频的跨模态注意力计算，进一步优化了加速器的性能。

# 科学计算

采用 CIM加速科学计算面临两大主要挑战：更高的精度要求与更复杂的计算类型。CIM架构受限于器件物理特性，难以直接支持高精度运算。对此，研究者提出位切片技术扩展位宽，但需额外增加移位电路和计算周期。因此，部分工作转向混合精度计算：先利用CIM加速器执行低精度近似计算，再由高精度数字逻辑逐步逼近精确结果。已有研究提出了用于方程求解的 CIM 系统[34]，可支持 5000 个方程求解，误差控制在

${ { 1 0 } ^ { - 6 } }$ 以内。丁文隆等[35] 提出科学计算尾数压缩与对齐位优化策略，在保证高精度浮点 VMM计算的同时，能够根据具体应用的求解精度要求选择合适的浮点数尾数压缩位数，减少阵列及外围电路的能耗。其次，科学计算常涉及 VMM之外的复杂操作，例如矩阵求逆，其时间复杂度呈多项式级增长。对于矩阵求逆操作现已有研究提出基于 CIM的矩阵求逆电路[36] 来加速求解。

# 安全算法

安全计算场景需要对数据进行加密和解密，这个过程涉及高维整数系数多项式的加法与乘法运算。典型的加密（解密）算法涉及数论变换（number theoretictransform,  NTT） 及 其 逆 变 换 （ inverse  number  theoretictransform, INTT），以上计算结构与离散傅里叶变换相同，但采用模算术[37]，可分解为乘法和加法。已有研究设计了一个支持此类结构的 CIM宏[38]，采用位串行风格实现多比特操作，并优化了映射调度和模算术算法，在相同位宽下，其延迟和能耗分别是 $\mathbf { \boldsymbol { x } } 8 6$ 软件解决方案的 1/10 和 1/2860。

# 存算一体芯片

目前已有许多研究工作设计基于忆阻器的存算一体 芯 片，以 下 分 别 介绍 3种 忆 阻 器 介 质（RRAM、MRAM 和PCM）的存算一体芯片研究进展。

# 基于 RRAM 的存算一体芯片

Yao 等[39] 提出了基于 1T1R 单元 RRAM 的 CIM阵列，每个芯片包含一个裸阵列，大小为 $1 2 8 \times 1 6$ ，多个芯片连接至同一个印刷电路板（printed circuit board,PCB）以共享外围及控制电路。部署五层卷积神经网络在 MNIST数据集上的准确率为 $9 6 \%$ ，系统能效达11.014 TOPS/W。Wan 等[40] 设计了集成 48 个 $2 5 6 { \times } 2 5 6$ 阵列的存算一体芯片并配置共享神经元电路以实现灵活数据流控制，支持多种AI模型。

华中科技大学冯丹教授团队设计了基于 RRAM存算一体芯片并流片，采用 $2 2 \mathrm { n m }$ 工艺，总容量达 $3 2 \mathrm { M b }$ ，能效达 13.25 TOPS/W。该设计中增加了缓存模块，提升连续计算能力。原型系统采用 FPGA作为控制器，

支持多芯片协同计算，并探索了大模型的部署应用方法。

# 基于 MRAM 的存算一体芯片

Jung 等[41] 提出了基于 MRAM 的 CIM 阵列，单个阵列为 $6 4 { \times } 6 4$ ，采用 $2 8 ~ \mathrm { { n m } }$ 工艺，并且集成了时间域的模数转换（time to digital converter，TDC）读出电路，能效达 405 TOPS/W。实验评估表明，其 VGG 网络在MNIST数据集的准确率为 $9 8 . 8 6 \%$ ，并且演示了实时人脸识别，准确率达 $9 3 . 4 \%$ 。然而，该芯片采用单阵列设计，面积效率较低。此外，该阵列采用 4-bit TDC，精度范围无法覆盖完整输出范围。

华中科技大学冯丹教授团队设计了基于 MRAM存算一体芯片并流片，采用全国产 $2 8 ~ \mathrm { { n m } }$ 工艺，总容量达 64Mb，全芯片能效达 140.54 TOPS/W。原型系统评估 表 明，三层 MLP在 MNIST数 据 集 的 准 确 率 为$9 4 . 7 9 \%$ ，LeNet-5 在 CIFAR10 数据集的准确率为 $6 6 . 2 6 \%$ ，脉 冲 神 经 网 络 （ spiking  neural  network,  SNN） 在 DVSGesture 数据集准确率为 $9 6 . 5 3 \%$ ，与 CPU（FP32）相比，计算准确率下降在 $2 \%$ 的范围内，支持实现 DeepSeek[42]全连接层的部署运行（版本：DeepSeek-R1-Distill-Qwen-1.5B）。

# 基于 PCM 的存算一体芯片

Gallo等[43] 提出了一个片上互联的 64核芯片，每个核为 $2 5 6 { \times } 2 5 6$ 的 PCM 阵列，配备 DAC、ADC 和数字处理单元，提高了推理效率，能效达 63.1 TOPS/W，支持 ResNet 与 LSTM 等大型模型[43]。

Ambrogio等[44] 结合片内多核和多芯片协同计算的设计思想，成功将参数超过 4500万的循环神经网络（recurrent neural network, RNN）部署到 5 个多核芯片，每个芯片包含 34个模拟 tile，每个 tile包含 $5 1 2 { \times } 2 0 4 8$ 个 PCM单元，通过二维网状结构（2D-Mesh）互联。尽管其支持核间模拟通信以减少能耗与延迟，但仅适用于小型网络，在单芯片上部署大型网络时，每个核内仍需集成 ADC与数字外围，尚未实现完全模拟通信的CIM 系统。

过去五年，面向 AI的存算一体芯片主要朝着功能多样化、组织异构化的方向发展，支持的应用规模也逐渐增大，呈现出蓬勃发展的趋势。硬件组织结构也由早期的单阵列简单结构发展为片上集成的多层级结构，阵列与核间支持高效通信的互连网络结构也变得越来越复杂。

# 挑战及未来发展

尽管基于忆阻器的存算一体加速器展现出巨大潜力，但仍面临多方面的技术挑战。

在器件与电路层面，由于器件和电路制备技术尚有发展空间，还需要提高计算精度和存算密度。要支持高精度计算，需降低单元电导波动（如噪声、阻值漂移、温度影响、单元非线性等）、计算电压偏差。为提高存算密度，需优化器件结构以及材料设计，降低工作电压、电流和电导，以减少对访问晶体管尺寸的要求，提升器件密度。

在系统层面，应用除了 VMM操作外，还涉及激活函数、池化等操作，需由 DPU完成，因此外围电路设计至关重要。目前 ADC在面积与功耗上的开销依然突出，仍是制约 CIM 加速器进一步发展的瓶颈，因此需在面积、速度和功耗上高度优化以减少 ADC的开销，同时仍保证输出精度。提高 CIM 系统中计算资源的可重构性，为部署不同应用提供灵活性。存算一体设备目前缺乏兼顾可靠性和高并行性的读出电路，存算一体硬件采用模拟方式进行计算，相比数字计算更容易出错，为了提高可靠性需研究补偿策略以及纠错码（errorcorrection code, ECC）纠错方案。数字逻辑应靠近阵列，减少数据传输开销。实现低延迟、低功耗计算需配合高效通信机制、流水线调度与中间缓存（如 SRAM）优化。面向 AI计算的存算一体领域尚未制定标准化的指令集，软件和硬件未完全解耦，导致同一份代码在不同的加速器设备之间难以移植，软件开发成本高，不利于底层微架构版本迭代，未来需制定标准化的存算一体通用指令集。已有发布的芯片大多为原型系统，成熟的产品仍需进一步推进。

在软件工具层面，需提供快速准确的仿真工具对忆阻器件及 CIM 系统进行仿真，目前仍面临以下挑战：1）缺乏对大规模 CIM系统和复杂 AI模型的仿真支持；2）不同工具的关注点不同，未考虑各工具之间以及不同层级之间的关联性；3）架构级与电路级仿真之间在精度与效率上的权衡仍需深入研究。对于编译器，仍存在以下问题：1）大多数是闭源的；2）虽然多数可以与主流机器学习框架（如 PyTorch等）对接，但在互操作性和基础框架（如 ONNX、LLVM等）复用方面仍有很大改进空间；3）部分编译工具虽复用了基础框架，但方式

各异，不同工具之间难以兼容，导致开发者需为特定平台 定 制 流 程 。 需 进 一 步 关 注 的 问 题 和 技 术 有：1）ONNX与机器学习框架间对算子/数据类型的不兼容问题；2）大多数编译器针对特有硬件架构和指令集进行设计和编译优化，与硬件架构耦合性太强，难以适应不同架构的需求，应采用分层设计逐层抽象，避免高层优化与硬件强相关；3）目前所支持的算子仍然有限，亟须对复杂模型的支持（例如批归一化、大语言模型的RMSNorm 等）；4）存算一体系统的非理想因素会影响计算准确性，需探索通过编译优化缓解非理想因素的影响；5）异构场景下存算一体系统的编译优化仍需探索，需研究任务卸载的优化策略。 ■

# A Review of Memristor-Based Computing in Memory Accelerators

Heng Zhou1,2,3 ,4, Jinpeng Liu1,2,3,4, Dan Feng1,2,3,4, Wei Tong1,2,3,4

1. Wuhan National Laboratory for Optoelectronics   
2. Key Laboratory of Information Storage System, Ministry of Education of China   
3. Engineering Research Center of Data Storage Systems and Technology, Ministry of Education of China   
4. Huazhong University of Science and Technology

Abstract:  To  meet  the  rapid  evolution  of  artificial  intelligence  (AI)  algorithms,  the  demand  for  computing  resources  is  growing exponentially, posing significant challenges for deploying AI models on hardware. Memristor-based computing in memory accelerators offer a promising solution to the energy efficiency and latency issues in large-scale AI model deployment—by performing computation directly within the memory cells where data are stored. This approach eliminates the frequent data transfers between processing units and memory units inherent in the von Neumann architecture, thereby greatly reducing both time and energy consumption. In recent years, research in this field has progressed rapidly, and memristor technology is undergoing a critical transition from proof-of-concept to commercialization, with prototype  systems  already  capable  of  accelerating  AI  model  inference  across  various  application  scenarios.  This  article  systematically reviews memristor devices and crossbar arrays, system architectures, software tools, representative applications, and development trends, and highlights the key technical challenges that remain to be addressed.

Keywords: memristors; crossbar array; computing-in-memory; accelerators; non-ideal effects of memristors; compiler; simulator

摘　要：为应对人工智能（artificial intelligence, AI）算法的快速发展，计算资源的需求正呈指数级增长，这为 AI 模型的硬件部署带来了巨大挑战。基于忆阻器的存算一体加速器为解决大型 AI 模型部署中的能效与时延问题提供了极具前景的方案——即计算直接在存储数据的存储单元中完成。这种方式显著减少了冯·诺依曼架构中处理单元与存储单元之间频繁的数据搬运，从而极大降低了时间和能耗开销。近年来，该领域研究发展迅速，忆阻器技术正经历从概念验证走向商业化产品的关键转变，现有产品原型系统已能在多种应用场景中加速 AI 模型推理。本文系统地梳理了忆阻器件及交叉阵列、系统架构、软件工具、典型应用及发展趋势，并给出了当前仍需解决的关键技术问题。

关键词：忆阻器；交叉阵列；存算一体；加速器；忆阻器非理想因素；编译器；仿真工具
