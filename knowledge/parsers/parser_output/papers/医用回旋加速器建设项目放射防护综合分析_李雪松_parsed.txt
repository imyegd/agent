（3）回旋加速器维护过程中的辐射源项分析。回旋加速器一般每半年要进行一次大的维护。经过长时间的束流照射，回旋加速器的靶、靶膜、碳膜和过滤膜等均带有较强的放射性，此时，进行靶的维护、靶膜、碳膜和过滤膜更换的工作人员就会受到辐射危害。为了减少工作人员的受照剂量，维护一般在回旋加速器停机24h后进行，此时，一些短半衰期的核素通常已经衰变完毕，只剩一些长半衰期的核素，如 ${ }^{56} \mathrm{Co}$ 、 ${ }^{57} \mathrm{Co}$ 、 ${ }^{54} \mathrm{Mn}$ 等。工作人员在将靶膜、碳膜和过滤膜转移到废物箱以及洗靶的过程中，可能会受到这些核素的照射。

# 2 工作场所布局

医用回旋加速器工作场所通常包括回旋加速器机房、热室及其操作室、物料间、包装间、洗衣间、洁具间、消毒间、洁净走廊、更衣室、无菌检测间、阳性对照间、放化实验室等用房。回旋加速器机房与热室之间埋有管道，以便将回旋加速器生产的正电子核素传输到热室内，管道使用 $50\mathrm{mm}$ 甚至更厚的铅砖覆盖进行辐射屏蔽。热室包括合成热室和分装热室，正电子核素在合成热室内被合成为正电子药物后，再传输到分装热室内供质检和分装。工作人员进入热室操作室、无菌检测间、阳性对照间需要经过一更和二更，除了工作人员通过更衣室、

洁净走廊进入热室操作室的门外，热室操作室不能有其他门与外界相通，物料间、包装间与热室操作室之间传递物品或放射性药物应使用传递窗，如果需要设置药梯将放射性药物转移至他处，药梯开口应设置在热室操作室外，以保证热室操作室内的洁净度达到要求。

# 3 屏蔽计算

回旋加速器可以分为带自屏蔽系统的回旋加速器和不带自屏蔽系统的回旋加速器。自屏蔽系统可以将运行过程中产生的大部分射线隔绝在内，只有少量的中子和 $\gamma$ 射线会泄漏出来。因此，对于带自屏蔽系统的回旋加速器，其墙体可以建设的更薄，且不需要迷路就可以将防护门外的辐射剂量率控制在较低的水平，而不带自屏蔽系统的回旋加速器通常需要多道迷路的散射以降低防护门外的辐射剂量率。

（1）回旋加速器机房墙体。回旋加速器机房墙体外的辐射剂量率可根据公式 $\mathrm{d} = TVL[\lg (\mathrm{H}_{\mathrm{s}} / \mathrm{H}_{\mathrm{p}})]$ 进行计算，其中， $\mathrm{d}$ 为墙体屏蔽厚度，TVL为什值层厚度，其值可查阅NCRPReportNo.51， $\mathrm{H}_{\mathrm{s}}$ 为关注点处的辐射剂量率， $\mathrm{H}_{\mathrm{p}}$ 为关注点处的辐射剂量率控制水平。  
$\mathrm{H}_{\mathrm{S}}$ 可根据公式 $\mathrm{H}_{\mathrm{s}} = \mathrm{H}_{0} / \mathrm{R}^{2}$ 进行计算，其中， $\mathrm{H}_{0}$ 为距离辐射源 $1 \mathrm{~m}$ 处的辐射剂量率， $\mathrm{R}$ 为辐射源与关注点间的距离。通常回旋加速器的生产厂家会提供回旋加速器运行状态下的辐射剂量率等高线图，查图即可获得 $\mathrm{H}_{0}$ 的数据，应分别计算中子和 $\gamma$ 射线防护所需的屏蔽厚度。  
（2）回旋加速器机房防护门。回旋加速器的防护门一般使用铅作为 $\gamma$ 射线防护材料，使用含硼聚乙烯作为中子防护材料。

对于带自屏蔽系统的回旋加速器防护门，仍可根据墙体屏蔽厚度的计算公式进行计算。而不带自屏蔽系统的回旋加速器由于设有多道迷路，辐射源发出的 $\gamma$ 射线经多重散射后到达防护门处的辐射剂量率已足够低，在屏蔽设计时可不考虑，因此，进行屏蔽计算时，仅需考虑防护门处的中子辐射剂量率。

不带自屏蔽系统的回旋加速器防护门处的中子辐射剂量率可根据公式 $\mathrm{H}_{\mathrm{r1}} = 2\mathrm{H}_{0(\mathrm{r0})}(\mathrm{r_0 / r_1})^2$ 和 $\mathrm{H}_{(\mathrm{ri})} = (\frac{\mathrm{e}^{-\mathrm{r_i / 0.45}} + 0.022\mathrm{A_i^{13}e^{-r_i / 2.35}}}{1 + 0.022\mathrm{A_i^{13}}})\mathrm{H_{oi}}$ 进行计算，其中： $\mathbf{r}_0$ 为源到迷路口的距离， $\mathbf{r}_1$ 为从源到第一条支路的距离， $\mathrm{H}_{0(\mathrm{r0})}$ 为迷路口的剂量当量率， $\mathrm{A_i}$ 为迷路的横截面积， $\mathbf{r_i}$ 为第i个支路的长度， $\mathrm{H_{oi}}$ 为第i个支路的入口的剂量当量率。  
（3）热室及其操作室。热室及其操作室的屏蔽厚度可按照其操作放射性药物的最大活度进行计算，公式仍为 $\mathrm{d} = TVL[\lg (\mathrm{H_s / H_p})]$ ，而 $\mathrm{H}_{\mathrm{s}}$ 可根据公式 $H_{s} = \frac{A\times\Gamma}{R^{2}}$ 进行计算，其中，A为放射源活度， $\Gamma$ 为放射源剂量率常数，R为参考点与放射源间距离。

对于除回旋加速器机房和热室及其操作室以外的其他配套工作场所，如放化实验室、无菌检测间、阳性对

照间等房间，因其使用放射性药物的量极低，通常不需要采取屏蔽防护措施。

# 4 辐射安全装置

由于医用回旋加速器建设项目属于危害严重类的放射诊疗建设项目，它的辐射源项比较复杂，而且防护难度较高，为保护工作人员和相关公众免受或少受辐射危害，需要采用一系列辐射安全装置。

首先，回旋加速器运行启动应与辐照参数预选数联锁，只有当各项参数（如水冷、真空度、气压、磁场等运行参数）给出预选值显示，回旋加速器才能启动。

其次，回旋加速器应与机房防护门进行联锁，在运行过程中，如果防护门开启，回旋加速器将自动退出运行状态，在门未关闭时，回旋加速器无法启动。

此外，机房防护门外上方醒目位置处应设置工作状态指示灯，工作状态指示灯应能显示出回旋加速器的不同工作状态，如绿色代表机房内辐射剂量率较低，可以安全进入，红色代表回旋加速器正在运行等，防护门上应设置电离辐射警告标志。

回旋加速器机房内应设置多个监控装置，确保机房内无视觉死角（包括迷路），以便工作人员及时发现异常情况并采取措施。机房内应设置紧急开门按钮、固定式辐射剂量监测报警装置和声光报警装置，回旋加速器控制室及机房内应设置紧急停机按钮。在有人员误留在机房内或在安全联锁失效时误入机房内时，可以及时发现回旋加速器正在出束，并通过按紧急停机按钮直接切断设备电源，或通过按紧急开门按钮离开机房。

# 5 表面污染控制与防护

医用回旋加速器工作场所的地面应使用易清洗、不渗透的材料（如PVC），并保证材料连接处无缝隙（包括墙壁与地面的连接处），操作台、洗手台应采用表面光滑、平整、易于清洗去污的材料，洗手台应采用感应或脚踏出水的方式。场所内应设置洁具间，放置清洁用品，专门用于医用回旋加速器工作场所的日常清洁，且不能与工作场所外的清洁用品混用。

热室操作室入口处的更衣室应设置淋浴间，放置表面污染监测设备和去污工具（如一次性手套、鞋套、口罩、防护服、去污剂、吸水纸等）。工作人员在更衣室更换服装后，方可进入热室操作室。工作人员工作结束后，应在更衣室清洗、更衣并对手部等体表部位进行污染测定，如其污染水平超过规定值，应采取相应去污措施，确认未受放射污染，方可进入外部清洁区。

# 6 放射性废物的处置措施

医用回旋加速器工作场所工作中产生的放射性固体废物主要包括回旋加速器维护产生的废弃物（包括靶膜、碳膜和过滤膜等）、一次性卫生用品、更换下来的排风系统中的活性炭等。

回旋加速器维护时产生的废弃物（包括靶膜、碳膜和过滤膜等）均具有较强的放射性，其特点是数量少、半衰期长，可在独立设置的废物间或回旋加速器机房内

放置铅防护废物桶，置于其中长期衰变。而除此以外的其他放射性固体废物因其半衰期均较短，可收集并存放在废物间满10个半衰期后，由工作人员带出医用回旋加速器工作场所。

医用回旋加速器工作场所工作中产生的放射性液体废物主要为工作场所清洁或人体体表去污产生的污水、剩余的放射性药物等，产生放射性液体废物的房间包括淋浴间、洁具间等。这些放射性液体废物需通过管道排放至衰变池，在衰变池存放足够长的时间，达到要求后（总 $\beta < 10\mathrm{Bq} / \mathrm{L}$ ）方可排放。

医用回旋加速器工作场所工作中也会产生放射性气体废物，因此，需要设置专门的排风系统。首先，回旋加速器机房内和热室操作室内应设置独立的排风系统，如果回旋加速器带有自屏蔽系统，那么，其自屏蔽系统内也需要设置排风系统。为了避免放射性气体废物向清洁区扩散，回旋加速器机房需要保持负压通风。

热室操作室及其洁净走廊、更衣室，无菌检测及其更衣室，阳性对照及其更衣室等区域为洁净区域。为了保证洁净度，洁净区域需要设置送风和回风，其中送风口设置在吊顶高度处，回风口设置在近地面处。洁净区域各房间内设置压力表，可实时监测各房间内压力并自动调节，热室操作室内的气压低于洁净走廊的气压，从洁净走廊到二更，再到一更，压力逐次降低，这样的压力设置既可以保证洁净区域的洁净度，又可以防止热室操作室内的放射性气体废物向外扩散。

此外，热室操作室内的热室也应设置独立的排风系统，排风风速应不小于 $0.5\mathrm{m / s}$ 。放射性气体废物通过管道排放至所在建筑物的屋顶，并设置活性炭吸附净化装置进行过滤。

# 7 结语

随着PET诊断技术的快速发展，正电子药物的市场需求呈现出显著增长的态势，用于生产正电子药物的医用回旋加速器也在更多的医疗机构得到了应用。尽管回旋加速器辐射源项复杂，防护难度高，不过，通过合理的屏蔽设计、有效的辐射安全装置及其他放射防护措施，减少工作人员的接触时间，降低工作场所的辐射水平，避免放射事故的发生，从而将工作人员及相关公众的受照剂量降低到可接受的水平，保障他们的身体健康。
