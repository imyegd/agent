# 质子超导同步回旋加速器相关物理技术研究

林鹏太, 杨玙菲, 万鑫淼, 任志强, 廖文龙, 骆小宝, 常轩恺, 李智慧†

(辐射物理及技术教育部重点实验室，四川大学原子核科学技术研究所，成都  610064)

摘要: 超导同步回旋加速器具有结构小、造价低的特点，非常适合应用于质子治疗系统。我们对一台质子治疗用 $2 3 0 \ \mathrm { M e V }$ 质子超导同步回旋加速器进行了初步设计，对其磁铁、横纵向动力学及引出进行了研究。该加速器磁铁半径为 $1 . 1 \textrm { m }$ ，磁极半径 $0 . 5 3 ~ \mathrm { m }$ ，最大磁场 5.71 T。动力学计算表明磁场分布可以保证束流的稳定传输；纵向动力学分析表明，高频频率变化范围为 $6 0 . 5 { \sim } 8 5 . 6 ~ \mathrm { M H z }$ ，当同步相位为 $3 0 ^ { \circ }$ 时，相位接收度可达 $9 0 ^ { \circ }$ ；通过数值模拟优化了再生器结构参数，并通过动力学计算分析了束流的引出过程。动力学计算结果表明，由于再生器的作用，参考粒子在引出半径圈间距超过 $1 . 5 \mathrm { { c m } }$ ，且其在垂直方向的运动仍能维持稳定。本文工作可以为超导同步回旋加速器的设计提供参考。

关键词: 超导同步回旋加速器；质子治疗；再生引出系统设计；主磁铁设计

# 0 引言

质子束在人体中沉积的能量与速度的平方成反比，主要沉积在射程末端形成剂量“布拉格峰”，可以通过控制质子的能量和轨迹，使质子放射剂量精准沉积在肿瘤区，极大降低副作用[1−2]。

同步加速器、等时性回旋加速器和同步回旋加速器是目前质子治疗系统采用的主要加速器类型。这三者中，同步加速器的尺寸相对较大、造价高，限制了其的推广使用；等时性回旋加速器由于结构紧凑，造价较低，是目前商用质子治疗系统的主流加速器类型；同步回旋加速器工作在脉冲状态，其平均流强要远小于回旋加速器。但是同步回旋加速器磁铁结构简单，当采用超导技术时，其尺寸和重量会得到大幅度减小，使得其可以直接安装在旋转机架上，从而大大降低束流传输系统的建造成本，使其成为质子治疗用加速器的有力竞争者。国内外开展了很多关于同步回旋加速器的设计和研制工作[3−6]，其中Mevion[7]已经实现了超导同步回旋加速器质子治疗系统的商业化生产。

束流引出系统是超导同步回旋加速器的关键系统，也是超导同步回旋加速器设计的关键技术难点。一方面，超导同步回旋加速器加速粒子的过程中，射频电场频率

需要根据粒子回旋频率的改变而改变，射频腔体的品质因数相对于固定频率的腔体要低得多，导致其加速电压相对较低；另一方面，超导同步回旋加速器工作在5 T左右的强磁场中。这两者导致超导同步回旋加速器中束流的轨道圈间距很小，很难采用传统的静电偏转器作为引出方式[8]；同时很强的主磁场会造成负离子的剥离损失，因此，超导同步回旋加速器一般都只能加速正离子，剥离引出也不适合应用于超导同步回旋加速器。

再生引出是20世纪50年代提出的针对同步回旋加速器的一种引出方案，这种方案最终被Couteur Le[9−10]发展完善，并且成功应用于 IBA(Ion Beam ApplicationsSA) $2 3 0 ~ \mathrm { M e V }$ 质子超导同步回旋加速器 [11]和 MevionS250i质子加速器[7]。本文将针对一台 $2 3 0 \ \mathrm { M e V }$ 应用于质子治疗的超导同步回旋加速器，对其再生引出系统进行了系统的动力学研究，并给出再生器的设计。

由于引出系统的设计和主磁场紧密相关，因此在文章的第一部分，我们将介绍这台超导同步回旋加速器的主磁铁设计，以及相关的轨道、动力学特性分析。文章第二部分将在此动力学和主磁场的基础上，提出针对这台加速器的再生引出系统的设计，结合轨道动力学，优化再生器的结构设计，最后给出满足要求的引出系统设计方案。

# 1 主磁场设计

超导同步回旋加速器的主磁场与经典回旋加速器类似，磁场关于中心旋转对称性，同时关于中心平面 $z { = } 0$ 对称，磁极结构比等时性回旋加速器的磁极结构要简单的多。为了减小加速器尺寸，参考IBA设计的 $2 3 0 \mathrm { M e V }$ 超导同步回旋加速器所采用的最大磁场强度，该同步回旋加速器的最大磁场确定为5.71 T，位于磁铁中心。根据带电粒子在旋转对称磁场中横向运动稳定性的要求[9]，超导同步回旋加速器的磁场从中心到磁极边缘随半径应逐渐减小，其磁场降落指数 $n$ 必须满足 $0 { < } n { < } 1$ 。考虑到磁极的利用效率，在大部分区域 $n { < } { < } 1$ 。由于超导同步回旋加速器的加速电压一般较低，质子在加速器中运动的圈数较多，所以受到共振的影响较大。在主磁场设计中，应充分考虑共振对运动稳定性的影响 [12]，使质子尽可能快地通过不可避免的共振线。本文在设计主磁场时考虑了五阶以内共振对质子运动的影响。当质子接近共振线时调整磁极面使磁场迅速减小，减小质子通过共振线的圈数，以最小化共振对质子运动的影响。经过优化，主磁铁主要参数见表1，主磁铁1/4截面结构如图1所示。

# 2 横、纵向动力学分析

质子在电磁场中会受到洛伦兹力，其运动满足牛顿第二定律，即

$$
\frac {\mathrm {d}}{\mathrm {d} t} \boldsymbol {P} = q \boldsymbol {E} + q (\boldsymbol {v} \times \boldsymbol {B}), \tag {1}
$$

其中：矢量 $P = \gamma m _ { 0 } \nu$ 为质子的机械动量； $\nu$ 为质子的速度； $\gamma = 1 / \sqrt { 1 - \left( \nu / c \right) ^ { 2 } }$ 为相对论因子； $c$ 为真空中的光速； $m _ { 0 }$ 为质子静止质量； $E$ 为质子所在位置的电场强度矢量； $\pmb { B }$ 为质子所在位置的磁感应强度矢量； $q$ 表示质子电荷量。

虽然目前的三维电磁场计算软件可以得到精度很高的三维磁感应强度分布，但是，考虑到实际磁场测量中只能获得磁极中心平面上的二维磁场分布，所以，在回旋加速器及同步回旋加速器的轨道计算中，通常都是根据磁场的对称性，利用中心平面的二维磁场分布来获得磁场在三维空间的分布[12]，即

$$
\begin{array}{l} B _ {z} (r, \theta , z) = B _ {z} (r, \theta) - \\ \frac {1}{2} z ^ {2} \left(\frac {\partial^ {2}}{\partial r ^ {2}} + \frac {1}{r} \frac {\partial}{\partial r} + \frac {1}{r ^ {2}} \frac {\partial^ {2}}{\partial \theta^ {2}}\right) B _ {z} (r, \theta) + 0 \left(z ^ {4}\right), \tag {2} \\ \end{array}
$$

$$
\begin{array}{l} B _ {r} (r, \theta , z) = z \frac {\partial}{\partial r} B _ {z} (r, \theta) + 0 \left(z ^ {3}\right), (3) \\ B _ {0} (r, \theta , z) = \frac {z}{r} \frac {\partial}{\partial \theta} B _ {z} (r, \theta) + 0 \left(z ^ {3}\right), (4) \\ \end{array}
$$

其中： $r , \theta , z$ 为粒子在以磁极旋转对称轴为 $z$ 轴，以磁铁中心为原点的柱坐标系中的坐标位置。 $B _ { z } ( r , \theta )$ 为中心平面上坐标为 $( r , \theta )$ 处纵向磁场大小， $B _ { \mathrm { r } } ( r , \theta , z )$ 为三维空间中坐标为 $( r , \theta , z )$ 处的径向磁场大小, $B _ { z } ( r , \theta , z )$ 为三维空间上坐标为 $( r , \theta , z )$ 处纵向磁场大小。以上三维磁场表达式只保留了偏离中心平面位置 $z$ 的平方项，如果需要更高精度，可以采用类似的方法展开到 $z$ 的更高阶。本文设计中，考虑到在引出区域非线性效应的影响，在粒子轨道计算程序中，磁场展开至 $z$ 的平方项。

同步回旋加速器中，粒子只在加速间隙受到电场的作用。该电场可以通过谐振腔的数值计算来得到中心平面上的电场分布，然后利用与磁场类似的方法，得到电场的三维分布。

# 2.1 横向动力学分析

在不考虑引出系统影响的情况下，同步回旋加速器中粒子的轨道比较简单，其静态平衡轨道为圆，非参考粒子围绕静态平衡轨道振荡，振荡频率由磁场降落指数决定。在线性近似下，其轨道满足：

$$
\frac {\mathrm {d} ^ {2} z}{\mathrm {d} \theta^ {2}} + n z = 0, \tag {5}
$$

$$
\frac {\mathrm {d} ^ {2} r}{\mathrm {d} \theta^ {2}} + (1 - n) r = 0, \tag {6}
$$

其中： $z$ 表示粒子相对于中心平面的位移； $r$ 表示粒子相对于参考粒子的径向位移； $\theta$ 表示方位角； $n$ 为磁场降落指数。通过方程(5)和(6)可知，非参考粒子在r、z向的振荡频率分别为 $\sqrt { 1 - n }$ 和 $\sqrt { n }$ 。

周期系统的周期传输矩阵为

$$
\left[ \begin{array}{l l} \cos \mu & \beta \sin \mu \\ - \gamma \sin \mu & \cos \mu \end{array} \right] = \left[ \begin{array}{c c} \cos (2 \pi \sqrt {K}) & \frac {\rho \sin (2 \pi \sqrt {K})}{\sqrt {K}} \\ \frac {- \sqrt {K} \sin (2 \pi \sqrt {K})}{\rho} & \cos (2 \pi \sqrt {K}) \end{array} \right] 。 \tag {7}
$$

为进行多粒子模拟分析，横向匹配束流需通过周期传输矩阵 (7)计算，当矩阵 (7)表示径向传输矩阵时$K { = } 1 { - } n$ ，表示垂直方向传输矩阵时 $K { = } n$ 。矩阵(7)中，等号左侧为Twiss参数，等号右侧为粒子在二极磁铁中运动的传输矩阵。其中， $\beta$ 为包络函数， $\mu$ 为相移，γ为偏角包络函数。不难发现 $\beta = \rho / \sqrt { K } = 1 / \gamma$ 。结合磁场参数，可以计算半径 $\rho$ 处横向匹配束流的相椭圆参数满足： $\beta _ { \mathrm { r } } { = } r _ { \mathrm { m a x } } / r _ { \mathrm { \ m a x } } ^ { \prime } { = } \rho / \sqrt { 1 - n }$ ， $\beta _ { \mathrm { z } } { = } z _ { \mathrm { m a x } } / z _ { \mathrm { \ m a x } } ^ { \prime } { = } \rho / \sqrt { n }$ 。其中，$\beta _ { \mathrm r }$ 为径向包络函数， $\beta _ { \mathrm { z } }$ 为轴向包络函数， $r _ { \mathrm { m a x } }$ 为束团径向最大半径， $r _ { \mathrm { m a x } } ^ { \prime }$ 为束团径向最大偏角， $z _ { \mathrm { m a x } }$ 为束团轴向最大半径， $z _ { \mathrm { { m a x } } } ^ { \prime }$ 为束团轴向最大偏角。

我们利用自己编写的程序，对粒子运动轨道进行计算。程序采用四阶龙格库塔算法，以时间为自变量，磁场采用式 (2)、(3)、(4)展开方式获得， $B _ { z } ( r , \theta )$ 关于 r、 $\theta$ 的一阶和二阶导数通过差分方式求得，角向和径向步长分别取1°和 $1 \mathrm { { c m } }$ 。

# 2.2 纵向动力学分析

纵向动力学计算时，我们假定加速间隙宽度为$1 \mathrm { c m }$ ，加速间隙之间的电场为均匀分布，并随时间按下式变化：

$$
\boldsymbol {E} (t) = E _ {0} \cos \left(\omega_ {\mathrm {r f}} (t) t + \phi_ {\mathrm {s}}\right) \boldsymbol {e} _ {\theta}, \tag {8}
$$

其中： $E _ { 0 }$ 为加速间隙的电场强度峰值，其数值上等于加速电压峰值与加速间隙宽度的比值； $\omega _ { \mathrm { r f } }$ 为加速电场的角频率； $\varphi _ { \mathrm { s } }$ 为粒子加速电场初始相位，即参考质子平衡相位； $e _ { \theta }$ 为 $\theta$ 方向单位向量。由于整个加速过程中相位滑移系数 $\eta { = } \alpha _ { \mathrm { c } } { - } 1 / \gamma ^ { 2 } ( \alpha _ { \mathrm { c } }$ 为动量紧缩因子，γ为相对论因子)恒大于0，则平衡相位 $\varphi _ { \mathrm { s } }$ 必须大于0。

# 3 再生引出系统设计

超导同步回旋加速器加速电场幅值为 $2 0 \mathrm { k V }$ ，依据本文的设计参数可得质子束运动圈间距在引出半径处仅为 $4 0 \mu \mathrm { m }$ 左右，使用偏转电极作为引出器，大量质子束将会撞击偏转电极造成束流的损失。超导同步回旋加速器一般使用再生器引出束流，引出原理示意图如图8所示。其原理是在磁极边缘垫补局部铁块(图中红色扇形框所示)，产生沿半径非线性增加的磁场，利用 $\nu _ { \mathrm { r } } { = } 1$ 共振使质子经过再生器后轨道中心向一个方向移动，从而导致在一定方位角径向圈间距增加，而垂直方向仍然维持稳定运动。一般认为参考质子径向圈间距大于 $1 . 5 \mathrm { { c m } }$ 、

垂直方向维持稳定运动，质子加速至 $2 3 0 \ \mathrm { M e V }$ 时具有足够的径向和垂直方向稳定区域，是判断再生器设计是否合理的判据。

不加再生器时质子在加速过程中会遭遇 $\nu _ { \mathrm { r } } { = } 2 \nu _ { \mathrm { z } }$ 共振，受到 $\nu _ { \mathrm { r } } { = } 2 \nu _ { \mathrm { z } }$ 共振的影响质子径向运动和垂直方向运动将发生能量交换，很可能发生径向振荡振幅减小而垂直方向的振荡振幅增加，从而造成质子束的损失，因此，再生器的放置思路应是在质子进入此共振之前将质子束引出加速器外。再生器的设计是再生器结构调整与动力学计算之间反复迭代计算的过程。再生器垫补过程中随着再生器垫补厚度的增加，再生器产生的磁感应强度增加，束流的圈间距也随之增加；当再生器的垫补厚度超过一定范围以后，束流的圈间距虽然继续增加，但其垂直方向运动振幅也会迅速增加直至撞击磁极而损失。再生器的设计应当满足质子引出要求的同时，尽可能增加再生器的间隙使尽可能多质子通过。经过不断迭代计算，确定了再生器最终结构，图9为再生器结构中心沿径向的1/4截面图和再生器半径 $4 8 . 5 \ \mathrm { c m }$ 处沿角向截面图，再生器结构主要参数见表3。

# 4 结论

本文针对 $2 3 0 \ \mathrm { M e V }$ 质子超导同步回旋加速器开展了磁铁设计、横纵向动力学及再生引出系统的设计研究。本文设计的主磁铁极面结构相对简单，同时关于中心平面旋转对称，目的是降低工程上的实现难度。动力学计算结果表明，中心平面磁场满足径向与垂直方向的聚焦要求，且质子在加速过程中可迅速穿越共振区域，最终被正常加速至引出区。这证明了主磁铁的结构设计符合预期。多粒子跟踪计算结果表明，当参考质子在引出半径径向圈间距超过 $1 . 5 \mathrm { { c m } }$ 时，其垂直方向的运动仍能维持稳定。本文设计的主磁铁和再生引出系统具有足够的径向和垂直方向稳定区域，以加速内部质子束的动能至 $2 3 5 . 7 \mathrm { M e V }$ ；但随着质子束进一步向外运动，垂直方向的运动振幅放大较大。根据本文动力学计算结果显示，质子束加速至 $2 3 5 . 7 \mathrm { M e V }$ 时垂直方向的运动振幅最好维持在 $5 \mathrm { { m m } }$ 以内。动力学计算结果显示磁通道入口处不可避免会造成质子束损失。根据再生器处的动力学模拟结果可知，通过限制加速器中心区域质子束垂直方向的振幅，可以减小质子束在再生器区域的损失，进而提高引出效率，同时减小质子束碰撞加速器结构导致的活化。

# The Research on Physical Technology of Superconducting Synchrocyclotron

LIN Pengtai,  YANG Yufei,  WAN Xinmiao,  REN Zhiqiang,  LIAO Wenlong,  LUO Xiaobao,  CHANG Xuankai,  LI Zhihui† (Key Laboratory of Radiation Physics and Technology of Ministry of Education, Institute of Nuclear Science and Technology, Sichuan University, Chengdu 610064, China)

Abstract: Superconducting synchrocyclotrons offer compact structure and low cost, making them highly suitable for proton therapy systems. This paper presents a preliminary design of a $2 3 0 \mathrm { M e V }$ superconducting synchrocyclotron for proton therapy, investigating its main magnet design, transverse and longitudinal dynamics, and regenerator extraction system design. The accelerator features a magnet radius of $1 . 1 ~ \mathrm { m }$ , pole radius of $0 . 5 3 ~ \mathrm { m } .$ , and maximum magnetic field of 5.71 T. Dynamic calculations confirm that the magnetic field distribution ensures stable beam transmission. Longitudinal analysis shows the RF frequency varies from 85.6 to $6 0 . 5 \mathrm { M H z }$ , with a phase acceptance of $9 0 ^ { \circ }$ achieved at a synchronous phase of $3 0 ^ { \circ }$ . Numerical simulations optimize the regenerator structural parameters, and beam extraction dynamics are analyzed computationally. Results demonstrate that with the regenerator, the reference particle maintains vertical stability even when its radial turn separation exceeds $1 . 5 \mathrm { { c m } }$ at the extraction radius. This study provides valuable references for the design of superconducting synchrocyclotrons.

Key words: superconducting synchrocyclotron; proton therapy; regenerator extraction system design; main magnet design
