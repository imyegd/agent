

# 一、总体结构先给你一个“工程视角”

你这 36 个变量，本质上可以分为 **6 大类子系统**，每一类对子系统稳定性、束流形成、传输或测量都有直接或间接影响：

| 类别 | 子系统             | 对束流强度的作用机制       |
| -- | --------------- | ---------------- |
| ①  | 束流本体            | 输出结果 / 监测量       |
| ②  | 电子源与发射系统        | 决定电子产生能力         |
| ③  | 加速与引出系统         | 决定电子能量与抽取效率      |
| ④  | 聚焦 / 对中 / 消像散系统 | 决定电子束是否“打得准、收得住” |
| ⑤  | 工件台运动系统         | 影响有效束流耦合与测量      |
| ⑥  | 冷却与环境系统         | 影响长期稳定性与漂移       |

下面我**逐类、逐变量**讲（不是泛泛而谈）。

---

# 二、束流本体

## 1️⃣ 束流（束流强度）

**含义**

* 设备中实际被监测的电子束流强度（通常是电流、计数率或归一化强度）。

**作用**

* 是整个系统的**最终输出指标**；
* 在异常诊断中通常是**被解释变量 / 目标变量**。

**与其他变量关系**

* 束流 ≈ 电子发射能力 × 加速抽取效率 × 聚焦与传输效率 × 系统稳定性
* 几乎**所有变量都通过不同路径影响它**。

👉 在知识库中，它通常作为：

> `Target / Observation / OutputNode`

---

# 三、电子源与发射系统（决定“能不能发出来”）

## 2️⃣ 灯丝电源电压

## 3️⃣ 灯丝电源电流

**含义**

* 灯丝是电子枪的**热阴极**；
* 电压 / 电流决定灯丝温度。

**作用**

* 决定热电子发射能力（热发射定律）；
* 灯丝电流 ↑ → 温度 ↑ → 电子发射数 ↑。

**对束流的影响**

* **强正相关（基础性影响）**；
* 灯丝异常 → 束流整体偏低或不稳定；
* 长期高电流 → 灯丝老化 → 束流缓慢衰减。

👉 知识库中典型关系：

```
灯丝电流 ↑ → 电子发射能力 ↑ → 束流 ↑
```

---

# 四、加速与引出系统（决定“能不能拉出来、拉多快”）

## 4️⃣ 加速电源电压

## 5️⃣ 加速电源电流

**含义**

* 对电子进行能量加速的高压系统。

**作用**

* 决定电子束能量；
* 影响束流的空间电荷效应与发散程度。

**对束流影响**

* 电压不足 → 束流被空间电荷限制；
* 电流异常 → 加速系统负载变化，可能反映束流不稳定。

---

## 6️⃣ 引出电源电压

## 7️⃣ 引出电源电流

**含义**

* 从电子源区域将电子“拉出”的关键电源。

**作用**

* 决定电子是否顺利脱离阴极区；
* 与灯丝、电极结构高度耦合。

**对束流影响**

* **直接决定束流大小**；
* 电压波动 → 束流强烈波动。

👉 在诊断中经常出现规则：

> 灯丝正常 + 引出异常 ⇒ 束流异常

---

## 8️⃣ 抑制电源电压

## 9️⃣ 抑制电源电流

**含义**

* 用于抑制反向电子或二次电子的电源。

**作用**

* 防止电子回流干扰；
* 提高束流稳定性和测量准确性。

**对束流影响**

* 抑制不足 → 束流测量偏高或噪声大；
* 抑制过强 → 有效束流下降。

---

# 五、聚焦 / 对中 / 消像散系统（决定“打得准不准”）

## C1 / C2 / C3 电源（6–15）

包括：

* C1电源电压 / 电流
* C2电源电压 / 电流
* C3电源电压 / 电流

**含义**

* 多级电磁透镜或电极系统。

**作用**

* 控制束斑大小、会聚位置；
* 调节束流发散角。

**对束流影响**

* 聚焦不当 → 束流在传输路径中损失；
* 表现为：**灯丝、加速正常，但束流偏低**。

---

## 对中与倾斜系统（16–23）

包括：

* X / Y 偏移电压、电流
* X / Y 倾斜电压、电流

**含义**

* 用于校正电子束轴线位置和角度。

**作用**

* 保证束流沿设计光轴传播；
* 避免打在光阑、电极上。

**对束流影响**

* 对中不良 → **有效束流下降**；
* 往往造成慢性、隐蔽的束流衰减。

👉 很适合做**因果规则节点**：

```
对中偏移异常 → 束流传输损失 ↑ → 束流 ↓
```

---

## 消像散系统（24–31）

### 斜向消像散（1–4）

### 轴向消像散（1–4）

**含义**

* 修正电子束在不同方向上的像散畸变。

**作用**

* 保证束斑形状接近理想圆形；
* 提高束流在目标处的有效密度。

**对束流影响**

* 消像散不当 → 束斑拉长、能量密度下降；
* 在监测系统中体现为束流“变弱”。

---

## 32️⃣ 微调焦电流

**含义**

* 精细调节束流焦点位置。

**作用**

* 用于补偿温漂、机械漂移。

**对束流影响**

* 偏离最优点 → 束流强度下降；
* 是典型的**细粒度影响变量**。

---

# 六、工件台系统（影响“束流是否被正确接收”）

## 33️⃣ 工件台位置 X

## 34️⃣ 工件台位置 Y

**含义**

* 工件相对于束流的空间位置。

**作用**

* 决定束流是否准确打在目标区域。

**对束流影响**

* 位置偏移 → 有效接收束流减少；
* 在监测值中表现为束流变化。

---

# 七、冷却与环境系统（影响“稳不稳定”）

## 35️⃣ 冷水机压力

## 36️⃣ 冷水机内部温度

**含义**

* 为电源、线圈、电子枪提供冷却。

**作用**

* 控制温升、避免参数漂移。

**对束流影响**

* 温度升高 → 电阻变化 → 电流、电压漂移；
* 表现为**慢变型束流衰减或抖动**。

---

# 八、给你一个“知识库建模级总结”（很重要）

如果你要做 **知识库 / 知识图谱 / RAG**，这些变量天然可以建成：

### 1️⃣ 实体类型

* `PowerSupply`
* `BeamOptics`
* `Environment`
* `MotionSystem`
* `Observation`

### 2️⃣ 典型关系

* `affects`
* `stabilizes`
* `controls`
* `induces_drift`
* `causes_loss`

### 3️⃣ 核心因果主线（可直接写进论文）

> **束流强度是电子发射能力、加速引出效率、束流光学调制能力以及系统稳定性共同作用的结果**
