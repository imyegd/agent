# 工具总览

本文档汇总项目中所有 LLM 可调用的工具及其功能说明。

## 工具列表

| 分类 | 工具名称 | 功能描述 |
|------|----------|----------|
| **数据查询** | `query_beam_data` | 按时间范围查询束流数据，适合数据核对、趋势分析、异常诊断前数据确认。返回 query、summary、data 及可选的 statistics。 |
| **数据查询** | `get_data_info` | 获取数据集元信息（总记录数、时间范围、列名、target 统计、样本记录）。建议在首次查询前调用，用于确定时间范围和可用列。 |
| **异常检测** | `detect_anomaly` | 基于回归预测偏差和 3σ 工程判据，判断指定时间段是否存在异常。 |
| **异常诊断** | `diagnose_by_statistical_difference` | 基于统计差异（Z-score）的异常特征诊断。比较异常时段与正常时段各变量的统计分布差异，识别显著偏移的关键变量。 |
| **异常诊断** | `diagnose_by_pls` | 基于偏最小二乘（PLS）模型的异常特征诊断。通过各变量对目标束流的线性投影权重，识别与束流异常高度相关的关键变量。 |
| **异常诊断** | `diagnose_by_shap` | 基于 SHAP 的异常特征诊断。对回归模型（RF/XGB/LGBM/MLP/Linear）进行解释，分析异常时段内各变量对预测的贡献，识别导致束流偏离的关键变量。 |
| **异常诊断** | `diagnose_by_autoencoder` | 基于自编码器的异常特征诊断。通过各变量的重构误差，识别相对正常工况显著偏离的变量，适用于无故障标注场景。 |
| **可视化** | `plot_beam_data` | 绘制指定时间段的束流时序图。主图显示 target（束流强度），可叠加若干特征曲线，并可高亮异常区域。 |
| **RAG 知识库** | `explain_diagnosis_features` | 承接异常诊断结果，从 generation 知识图谱解释诊断出的 feature（feature1–feature34）的物理含义、所属子系统、详细参数等。 |
| **RAG 知识库** | `explain_variable_meaning` | 解释变量含义和用法，支持中文变量名、featureN 或自然语言问题，从 generation 知识图谱查询。 |
| **RAG 知识库** | `search_domain_knowledge` | 从常规知识库检索束流、加速器、微电子等专业知识，使用混合检索（TF-IDF + 向量语义）。 |

## 分类统计

| 分类 | 数量 | 说明 |
|------|------|------|
| 数据查询 | 2 | 数据获取与元信息 |
| 异常检测 | 1 | 判断是否存在异常 |
| 异常诊断 | 4 | 定位异常相关特征 |
| 可视化 | 1 | 时序图绘制 |
| RAG 知识库 | 3 | 依赖 Neo4j 和向量索引，未配置时不可用 |
